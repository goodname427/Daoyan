### 1.2 法术生命周期管理（参考 GAS）

**目标**：区分「瞬时」与「持续」，并让法术可配置周期、时长、冷却、可打断性。

生命周期类型：

| 类型       | 语义                                        | 典型用途                 |
| ---------- | ------------------------------------------- | ------------------------ |
| `instant`  | 开始 → 执行 → 结束                          | 剑气、爆发、位移         |
| `duration` | 开始 → 每周期重复执行 → 到期结束            | 护体罡气、持续灼烧、领域 |
| `channel`  | 开始 → 持续引导（移动受限）→ 主动或被动结束 | 蓄力大招                 |

法术元数据（`SpellMeta`）：

```ts
{
  name, kind: 'instant'|'duration'|'channel',
  period: number,        // 每多少秒重复一次（duration）
  duration: number,      // 持续秒数（duration / channel）
  cooldown: number,      // 冷却
  interruptible: boolean // 受击是否打断
}
```

运行时 `CastInstance` 状态机：`pending → running → ending → done`，
持续类法术到期时触发「结束段」（后续可扩展 onEnd 逻辑）。

### 1.3 蓝图式节点编辑器

**目标**：拖拽节点 + 连线来写法术，降低门槛（UE 蓝图风格）。

- 用 React Flow：节点 = 元函数 / 常量 / 变量 / 控制流
- 端口按类型着色（num / bool / vec2 / entity / list），**拒绝类型不匹配的连接**
- 节点图 ⇄ AST 双向转换（先做 图 → AST，再做 AST → 图）
- 与 DSL 编辑器并列，随时切换；三者产出同一份 AST

### 2.2 完整属性表

`AttributeSet`：

| 属性                         | 作用                                 |
| ---------------------------- | ------------------------------------ |
| `hp / hpMax`                 | 生命                                 |
| `mana / manaMax / manaRegen` | 法力与回复                           |
| `shenshiMax`                 | 神识上限（境界）                     |
| `speed`                      | 移动速度                             |
| `castSpeed`                  | 施法速度倍率（影响 tick → 实际时间） |
| `power`                      | 术法威力倍率（影响伤害）             |
| `manaCostMul`                | 法力消耗倍率                         |
| `cooldownMul`                | 冷却倍率                             |
| `perception`                 | 感知半径倍率                         |
| `armor`                      | 减伤                                 |

- 属性既影响元函数**效果**（伤害、位移、感知半径），也影响**消耗**（法力/耗时）
- 提供读写属性的元函数：`自身属性(名)` / `目标属性(目标, 名)` / `加持(目标, 名, 数值, 秒数)` / `削损(...)`
- 加持/削损走 GAS 风格的 **Modifier** 系统：加法 / 乘法、可限时到期
