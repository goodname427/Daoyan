# 架构不变量

这些规则用于保护产品核心。修改它们必须先写 ADR，并说明迁移与回退方案。

1. **核心可无头运行**：`src/core/` 不使用 DOM、Canvas、WebAudio、React 或 Electron API。
2. **AST 是唯一 IR**：DSL 与蓝图只负责读写 AST；分析和执行语义不在编辑器中复制。
3. **资源语义稳定**：神识对应状态，法力对应世界 I/O，耗时对应执行；自定义法术不直接声明资源价格。
4. **预算可信**：静态已知的资源必须与 VM 逐项对齐；未解析的请求值、距离或实体状态必须显式标记为动态。只有不含动态项时才能宣称有限上界，且该上界不得小于相同输入下的 VM 实测消耗。
5. **程序默认可判定**：禁止递归；循环和列表容量必须满足静态分析约束。
6. **统一句柄与施法同构**：世界对象共享不复用的 `entity` 句柄并按能力判定操作；玩家和妖兽使用同一个 Actor、属性结构和施法管线。
7. **依赖单向**：核心层不依赖游戏表现；战斗通过世界事件或钩子向外通知。
8. **编辑与实战分责**：推演台编辑并验证法术；演武场配置并消费法术，不维护独立副本。
9. **共享状态单一所有者**：跨场景数据由共同上层拥有，页签切换不得隐式重置。
10. **逻辑属性统一控制**：依据 [ADR 0017](../adr/0017-统一实体控制属性模型.md)，属性 descriptor 定义稳定效果语义，目标 binding 声明能力、持久化模式、权限与抗性；公开控制统一为 `(目标, 效果, 时间)`，不得按实体种类分叉。缺能力明确拒绝。
11. **控制生命周期显式**：commit 只写基础状态，overlay 只移除本层并重算有效下层，maintain 由核心施法会话持有；时间 `0` 表示无限而非免费。write 不随施法会话结束撤销：commit 不回滚，overlay 由世界持有至自身到期、替换或目标能力失效。持续维持按模拟时间 `0.25` 秒效果前结算，首周期和同源更新均先付费；暂停不计时，会话结束原子清理全部 maintain，单条控制失效及时清理对应记录。
12. **控制预算不得隐形**：关系门槛、倍率、抗性与实际效果共同决定法力和 tick；己方基础及维持费用为正，非己方有正固定门槛。起手和周期分开表达，无限维持显式无界，tick 计入执行债务，存续记录计入有界状态容量；分析和执行共用价格规则。
13. **运动有来源且保留惯性**：依据 [ADR 0018](../adr/0018-运动供能与命中守恒.md)，实际 `velocity`、主动驱动上限 `speedMax` 和朝向分离；降上限、改朝向或停供不直接抹改速度。输入只产生授权意图，核心按模拟时间积分；基础移动消耗有界、不可兑换的世界功率，暂停不补给。位置只经积分、碰撞修正、受控创建或独立校验并付费的传送改变。
14. **储能与命中不可重复计量**：创建费不自动成为储能，motion/damage/scan 分池；注能先原子付款，已做功不再作为可退款余额。命中及穿透逐次扣 damage，实际生命损失不得超过释放能量，即使最低伤害或负护体也不例外。本版不开放动能转伤害或跨池转换，基础世界功率不能转成法力、储能、伤害或退款；旧弹道仅可证明等价迁移，否则定位拒绝并保原件。
15. **敏感属性与产出不可套利**：依据 [ADR 0019](../adr/0019-属性探查与资源账本.md)，六属性统一 maintain 并校验合成安全域；上限变化不注入当前资源，神识超额禁止新分配但允许释放。控制、注能、产出、探查/监控及转移等不可折扣；额外回复先付覆盖额外收益的正价，提速不减少 tick 工作或改变收费周期。
16. **句柄不等于读取权**：所有世界读取经能力、字段权限、可见性及距离检查；自身读取仍为正价。查询成功与不可探查可判别，拒绝不得携带私有值，报价、日志、事件与面板也不能成为旁路。快照只表示获准时刻的结果，不自动更新。
17. **账本与预算分单位且原子**：法力毛支出、能量 E、不可兑换 Wm、tick 工作和神识峰值分别核对；预留不得重复消费，已付工作不可退款，未用储能仅向固定受益账户幂等退款，接收不了的部分记损耗。动态/无界及外部状态容量必须显式，非法价或资源失败不能产生部分效果；旧 AST 只有证明权限、状态及资源等价才迁移，否则定位拒绝并保原件。

18. **事件派发确定且有界**：依据 [ADR 0020](../adr/0020-事件执行上下文与生命周期.md)，世界先提交效果/账本和必要清理，再按模拟时刻、世界序号、订阅序号派发独立 VM；共享账户逐笔竞争，订阅、因果重入、队列及工作均有硬上限。耗尽只由可用法力跨越固定可支付边沿产生，响应失败不递归造事件；被动事件不替代付费监控，载荷不得绕过读取权。
19. **执行权限与生命周期不由句柄或按键授予**：owner、controller、payer 与退款受益人分离；法球仅消费预付池或显式有限预留授权，不能支用所有者未来法力。控制者死亡先撤权、终止会话并关闭账户接收，再结算和派发只读终止摘要；独立行为仅按预先声明的死亡后授权及有限资源存续。首次终态和退款幂等，已提交 write 不因 VM 结束回滚。
20. **蓄力与即时创建语义显式**：蓄时瞬发在准备工作完成且合法松开时发布一次效果，提前松开取消；持球按周期付款注能，合法释放才付冲量并激活。五参创建成功仍即激活，不隐式变为持球；旧槽防重属于输入适配，不锁住同名事件响应。暂停冻结模拟及派发，有界缓存输入，恢复先清理到期再处理意图。

第 10–20 项是已采纳的实现约束，不表示旧控制链、运动/能量链或事件/会话链已完成迁移；第 13–14 项覆盖第 10–12 项涉及直接位置写入、旧 speed/rotation 与固定命中的冲突语义，第 15–17 项细化安全域、授权、不可折扣与预算/退款，第 18–20 项固定事件排序、授权及终止边界，其余控制合同继续有效。运行时完成情况以工作项证据为准。
