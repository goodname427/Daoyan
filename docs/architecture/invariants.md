# 架构不变量

这些规则用于保护产品核心。修改它们必须先写 ADR，并说明迁移与回退方案。

1. **核心可无头运行**：`src/core/` 不使用 DOM、Canvas、WebAudio、React 或 Electron API。
2. **AST 是唯一 IR**：DSL 与蓝图只负责读写 AST；分析和执行语义不在编辑器中复制。
3. **资源语义稳定**：神识对应状态，法力对应世界 I/O，耗时对应执行；自定义法术不直接声明资源价格。
4. **预算可信**：静态已知的资源必须与 VM 逐项对齐；未解析的请求值、距离或实体状态必须显式标记为动态。只有不含动态项时才能宣称有限上界，且该上界不得小于相同输入下的 VM 实测消耗。
5. **程序默认可判定**：禁止递归；循环和列表容量必须满足静态分析约束。
6. **统一句柄与施法同构**：世界对象共享不复用的 `entity` 句柄并按能力判定操作；玩家和妖兽使用同一个 Actor、属性结构和施法管线。
7. **依赖单向**：核心层不依赖游戏表现；战斗通过世界事件或钩子向外通知。
8. **编辑与实战分责**：推演台编辑并验证法术；演武场配置并消费法术，不维护独立副本。
9. **共享状态单一所有者**：跨场景数据由共同上层拥有，页签切换不得隐式重置。
10. **逻辑属性统一控制**：依据 [ADR 0017](../adr/0017-统一实体控制属性模型.md)，属性 descriptor 定义稳定效果语义，目标 binding 声明能力、持久化模式、权限与抗性；公开控制统一为 `(目标, 效果, 时间)`，不得按实体种类分叉。缺能力明确拒绝。
11. **控制生命周期显式**：commit 只写基础状态，overlay 只移除本层并重算有效下层，maintain 由核心施法会话持有；时间 `0` 表示无限而非免费。write 不随施法会话结束撤销：commit 不回滚，overlay 由世界持有至自身到期、替换或目标能力失效。持续维持按模拟时间 `0.25` 秒效果前结算，首周期和同源更新均先付费；暂停不计时，会话结束原子清理全部 maintain，单条控制失效及时清理对应记录。
12. **控制预算不得隐形**：关系门槛、倍率、抗性与实际效果共同决定法力和 tick；己方基础及维持费用为正，非己方有正固定门槛。起手和周期分开表达，无限维持显式无界，tick 计入执行债务，存续记录计入有界状态容量；分析和执行共用价格规则。

第 10–12 项是本版本已采纳的实现约束，不表示旧控制链已完成迁移；运行时完成情况以工作项证据为准。

玩家新建法术的实体、属性与控制说明见[实体与属性](../reference/entities-and-attributes.md)和[法术编写指南](../reference/spell-authoring.md)；公开入口目录由注册表生成于[元法术参考](../reference/meta-spells.md)，legacy-only 兼容别名不属于新玩家入口。参考页描述当前工作树可见的接口，不代替本版本集成和验收证据。
