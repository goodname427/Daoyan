# 统一世界理论与详细策划：主策设计审核记录

**边界**：`pilot-agent-intent-2026-09-24`，范围修订 `13`，策划修订 `2`；审核对象是[唯一理论正文](./world-theory-draft.md)与引用它的[模块详细策划](./world-rule-design.md)。本记录是内容审核和直接证据核对，**结论为有条件退回制作人取舍**：已批准方向内的两处组合遗漏及两处体验表述已修订，六类关键规则仍未闭合，不能宣称理论定型或新规则可玩。不选开发切片，不制作预设/敌方修士，不修改代码、测试、已采纳 ADR 或运行中的版本状态。

## 审核依据与认识状态

问题是旧原型的统一句柄、分池和事件不足以解释自然物理、生命、材料与跨实体玩家程序。范围仅核对推导、反例账本、完整玩家往返、旧证据及未决取舍；非目标是给候选参数拍板、验证新运行时或承诺兼容旧法术。验收以本任务合同的逐项审核、可定位证据、可推导修订和明确升级问题为准。

## 统一原则逐项审核

“成立”只指候选理论的因果叙述足以继续反证；不等于数值闭合或现行游戏支持。各行同时对修士、法球、稳定物体、固定机关、人工生命采用结构、来源、授权和环境条件，不给类型专名免费能力。

## 相邻玩法及反例账本复核

按“触发 → 执行者/付款方 → 来源/去向 → 作用/反作用 → 工作 → 耗尽或失败”查[理论逐笔表 H/B/E/C/L/R](./world-theory-draft.md#跨实体与边界反例的交易明细)与[详细策划验收表](./world-rule-design.md#设计审核的反例与验收情形)。`M?`/`T?` 是待定价，绝非零价；每笔有独立效果或接触 ID。

| 反例                                          | 逐笔核验和失败后余态                                                                                                                                                                                                                                                                                        | 结论                                                                                                                                                                                                     |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **接力护送 H1–H3**                            | 定时/偏航触发；修士、法球或机关的实际执行结构从自有/有限授权账户付观察 `M?`、占有限记忆并做 `T?`；H2 由 `M` 或可追来源 `P` 推屏障，反作用进执行者、锚定地面或世界，热进环境；H3 另按自然接触分冲量。越权无私值，欠费不消除惯性，缺施力结构/接触才拒绝；观察已付不因 H2 失败退款。                           | **条件成立；修正遗漏**：固定机关不能自移仍可用真实推杆推屏障，原稿把“不能移动自身”误当“不能施力”。结构、`P` 和价格待定。                                                                                 |
| **自修复信标 B1–B4**                          | 接触 `C-B` 自然结算；获准信标/机关/人工生命或残存回路在死亡后有效授权下醒来。已有余额可先付自身读取，零余额先从预授权环境账户转 `m`，满足 `m=净入账+启动收款+散逸`，再付读取及材料修复 `M?/T?`；材料从现存供应处迁移，废料/热入环境。越权遗体读不返私值，无来源/材料/能力则修复不提交，既成转入和读取保留。 | **条件成立；修正遗漏**：原 B2 先读后吸收使零余额者无法启动，与来源付启动价原则冲突。环境可用性、效率、材料及复苏身份仍未定。                                                                             |
| **100/20 储备挪用 L1–L2**                     | 修士或有维持义务的人工生命可把实际 100 全付合法术式；比 80 多出的效果只能来自同一价格函数的额外 20。反作用与收款入世界/目标，攻击工作 `T?`；若维持先使执行结构失效则攻击不提交，攻击先成则余额 0，之后无补源才失稳并可能死亡，遗体继续在场。                                                                | **顺序自洽、阈值未闭合**；安全 80 是建议而非锁定余额，“牺牲”不赠伤害。                                                                                                                                   |
| **无源/额外供能、创建者死亡 E1–E2**           | 稳定物从已有材料组织，若组织施术另付；不稳定球周期从自己的有限储备维持。额外注入是获准账户转移且受容量限，只有用于维持才可能延寿；创建者死亡撤未来提款/控制，预先独立授权可在余额内继续。欠费后默认退化，残余材料/法力按终止账转出，不凭 `life`/所有者标签消失。                                            | **因果成立、速率和死亡后授权未闭合**；当前 [world.ts](../../../src/core/world.ts) `tickActor` 自动回复、[battle.ts](../../../src/game/battle.ts) `life` 倒计时是旧合同。                                 |
| **起步、场外/擦边、连续碰撞及遗体再损 C1–C3** | 修士起步由 `P` 或有源转换供能，脚/地互给冲量；球擦边若无实际接触无 `C`，撞墙/两人/遗体逐次各有双边接触 ID、形变与热去向；开放边界移交范围外，实体不无因删除。球上响应需独立授权、付款与 `T?`；耗尽仅阻止新作用，不撤自然结果，遗体可继续破损但不二次死亡。                                                  | **机制候选成立、接触/材料精度未闭合**；旧 [hitProjectile](../../../src/core/world.ts) 以 damage 池扣活体 HP，[Battle.updateProjectiles](../../../src/game/battle.ts) 场外/寿命删除，不能作为新物理证据。 |
| **回收套利 R1**                               | 创建付 `m`、材料/运动另记；回收只从当时获准且可用环境分区取得 `r`，收集耗时/可能耗启动价，未回收量及可用性损失留环境。无权/无来源/容量不足拒绝；若球或动能仍在，全世界状态并未回到起点。                                                                                                                    | **未闭账**：缺转换与可用性定量上界，不能由“价格覆盖收益”或固定折扣推出 `r<m`，也不能开放可重复净增效果的循环。                                                                                           |

## 六类未决取舍：结论、证据与提交制作人的问题

每一类都有原则已能约束的部分，但没有一类完成了可实施的定量/边界闭合。[理论六类表](./world-theory-draft.md#六类理论缺口的本轮推敲结果)和[详细策划选项](./world-rule-design.md#提交设计审核的未决取舍)为原始证据；下列问题是本次审核后的裁决入口，不代替制作人选择。

| 类别                                 | 审核结论与定位证据                                                                                                                                                                                              | 处理方式与待制作人判断                                                                                                                                     |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 有效质量、接触、材料结构             | **待判断**。默认双边碰撞和稳定/失稳可推导，[理论物理/损伤](./world-theory-draft.md#三伤害的本质)与 [ADR 0018](../../adr/0018-运动供能与命中守恒.md) 的“不用动能致伤”冲突。                                      | A 有限形状/有效质量加可损材料；B 暂限为动量展示并明说不能体验自然致伤。请判断本版要到何种材料/接触精度，B 是否仍满足跨实体承诺；之后另作 ADR 覆盖。        |
