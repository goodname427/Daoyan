## 统一规则逐项核验

“条件成立”只说明候选因果和失败边界足以继续反证，不表示参数闭合或当前代码支持。修士、法球、稳定物、机关和人工生命一律按实际结构、来源、授权和环境判定，不由实体专名获免费效果。

## 相邻玩法及指定反例账本

按触发 → 执行者/付款方 → 来源/去向 → 作用/反作用 → 工作 → 耗尽/失败复核[理论 H/B/E/C/L/R 逐笔表](./world-theory-draft.md#跨实体与边界反例的交易明细)；细则反证分别见[物理](./physics-material-design.md#可复核情境与反例)、[资源](./mana-ledger-design.md#场景流水拒绝与空状态)、[生命](./life-identity-design.md#四项指定反例完整与余态)、[程序](./programmable-spells-design.md#同一程序的五种载体反证)。`M?`、`T?` 是待定价/工作，不是零价或运行许可。

| 情形                               | 逐笔结算及失败余态                                                                                                                                                                                                                                                                                 | 判定                                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 接力护送 H1–H3                     | 定时/偏航触发；修士、球或有推杆的固定机关执行。H1 从自有/有限获准账户付观察 `M?`、`T?`、记忆容量；H2 从获准 `M` 付屏障冲量，反作用给执行者/锚地，热入环境；H3 目标接触按自然双边冲量与材料 `X` 另记，无术式 tick。缺感知、推杆、接触、授权或余额只拒相应笔；H1 已付不退，球欠费仍滑行。            | 条件组合；固定不等于不能推动。价格/承受未知则 H2 暂不可执行，不加“护送元法术”。                  |
| 遗体旁自修复信标 B1–B4             | B1 自然接触提交 `C`；信标、机关、人工生命或有残存结构遗体须具执行和事件授权。零余额先 B3 从**预先获准来源**转入并由来源总转出付启动价，再 B2 付获准读取 `M?/T?`，B4 用执行者余额和既有材料做窄域改接，废料/热/法力入环境。越权、无源、无材料、无结构或未知报价拒对应笔；已提交接触/转入/读不回滚。 | **理论缺口**：生命回路若不在窄材料域，不能组合“复苏同一生命”；只承诺域内修复，不能暗加万能修复。 |
| `100/20` 与及时补源 L1–L2          | 修士或同回路人工生命可获准从 100 付 100 的合法攻击，较 80 多出的 20 只能按同价函数买增量；世界/目标收款，反作用和 `T?` 记账。下一维持窗口若无有权来源补 20 则结构退化；补源先于临界提交可继续维持。维持先使结构失效则攻击不提交，攻击先提交不因后死回滚。                                          | 80 是安全建议非硬锁；死亡时刻/同刻序待定，余额零不等于死亡。                                     |
| 稳定物、失供球、额外注能 E1–E2     | 创建者从既有材料组织，组织/初始冲量另付并记反作用；稳定物无维持价，不稳定球由自身余额/有限预留付周期 `M?/T?`，环境收散逸。额外注能是独立转入，只有实际用于维持才可能延寿；欠费后 `X` 退化，余材料/余额终止移交。                                                                                   | 条件成立；失稳速率和终止去向未定。固定寿命不能替代。                                             |
| 创建者死亡                         | 死亡撤未来提款、控制和派生授权；球/机关若有**预先独立授权**、结构及余额可继续。遗体受自然作用，未用预留给固定受益人幂等清算；不从死者账户自动回复/退款。                                                                                                                                           | 独立授权期限/额度待定；创建者死亡不删除已存在球。                                                |
| 场外、擦边、撞墙、连续两目标 C1–C2 | 修士起步付有来源 `M?` 并与地交换冲量；球有真实擦边才记 `C`，撞墙冲量经锚点给地，连续撞两人用更新速度/材料逐次结算。开放边界移交或标“范围外未知”。自然 `C` 不收新 `M/tick`，响应另付；无接触无事件，响应欠费不撤 `C`，不能同动能再扣旧池。                                                          | 条件成立；扫掠精度、持续接触去重、域外接管待定。                                                 |
| 遗体再损                           | 自然接触/获准材料作用继续改遗体 `X`，热和碎料入环境；原 `LifeId` 不再死亡第二次。修结构不自动恢复旧身份；无接触无新伤害。                                                                                                                                                                          | 条件成立；身份连续性待判断。                                                                     |
| 回收套利 R1–R2                     | 创建付 `m`，结构/运动/环境 `U` 各有去向；欲从已付散逸吸回 `r` 再造同球，已选受限域拒 R2、`r=0`，不退已做功。另有预授权有限来源须新笔报价并减可用量。                                                                                                                                               | 全世界无套利未证；开放回收上界前不可表达，固定折扣不是证明。                                     |

横向检查：修士和人工生命只有实际回路才有生命维持；法球可施法但未必活；稳定物和机关同受自然接触，机关有推杆可施力，石块无执行结构则不响应；遗体有材料而原生命已死。[理论五类表](./world-theory-draft.md#五可编程世界是否真的能产生未预设的玩法)、[生命三维表](./life-identity-design.md#存在生命与施法是三个维度)和[程序五载体表](./programmable-spells-design.md#同一程序的五种载体反证)提供交叉定位。

## 推演台—演武场—同一法术书

[桥接细则完整流程](./player-bridge-design.md#玩家完整体验闭环)依次规定：空书引导；DSL/蓝图编辑同一 AST，非法草稿定位但不执行；分析法力/tick/神识及动态上界；沙盒单步与可重放时序；同书绑定；演武观察自然 `C`、付费 `A`、转入、读取、事件；按拒绝节点返回原书修改、再推演和复测。[请求矩阵](./player-bridge-design.md#请求与反馈案例矩阵)给成功、拒绝、授权空查询；[失败空书往返表](./player-bridge-design.md#失败空书旧原件与往返验收)给空书、缺绑定及页签往返。静态通过不赠运行授权；拒绝不回滚已付独立笔；私有目标不可从报错/HUD/报价泄漏存在，获准空查询按实际读取收费。

鼠标、键盘、手柄、AI、实体事件只形成[设备无关意图](./player-bridge-design.md#设备无关意图与统一请求)。瞄准仅为方向/目标意图，非私有读权。固定世界初态、程序版本、执行者结构、权限、付款来源、目标/方向、已提交事件及队列先史、随机种子和模拟时序，规范世界请求应同价、同 tick/神识、同效果/拒绝/空结果与余态；墙钟、帧率、屏幕像素、暂停、表现和输入配置不能改变结算。事件先前自然接触若不同，比较初态已不同。[理论桥接](./world-theory-draft.md#现实桥接与同一世界请求)与[桥接等价条件](./player-bridge-design.md#跨入口等价前提)一致。

这只是**设计验收合同**。[LabView](../../../src/app/LabView.tsx)、[CombatView](../../../src/app/CombatView.tsx)和[现行编写指南](../../reference/spell-authoring.md)仅有旧法术编辑、分析、推演、绑定、战斗及往返入口；手柄、五载体装载、材料/身份账和跨入口等价无新规则 E2E 证据。[战斗测试](../../../test/combat.test.ts)中的“WASD 能驱动移动”“妖兽被动施法”“暂停冻结周期”只证明旧局部路径，本次未运行新页面体验。

| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 物理/材料 A：方向已定，接触与结构精度未定。[物理状态](./physics-material-design.md#状态所有权与共同术语)、[ADR 0018](../../adr/0018-运动供能与命中守恒.md)。                                          | **推荐有限二维形状与分区材料**：擦边、墙、遗体、局部破损可预测；代价是容差、参数和性能验证。备选整体耐久：实现较轻，却难解释局部护体/修复和材料去向。请判断部位粒度及连续碰撞允许误差；自然致伤需新 ADR 覆盖旧禁令。                                     |
| 2. 主动驱动 B：有来源 `M` 已定，取源/补给价未定。[资源普通驱动](./mana-ledger-design.md)、[world.ts](../../../src/core/world.ts) `updateActorMotion`、[ADR 0018](../../adr/0018-运动供能与命中守恒.md)。 | **推荐可见、有界的身体/机关取源与行动报价**：玩家能预估走路和推杆消耗及补给，代价是行动节奏/UI 重设计。备选只从当前施法余额付：账简单却可能使低法力玩家不能日常移动。请判断来源取得、展示、补给；不能恢复免费 `Wm`。                                     |
| 3. 环境/回收 B：受限域已定，转换与无套利未证。[资源 R1/R2](./mana-ledger-design.md#场景流水拒绝与空状态)、[ADR 0019](../../adr/0019-属性探查与资源账本.md)。                                             | **推荐仅开放预授权、有限容量且可报价的来源**：信标来源可理解，暂不能自由吸环境法力；代价是玩法域较窄。备选开放一般回收：玩法丰富，但先须证明 `U`、启动价、效率和全循环上界。请判断环境可用信息的可见度与将来开放目标；现阶段 R2 不可表达。               |
| 4. 休眠复苏 B：可恢复方向已定，同一身份未定。[生命流程](./life-identity-design.md#失供临界休眠与恢复流程)、[遗体反例](./life-identity-design.md#四项指定反例完整与余态)。                                | **推荐未越不可逆关键回路阈值且有连续记录才同身份苏醒**：玩家可救回临界者；代价是回路、记忆连续性和 UI 较复杂。备选修复后只生成新 `LifeId`：清楚但削弱救援体验。请判断结构、记忆、控制的最低连续证据；未决时仅承诺结构修复、身份 unknown。                |
| 5. 原子/材料 B：窄域已定，具体域和不可约性未证。[程序表达域](./programmable-spells-design.md#表达域与不可组合性)、[ADR 0017](../../adr/0017-统一实体控制属性模型.md)。                                   | **推荐先开放有限无生命材料及连接的改接**：玩家能造屏障、修信标外壳且来源可审；代价是暂不能编写回路复苏、任意创造或传送。备选包含生命组织/任意材料：表达强，但须新增不可约作用和报价/守恒证明。请判断最小编辑域是否满足自定义实体行为；域外直报不可表达。 |
| 6. 程序载体 B：类型白名单已排除，权能/事件界未定。[程序事件](./programmable-spells-design.md#原子提交事件与玩家可见结果)、[ADR 0020](../../adr/0020-事件执行上下文与生命周期.md)。                       | **推荐实际容量、感知/执行结构和预先独立的有限期限/额度/字段授权**：球、机关、人工生命同合同运行，死者不赠权；代价是配置及拒绝反馈复杂。备选死亡一律撤所有程序：易懂但砍掉独立信标/护送余态。请判断遗体残余程序、死后授权时限和私有字段；超域拒绝。       |

另有共同待判断：同刻接触、补源、维持、生命临界、撤权与事件派发的权威顺序，及合法尝试价。推荐先固定“已提交事实不回滚、最新状态逐笔重验、未知报价不执行”，再用 L1/L2、B1–B4 和并发响应反证顺序；按 UI 帧/回调序的备选会令同初态不同果，不推荐。[理论因果](./world-theory-draft.md#跨模块因果与账户同一笔事实只有一个所有者)、[账本事务](./mana-ledger-design.md#事务顺序及跨模块接口)及[ADR 0020](../../adr/0020-事件执行上下文与生命周期.md)为证据。
