## 跨模块规则、交互和验收核对

1. **自然先于付费作用。** 同一模拟时刻先结自然接触与失供 `C/N→X`，再结预授权到期补源、主动作用、到期维持、生命/身份与撤权、事件投递。自然碰撞无需新法力付款；事件只提出后续请求，不能赠能量、材料或权限。球失去主动驱动仍按惯性和结构演化；场外仅移交已知事实，不能免费命中或消失。
2. **物理包与法力账分别守恒。** `Acquire`、物理装载、可能的程序装载付款、作用报价和实扣是不同事实。H2/B4 仅消耗已锁切片，未用余量不能当第二份来源；同源、同料、同 payer 依稳定世界序竞争。无包、断锚、缺料、损坏换版或二次回收只拒后续主动作用，既有自然事实、合法读款和转入不倒带。攻击不能套用 H/B 价格，`100/20` 仅是有来源付款的条件反事实，不是自动伤害或死亡。
3. **生命、身份与载体不按名称授特权。** M1/A1 各自凭关键回路、保存承载与结构/记忆/控制唯一三链判断；后到资源不回救本刻维持。四载体各自报能力、容量和队列，独立授权的人工生命不因创建者死亡自动失效，旧派生权只在有证终界后撤销。关键回路编辑仍不在惰性 `k0` 作用域，故修壳不等于复苏。
4. **玩家桥接必须等价。** 六入口在同一世界初态、AST/hash、授权、来源、模拟序和种子下比较报价、实扣、事件与公开余态；敌方修士使用自身账户和可见集。暂停有效边沿仅缓存一次，恢复先处理到期再复验；无权与不存在目标不泄私值，获准空读只按独立已签读价结算。回推演台改变 hash 必须重报价，旧世界事实不回滚。
5. **可执行的后续验收。** 先取得各源合法先史、H/B 四次独立原读、装载及作用后双端读、AT0 独立描述符与价、M1/A1 自然及保存读数、四体容量和工作帧；再在推演台与演武场分别重放成功、拒绝、空读、未知及域外格，核静态资源上界不小于实耗。九类反例包含无源、断锚、场外、连续碰撞/遗体再损、创建者死亡、身份分叉、攻击无价、容量未知和二次回收。以上是未来开发及候选阶段的验收脚本，本阶段没有实玩读数。

## 规则、接口与反例交叉核对

1. **自然与主动作用。** 默认接触、失供、惯性和损伤可先生成有证 C/N→X；主动作用必须同时有获准执行器、接触或反作用锚、可取物理包、材料去向及法力 payer/grant。法力余额不生成 E0，命中事件不赠包。H2/B4 的有限纸面源可在未来按四次独立读数及误差复验，当前不能称已可用。无包、断锚、缺料、损坏换版或二次回收均拒新作用，保留已发生的自然事实和已付读取。
