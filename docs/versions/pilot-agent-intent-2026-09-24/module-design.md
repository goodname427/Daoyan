# 详细策划节点公开结论：mdu 五项同版整合

- 版本：pilot-agent-intent-2026-09-24；策划修订 2；范围修订 13。
- 问题：上一轮主策复审退回可取得的正功、攻击独立报价、两体生命身份和逐体容量的正证。制作人的 A/B/B/B/B/B 选择是详细策划输入，不是方案通过或开发许可。
- 范围：只整合本轮五项已交付模块证据，核对统一世界理论中的规则、跨模块接口、玩家纸面流程和验收边界。
- 非目标：重写模块策划、补造现场读数、实现游戏、选择开发切片、重跑已通过的定向命令或推进秘书运行状态。

**阶段结论：五项 mdu 任务均已交付可复审的详细纸面设计，但完整正向玩法仍未取得可签证书。** H2 正功与 B4 惰性材料摄取有有限初态、取得链、辅助装载、四读目标和保守下界的纸面构造；现场取得、原始读数、装载工作与价格尚未签。AT0 攻击另缺独立作用包和报价；M1/A1 生命终界及四载体容量也缺正证。当前相关成功 LoadTx、Tx↔A 均为空，攻击价格未知，生命与身份保持未知。主策须独立复审这些闭合条件和产品局限，再判断是否能形成交制作人审阅的完整版本方案；本结论不授予游戏开发许可。

## 规则、接口与反例交叉核对

1. **自然与主动作用。** 默认接触、失供、惯性和损伤可先生成有证 C/N→X；主动作用必须同时有获准执行器、接触或反作用锚、可取物理包、材料去向及法力 payer/grant。法力余额不生成 E0，命中事件不赠包。H2/B4 的有限纸面源可在未来按四次独立读数及误差复验，当前不能称已可用。无包、断锚、缺料、损坏换版或二次回收均拒新作用，保留已发生的自然事实和已付读取。
2. **账户与报价。** Acquire、物理 LoadTx、可能的装载程序 Tx-load、作用 Quote/Tx-action 是不同事实；同源、同料和同付款账户按世界稳定序互斥锁定。公开缺证或未知价零扣；只有已知价、足额锁款且合法有界求证后因先序换版失败，才从同一锁额结互斥尝试价。AT0 与旧 100 M 攻击不得借用 H2、B4 或旧候选价；100/20 最后一击只转移实际已到账余额，不凭空形成伤害或自动判死。
3. **生命、程序与授权。** M1/A1 各凭关键回路、保存和结构/记忆/控制唯一三链判生命与身份；⑥到款不能倒救本刻④维持。终界四证未齐则冻结旧私权，不伪造 DeathBarrier；真终界才一次撤主体及派生权。人工生命有自身来源和独立授权时不随创建者自动死亡；球失去主动供能仍按自然惯性和结构演化。相同程序可组合接力护送及遗体旁惰性修壳，固定机关缺移动能力、球无反冲不能自推、无关键修复能力不能醒回，均按共同能力和作用域拒绝。
4. **桥接与玩家验收。** 同初态、同 AST/hash、规范意图、授权、来源、模拟顺序与种子时，六入口的报价、实扣、公开字段、事件和余态应相等；敌方修士使用自身账户及可见集，无阵营折扣。获准空读按独立读价结算但无新作用；无权或不存在目标不泄漏私值。暂停恢复不重放旧输入边沿；回推演台修改为新 hash 必须重报价，不回滚旧事实。同刻双响应须先验本体队列容量和同源竞争，不能复制包或借其他载体余位。

## 尚未闭合及后续评审边界

- **物理来源正证**：H2/B4 的有限初态与误差算法已具体，仍需未来现场取得、四读、辅助装载工作、接触及热/反作用量测。其余拟开放正功和摄取仍缺各自取得与作用包。当前成功流水不可执行。
- **价格与预算**：装载法力价、AT0 独立物理作用及攻击价、四载体容量和实际工作量未签。条件 M/tick/S 式不能当静态上界已不小于实耗。
- **生命与恢复**：M1/A1 的自然梯度、保存承载、恢复抵达及三链身份没有正证。窄域只修惰性壳的“能保存却不能醒回”须由主策评估是否可接受；若确需关键材料编辑、M→E0、热或环境回收、独立死后授权，应先以玩家效果、优势、代价和推荐理由提交制作人取舍，不能在本页暗开。
- **旧原型影响**：当前 DSL/蓝图、固定寿命、命中伤害、自动回复、预设、敌方 AI 与存档不是新证。若方案获批，先核定 [ADR-0017](../../adr/0017-统一实体控制属性模型.md) 至 [ADR-0020](../../adr/0020-事件执行上下文与生命周期.md) 的覆盖、旧数据隔离和回退；原型期允许明确重做或移除，不以旧兼容替代规则闭合。游戏开发和新规则实玩均未开始。
