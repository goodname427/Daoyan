## 跨模块合同与相邻情形

1. **先自然事实，再付费请求。** 物理层先提交运动、双边接触 `C` 与结构变化；事件可唤醒程序，授权、报价、预留和最新状态重验成功后才产生 `A/X` 与资源交易。事件欠费或队列满不撤销接触；同一冲量、损伤不可从旧 `damage` 池再扣一次。作用 ID 和交易 ID 互相引用，同刻按[理论权威顺序](./world-theory-draft.md)结算。
2. **来源、生命和权限分判。** 主动驱动、观察、维持、修复从获准来源付款；已付惯性自然继续。账户零余额不直接删球或判修士死亡。生命据结构与实际供能判状态，死亡再撤权。独立法球或信标仅凭事先有限授权和自身资源继续，创建者死亡不追删实体。
3. **程序和桥接不复制世界规则。** DSL/蓝图共用 AST，分析、报价、VM 使用同一作用语义；动态或未知预算明示，读取受字段权限约束。按键、AI、UI 或实体事件均不得绕开授权。固定世界初态及规范请求时，推演与演武应同价、同效果、同余态。
4. **接力护送**检验未逐项点名的组合：同一观察、记忆、施力程序交给修士、球和固定机关，只因结构、锚点、授权与来源不同而成功或拒绝；欠费的球仍可能惯性滑行。[H1–H3 账](./world-theory-draft.md)区分已付观察、主动作用与自然接触。
5. **遗体旁自修复信标**检验事件、零余额转入、私有读取、材料迁移和生命身份。[B1–B4 账](./world-theory-draft.md)把接触、来源总转出、读取与域内修复拆开；无源、越权、欠费或缺材料拒对应笔，先前已提交笔保留。关键生命回路若在窄域外，复苏与同身份请求仍不可表达。

上述是纸面条件式验收，并非新规则运行通过。减速、破防、碰撞触发伤害和追踪是共通规则的测试例子，不是封闭玩法清单。

## 主策复审须核定的边界

| 未闭合合同       | 当前边界及待决问题                                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 物理和材料       | 有效质量、接触容差、材料白名单/粒度、结构承受与场外接管尚无共同可执行数值；不能宣称新碰撞与结构伤害已实现。                   |
| 法力和做功       | `M→冲量/结构` 报价、普通驱动来源、环境 `U`、回收上界、合法尝试费未证明；未知价标待定价/不可表达，不能以旧倍率或免费补给填洞。 |
| 生命和身份       | 临界/死亡阈值、休眠维持价、连续身份最低证据及窄材料域能否包含关键回路未定；修好遗体不等于同一生命复苏。                       |
| 程序和授权       | 原子逐项不可约证明、有限容量、死后独立授权的签发者/期限、事件可见字段及同刻并发余态仍须整版复核。                             |
| 玩家入口和旧原件 | 输入边沿、暂停缓存/恢复序、公共 UI 字段、动态账本粒度及旧 AST/绑定/存档的拒绝或隔离体验待定；预设和敌方修士只作后续验证目标。 |

模块稿的限制与代价是推荐解释，不能把待定参数冒充制作人已选。主策应独立复审新玩家语义、不可逆的 ADR 覆盖及反例；若仍需制作人取舍，以通俗文字逐案说明玩家效果、优势、代价、推荐及理由。原型期允许重做旧法术和存档，但须保留原件、定位不等价处并另定回退。现行统一句柄、授权裁剪、原子账和确定事件有可复用部分；固定寿命、自动回复、三池、旧碰撞伤害及部分 ADR 0017–0020 语义与候选方案冲突，不能由此文静默覆盖。详见[理论旧实现证据账](./world-theory-draft.md)及各细则的 ADR 影响表。
