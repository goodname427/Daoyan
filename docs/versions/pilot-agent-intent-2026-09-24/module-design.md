## 跨模块核对

1. **同一事实只写一次。** 物理按稳定接触组提交自然 `C/X`，对未裁定接触保留待解区间；程序不得把碰撞事件再写成伤害。主动作用先从物理取得作用量和材料证书，再由账本同一 `Quote` 锁定来源并原子提交 `Tx↔A/X`。自然、付费、生命与事件引用同一因果根；后笔失败不撤先前事实。
2. **共同报价有明确范围。** `D0` 只含有限惰性材料、形状、时段和账户上界；`P0` 的正价、尝试价和静态毛界只在该证书域成立。物理结果未裁定时没有作用价；材料缺额可收已列目录的合法求证尝试价，未知价或私有输入不足不能填零、套旧三池倍率或收未报价的尝试费。账本守恒按来源毛扣、净到账、世界收款及不可取散逸逐笔核对；开放回收仍在域外。
3. **身份与授权分判。** 六阶段顺序先处理自然、预授权到期转入、已到期主动作用、维持/失稳、生命身份及撤权，最后派事件。同刻最后一击可支用全部现有余额，但下一维持仍独立结算；零余额不等于死亡。`DeathBarrier` 先撤死者派生权限；有独立身份和来源的人工生命并不随创建者死亡。首批关闭控制者死后独立 grant；旧理论中“遗体凭残存结构及独立授权继续施法”的条件示例在首批不可执行。
4. **组合与桥接不得获得特权。** 同一程序给修士、球或机关，差异只来自真实结构、授权、来源和证书。接力护送中球欠费仍按已付惯性滑行；自修复信标可在活跃执行者和获准来源条件下尝试窄域修壳，不能编辑关键生命回路或宣告原身份复苏。鼠标、AI 与事件的相同规范请求，在同初态、授权、事件先史和模拟时刻下应同报价、实扣、裁剪反馈及余态；敌方修士也适用。

## 主策复审重点和后续门禁

本轮推荐有限二维形状及惰性材料 `D0/P0` 作为**可反证的首批候选**，并关闭未能界定签发者与预付账户的死后独立授权。主策须核对物理残差和不同步长结果、共同价函数系数与静态界、维持/读取及普通驱动报价、同一身份连续证据，以及关闭死后 grant 对信标玩法的影响。模块文件中较早 `mdc-*` 未决段落，以各自 `mdn-*` 首批章节及本页限定域为准，不能引用为现时“全部无价”结论。

若主策发现超出制作人已选方向的产品冲突或必须覆盖 [ADR 0017](../../adr/0017-统一实体控制属性模型.md)–[0020](../../adr/0020-事件执行上下文与生命周期.md) 的不可逆选择，评审材料应以通俗语言说明各案的玩家效果、优势、代价、推荐理由和旧原型/存档影响。本页不把已选 `A/B/B/B/B/B` 重新交制作人作工程参数题，也不把旧原型兼容当作策划阻断。主策复审和制作人审阅完整方案前，不进入游戏开发。
