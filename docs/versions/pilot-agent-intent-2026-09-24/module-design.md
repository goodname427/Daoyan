## 跨模块核对与阶段目标

1. **物理、付款与材料。** 自然接触及结构失稳先写 `C/N→X`，不消耗法力；主动 `A0/P0` 须在同一接触、反作用、供能、材料及版本证书下报价并原子签 `Tx↔A/X`。`M`、物理功 `E0`、冲量 `J0`、材料 `Q[k]`、tick 和神识分别记量纲，不互相充当付款。起步 `12 M`、续步 `19 M` 的纸面链与预授权 `23 M→净入20+启动2+散逸1` 对账；已付热和散逸不重新成为可取 `U`。球被推后的惯性、真实自然撞击与此前合法 `Tx/A` 保留。
2. **生命、授权与事件。** `M1/A1` 分别用物理回路 `N→X` 和自身已到账账户支付到期 `K0/V0`；欠费不能直接写死亡。生命模块只从真实结构与到账判临界、休眠、死亡和身份；不可逆证书才发一次 `DeathBarrier`。程序在装载、唤醒及每笔提交重验容量、字段 grant、付款与撤权；死亡主体派生授权关闭，独立人工生命凭自身有效资格继续。阶段⑥的事件补源不能倒填阶段④，先前已提交事实不回滚。
3. **两个未按玩法名预设的相邻情形。** 护送 H 由获准读取、有限记忆及有反作用的施力组成，同一程序可交不同载体，但无脚地/推杆或球无喷出物时拒本笔；信标 B 只能在获准接触、封闭来源、普通外壳读数和 `D0` 惰性材料证齐时转入并修壳。缺料、私值越权、关键回路编辑或原身份复苏不得被普通修壳冒充。二者都检验球、机关、修士和人工生命的同一请求、价与失败合同。
4. **跨现实入口等价。** 桥接固定初态、AST/hash、描述符/报价、执行者结构、grant、payer、模拟序与种子后比较规范请求及逐笔余态；设备、阵营和 AI 标签不改变世界价格或权限。空书没有隐式程序；获准空读有价，隐藏与无权目标不泄漏存在性；暂停/恢复不重复提交输入边沿。旧诊断绑定旧程序 hash，返回同一法术书修改后重新预算，不能撤回战斗中的已付事实。

这四项核对覆盖本轮阶段目标中的规则、交互、边界与可执行验收。纸面链成立的域外仍须显示 `unknownPrice`、`undetermined*`、`capacityUnknown` 或 `unexpressible`，不可将未测回路、任意材料编辑、开放环境吸能、自由飞行和独立死后 grant 写成已成功。首批条件证书能否给出可信的实际实体测量及玩家体验，仍待主策复审、制作人审阅后进入开发和候选阶段验证。

## 审核与现行原型边界

主策下一步应独立核查：接触/材料精度和普通行动的可玩范围、逐体回路及程序容量证书能否实测、`A0/K0/V0` 价函数与静态上界、封闭来源及回收不套利、生命截止和身份连续、同刻事件顺序，以及 H/B 在缺证时的诚实拒绝。若要扩展关键回路编辑、开放回收、远距感知或死后授权，应先列通俗的玩家效果、优点、代价、推荐选项和理由，交制作人取舍；现有 `A/B/B/B/B/B` 输入本身不等于详细策划获批。

现行代码仍是旧原型，不能用旧自动回复、固定球寿命/命中伤害、专名追踪或按键读取冒充新规则的实现。若方案获准，实施前须以新 ADR 逐条裁定 [ADR 0017](../../adr/0017-统一实体控制属性模型.md)–[0020](../../adr/0020-事件执行上下文与生命周期.md) 与旧三池、HP/生命、运动、探查/退款、事件及死后权限的冲突，并说明旧 DSL、蓝图、预设、敌方修士和存档的隔离或重做影响。原型期兼容不构成立项前阻断；本阶段未写新 ADR、未修改游戏或验证实际可玩性。
