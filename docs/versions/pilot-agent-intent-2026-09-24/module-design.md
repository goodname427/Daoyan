## 跨模块核对

1. **顺序与唯一事实。** 自然接触/失稳写 `C/N→X`；预授权补源只写真实 `Tx`；主动作用需同一报价与付款签 `Tx↔A/X`；到期维持/保存另行结算；生命据已提交事实判状态与身份、撤权后才派事件。B1 唤醒的 B3 转入不能倒填本刻已到期维持，H2 付费施力不保证 H3 碰撞。后笔失败不撤先前合法事实。
2. **资源与生命。** R0 获准空查询处理全部声明槽并实扣；隐藏目标与不存在目标不得由报错、价格或时延区分。K0/V0 成功须有独立来源、净到账和物理功能事实。`100/20` 中安全支用 80 不是硬锁；全额攻击后如维持失供，生命只按真实退化和救援证书判。`LifeId` 连续须结构、记忆、控制三链；死亡只发一次屏障，遗体及新闭环不复用旧 ID。
3. **相邻玩法的成立域。** H 在有感知槽、授权、账户、反作用体及物理证书时，修士、球或机关可同合同执行；欠任一条件只拒相应步骤。B 仅是活跃信标获准转入、读取公开外壳、迁移真实惰性材料。死者私值、关键回路修复、原身份复苏和非零独立死后响应不在此证书域；创造者或旧 owner 不自动授予球/信标付款权。
4. **玩家入口与信息。** 桥接投影 `Quote/Tx/C/A/X/LifeAssessment` 及拒绝原因，仍按观察者授权裁剪。空书不产生隐式程序，空查询不免费，身份未知不授旧私权；推演台与演武场共享同一书和结算。输入设备、阵营、AI 或事件来源标签不是价格与权限特权。

以上回应[上轮退回的三项合同](./design-review.md#相比上一轮仍须补齐的可验收合同)：R0/K0/V0 有有限来源和报价，生命有有限判据，H/B 有逐笔复算及纸面玩家反馈。成立范围受证书约束，仍待主策独立审核。

## 主策复审与产品边界

主策需核查接触尺度、报价系数、普通身体代谢与开放回收的来源和无套利、域外读取及关键回路编辑、具体实体阈值与连续损失容限、结构容量、同刻事件，以及死后独立授权若开放的签发者和预付范围。证书缺失分别报告 `unknownPrice`、`unexpressible`、接触未裁定或身份 `unknown`，不能用旧数值、专名法术或无源自动回复填洞。

若有超出已选方向的真实产品取舍或需覆盖 [ADR 0017](../../adr/0017-统一实体控制属性模型.md)–[0020](../../adr/0020-事件执行上下文与生命周期.md) 的不可逆选择，主策材料应以通俗文字列各案玩法效果、优势、代价、推荐理由及旧 DSL、蓝图、预设、敌方修士、存档影响。原型兼容不阻断理论选择。本阶段不立新 ADR 或选开发切片；主策复审、完整方案交制作人审阅前不进入游戏开发。
