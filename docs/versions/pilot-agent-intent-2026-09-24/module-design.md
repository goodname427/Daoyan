## 跨模块核对

1. **规则与资源。** 物理独占自然 `C/N→X` 及主动作用的承力、材料和能量证书；资源仅在同版来源、付款、授权、物理去向和价格齐备时提交 `Tx↔A/X`。`M`、`E0`、`Q[k]`、tick 和神识不互换。已付作用、自然碰撞、热和惯性不因后续请求失败回滚；已付散逸不能直接再次取用。预封存物理包缺上游证书时，余额和条件算式都不能推出一般可执行正功。
2. **生命、授权与事件。** M1/A1 生命依已提交结构、到期维持/保存、反馈与身份连续链判定；实体存在、账户余额和生命状态分开。程序在装载、唤醒及每笔提交重验容量、字段 grant、付款和撤权。阶段⑥补源不倒填阶段④；创建者死亡不抹球或机关结构、余额和惯性，死者派生 grant 则失效。
3. **相邻玩法。** 接力护送 H 是获准读、有限记忆和有反作用施力的组合；信标 B 是获准接触、封闭转入、读取和惰性外壳改接的组合。修士、法球、机关和人工生命都由结构、授权、储备和环境决定能力。缺推杆、能源、材料、方向槽或权限只拒新作用，保留先前合法交易；修壳不宣称原身份复苏。J1 可单独有证推屏障，但完整 H 的方向记忆未签证。
4. **桥接与验收。** 固定世界初态、AST/hash、证书、grant、目标可见性、事件先史、模拟时刻/序号和种子后，跨入口比较规范请求、报价、裁剪字段、事件及余态。获准空读可付读价；隐藏与不存在目标不以反馈泄密；暂停/恢复不重复提交输入边沿。返回同一法术书修改后用新 hash 预算，旧已付事实不撤。旧 DSL/蓝图、绑定、预设和存档无等价证据前隔离并给诊断。
