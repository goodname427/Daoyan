## 跨模块合同与相邻情形

1. **自然与付费分账。** 物理先提交自然运动、接触和材料变化 `C/X`；事先获准的到期补源、主动作用、维持与失稳、生命身份撤权、事件派发依[理论六阶段](./world-theory-draft.md#同刻权威顺序f3f4-的共同因果合同)排序。物理作用 ID 与账本 `Tx` 关联，同一冲量和结构损耗不再经旧 `damage` 池重复收费。接触唤醒的事件不能倒流救本刻先前的维持义务。
2. **来源、存在、生命与授权分判。** 法力只能由获准来源转往账户或环境去向；付款后的惯性自然继续。生命只消费实际结构和到账供能，死亡再撤失效主体的权。创建者死亡不删除已有球；独立程序只在结构、期限、额度和字段授权仍有效且自身有来源时继续。
3. **共同价与有界表达。** 程序提交带目标、局部材料域、期望冲量/状态差、窗口、反作用、付款方和获准快照的作用描述符；物理核验作用与材料，账本核验报价及来源。动态价须给保守上界，无法证明则显示动态或无界。没有可信正价和回收上界的作用保持待定价；窄材料域外保持不可表达，不能退回专名元法术或旧折扣。
4. **同一世界请求。** 桥接只提供来源意图与已获准字段；修士、法球、机关和敌方修士走同一能力、授权、报价、执行、事件与失败合同。UI 不显示未获准私值，模拟时间决定世界账序，暂停或表现帧不改变已提交事实。

[接力护送](./world-theory-draft.md#同一程序的两个未点名相邻情形)用同一观察、记忆和施力程序分别装载修士、法球和有推杆的固定机关，检验结构、锚点、来源与权限；球欠费仍可惯性滑行。[遗体旁自修复信标](./world-theory-draft.md#同一程序的两个未点名相邻情形)检验真实接触、预授权零余额转入、获准读取、材料修复和身份连续性：后笔失败不回滚前笔，域外关键回路不能因预设名称获得复苏能力。两者是跨模块纸面反证，并非已运行的预设。
