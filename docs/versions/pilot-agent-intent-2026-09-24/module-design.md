## 同版合同与反例核对

1. **自然、物理来源、法术付款。** 默认接触和失供先形成有证 `C/N→X`，不需要法术付款；主动作用须有合法取得的包、材料、反作用/热去向和获准 `M` 付款，`Tx↔A/X` 单独登记。同一动能、材料或回收凭证不可重复使用；法力余额不能生成 `E0`。缺上游或装载四读即拒新正功，已发生的惯性、碰撞、读取和转入不倒带。
2. **生命、授权、事件。** M1/A1 分别取证，关键回路、反馈/保存和身份三链不能由实体类型、壳完好或账户余额代替。只有正证终界才签唯一 `DeathBarrier` 并撤主体及派生私权；证据不全保持 `unknown` 且冻结旧私权。⑥触发的补源只能供下一窗口，不能倒救④维持。已获独立来源与授权的人工生命不随创建者自动死亡；遗体再损不重复死亡。
3. **程序与相邻玩法。** 接力护送组合获准读取、有限方向记忆、施力和自然接触；自修复信标组合接触、转入、读取和惰性壳修复。同一程序在不同载体上可能因结构、来源、权限、材料或容量不同而得到不同结果；这不是按实体名字授权。固定机关缺移动能力、球欠主动驱动但保留惯性、无料不能修壳；关键生命回路编辑和无反作用孤球攻击仍在有限域外。追踪能组合时不扩成专名元法术。
4. **桥接与玩家往返。** 现实输入只形成规范请求；同初态、AST/hash、授权、来源、先史、模拟时刻/顺序及种子下，六入口应有相同报价、实扣、材料、事件和余态。获准空读可以按独立读价结算；无权和不存在目标不得泄漏私值。暂停恢复不重放旧输入边沿。返回推演台编辑后新 hash 必须重报价，旧实扣与自然事实不回滚。敌方修士无隐藏折扣或免费探查。
