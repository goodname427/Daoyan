## 已形成的策划

[唯一理论正文](./world-theory-draft.md)从默认物理、有来源的法力转移、付费干预和结构能力解释实体存在、生命维持、损伤、死亡与瓦解；区分自然碰撞和事件触发的术式作用，并逐笔列出施法者、付款方、来源、去向、工作和失败。它逐名审计当前 94 项公开元法术入口，保留可组合行为与真正原子世界作用的边界；熵方向仍是探索假说。

[模块详细策划](./world-rule-design.md)把同一合同落到法术书、AST/分析器、无头世界、VM/事件、输入桥接、推演台与演武场：玩家编写、检查预算与失败、推演、绑定实战，再回同一法术书修改。鼠标、手柄、AI 和实体事件只传达意图；同一世界初态、权限和模拟时序须得到同价同结果。规则不以法球碰撞、减速或破防等例子形成封闭清单。

设计核验同时覆盖未逐项点名的**接力护送**和**遗体旁的自修复信标**，以及稳定造物、人工生命、创建者死亡、额外供能、场外与擦边、自然碰撞、遗体再损、`100` 余额挪用原定 `20` 维持储备、回收套利和跨入口等价。每项均要求能辨别成功、拒绝、空结果及已提交前笔的去向。当前推演台与演武场已有编辑、预算、绑定和战斗往返入口；通用实体程序、材料与生命账、新结构损伤等仍只是策划目标，未获新体验验证。

## 设计审核边界

理论与模块设计把以下六类取舍保留为**未决**：有效质量/接触与材料结构的精度；普通驱动储备的来源和补给；法力与做功、环境可用性及回收上界；生命临界、休眠复苏和身份连续性；不可组合元法术的最小集；通用程序载体、记忆、事件及死亡后授权。审核应逐项检查是否可由统一规则推导、反例能否闭账、玩家能否理解。需要新的产品解释或不可逆架构选择时，携[设计中的证据与选项](./world-rule-design.md#提交设计审核的未决取舍)交制作人判断，不从例子直接指定开发切片。

现行原型和 ADR 0017–0020 的**局部已覆盖、缺口与待判断**已在[设计对照表](./world-rule-design.md#旧策划现行原型测试入口与-adr-对照)及[理论证据账](./world-theory-draft.md#旧解释现行实现与可体验入口的证据账)逐项注明。固定寿命/伤害、无源自动回复、专名追踪、按键入口及旧价格可能重做或移除；旧法术与存档不作为新规则的设计约束，但用户原件、拒绝诊断、ADR 覆盖与回退影响须在后续决定前说明。本节点不改这些实现或既有 ADR，不制作预设或敌方修士，也不排开发顺序；二者留作规则定型后的同合同验证对象。
