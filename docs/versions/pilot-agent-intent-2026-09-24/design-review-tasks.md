# 策划审核节点任务（范围修订 13，开发停滞定向复核）

**问题。** `dev-world-a` 四轮开发审查仍未接入现有 `World/VM`；移除无依据的自然破壳阈值后，B1 首撞至 B4 修壳的条件正例也失去成立依据。主策需先核对 [ADR 0018](../../adr/0018-运动供能与命中守恒.md) 的旧伤害池限制与已批准[物理策划](./physics-material-design.md)中自然结构损伤的边界，不能用独立 `PilotWorld` 草稿或虚构阈值交付。

**范围与成果。** 只设 `drb1-world-vm-reentry` 一项成果，替代上一轮 `mdaf-world-review` 的任务清单，不改其历史证据。主策在[审核记录](./design-review-findings.md)追加本轮裁定：哪些旧条款拟被首批 A 覆盖、哪些仍有效；B1 接触、材料响应及 B4 的成立和拒绝条件；若在已批规则内可行，写出三行为接入现有 World、编译器和 VM 的窄范围实现合同与反例。若需新世界规则或不可逆取舍，先给制作人通俗比较和推荐，停止把该选择当作已批准实现。此任务只产出策划审核文档和独立任务证据，不改游戏代码、测试、模块策划或 ADR。

**验收与边界。** 核扫掠接触、同刻多接触、材料阈值有证/缺证、无损碰撞、再撞、跨步长一致、B4 普通 `k0` 域和失败后自然及已付余态；真实 VM 资源测量留给后续获准的开发交付。本轮不预拆开发、QA 或候选任务，不纳入未来预设与敌方修士。共享 `design-review.md`、`design-review.json` 和 `docs/status.md` 由 Version PM 收束。机器合同见 [design-review-tasks.json](./design-review-tasks.json)，单任务没有同节点依赖或写入冲突。
