# 设计审核节点任务（范围修订 13）

本节点只有一项可独立验收的成果：`unified-world-review`。主策将制作人意图、上一节点的唯一世界理论和模块详细策划放在同一审核中，核对跨实体规则、资源账、未点名的相邻玩法、推演台到演武场的完整体验，以及六类未决取舍。审核记录须区分已由原则闭合的结论、可修订的遗漏和需要制作人判断的问题；不能把立项批准当成理论细节获认可。

承接任务的 Feature PM 自行安排核查与修订步骤。独占写入范围仅为[设计审核记录](./design-review-findings.md)、[唯一世界理论正文](./world-theory-draft.md)和[模块详细策划](./world-rule-design.md)；无同节点前驱或写入冲突。无法从已批准方向推出的新规则或不可逆取舍只附证据与选项升级，不在本节点选开发切片、改游戏实现或安排预设与敌方修士。节点总报告 `design-review.md` 和 `docs/status.md` 留给 Version PM 收束。详细交付与验收见[机器合同](./design-review-tasks.json)。
