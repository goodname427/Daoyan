# 设计审核节点任务（范围修订 13，四项 mdo 成果后复审）

**问题**：上轮主策退回获准读取、生命维持及保存的独立报价和生命身份判据；最新[详细策划结论](./module-design.md)已整合四项 `mdo-*` 成果，尚需独立判断这些有限合同能否组成自洽、可供制作人审阅的完整版本方案。

**范围**：一项成果 `mdo-world-review`。主策核对唯一[世界理论正文](./world-theory-draft.md)、物理与程序前驱、法力/生命/桥接细则及两条相邻玩法的逐笔反例；逐项对照制作人意图、旧实现、相关 ADR 和玩家往返纸面脚本，在[审核记录](./design-review-findings.md)标明已覆盖、缺口或待制作人判断，附证据及处理去向。已批准方向内的文档遗漏可修正，世界公理只写入唯一理论正文。

**非目标**：不拆分主策内部取证步骤，不规划后续节点，不选开发切片，不修改游戏代码、测试、预设或敌方修士。候选参数和纸面验收不代表制作人批准或新规则已可玩；新的产品解释及不可逆取舍须先给出通俗比较和推荐，再交制作人判断。

[机器合同](./design-review-tasks.json)列稳定 ID、交付物、验收、读取路径及独占写入路径；本节点无同节点前驱。`design-review.md` 节点总报告和 `docs/status.md` 留给 Version PM 收束。主策复审后只有完整且自洽的方案才建议交制作人审阅，游戏开发仍未获准。
