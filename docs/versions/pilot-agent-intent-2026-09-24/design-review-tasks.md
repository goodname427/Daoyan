# 设计审核节点任务（范围修订 13）

**问题**：[本轮详细策划总结](./module-design.md)记录六项 `mds-*` 交付，但工作与摄取包的真实上游、装载和封印证书仍缺，正向成功链只是条件算式；逐体容量和独立攻击价等也待证。模块完成不等于整版规则闭合。

**范围与成果**：仅设 `mds-world-review` 一项主策复审。对照[制作人意图](./intent-alignment.json)、[上轮退回合同](./design-review.md)、六份最新模块细则、[唯一世界理论](./world-theory-draft.md)、本轮任务结果、相邻情形及旧原型，在[审核记录](./design-review-findings.md)逐项写已覆盖、缺口或待制作人判断和证据。若仍不闭合，给出具体的详细策划退回合同；若需新产品或不可逆取舍，给制作人通俗比较与推荐。

**验收与边界**：核对物理、法力、生命、容量、事件与桥接的同版来源和失败余态，复算 H/B、普通行动、代谢、`100/20` 及跨入口纸面流程。无证成功保持未知或拒绝；纸面方案不算实际可玩。本节点不选开发切片，不修改游戏代码或测试。

[机器合同](./design-review-tasks.json)给出稳定 ID、交付物、验收、必要输入和独占写入路径。单项任务无同节点依赖或写入冲突；共享 `design-review.md` 总报告和 `docs/status.md` 留给 Version PM 收束。制作人审阅完整方案前不进入游戏开发。
