# 设计审核节点任务（范围修订 13）

**问题**：[本轮详细策划结论](./module-design.md)整合了六项 `mdv-*` 交付，形成同版纸面规则，但现场原读、装载与攻击价格、容量及生命连续证仍未取得。交付完成不等于整版理论自洽或具备可执行的玩家体验。

**范围与成果**：只设 `mdv-world-review` 一项独立主策复审。在[审核记录](./design-review-findings.md)对照制作人意图、已批准策划、前轮退回合同、六份模块方案及[唯一世界理论](./world-theory-draft.md)，核对共同因果、反例、未列举的跨实体行为、跨入口纸面流程及旧原型影响。逐条标记已覆盖、缺口或待制作人判断，附证据和处理去向。

**验收与边界**：复算物理来源、法力与材料账、生命身份、程序容量、事件和暂停桥接；条件成功不冒充现场量测或实玩。缺口形成具体退回合同，新解释或不可逆取舍形成通俗比较与推荐，不预选开发切片，也不改游戏实现或测试。[机器合同](./design-review-tasks.json)记录稳定 ID、交付物、验收、输入和独占写入路径。单任务没有同节点依赖或写入冲突；`design-review.md`、`design-review.json` 和 `docs/status.md` 留给 Version PM 收束。完整方案交制作人审阅前不进入游戏开发。
