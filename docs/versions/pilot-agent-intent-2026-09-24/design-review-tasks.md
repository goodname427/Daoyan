# 策划审核节点任务（范围修订 13）

**问题**：上一轮主策审核退回的首批 A 玩家桥接范围冲突，已由 `mdaf-bridge-scope` 修订；详细策划节点只完成了轻量同键对账。主策仍需独立判断统一理论、五份模块细则、玩家体验和未列举情形是否组成完整可审阅的方案。

**范围与成果**：只设 `mdaf-world-review` 一项可独立验收的审核成果。以制作人已选首批 A（J1 一次有源杆推、D1 一次有源起步、B1 首撞后 B4 一次普通惰性壳修补）和范围修订 13 为边界，复核桥接修订、同版来源及逐付款方账、程序与生命边界、六入口和同书往返、扩展反例、ADR 及旧原型影响。审核结论与证据写入 [审核记录](./design-review-findings.md)，任务结果写入独立证据 JSON。阅读、对账和反证属于同一成果内部工作，不另拆 Feature PM。

**验收与边界**：逐项给出已覆盖、缺口或需制作人判断及文件或行为证据；可在已批方向内补齐的细节明确退回归属，新的世界规则或不可逆取舍先给通俗比较、玩家影响和推荐理由。真实原读、实扣、规范 AST/hash、逐体容量、VM 实耗及实际同书往返留获批开发后验证。本节点不改模块策划、游戏实现、测试或 ADR，不把代理复审当作制作人已批准完整方案或开发；更多预设和敌方修士只检验扩展边界。

[机器合同](./design-review-tasks.json)声明稳定 ID、交付物、验收、必要输入与独占写入范围。单任务无同节点依赖及写入冲突；共享 `design-review.md`、`design-review.json` 和 `docs/status.md` 留给 Version PM 收束。
