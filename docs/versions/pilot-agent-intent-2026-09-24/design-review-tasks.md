# 设计审核节点任务（范围修订 13）

**问题**：[本轮详细策划总结](./module-design.md)已整合五项 `mdu-*` 成果，但合法正功来源、独立攻击报价、逐体容量和生命身份等仍有正证缺口。模块文档交付与条件算式不能代替主策对整版自洽性的独立判断。

**范围与成果**：只设 `mdu-world-review` 一项成果。在[审核记录](./design-review-findings.md)对照制作人原始方向、已批准策划、五份本轮方案及结果、[唯一世界理论](./world-theory-draft.md)、跨入口纸面流程及现行实现，逐条写已覆盖、缺口或待制作人判断及证据。既检查指定反例，也检查未逐项列举的实体与事件；缺口形成具体退回合同，新解释或不可逆取舍形成通俗比较与推荐。

**验收与边界**：同版复算物理来源、法力与材料账、自然损伤、生命身份、程序容量、事件和桥接；条件成功不冒充可玩成功，纸面矩阵不冒充实测。本节点不预选开发切片，不改游戏实现或测试。[机器合同](./design-review-tasks.json)记录稳定 ID、交付物、验收、输入和独占写入路径。单任务无同节点依赖或写入冲突；`design-review.md`、`design-review.json` 总结和 `docs/status.md` 留给 Version PM 收束。制作人审阅完整方案前不进入游戏开发。
