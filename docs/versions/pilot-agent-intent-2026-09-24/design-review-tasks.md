# 设计审核节点任务（范围修订 13，六项 mdp 成果后复审）

**问题**：上轮主策退回普通行动的有源报价、具体生命物理证书及首批可表达域。本轮[详细策划结论](./module-design.md)已收束六项 `mdp-*` 成果，但尚未经独立主策复审，不能据此认定完整方案已可交制作人。

**范围**：仅一项成果 `mdp-world-review`。主策对照[制作人意图](./intent-alignment.json)、上轮[退回结论](./design-review.md)、六项模块细则与[唯一世界理论正文](./world-theory-draft.md)，核对物理、法力、生命、程序和桥接的共同因果；用最后一击、普通行动、接力护送及活跃信标检验相邻与失败情形，并对照旧原型和 ADR。逐项在[审核记录](./design-review-findings.md)标明已覆盖、缺口或待制作人判断，附证据和去向。已批准方向内的遗漏可修订，世界公理只维护在唯一正文。

**非目标**：不拆主策内部取证步骤，不规划后续节点，不选开发切片，不修改游戏代码、测试、预设或敌方修士。纸面方案不等于规则已可玩；新产品解释或不可逆取舍须先给出通俗比较与推荐，再交制作人判断。

[机器合同](./design-review-tasks.json)列稳定 ID、交付物、验收、读取路径及独占写入路径；本节点无同节点前驱。`design-review.md` 节点总报告及 `docs/status.md` 由 Version PM 收束。主策只有在方案完整自洽时才建议交制作人审阅，游戏开发仍未获准。
