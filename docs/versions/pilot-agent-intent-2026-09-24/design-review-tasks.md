# 设计审核节点任务（范围修订 13，退回后复审）

**问题**：上一轮[设计审核](./design-review.md)因价格与资源、生命/材料表达域、同刻事件与授权未闭合而退回。[本轮详细策划](./module-design.md)已收到六项 `mdr-*` 交付；交付完成不等于跨模块规则已自洽。**范围**：按制作人已选的 A/B/B/B/B/B 方向复审唯一理论、五份模块细则、反例账本和推演台—演武场体验。**非目标**：重选方向、拆内部核查步骤、选开发切片、修改游戏代码或测试、安排预设及敌方修士。

本节点只有一项可独立验收的成果：`unified-world-review`。交付[主策审核记录](./design-review-findings.md)；若发现已批准方向内可修正的遗漏，同步修订[唯一世界理论正文](./world-theory-draft.md)和受影响的物理、资源、生命、程序或[桥接细则](./player-bridge-design.md)。验收逐项判定退回原因及六类已选方向的跨模块闭合情况，并用接力护送、自修复信标、`100/20` 储备和碰撞等反例核对来源、作用、时序、失败及玩家可见结果；每项发现有定位证据、修订结果或升级去向。新产品解释或不可逆取舍须以通俗选项、玩家效果、代价、推荐及理由升级，不预写成既定规则。

该任务独占审核记录与上述六份策划正文，无同节点前驱或写入冲突；旧 `world-rule-design.md` 仅供历史对照。Feature PM 自行安排内部步骤。[机器合同](./design-review-tasks.json)列出实际前驱 `mdr-*` 证据和直接读写路径。节点总报告 `design-review.md` 与 `docs/status.md` 留给 Version PM 收束；制作人审阅完成前不进入游戏开发。
