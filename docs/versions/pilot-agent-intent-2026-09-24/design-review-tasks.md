# 设计审核节点任务（范围修订 13）

**问题**：[详细策划结论](./module-design.md)已汇总六项 `mdw-*` 纸面成果，但条件构造、现场原读和未来可玩验收的证据等级不同。上一轮 `mdv` 退回项是否已形成完整、可审阅的统一规则方案，仍需主策独立判断。

**范围与成果**：只设 `mdw-world-review` 一项独立复审。在[审核记录](./design-review-findings.md)对照制作人意图、已批准范围、前轮退回合同、六项本轮成果和[唯一世界理论](./world-theory-draft.md)，核查共同因果、未列举的跨实体组合、跨入口玩家流程、旧原型与 ADR 影响。每项结论标明已覆盖、缺口或待制作人判断，并附定位证据。

**验收与边界**：区分可核验的纸面规则、仍需裁决的产品解释与开发后才能取得的原读和实玩证据。规则缺口形成可复核退回合同；新解释或不可逆取舍只提交通俗比较和推荐。此节点不选择开发切片、不改游戏实现或测试。[机器合同](./design-review-tasks.json)声明稳定 ID、输入、验收与独占写入路径。单任务没有同节点依赖或写入冲突；`design-review.md`、`design-review.json` 和 `docs/status.md` 留给 Version PM 收束。完整方案经制作人确认前不进入游戏开发。
