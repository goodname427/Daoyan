# 设计审核节点任务（范围修订 13）

**问题**：[上一轮主策审核](./design-review.md)退回 D1/B4 桥接物理摘要；[本轮详细策划汇总](./module-design.md)确认桥接已更正，但[唯一世界理论](./world-theory-draft.md)仍沿用同键的旧能量口径，因此节点目前受阻。桥接任务完成不表示跨模块联签。

**范围与成果**：只设 `mdac-world-review` 一项独立主策复审。对照制作人[原始意图](./intent-alignment.json)、已批准范围、上轮退回、[桥接交付](./player-bridge-design.md)、物理/账本及唯一理论，裁定 D1/B4 同版数值和 B4 队列三分判；再核三条同书纸面体验、六入口等价及未列举情形。审核结果写入[审核记录](./design-review-findings.md)，每项须有定位证据和明确去向。

**验收与边界**：理论冲突若仍存在，精确退回理论归属者修订，不把模块任务 `completed` 当整版通过。A/B/C 首批范围或新规则如需制作人选择，先比较玩家效果、收益、代价并推荐；本任务不代选，也不批准开发。真实原读、实扣、AST/hash、容量、VM 实耗与实玩属于获批开发后验收。[机器合同](./design-review-tasks.json)声明稳定 ID、输入、验收和独占写入；单任务无同节点依赖或写入冲突。`design-review.md`、`design-review.json` 和 `docs/status.md` 留给 Version PM 收束。
