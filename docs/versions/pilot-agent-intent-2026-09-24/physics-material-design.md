# 默认物理与材料结构：模块详细策划

**版本与状态**：`pilot-agent-intent-2026-09-24`，范围修订 `13`，策划修订 `2`；`module-design / mdn-physics` 首批有限域候选，承接 `mdc-physics` 细则。制作人已选择 A：有限形状、有效质量、双边接触与可损材料；普通主动驱动由有来源法力付款等其余五项选择依[统一世界理论](./world-theory-draft.md)。直接前驱 `mdc-theory` 已交付共同因果、单位与六阶段顺序；此前 `mdr-world` 也已交付文档，均**不等于**理论定型或主策复审通过。本文所列数值仅为首批纸面候选，不批准最终平衡、不可逆架构、代码开发或 ADR 覆盖。统一世界理论独占公理、同刻权威顺序及跨模块反例总账；若细则推翻它，先退回理论修订。

## 问题、范围与验收

现行[世界](../../../src/core/world.ts)已有位置、半径、速度、阻力和法球分池，[战斗](../../../src/game/battle.ts)也能检测部分重叠；但生命 HP、弹道固定寿命与 `damage` 池仍代替了材料和自然损伤，活体分离与球命中未形成统一双边接触。玩家无法从同一规则推断石块、修士、法球、墙和遗体的相互作用。

本模块定义物理状态所有权、默认演化、自然接触、材料状态、付费作用接口和可复核情境。**非目标**：决定最终材料参数、生命身份、法力兑换率、环境回收、全部元法术、旧数据迁移或实现顺序。验收：各情境的成功、失败、空状态均能追到唯一接触/作用 ID、双边冲量、材料去向和资源交易；欠费不能抹去自然事实，HP 或计时器不能凭空消灭材料。选择 A 是方向，不等于完整刚体或真实化学模拟。

### 单位、身份与状态归属合同

以下是**可复核的量纲候选**，不是平衡数值或 `M` 到物理功的兑换率。`L` 为世界长度单位，`s` 为模拟秒，`Q[k]` 为材料种类 `k` 的数量单位，`μ` 为同一世界使用的惯性基准单位。`M` 是资源模块的法力单位，不能与 `μ·L²/s²` 相加；`tick` 是程序工作量，也不是 `s`。

| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 实体物理态 `P`              | 物理层：位置/形状尺寸 `L`，朝向无量纲角，速度 `L/s`，移动材料质量 `μ`，方向有效逆质量 `1/μ`；固定锚地有自己的有限材料量与约束路径 | 同一实体 ID、模拟时刻、形状版本、材料分区版本、约束及相应方向的有效质量来源；约束方向的逆质量可为零，但不把墙自身材料质量记为无穷大。                                                         |

每笔有全局单调的 `worldSequence` 排序字段及全局唯一的 `(世界命名空间, 类型, kindSequence)` 事实 ID，样例简写为 `C-1/X-1/A-1`；同号而异类型仍是两笔不同事实。前缀只表示事实种类。同刻按[理论权威顺序](./world-theory-draft.md#同刻权威顺序f3f4-的共同因果合同)与稳定世界序号派号，重放相同初态、输入、种子须得同序同 ID。跨域移交保留原世界命名空间与已结 ID，接收域为新事实使用自身命名空间，不重新签发旧 `C/X/A`。默认失稳若改 `X`，其先因另有唯一 `N-<kindSequence>`，记录到期窗口、环境和旧 `X` 版本；移交事实为唯一 `H-<kindSequence>`。尝试失败可以有请求 ID 和资源模块定义的尝试工作记录，但不能伪造成功作用 ID。事件只引用已提交的 `C/X/A` 及获准字段，不持有第二份物理状态。

材料 `X` 是按实体与环境分区持有的有限 `Q[k]`、连接图、承力部位、形变/温度等可影响后续响应的状态，以及功能联系；材料密度或等效惯性按同一公开配置导出质量，不能凭 `hpMax`、`damage` 或实体类型赋值。每类材料及连接声明承受条件（例如方向冲量阈值 `μ·L/s`、形变范围与热容量）和失稳/修复转换规则；未定的材料或阈值标“待规则裁定”，不默认不碎或必碎。自然断裂把材料改记为残块/废料并保留质量去向；材料功能失效可影响生命回路，但物理层不签发死亡或复苏结论。显示用 HP 只能从这些可检查状态投影，不得反过来改变 `X`。

## 默认演化与唯一结算

无施法时，世界按模拟时间 `Δt` 推进惯性、已定义的阻力、接触、材料疲劳/散逸与有来源的环境作用。稳定石块在当前无扰条件下可一直存在，无逐秒维持价；不稳定结构必须指出自身连接/环境导致何种退化，不能借“法球寿命”直接归零。默认求解不扣角色 VM tick；`tick` 只计程序工作。阻力、形变等使机械能进入材料与环境，不能使法力账户无源增加。暂停冻结模拟时间与接触序，渲染帧率不改变接触次数或收费。

对两体 `i/j` 的一次实际接触，先从有限形状与扫掠轨迹求首次接触时刻；只有间隙闭合且相对法向运动或约束需要响应才解冲量。记录 `J_i = -J_j`；若 `j` 是固定墙，则 `J_j` 沿锚定链进入地面/环境，不能删去。切向摩擦、恢复系数和形变须使接触后动能不超过接触前动能加上**已另记来源**的外部做功；材料各部位按其承受范围吸收/变形/断裂，余量入热、声及环境。擦边可有切向/较小法向作用；几何虽接近但未接触则无 `C`。高速扫掠不能跳过中途墙、人或遗体；同一时刻按稳定接触序结算，后续目标用更新后的速度和结构重新计算，不复用首目标结果。

首版无旋转的法向核算可写成 `J_n = -(1+e)·v_rel,n / (w_i+w_j)`，其中 `v_rel,n<0` 为闭合速度（`L/s`），`e∈[0,1]` 为恢复系数，`w_i/w_j` 是该法向的有效逆质量（`1/μ`）；所得 `J_n` 为 `μ·L/s`。只有一方锚定时其 `w=0`，冲量经锚定链传走；两方在该方向都不可移动时转为约束/形变问题，不能除以零或生成无穷冲量。法向冲量与切向摩擦对双方速度的改变、材料吸收及环境耗散一同入同一 `C`；若材料断裂导致约束变化，后续接触必须用新 `w` 和 `X` 复算。真实材料阈值、摩擦与 `e` 的取值仍是待决参数，公式不授权凭旧 `damage` 池补差。

**接触容差与去重的候选合同。** 形状的有符号间隙 `g` 以 `L` 计，`g>0` 为分离；扫掠在模拟区间内求最早 `g=0` 的时间 `s`。几何容差 `εL`（`L`）只界定求根及形状近似误差，时间容差 `εt`（`s`）只用于把不可区分的接触时刻纳入稳定排序；二者必须由场景配置公开、有限、非负，且不能因帧率或阵营改变。可证明最小间隙仍大于 `εL` 时是未接触，**不能**以“靠近”生成 `C`；落在误差带而无法证明相交时标为“接触未裁定”，不暗发命中或伤害，须缩小步长/提高几何精度再求。容差内已证实接触且有相对闭合、切向摩擦或约束反力时才结算。候选首版以扫掠圆盘/线段的连续检测避免跨步穿透；同一初态的分步与合步须产出同一物理接触序及公开容差内结果。

同一对部位在持续贴靠期间以 `(两端 ID、部位 ID、接触段 ID)` 为去重键：首次结算获一个 `C`，后续仅当新增可测冲量/摩擦/形变时才有新的 `C`，并引用前段；完全静止的约束支撑可留有限汇总，不逐帧发布新“首次命中”。分离超过公开的 `εL` 后再闭合才开新段。接触时间在 `εt` 内并列时按部位/实体稳定 ID 排序，每笔用刚更新的速度和材料复算；若相互耦合到排序会改变结果，应作为同一接触组求解并记录组 ID 与全部成员，不能用数组遍历偶然顺序。各 `C` 的双边冲量、环境锚定冲量之和须平衡；恢复、摩擦、形变及热的能量账不能净增，除非明确引用更早已付的外部做功 `A/T`。求解器的数值残差只允许在公开容差内并记去向，不成为免费动能或材料。

### 连续碰撞的规范化与精度边界

候选算法先以形状版本和扫掠区间列出候选对，按连续轨迹求最早可信接触时刻；区间细分只为证明根或排除接触，不能把步末重叠当作唯一判据。把时间差不超过 `εt` 且共享实体、部位或约束路径的候选连成接触组。组内**冻结同一接触前状态**，按稳定的 `(最小实体 ID、最大实体 ID、部位 ID、接触段 ID)` 枚举约束，再联立求非穿透、双边冲量及材料吸收；提交之后才用新状态寻找下一组。互不耦合的同刻组按规范键派号，交换输入数组、玩家/妖兽遍历顺序或渲染帧不能改变状态和账本。若多解，必须由公开、确定且守恒的破同规则选择；若现有精度无法证明同解，返回“接触未裁定”并细分，不能任意先撞一方。规范键负责事实编号，**不**允许用串行编号替代耦合组的联立结算。

每一实际接触对及接触段仅有一个 `C`；同一材料部位在一个原子接触组内的合计状态转移仅有一个 `X`，其 `parents` 可列多个 `C`，各 `C` 引用该 `X`，不按每条事件或每个碰撞候选再发一笔。不同时间的后续接触若再次改变已提交的 `X` 版本，才发下一个 `X`。无可测结构变化就无 `X`；未裁定的候选既无 `C` 也无命中事件。去重键、根区间、组成员、接触前后版本和数值残差都由物理层保存；资源与生命只消费事实引用。

`εL`、`εt`、分离滞回、部位离散尺寸、求根误差上界、联立求解容差及最大细分成本均为**待决尺度**。批准方向只支持有限二维形状、有效质量和可损材料，不能推出这些数字或复杂旋转/塑性精度。推荐先用圆盘、线段和少量承力部位，以相同初态大步/小步及 30/60/120 Hz 复算同组结果；若无法同时满足擦边可辨和双目标顺序无关，须将精度/性能取舍交制作人与后续 ADR，当前域保持未裁定。

**自然变化与作用的结算次序。** 每一模拟时刻先提交已到期的自然运动、接触 `C` 与由此产生的双方 `X`，再处理此前已获准且到期的补源，随后逐笔复检到期付费 `A/T`，再处理维持/失稳、生命判定与撤权，最后派发接触事件；完整跨模块顺序由统一理论持有。自然撞坏施力结构后，本刻主动请求必须按新结构拒绝；同刻后续响应不能用事件前的生命或权限。自然 `C/X` 不扣新 `M`、神识或 VM tick，数值求解耗时只是模拟计算；自然环境影响仍要记录真实材料/动量来源。程序观察、判断、主动施力和材料改接分别由程序/资源模块计其工作与资源；事件排队本身不产生第二笔物理作用。

自然接触的“伤害”只是在 `X` 受损后的读数，不能从旧 `damage` 池再取一份，也不能按阵营、生命标签或最低 1 点保底。活体的组织/护体、非生命球壳、墙和遗体各以实际承力材料响应；护体吸收有自己的结构/储能去向。生命模块随后判关键回路和身份，物理层不能把一次结构损伤直接判死亡，遗体也不会“二次死亡”。球上响应由 `C` 唤醒后形成独立术式 `S`；`S` 若付费施力或改变允许的局部结构，生成另一个 `A` 和交易 ID，不能把 `C` 的同一动能再出售或用旧伤害池补算。接触已经提交而响应失败时，`C` 不回滚。

## 付费接口、失败与移交

候选接口按事实而非实体名称定义：`读取物理快照(实体, 字段, 时刻, 授权)` 只返回获准有限字段；`报价作用(执行者, 受力体, 反作用体/锚点, 目标冲量或有界时段, 材料范围, 授权, 账户)` 返回有界需求或“待定价/不可表达”；`提交作用(报价, 资源预留交易 ID)` 在最新状态复验后原子产生 `A`、双边作用与材料/环境去向。资源模块确定 `M` 扣转、合法尝试价和 `U` 上界；程序模块确定 AST 中的原子操作、能力、权限、神识与 tick。不能报价时不发布效果，`M?` 绝非零价。已经提交的读取、来源转入或自然接触各自保留。多程序争用余额按同一模拟时刻的稳定事件序重验，禁止负账。

主动起步、制动、转向、球二次推进和机关推杆都须有真实反作用路径与获准 `M` 来源；脚踏地面、机关锚点和球与环境的作用路径可不同，但不因“普通移动”免费。一次已付冲量留下的惯性不逐帧重付；反作用体不存在、结构不能承受、无授权/余额、报价上界不明则本次主动作用不提交，既有速度仍按默认演化。付费局部改变材料还须指明材料供应处、目标连接、废料/热、可编辑域及结果边界；“修复”不凭空生料或加 HP，域外材料暂不可表达。传送若由其他模块单独定义，必须是获准付费的空间作用，不可由位置 setter 绕过接触；其落点与旧状态核验后才交给物理层继续默认演化。

自然致伤和付费改接共用同一个 `X` 结果判据：实际承力材料先受冲量/热/剪切并留下变化 `X`，生命模块仅从提交后的关键回路、环境与来源判活、休眠、死亡或仍未知。付费术式若在窄编辑域内改动 `X`，也须列输入材料、废料、热和结构前后值，且有 `A/T/X` 三方引用；域外生命组织不可借“修复”或旧 `damage` 绕过。碰撞未超材料阈值可有 `C` 而无 `X`，结构变了却未越生命阈值可有 `X` 而无死亡；死者遗体再损只增加新 `X`，不重复签发原 `LifeId` 死亡。护体是实际材料/结构或另有来源的作用，须说明吸收、偏转、变形与环境去向，不能由减伤数字无源吞掉冲量。

### 材料分区、作用描述符与下游交付

候选窄域 `D` 先限于**已登记的惰性材料种类、有限数量、外壳/墙面/机关连接和局部承力部位**；每个分区持有 `Q[k]`、密度或惯性映射、几何版本、连接边、形变/热状态与功能标签。结构损伤按受力部位的承受条件计算：先分配冲量与做功，再把可逆形变、永久变形、断裂后的残块/废料及环境热声逐项入 `X`；不越阈值时只更新速度/耗散，不凭空扣一个 HP 数。分区 `Q[k]` 前量等于后量、转给其他分区量与废料量之和；环境收容方也有 ID。材料种类、密度、阈值、部位尺寸、修复损耗和热耦合数值未获批准，缺项时自然结果标“材料响应未裁定”，主动编辑标“待定价”或“不可表达”，绝不默认零损、必碎或成功。

向共同[理论报价](./world-theory-draft.md#共同报价与唯一因果记录本轮策划推导)提供的物理投影为 `D物理 = (作用种类, 目标/局部区域及获准快照版本, 起止时刻与有界持续 s, 双边目标冲量 μ·L/s, 所需正做功及允许耗散 μ·L²/s², 反作用接收方/锚地, 预期各 Q[k] 差量与连接/形变差量, 材料域标识及作用上界)`。物理只算可审计需求和可行区间；资源模块将其与执行者、付款账户、授权、来源分区、VM tick、容量及环境 `U` 合成同一个 `Quote`，独占 `M` 价格、预留、`T` 和拒绝尝试价。报价只能读获准且新鲜的材料/抗性字段；缺私有报价输入时返回待定价，不用隐藏真值泄漏价格。物理提交 `A` 前复验形状与 `X` 版本，资源成功 `T` 与 `A` 一对一关联；自然 `C/X` 没有虚构的 `T`。一次材料改接只发一个 `X`，其材料转移、废料及热均在同一事实内，不另发“治疗伤害”。

向生命交付的是提交后的 `X` 版本、关键连接/功能裕度、材料供应与环境条件的获准结构快照，以及造成该版本的 `C/A/N` 引用；**生命模块**自行依据维持来源和身份连续证据判活、休眠、死亡或身份未定。物理不把结构裕度换算成旧 HP，也不替生命签发 `LifeId`。域内的外壳补料或普通连接重接可在材料真实存在、结构可承受、权限与共同报价成立时表达；生命关键回路编辑、原身份复苏、任意新材料生成及未证明可逆的组织重建在当前 `D` 外，报“不可表达”。外壳修好只能改变 `X`，不能自动宣称原生命复苏；若要开放关键回路，须先由生命、程序、资源和产品评审扩域并补 ADR。

场外必须先确定边界性质：有形墙参与双边接触；开放边界不反弹、不自动命中、不因离开视口删除物质。模拟域不能继续追踪时，移交 `{实体及材料状态、位置、速度、账户引用、授权/程序状态、已结接触 ID、模拟时刻、目标域或范围外未知}`，源域停止积分，接收域确认后继续同一因果序；无接收域则保留“范围外未知”而非声称实体消失。余额终止/退款只按资源模块的明确终止原因办理，越界不是退款或销毁原因。最终开放边界与域外模拟深度仍待选择。

固定同一初态还须逐项复核每笔材料种类 `Q[k]` 的来源与去向、两侧及锚地总冲量、接触前后能量与耗散、`X` 造成的生命判读及事件 ID 的单次引用。若 `X` 尚无承受阈值、`M→功/X` 尚无报价、域外接收方未知，分别给“自然结果未裁定”“主动作用不可执行”“范围外未知”，不把这些空缺换算成 HP、寿命秒数或零价。

同态复核还须用相同材料和初态把球换成机关推杆、把活体换成无生命外壳或遗体：可移动性、执行能力和生命判定可以不同，但接触、来源和失败合同不能因 `Actor`/`Projectile` 分支获得额外动量或免损。比较大步/小步、30/60/120 Hz 和连续两目标轨迹时，容差与接触排序须公开，不能靠帧率多付、多伤或漏碰。

## 首批有限材料域与精度证书（`mdn-physics`）

**给共同报价的物理证书。** `物理报价投影(请求, 获准快照)` 对主动施力输出 `{目标/反作用体或锚点, 区间 s, J目标与 J反作用 [μ·L/s], ΔK正与必要结构功 [μ·L²/s²], 热声上界及去向, 形状/材料/约束版本, 可承受上界}`；对 `D` 内改接再输出逐种逐分区的 `{Q前, Q后, ΔQ, 供给方, 接收方, 废料方}`、普通连接前后版本及结构功。自然碰撞也产出相同单位的**结算投影**（实际 `J/ΔQ/耗散/C/X`），供显示和下一笔报价读取，绝不向资源模块请求碰撞付款。资源模块以这些量连同获准来源、执行工作和授权形成唯一 `Quote`、`T` 与毛支出上界；物理层不把 `μ·L²/s²` 擅换 `M`。缺质量/材料证书、有效反作用方、作用上界或获准新鲜字段报 `待定价`，`D` 外报 `不可表达`；既有自然 `C/X` 不因随后报价失败撤销。

## 普通行动与两类生命结构的增量证书（`mdp-physics` 候选）

**问题**：`D0/P0` 已证明有限惰性施力和接触，却未证明脚、推杆及生命关键回路能承担普通行动或失供。**范围**：下表只给可测的物理前态、版本依赖、守恒去向和拒绝余态，供资源与生命模块复核。**非目标**：指定 `M` 价、生命状态/身份、批准活体材料编辑或宣称现行代码实现。**验收**：对同一前态重放，成功有唯一 `A/C/N→X` 和两端账，拒绝没有虚构作用；缺材料或几何证书时停在未裁定/域外。以下数值是条件式纸面夹具，`E0=1 μ·L²/s²`、`J0=1 μ·L/s`、`q=1/1024 Q[k]`，并非所有修士或造物的常数；物理上界须由被试材料证书签名，不以样例冒充已获准的 `P0` 价格。

## 现行证据与 ADR 0018 冲突定位

[ADR 0018](../../adr/0018-运动供能与命中守恒.md)已采纳，当前仍是既有实现合同；本策划不能自行覆盖它。沿用其“位置、朝向、实际速度分离”“已付惯性不续费”“变向有价”“数值步长不等于 VM tick”“传送单独校验”“效果/账户不可双计”等方向，但选择 A 与本轮普通驱动 B 带来下列**待新 ADR 覆盖**的明确冲突：

| ADR 0018 条款及现行证据                                                                                                                                                                                                                                                                                                                                                  | 本轮候选变化与处理                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 决策一的阻挡去法向速度、不交换实体动量；决策四禁止动能致伤，碰撞只释放 `damage` 池。现行 `Battle.updateProjectiles` 用步末圆盘重叠和 Actor 数组顺序选择活目标，`Battle.separate` 依活体数组遍历推开并去法向速度；`World.hitProjectile` 仅接受存活敌对 vitality 目标，先记碰撞再从池扣量改 HP；[实体测试](../../../test/entity-vnext.test.ts)验证旧分池、寿命及命中路径。 | 连续扫掠、耦合同刻组、双边冲量和双方 `X` 自然损伤取代按类型的碰撞结算；自然 `C` 与付费 `A/T` 分账。新 ADR 须定有效质量、材料阈值、容差/组解、旧伤害池处置与迁移，保证同一动能只用一次；现有测试不证明新合同。 |
| 决策二给普通移动独立、自动补给的 `Wm`；现行 `World.updateActorMotion` 周期付 `movePower` 又自动回复。                                                                                                                                                                                                                                                                    | 已选 B 要求所有主动驱动从获准 `M` 付价；供源、身体效率和价格交 `md-mana`，不得把 `Wm` 换名继续无源补给。                                                                                                      |
| 决策一/六容许弹道固定寿命，战斗代码每帧扣 `life`，出界或命中删除球。                                                                                                                                                                                                                                                                                                     | 结构存续由 `X`、自然失稳及有来源维持决定；范围外移交、接触后的材料去向须另定。旧 `life` 可作为原型操作边界证据，不能当新世界消失原因。                                                                        |
| 决策三/四以三池和固定威力请求计释放，现行测试可证明池不透支。                                                                                                                                                                                                                                                                                                            | 不继承 `1 M→0.8 E`、固定 `K`、旧 `damage` 等式为材料物理价格；`md-mana` 定账与上界，`md-life` 定生命结果。旧数据与法术保原件并定位不等价，待 ADR/迁移决策。                                                   |

这些冲突发生在详细策划与现行采纳 ADR 之间，不以本文件直接改写代码或偷偷宣布 ADR 失效。物理模块候选验收先用前述反例反证；确定精度、作用价、材料域和生命接口后，再提交有覆盖条款、回退与迁移说明的新 ADR。

**覆盖影响清单**：新 ADR 至少要逐条裁定 ADR 0018 决策一的“阻挡只去法向速度、无实体间动量转移”、决策二的 `Wm` 来源、决策三的三池 `E` 锚点/可退款储能、决策四的禁止动能致伤及 `damage` 池、决策六的固定寿命/命中终止迁移；决策五的独立传送与落点校验可继续作为接口边界，但价格与材料占用要复核。代码影响直指 `world.ts` 的 `updateActorMotion`、`hitProjectile`、`damage`、`life`，`battle.ts` 的 `separate`、弹道命中/出界清理，及既有实体测试。旧存档的 `hp/damage/life/Wm/E` 不能无证据自动换成 `μ/Q[k]/X/M`；新 ADR 须列保留旧原件、隔离预览、可证明等价转换或明确拒绝的路径。当前策划仅定位影响，不选择迁移或回退执行方案。
