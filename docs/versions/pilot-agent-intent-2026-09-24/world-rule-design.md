**唯一世界规则正文**：[道衍世界的统一理论](./world-theory-draft.md)。世界前提、推导、反例、逐笔账本、94 项公开入口审计和六类未决结论只由该正文维护。本文定义玩家流程、模块责任、表达和核验合同；若两文冲突，先修正唯一正文再同步本文，不在此另立公理。意图分类与未点名情形见[范围 13 意图记录](./intent-alignment.json)，立项批准见[版本评审记录](../../../.daoyan-agent/releases/versions/pilot-agent-intent-2026-09-24.json)中的策划修订 `2` 的 `charter-review` 决定；旧[版本策划](./charter-draft.md)成文早于批准，仍写有“未批准”，不能反推当前阶段状态。

## 问题、价值、范围和非目标

现行游戏可编写法术、探查、创建弹道、绑定并战斗，却把自动法力回复、固定寿命/伤害、法球追踪、输入按键和碰撞分散在不同合同。玩家难以推断同一程序为何交给修士、法球或机关后能否执行、由谁付费、失败后剩余什么。目标是让玩家以获准感知、计算、原子作用、有限记忆和有界事件响应编写**未由策划逐项命名的行为**，并从推演台到演武场看到一致因果、账户和失败。统一句柄是基础，实体的能力、结构、来源、授权和付款才决定结果。

本策划覆盖默认物理与材料/结构、实体存在与生命、自然损伤与付费作用、资源与会话、通用实体程序、意图桥接、两个跨实体玩法、玩家完整往返、旧原型和 ADR 影响。**非目标**是制作新预设或敌方修士、平衡最终数值、修改代码、制定开发切片或时间顺序、采纳熵公理、迁移旧数据、声称新规则已经可体验。预设与敌方修士以后必须使用相同能力/授权/账本作为验证对象；不能以它们的技能清单限定玩家组合空间。

## 玩家从编写到返回修改

1. **推演台选择或新建法术。** 玩家在同一法术书里用 DSL 或蓝图表达观察、判断、动作、记忆和事件再启动；候选语义允许把同一有界程序交给有执行能力的不同实体。编辑器将世界内效果和现实输入意图分开展示：瞄准方向是被送入会话的意图，目标坐标仍须获准探查。无程序、无可用实体或无授权时显示空状态和缺项，不制造默认免费行为。当前只具备普通法术书与部分蓝图能力，[现行指南](../../reference/spell-authoring.md#当前能力边界)明确没有玩家事件订阅、跨次变量或自定义实体类型。
2. **检查与预算观察。** 解析与静态分析先报语法、类型、递归、列表容量、能力/授权要求和已知上界。法力、神识峰值、tick/模拟耗时、材料、可用来源、持续/事件次数分别展示；环境余额、目标关系、距离或未来事件未知时显示动态或无界，不能把已知部分说成总上界。`100` 余额与近期 `20` 维持义务同时显示“安全建议可用 80 / 实际可支用 100”，并说明后者的失供风险，不能强行锁住 20。价格或换算未决的作用显示“待规则裁定”，不能编造一笔有限报价。现行[推演台](../../../src/app/LabView.tsx)已有静态预算、推演与单步资源时间线，此处是其未来体验要求，不声称当前能显示材料或生命阈值。
3. **沙盒推演与失败处理。** 给定初态、模拟意图、权限、环境和事件，玩家逐步看到触发事实、执行者/施法者、付款账户、来源、每笔效果 ID、结构/运动结果、反作用与环境去向。无目标的成功空列表与无权、过期快照、欠费、缺材料、容量上限、结构失效、会话中断分开反馈。已提交的观察/碰撞保留，后续修复或术式失败不回滚既成事实；当前调用的非法价/资源失败不得留下部分效果。调试可呈现完整沙盒账，但不可让实战角色借调试面板读取私有世界状态。
4. **演武场绑定并验证。** 玩家把同一法术书中通过检查的程序绑定给有权执行的实体/槽位，配置只授予明确控制与有限付款授权，不直接产生法力、材料或生命。开始后同样的初态、授权、意图和模拟时序必须给出同样结算。鼠标/键盘、手柄、敌方 AI、机关/球上事件都转成同一个意图请求；槽位防重、暂停、帧率和渲染不改变世界价。球失去驱动仍保留惯性，接触自然作用与球上响应分别在时间线显示；创建者死亡后独立回路是否继续由预先授权和余额决定。当前[演武场](../../../src/app/CombatView.tsx)已有绑定、开战、暂停、反馈和账户摘要，新跨实体程序及材料因果尚无可体验入口。
5. **返回推演台修改。** 从失败笔定位到法术源位置、能力/权限/环境约束或动态价，修改同一法术书后再检查、推演和重新绑定验证。已保存版本保留可读的旧原文及不等价诊断；不得为让旧法术看似继续运行而隐藏注能、补贴或复制另一份战斗法术书。成功路径看得到效果与逐笔守恒；失败路径看得到没有提交哪一笔；空目标/零事件路径不报假错误，也不生成效果。

## 跨模块责任与交互合同

| 模块/状态所有者                        | 输入、输出与责任                                                                                                                                                                   | 边界和失败                                                                                                                                                                                              |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 共享法术书、DSL/蓝图、AST、分析器      | 法术源码/图统一成 AST；输出诊断、容量、已知预算与动态条件，保留源码位置。                                                                                                          | 不在编辑器复制世界结算；不将旧 AST 自动改成不等价的新作用；[架构不变量](../../architecture/invariants.md)仍要求 AST 唯一 IR。                                                                           |
| 世界状态与默认演化（无头核心）         | 唯一持有位置、有效惯性/接触、材料结构、身份、生命回路、环境和法力来源；提交自然接触及结构变化。                                                                                    | 没有施法也推进；稳定物不必逐秒付款；接触事件记录已发生事实，不能额外扣血。有效质量、材料粒度和环境可用性未决，不能将旧 `damage` 池当物理来源。                                                          |
| 能力、授权、账户与原子作用（无头核心） | 接收意图解析后的 `{执行实体, 程序, 目标/方向意图, 模拟时刻, 授权来源, 有限付款账户}`；分离 owner、controller、caster、payer、接收/退款受益账户；逐笔检查、定价、付款、提交和审计。 | 句柄不授读取/写入权；目标可存在但缺能力；失败不留下当前原子作用的半笔。余额、已做工作、已提交前笔不能因后笔失败倒退。来源与环境去向必须同时可核对。                                                     |
| VM、有限记忆、事件队列                 | 普通程序组合获准读取、计算和候选原子作用；记忆随执行结构占有限状态，订阅按事实、时刻、序号和容量唤醒独立会话。                                                                     | 事件载荷只含获准字段，不是免费监控；每次唤醒用当前账户付款，多个响应顺序竞争余额；因果深度/队列/工作超界须有失败摘要，不能递归刷新余额。结构/权限死亡后先撤销，再处理允许存续的独立回路与只读终止事实。 |
| 战斗与输入桥接                         | 鼠标、键盘、手柄、AI 或实体事件只产生设备无关意图及获准上下文，适配固定模拟时序；事件/账目交给核心。                                                                               | 键名、鼠标像素、屏幕边缘、HUD、表现帧、暂停及配置没有世界特权。相同请求不同入口同价同结果；离开模拟范围要明示边界/移交，不能无因删除实体。                                                              |
| 推演台、演武场与持久化上层             | 上层拥有同一法术书；前者编辑、检查、单步观察，后者绑定并消费；展示获准快照、动态/未知/失败。                                                                                       | UI 不扣费也不赠费，不从面板泄漏私有目标值；导入/导出和本地存档需版本化、隔离诊断和原件保留。旧运行余额不能凭静态字段伪造。                                                                              |

**统一事务**：先确定请求发起者与执行结构，再校验句柄、能力、授权、目标可见性、账户及材料；以模拟时刻的真实参数报价；预留本笔所需神识/法力/工作容量；扣来源并记世界/目标/环境接收；提交单次效果，最后发布只含获准字段的事实。拒绝发生在报价前还是报价后必须有公开、可复现的尝试价规则；目前仅承认“领域拒绝不得留下成功效果、已完成工作不回退”，尝试费大小仍待定。持续作用逐覆盖窗口先付费，未来未知周期标动态/无界；中断清理持有状态但不撤销已提交 write。效果 ID 与接触 ID 防同一作用在自然碰撞、旧池命中和事件响应中重复结算。详细示例流水见[理论正文的交易明细](./world-theory-draft.md#跨实体与边界反例的交易明细)。

**资源的不同含义**：法力是有来源、接收者及环境去向的转移量；神识是执行和有限记忆的状态占用；tick 是已做工作，`castSpeed` 可改变日历完成时间但不消除 tick；物理储备、材料和结构不是法力单位。若 `manaCostMul` 或法术优化使同等作用便宜，须能指出真实减少的观察、计算、做功或转换损耗；不可对探查、转移、材料与产出路径套任意折扣。回收套利反例须核算可用性和启动工作，上界尚未闭合时不许宣称套利已排除。现行三池 `E`、`Wm` 与 `M` 仍用于旧原型账目，不自动构成新理论的换算。

## 候选表达边界、参数和六类待证缺口

| 候选表达/参数                                    | 在玩家体验中必须可见                                                          | 尚待裁定，不能写死                                                                |
| ------------------------------------------------ | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 有效惯性、有限形状、接触冲量、材料承受和结构裕度 | 施力的反作用、擦边/正碰、自然损伤与遗体再损可逐笔追踪。                       | 几何与材料维度、接触阈值、有效质量和护体耦合精度；自然致伤何时进入可玩模型。      |
| 普通驱动 `P` 与已付冲量                          | 起步消耗真实储备，滑行不续费，欠源后仍按惯性运动。                            | `P` 的初始来源、补给、与 `M` 转换及失供体验；旧自动 `movePower` 不算证明。        |
| 法力 `M`、环境可用性与做功                       | 显示付款方、来源、目标/世界接收及散逸；收集仅得当时可用份额。                 | 每种原子作用的换算、信息读取价、环境账户划分与回收上界。无定量式不能证明无套利。  |
| 生命回路与维持窗口                               | 实体存在、存活、可施法、失供、死亡、瓦解分别显示；100/20 的安全建议不锁账户。 | 生命/死亡阈值、休眠复苏和身份连续性；不能由 HP=0 或 M=0 单独替代。                |
| 不可组合元法术最小集                             | 追踪是探查、计算、施力的普通程序；“伤害数”是结构结果摘要。                    | 通用创建、局部结构变化、账户转移、施力、获准读取的最小粒度及每项原子性证明。      |
| 通用程序载体、事件、有限记忆                     | 同一程序交给不同实体，只由能力、授权、余额和环境造成差异；订阅和状态占容量。  | 载体容量、死亡后授权、事件字段/重入上限及持久身份；当前内建响应不等于玩家可编程。 |

这些只是**候选参数类别**，没有虚构质量单位、法力到功的比例、生命秒数或收集效率。现行公开[元法术参考](../../reference/meta-spells.md)的 `1 M → 0.8 E`、`0.25` 秒维护、各入口基础价及 tick 是旧代码的可核实值；[理论正文逐名审计](./world-theory-draft.md#元法术与算法工作量审计)说明其归位与缺口，不作为新规则的平衡锚点。

## 设计审核的反例与验收情形

| 情形                                              | 成功/失败/空状态与核验要点                                                                                                                                                                                       |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 稳定石块、稳定球、不稳定球、人工生命              | 稳定结构无周期施法仍在；不稳定球失供后依结构退化，余额零不瞬删；人工生命有自主取源与维持回路才算生命。无材料创建失败，无回路只是实体。                                                                           |
| 额外供能与创建者死亡                              | 注能按授权账户转移且接收有容量；只在真实用于维持时延缓失稳。创建者死亡撤未来提款/控制，独立预付回路按剩余额度运行，失效退款仅到预定有效受益人或终止损耗。                                                        |
| 修士起步、球场外/擦边/撞墙/撞两人、护体与遗体再损 | 有施力与地面反作用；边界明示开放移交或接触体；未接触无碰撞事实，正碰逐次分摊冲量、结构和环境耗散。护体有吸收/偏转去向；遗体仍可破损但不再死亡。球上响应另付，任一响应失败保留自然结果。                          |
| 100 余额、下次维持 20 的最后一击                  | 付 80 保留 20；获准付 100 则多 20 只换来同价函数可解释的作用，维持后到期且无补源才失稳并可能死亡。维持先到且执行结构失效则未提交攻击；及时补源不强制死亡。                                                       |
| 回收后重复创建                                    | 对照所有账户、环境可用性、材料、运动和已做工作；未定上界时显示“未证无套利”。重复调用、取消、死亡退款不得收两次或返已做功。                                                                                       |
| 接力护送与遗体旁自修复信标                        | 按[理论交易明细](./world-theory-draft.md#跨实体与边界反例的交易明细)逐笔核触发者、执行者、付款、材料/物理来源、作用/反作用、工作、环境与失败；固定机关缺移动能力、球欠费滑行、遗体字段越权、无材料修复分别可辨。 |
| 相同意图从鼠标、手柄、AI、实体事件进入            | 同初态、授权、模拟时序下世界结果与账本一致；无目标返回成功空结果，不因帧率、屏幕或槽位名字生效。事件因队列限制丢响应时留失败摘要，不回滚既成接触。                                                               |

核验先做静态内容评审和可复算的候选流水；真实互动只在规则取舍、架构决策及实现后进行。本节点不把旧页面能点通、旧单测通过或文档检查写成新规则已实现。
