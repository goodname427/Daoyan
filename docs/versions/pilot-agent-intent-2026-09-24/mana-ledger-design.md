# 法力流、做功与账户账本：模块详细策划

**版本与状态**：`pilot-agent-intent-2026-09-24`，范围修订 `13`，策划修订 `2`；`module-design / md-mana` 候选细则。制作人已选择普通驱动 B、法力做功/环境/回收 B。[统一世界理论](./world-theory-draft.md)独占公理、认识状态和跨模块反例总账；[物理与材料模块](./physics-material-design.md)独占接触、反作用和材料事实。本策划不批准新兑换常数、游戏实现或覆盖已采纳 ADR。

## 问题、范围、非目标与验收

玩家需要从同一账目理解：为何修士起步须付费、球失供仍滑行、为什么零余额不能免费读取环境、最后一击与下一次维持怎样竞争，以及为什么已付费用不能靠回收循环赚回。当前[世界代码](../../../src/core/world.ts)的自动 `manaRegen`、`movePower` 补给、弹道 `motion/damage/scan` 三池和[定价代码](../../../src/core/pricing.ts)的 `1 M→0.8 E` 是旧原型事实，尚未证明新世界的做功或环境可用性。

本模块持有账户来源、有限授权取用、余额/预留、可用性、付款、转入、做功对价和终止清算的规则；物理层持有动量与材料去向，生命层持有失供后状态，程序层持有请求、授权、神识与 tick。**非目标**：猜定法力到冲量的换算、物理精度、生命阈值、材料编辑全集、环境开放回收或现行存档迁移。验收时逐笔核对来源、接收、环境、工作、退款权及唯一 ID；无法证明报价与无套利上界的作用不可执行，不能用折扣、免费补给或旧池公式填空。

## 玩家效果与账户边界

普通驱动 B 使修士脚踏地、机关推杆、球主动转向均从自身或**事先有限授权**的法力账户 `M` 付款。不同执行结构可以有不同效率，但同等作用须公开其报价依据。已付冲量留下的惯性、自然接触、材料形变与阻力按模拟时间 `Δt` 演化，不逐帧重复收法力或 VM tick；停止供给只拒绝新的主动驱动。代价是通常走路也受法力来源限制；若身体代谢与补源不能给出可玩的规则，应带体验代价升级，不偷偷恢复独立免费动力池。

法力做功/环境/回收 B 保留法力总量转移：所谓费用是付款账户减少、指定目标或环境分区增加；可用差异 `U` 随分布与结构改变，**不是可与 `M` 相加的第四种货币**。先只开放预先声明来源、可用容量、取用权和可信报价的转入及作用。玩家暂不能任意吸回已付散逸；可收集的环境份额、效率、启动价和回收上界尚未定型。世界接收了法力不代表玩家可再次取得它。完整世界无套利尚未证明，限制表达域只是当前安全边界。

| 状态与单位             | 唯一所有者、边界与展示                                                                                                                                                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `M` 法力账户与来源凭证 | 资源层持有世界分区、实体及获准外部账户的总余额、可用余额、锁定预留、容量、来源序、转入权和终止受益人；`可用=余额−预留`。创建者、执行者、账户所有者可不同；仅凭实体句柄或 owner 字段没有提款权。总量含环境分区，散逸/裁剪不得无去向消失。 |
| `U` 可用差异           | 资源层记录来源可取范围、当前容量/可用量、转换与散逸约束；报价须证实交易不使封闭循环的可用性凭空增长。未知 `U` 显示“未知/不可报价”，不显示零。                                                                                            |
| 物理来源和作用         | [物理模块](./physics-material-design.md)持有原有动量、已付冲量、双边反作用、锚点、形变、热/声和唯一 `A/C` ID。资源层只为主动 `A` 提供交易 ID，不把动能当可退法力；自然 `C` 没有新法力付款。                                              |
| 材料与结构 `X`         | 物理层持有材料量、供应处、连接、废料与环境收容方；生命层从 `X` 与供能判断状态。资源付款不能凭空生成材料或用 HP 数值代替迁移。                                                                                                            |
| 神识和 tick            | 程序层/共享账户持有有限局部值、记忆、订阅及并发峰值；神识为占用容量，释放不是法力退款。VM tick 为已完成及待偿的程序工作，`castSpeed` 只改变模拟耗时，不减少工作。默认物理 `Δt` 不是角色 tick。两者均不得兑换 `M`、动能或材料。           |

### 逐笔记录与守恒

一笔分录至少含 `worldSequence`、模拟时刻、`transactionId`、请求/会话/效果 ID、执行者、付款方、来源账户及来源凭证、接收账户或环境分区、单位与分类、毛支出、预留变化、前后余额、可用性前后或未知理由、已完成/待偿 tick、关联 `A/C` ID、材料来源及去向、退款受益人、终止原因。公开视图仅投影获准字段；私有余额、报价差或来源身份不能从拒绝结果反推。账户采用有界精度和安全整数；量化、舍入及溢出策略必须由后续定价合同统一给出，未定前不能据浮点近似许可透支。

每一来源的 `期初 M + 已授权转入 = 期末 M（含预留）+ 转出/付款/裁剪`；所有账户加环境分区的 `M` 总量前后相等。物理台账单列初末动量/运动能、主动做功、双边反作用、形变及热声；材料台账单列供应、目标、废料。`U`、神识和 tick 不与 `M` 相加。预留只是同一余额内的锁定，不算第二份收入；一笔作用成功才把锁定转成实付，未提交释放锁定，已做功不回退。需长期保留未结来源凭证；汇总历史时仍能逐笔追溯未用余额与退款归属。余额、凭证或明细容量不足则拒绝新注入，不能丢掉来源权。

| 账类                 | 付款方及来源 → 接收者/环境去向；已做工作                                                                                   | 可用性与退款受益人                                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 主动驱动/施力        | 执行者指定的获准 `M` 账户 → 标识环境分区/受力对象；程序读取、报价、请求记 tick，`A` 记冲量与反作用。                       | 支出后该份 `M` 不自动可吸回；已做功不可退，受益人“无”。                                                                              |
| 自然运动/接触        | 无法力付款；先前运动及重力/约束等物理来源 → 双方材料、地面与热声环境；无 VM tick，新 `C` 只记真实接触。                    | 不产生可用 `M` 或退款权；物理耗散不充当魔力补给。                                                                                    |
| 探查、程序与状态     | 获准付款账户 → 世界观察分区；已执行指令记 tick，有限记忆/订阅占神识。读取获准快照可成功返回空集合。                        | 已付读取及已完成工作不因后续作用失败退款；神识正常释放。                                                                             |
| 环境/他方转入        | 事先声明且获准的来源账户扣 `m` → 指定接收账户入 `m'`，启动收款和散逸各入标识分区；计启动工作。                             | `m'`、容量、`U` 上界与启动价均须可报价；初始余额零也不能借未发生的入账先付启动价。退款权若有须由来源合同单独指定，不沿用创建者身份。 |
| 创建、注能、材料改造 | 创建者/获准账户付款 → 世界/目标及有界实体余额；材料从实际供应处迁移，热/废料入环境；组织、初始冲量及持续维持各分笔计工作。 | 注入来源固定终止受益人；仅未用、可归因且规则允许的余额可清算。创建/组织费与已做功不可退。                                            |
| 取消、死亡、销毁     | 无新玩家付款；结清已做功与预留，未用余额按原来源凭证 → 固定受益账户或终止环境分区；清理本身无 VM 工作收费。                | 死亡不自动改受益人；受益账户失效或容量不足的份额记环境损耗，原子注销凭证。重复通知返回原结算。                                       |

**退款规则是候选约束，不是开放新铸币 API。** 旧[ADR 0019](../../adr/0019-属性探查与资源账本.md)对旧 `E` 池规定来源 FIFO、已做功不退、受益人创建时固定、终止恰一次、旧 `10 M→8 E→消费3 E→最多退5 M`。新域继承可追溯、非超额、不可重复的约束；**不继承** `0.8` 转换或 `1 E:1 M` 退款率作为新物理常数。新型材料/做功资产若不能给出“未用量”和最大可退上界，即不可退款。不得把已付环境散逸伪装成未用注能。

## 场景流水、拒绝与空状态

下表的 `q?`/`T?` 是**待证明价格/工作量，不是零**；这些行是验收轨迹和接口要求，未有可信报价前相应作用仍标“待定价/不可表达”。每一笔均记上表字段，真实发生的前笔不会因后笔失败回滚。稳定排序、提交前重验账户与授权，防止并发双花。

| 顺序及交易                 | 付款方、来源 → 接收、环境；物理/材料、工作、可用性及退款                                                                                                                                                                            | 拒绝或空状态                                                                                                                                                                                         |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `S1` 修士起步              | 身体执行者用自有或有限获准 `M` 账户支付 `q?` → 驱动环境分区；脚/地相反冲量登记 `A-S1`，身体增速、地/热承接反作用；请求记 `T?`。已付款不可退。随后滑行由先前动量供给，无新 `M/tick`。                                                | 没有落脚接触、驱动能力、授权、可报价上界或可用余额则无新 `A`；已有速度继续。无输入且无接触时没有新账。                                                                                               |
| `I1` 创建后额外注能        | 创建付款与材料迁移、初始冲量各立来源笔；追加注能由获准账户扣 `m` → 球的有界储备及转换环境分区，固定来源、受益人和最大可退额。球后续驱动/读取逐笔从其可用余额付 `q?`，剩余未用余额不等于已做功。                                     | 未授注入权、容量不足、转换或退款上界未知则整笔拒绝；余额不会因“球归我”自动增长。额外注能为零时成功空转不得制造来源凭证。                                                                             |
| `Z1` 零余额信标先转入      | 自身余额 0；预先获准来源扣 `m`，信标入净额 `m'`，启动费/损耗分别入环境，计 `T?`；来源记录原授权及 `U` 变化。完成后才可从 `m'` 付款做获准读取和材料修复。                                                                            | 来源无声明可用量、取用权、启动支付条件、效率或容量上界则转入不可表达/拒绝；不得以“余额零”为由免费启动、读取遗体私值或倒置付款顺序。来源余额为零或获准目标为空，返回无可转量/空结果，不泄漏私有余额。 |
| `L1` 100/20 最后一击先提交 | 修士当前 `100 M`，下一维持窗口示例需 `20 M`；安全建议 `80` 不是硬锁。合法有界攻击若按同一价格函数实收 `100`，账户 `100→0`、世界/目标收 `100`，额外 `20` 只换对应增量作用；反作用、材料结果有各自 ID，工作 `T?` 已记，无退款受益人。 | 只付 `80` 则余 `20`，不得免费产生 `100` 档效果；若维持先到并破坏执行结构、价格不可证明或余额先被占用，攻击不提交。                                                                                   |
| `L2` 下一维持窗口          | 到期时若已从获准来源取得 `20`，维持回路付款 → 世界与结构维持；否则余额 0，无付款/新维持，结构依默认演化退化，生命模块判休眠/死亡；不因“自爆”直接判死。                                                                              | 维持请求缺额不赊账，攻击也不反向撤销。空窗口尚未到期没有维持扣款；及时补源不强制死亡。                                                                                                               |

## 事务顺序及跨模块接口

请求先带执行者、程序/AST 作用、目标/方向、模拟时刻、有限付款授权及来源 ID；先查结构能力、材料域和授权，再以公开且不泄密的字段报价。报价含毛支出、法力来源、目标/环境去向、物理 `A` 候选及反作用条件、神识容量、tick 和动态边界。随后原子预检并锁定余额/容量，提交前复验目标、授权、材料和源状态，成功时同序提交付款分录与单次作用，最后发布事件。合法拒绝的尝试价大小尚待程序定价模块确定；已付尝试/读取及已完成 tick 保留，成功价不得重复加尝试价。无权、目标失效、缺材料、欠费、溢出或不可报价不得留下半笔成功效果；预留释放。已提交自然 `C` 与较早转入不会因后续程序失败回滚。

物理模块返还唯一 `A/C`、双方冲量、锚点链、`X` 前后及热声去向；资源分录引用 `A`，自然 `C` 只引用原有物理来源。球撞墙或遗体先提交 `C`，事件唤醒的术式另得 `S` 与付款交易 ID，同一动能不能再经旧 `damage` 池释放一次。生命模块读已提交的结构、真实供能及维持窗口，写休眠、复苏、死亡事实；`M=0` 或 HP 摘要不单独决定生命，也不自动销毁球。程序模块共用 AST、定价元数据和 VM 执行价；[定价代码](../../../src/core/pricing.ts)当前 `payableMana` 的倍率只代表旧域内显式可折扣部分。未证明真实减少 I/O、计算或损耗的操作不可折扣，转移、产出、读取、控制、创建与退款尤其不能靠 `manaCostMul` 获得净收益。现行[VM](../../../src/core/vm.ts)的共享付款、tick 债务和神识占用是接口证据，不是新做功换算证明。

静态分析须按**毛支出**列法力、来源容量、持续窗口、材料供应、神识并发峰值及累计 tick；余额转入和未来退款不抵消毛需求或预付义务。列表容量、订阅、事件次数及多 VM 共享账户须有硬界；未来环境状态、目标关系、事件数或持续时长未知时标动态/无界及运行限额，静态上界不能小于实付。账户、来源凭证、物理作用和事件按稳定世界序对齐。暂停冻结模拟时刻，渲染帧率不得改变定价或终止次数。

## 旧规则冲突、待证明域与评审出口

现行[世界代码](../../../src/core/world.ts)的 `tickActor` 自动回复、`updateActorMotion` 的 `movePower` 周期补给、`hitProjectile` 的 `damage` 池和球的 `motion/scan` 池能核对旧原型，却与本轮普通驱动 B 的有源付款、自然双边碰撞、材料损伤及有限环境转入不等价。旧三池的隔离防双花原则可保留，单位和 `0.8` 比率不能直接移植；自动 `manaRegen` 只有能证明实际来源、授权、覆盖价及可用性上界时才可能成为新操作。任意正倍率或给产出/退款打折会破坏守恒审计。旧法术/存档不能凭显示余额、伤害或固定寿命补造来源、材料或退款权；不等价时保原件并定位拒绝。

[ADR 0019](../../adr/0019-属性探查与资源账本.md)仍约束当前实现：原子预留、共享账本、保守预算、非超额且幂等退款、非折扣分类和探查权限值得沿用；它依赖 ADR 0018 的旧三池与 `Wm`，并用回复费用压住旧回蓝套利，**没有证明**普通身体动力来源、环境 `U`、新材料做功或开放回收上界。本策划不宣布 ADR 失效；实现前须新 ADR 明确覆盖条款、量化/来源凭证、旧数据保护和回退。

| 待定或禁止的表达域                              | 玩家效果、方案代价与推荐                                                                                                                                                                     |
