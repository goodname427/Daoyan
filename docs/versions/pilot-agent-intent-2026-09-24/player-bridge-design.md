## 反例检查

- **AI 借玩家视野**：保持 AI 请求、能力、payer 与自身授权不变，只让玩家看到隐藏目标。AI 的目标枚举、报价、结果和余态必须不变；若变化，入口等价/信息隔离失败。
- **事件重复付款**：同一 `factId/requestId/effectId` 的事件再次投递，接收者只取原请求的获准摘要和收据引用；J1、P0、P1、P2 全部新扣 `0`，不再生成 H1/POST 读、H2、自然碰撞或第二份 35/36。若订阅者要发起新的行动，它须以自己的 payer/grant、可见集和新因果 ID 重新报价，不得引用旧收据代付。
- **隐藏目标泄漏**：对隐藏、未存在和无权目标发送同一无权请求，均投影为 `deniedOrUnavailable`，错误字段、公开余态和响应类别一致；不得从价格差、空结果、事件或错误细节推知存在性、位置、身份或目标私值。
- **阵营折扣**：固定 Actor 能力、视野、grant、payer、版本和先史，只切换敌我阵营标签；报价、扣款、物理结果、事件序和裁剪余态必须完全一致。否则视为未经批准的特权。
- **暂停重放**：暂停冻结模拟时刻、读、付款、作用和事件派发；恢复按稳定到达序先复核到期/续费，再校验 session、grant、hash、payer、目标和期限。重复恢复、跨会话、改 hash 或过期请求不得二次付款/作用；暂停本身不能刷新授权或扩展视野。边沿容量溢出只产生一次取消/诊断，不重复提交交易。
- **来源与容量竞争**：同一 slice、单在途位、热位、锚或队列按稳定序只消费一次；后项用最新状态重报价，余额不足或资源已耗显示拒绝。B4 第二响应三分判：本体 FIFO 容量与占用已有同版原读且实满才为 `queueFull`；先序碰撞或作用使壳/槽/锚换版则旧容量证及 Quote 失效，先重读、重报价；容量/误差/已有占用未读则为 `capacityUnknown`。世界队列位不能代替本体容量。三个分支均保留首项已付工作、自然碰撞和热/废料，第二响应不拿旧收据二次领余或回滚已提交事实。

### 纸面操作脚本

1. **推演台编辑预算**：在 `book-mdu-01/v1` 分别打开 J1、D1、B4 节点，记录规范节点意图、条件分支、预算和纸面程序键。J1 只把两个 AST 名按 `J1ProgramIdentity` 作为一个假设别名；D1/B4 保持独立 AST/hash 假设。核 J1 `32 M / 38 S`、D1 `26 M / 37 S / 176+17 tick`、B4 `34 M / 40 S / 232+17 tick` 条件界，且不得以任一条容量覆盖另一体。

3. **返回原书改程序、撤证、重报价**：从演武返回原节点，改条件或读集并保存新书版本。撤销受影响的 AST/hash、Quote、读覆盖及 S/tick 容量证，按新 `readId/payerId/PriceVersion/receiptId` 与物理/结构/材料/锚/环境版本逐项重报价；保留旧请求已付款与已提交事实，不把其收据、余额或切片当新请求免费资源。新增现场读数、实扣、规范 hash、容量和 VM 用量留到获批开发后采集。

### `book-mdu-01/v1` 编辑、绑定、返书

1. **推演台编辑**：在同书分别保存 J1、D1、B4 的规范意图与条件分支；J1 只用一个 `J1ProgramIdentity`，D1/B4 各有独立假设 AST/hash。B4 节点明确选择“首撞有证普通壳缺，且分离窗口内惰性环 `port-corpse-k0-v0`、球头 `head-B1-v0`、`ML-B1-shell-k0-v1/contact-B1-impact-v1/contact-B4-v1/anchor-B1-v1`、热汇和废料桶同版可接”。预算面在十六读覆盖尚缺时显示 `unknownPrice` 与 `capacityUnknown`，只在标明 `n=0` 的纸面假设旁列 `34 M/40 S/249 tick`；不能以假设 hash 亮起“可施放”。J1/D1 的 `35/36` 跨账户和 `26` 自有账户条件值各自保留，均不并入 B4。
2. **演武场绑定与观察**：绑定只引用当前书节点，不转账、不授物理或付款 grant。先观察世界序 20 的实际自然分支：有证破壳才见获准 `C→N→X` 与缺口；接触不破仅 `C`；无撞三者均无；根、阈值或材料未知只见相应待证摘要。只有有证缺口、接入窗口、独立 B4 来源/供料/反作用、付款 grant、逐读价和本体容量均齐，才进入序 50 的获准读和序 80 的有价作用。B1 视图只见自身已结收据和获准结构摘要；自然碰撞不从 `acct-B1-B4` 扣款。已结 `Tx-B4↔A-B1-B4-01→X-B1-B4-01` 只表示普通壳已补，生命和身份仍单独评估；POST 未结时只报已付 `31`、暂余 `19` 的条件支，包余 `unknown`，不能报最终 `16`。
3. **返原书改程序**：从观察/收据回 `book-mdu-01/v1` 的原节点，改板阈值、目标版、条件、读集或获准投影后保存新书版本和新规范 AST/hash；从相同 S0/seed 独立重放前史。撤旧 `ReadTx` 覆盖、`mdz-B4-v1` Quote 与 `40 S/232/249 tick` 条件证中受影响部分；按新 `readId/phase/endpoint/projection/grant/priceVersion` 重新求 `n`，重验本体页/槽/FIFO/旧占用、接触/壳/锚/材料/热汇版本及逐 payer 到账/授权。新增读另价，旧请求已经付的读/装载、自然 `C/N/X`、热、残片、已提交作用与废料保留，但旧收据不能给新请求免费付款或复制 `slice-B4-01`。J1/D1 的书页各自同样撤受影响 Quote/证书，不把三体程序或账户合成一张证。

### 同一书的六入口、撤证与逐付款方账

1. **推演台编辑/预算。** 在 `book-mdu-01/v1` 分别保存 J1、D1、B4 规范意图。J1 的两个旧名称只指同一纸面 `J1ProgramIdentity` 和十五读；D1 独立 `AST-D1-mdaa-assumed-v1/H_D1_assumed_v1`，B4 独立 `AST-B4-mdaa-assumed-v1/H_B4_assumed_v1`，其十九读索引、分支和订阅随 AST 描述符有序。真实规范字节/SHA-256 `programHash=unknown`；同书名或视觉相同文本不能让 B4 借 J1/D1 的 hash、价、切片或证书。B4 预算当前明确显示“首批范围内；读价待签 `unknownPrice`，本体容量待证 `capacityUnknown`”；旧 `34 M/40 S/232/249 tick` 仅放在标明全部前提的纸面比较栏，不能点亮“可施放”。
2. **演武场绑定/观察。** 六入口分别把鼠标、键盘、手柄、妖兽 AI、实体事件、敌方修士的输入归一为同一 `{bookVersion,canonicalIntent,executor,capability,visibleFields,payer/grants,source/slice,requestId/effectId,simTime,worldSequence}`，再核同一规范 AST/物理/价格/容量版。完全同键时应得同价、同拒因、同交易序及同裁剪余态；入口或阵营标签不授视野、来源、付款、优先级或本体位。AI/敌方须用自身账户和可见集；事件仅携已提交事实的获准投影，同 ID 重投返回原裁剪收据、零新扣/零新作用。绑定本身不付款、不授 grant。玩家只观察自己获准的自然缺口、读取阶段和**真实已结**原子，其他 payer 私额、隐藏端点、旧 `LifeId` 私值及未读包余不进入公开响应；未来敌方行为仅检验等价条件，不属首批实现。

## `mdai-bridge`：同键同价、有限十九读与玩家投影（范围修订 13）

### 同一本书、六入口和撤证点

1. **推演台编辑。** 同一本 `book-mdu-01/v1` 保存 J1 一次杆推、D1 一次左足起步及 B4 一次碰后普通壳修补。J1 采用 `mdx-JH-AST-v1/H_JH_assumed_v1[assumption-only]`，旧 `AST-J1-mdaa-assumed-v1/H_J1_mdaa_assumed_v1` 仅为同一假设程序的纸面别名，十五读和 `38 S` 只属 J1；D1 独立 `AST-D1-mdaa-assumed-v1/H_D1_assumed_v1`、十四读与 `37 S` 条件证。B4 **新**身份为 `AST-B4-mdai-audit-v1/B4-R19-projection-v1/H_B4_mdai_assumed_v1[assumption-only]/C-B4-mdai-carrier-v1`，旧 `AST-B4-mdaa-assumed-v1/H_B4_assumed_v1` 因字段、价版和布局改变不是别名。三者真实规范字节及 SHA-256 均为 `programHash=unknown`；同书不等于同 AST、证书、账户或来源。

## `mdaj-bridge-consumers`：现行消费者状态与六入口纸面对账（范围修订 13）

**问题、范围、非目标与验收。** 最新[主策退回](./design-review-findings.md#drb5-world-closure-review)要求纠正桥接上节第 358、362 行的来源时序，并核新增程序安装峰；[直接前驱理论](./world-theory-draft.md)的 `mdaj-theory-consumers` 仅作已交付只读结论。范围是首批 A 的 `B4-v1/slice-B4-01` 普通 `k0` 修壳、十九个固定 `readId`、六入口纸面同键比较和 `book-mdu-01/v1` 往返；不新增字段、价、容量、生命规则或第二次付费修补。本轮验收是下表每格能追到现行来源、价版、收据与获准余态；真实 UI、World/VM、规范 hash、实收据及实玩仍未验证。前述旧 `mdag/mdah` 同名键数值是时间性记录，上节 `mdai` 表仅以本节的物理修价与 `559 S` 安装峰更新为现行解释。

**来源与版本。** [物理 `mdai-b4-fields/mdaj-physical-price`](./physics-material-design.md)第 631–710 行拥有十九项 `{endpointId,field,phase}`、`V0…VP`、自然 `C→N→X`、`10=4+2+4 E0`、旧壳 `3q=2q+fragment q` 和 B4 独立 `100=53+47 E0/12`、`32/12→8/12`、`4q=2q+q+q`；旧 `1 M/50→49` 现只属 `mdah-B4-read-v1[pending]` 历史候选。[账本 `mdai-b4-quote`](./mana-ledger-design.md)第 886–946 行独占 `priceVersion=mdai-B4-audit-v1/workVersion=audit-work-v1`、`Audit-B4-v1`、`receipt-B4-funded-v1`、`receipt-B4-read-[readId]-[requestId]-v1`、`payerGrant-B4-v1`、不可取收款和锁/释锁；材料 R0 固定 `2 M/≤21 tick`、十九读 `29 M/≤271 tick`，完整 `n_19=19,n_extra=0` 时本人 `29+5+10=44 M`、条件余 `6 M`。[程序 `mdai-b4-carrier/mdaj-carrier-install`](./programmable-spells-design.md)第 866–938 行拥有 `AST-B4-mdai-audit-v1/B4-R19-projection-v1/H_B4_mdai_assumed_v1/C-B4-mdai-carrier-v1` 的假设设计身份、索引 0–18、`≤313/330 tick`、响应 `314 S` 及安装 `559 S`，本版条件 `Smax=559 S` 且须本体 `C_S−O≥559` 和分项容量同版原读。旧 B4 hash 不是别名。[生命 `mdai-b4-life`](./life-identity-design.md)第 676–721 行与[理论 `mdai-world/mdaj-theory-consumers`](./world-theory-draft.md)第 1239–1293 行只消费同版价、事实与身份；普通壳修不修关键 `k_m/k_a` 或旧 `LifeId`，创建者四证齐才在⑤一次 DeathBarrier、⑥撤其派生未来权。账本的 `M` 不兑换物理 `E0/q`；J1 本人 `32`、P0/P2 各 `1/2`、条件 P1 `1` 的跨账户 `35/36`，D1 自有 `40−26=14` 均不能计入 B4 payer。

**六入口与同书核法。** 推演台在 `book-mdu-01/v1` 保存 J1 同一假设别名、D1 独立程序和 B4 上述新设计身份；B4 逐 `readId/phase/projectionHash/grantIssuerSet` 绑定 `mdai-B4-audit-v1`，不把设计 hash 当运行 SHA-256。演武绑定只引用同书版本、执行者及其字段可见集，不付款、不授权、不补物理包；观察按世界序 20 自然事实、30 裁剪事件、50 有价读、80 条件作用与独立 POST，显示本人**实结** `receiptId` 和获准壳态。返原书改条件/AST、字段投影、读 ID 或事件过滤后形成新书版本，撤受影响的 Quote、读覆盖、`C-B4-mdai-carrier-v1` 容量证和未执行锁，重新核 `V_i/VP`、grant/撤权、价版、`559 S` 安装及响应峰；旧已付与自然/主动已提交事实不退款、不复制切片。鼠标、键盘、手柄、妖兽 AI、实体事件、敌方修士各从相同 `S0/seed` 独立复位，只有规范意图、能力、可见字段、`executor/payer/grant`、`bookVersion/ASTVersion/programHash`、`B4-v1/slice-B4-01/readId/receiptId/priceVersion`、世界序与请求次序都相同，才要求同价、同拒因、同实结原子及同授权裁剪；设备、阵营或事件标签不改变函数。AI、事件订阅者和敌方用自身视野与账户，敌方修士只作入口等价反例，不在首批开发范围。同 `requestId/effectId` 重投仅返原裁剪结果，零新读、零新扣。
