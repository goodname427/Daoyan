# 法术语言、原子作用与跨实体执行：模块详细策划

**版本与状态**：`pilot-agent-intent-2026-09-24`，策划修订 `2`、范围修订 `13`；`module-design / mdn-spells` 续写 `mdc-spells` 模块细则。只读承接已完成的 [mdn-life](./life-identity-design.md)、[mdn-mana](./mana-ledger-design.md) 与 [mdn-physics](./physics-material-design.md)，不替它们重定身份、价格或材料事实。制作人选择元法术 B（收窄可编辑材料域）及载体/授权 B（以实际结构容量判程序资格）。本文件不批准数值、游戏开发或覆盖已采纳 ADR。[世界理论](./world-theory-draft.md)仍是唯一可编辑的公理正文。

## 问题、范围、非目标与验收

当前玩家能在推演台编辑 AST/DSL，在演武场绑定法术；公开目录有 94 项入口，但玩家不能把普通程序、有限记忆和订阅交给任意有容量的实体。[现行编写指南](../../reference/spell-authoring.md#当前能力边界)也明确没有玩家事件订阅、跨次常驻变量或用户自定义实体类型。旧创建弹道、三池、固定伤害、寿命与专名追踪把多个世界作用捆在一起，不能直接解释自然碰撞、遗体或人工生命。

**范围**是定义同一 AST 的表达边界、分析/报价/VM/订阅接口、装载与运行规则、拒绝和跨实体反例，并逐项归位旧入口及十项属性。**非目标**是敲定材料系数、生命/身份阈值、环境回收公式、程序存储容量数字、旧存档自动迁移或实现顺序。**验收**是同一程序只因实际结构、权能、材料和付款来源而呈现可解释差异；每笔作用有资源/物理/生命去向，静态预算不低报且未知价不伪装为零；五种载体的成功及八类失败边界和 ADR/旧数据影响均可复核。此处的“闭合”指给出可检验的候选规则和域外拒绝，未定数值仍需整版审核。

## 表达域与不可组合性

语言保留条件、定次循环、有界列表、函数调用、有限局部值及显式释放；默认禁止递归。程序以获准快照、计算、一次原子世界请求、有限持久记忆和事件/定时再启动组合行为。玩家预设、敌方战术和实体种类不得私有地增设效果。待开发的玩家流程是：推演台编辑同一法术书的 AST、查看权限/材料/动态预算诊断并单步推演；演武场将程序和有限授权装载到有容量的实体，显示逐笔付款与拒绝，返回推演台继续修改。当前 UI 未提供这条完整流程。

**材料编辑域 D 的候选边界**：只接收物理层登记为可编辑、已知 `Q[k]` 数量和来源的惰性固体部位与零件；首批用途限球壳、机关外壳、屏障和锚件。可操作的状态是有界材料分区、局部形状/尺寸、已登记的非生命连接边和承力部位。一次请求须列来源与目标分区、种类/数量上限、连接端点、前后结构版本、废料/热去向和目标能力；迁移、断开或接合不得增造 `Q[k]`，不得越过声明的部位范围。未登记种类或材料精度不足一律 `unexpressible`，不把任意数值写入 `X`。生命关键组织、调节/记忆回路、身份记录、任意物质变换、跨域传送、无限环境吸收及无损回收均在 D 外；“修复”只能改 D 内普通结构。即使后来生命模块认定某回路恢复，也只能基于另行获准的物理事实和 [mdc-life](./life-identity-design.md) 的连续证据，不能由本域推断复苏。D 的具体材料白名单、粒度和可报价价函数仍是设计评审缺口；在其确认前相应请求报待定价，不执行。

**候选最小原子及不可约反证**如下。这里的“不可组合”指在相同授权、价格、提交边界及失败余态下，任意有限次其他候选调用加纯计算都不能生成同一权威事实；未获价格证明的候选仍不开放执行。

| 原子与唯一新增事实                                            | 删除该原子后的反证及材料/价格边界                                                                                                                                                          |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 获准读取 `read`：带时刻与字段裁剪的观察快照                   | 其他调用只计算、移动法力或改变物理态；不能凭空获得受保护的最新字段。订阅只转交已发生且获准的事件摘要，不能代替主动范围观察。须按字段、范围、候选量与观测工作报价。                         |
| 账户转移 `transfer`：账本 `T` 的来源毛扣、净到账及损耗        | 读取、施力和材料改接不会给另一有限账户增加有来源的可用余额；施力内的付款只是消费，不能代替可再支用的到账。须含启动价、容量、可用性 `U` 和受益/退款凭证，禁从已付散逸回收。                 |
| 有反作用的施力 `applyForce`：物理 `A` 的双边冲量              | 读取和转账不改动量；材料改接最多改约束/形状，不能在相同瞬间给原有两体付费冲量并交代反作用。须证明有效质量、反作用路径、功及热上界；未知换算拒绝。                                          |
| D 内局部迁移/改接 `editMaterial`：物理 `A/X` 的材料与连接变化 | 读取、转账和施力可能导致自然碰撞破损，却不能在无接触且相同余态下把指定有源材料迁入指定连接并保持受控结构；随机撞击也不满足原子提交/权限。须证明 `Q[k]` 守恒、部位能力、热/废料与有限工作。 |

`断开` 与 `接合` 是同一 D 内改接原子的参数化方向；**结构建立**是从获准材料分区迁移、改接、装载有限程序、转入有限余额及可选初始施力构成的多笔流程，不增设“创建”原子。各笔分别提交，后一笔失败时已成材料结构仍按默认物理存在；不能宣称整条创建流程一次成功。若未来发现现有 `editMaterial` 无法表达某种新结构，先给出同权限/价格/余态的不可组合证明并交整版复审。事件登记、装载、记忆赋值是有容量的程序/权能管理，不自动成为新世界作用。

**追踪**＝获准读目标位置、比较快照与上次方向、付费施力、下次定时重启；失供后仅保留已付惯性。**碰撞伤害**＝[物理模块](./physics-material-design.md)一次自然接触 `C` 对两侧 `X` 的改变，生命损失是后续判读；碰撞响应若另施法须另付 `S/A`，同一动能不可经旧 `damage` 池二次释放。**自修复**＝获准读自身结构、取得有来源的余额、取得真实材料、付费局部迁移/接合，再由生命层判功能；缺任一前提不会得到专名豁免。[理论 B4](./world-theory-draft.md#跨实体与边界反例的交易明细)限定本程序只能修补窄域内结构：关键生命回路在域外时，复苏请求明确返回 `unexpressible`，已完成的接触、转入和读取各自保留，不以修补结果推断同一身份。接力护送、反制、定时护盾和失供告警同样是普通程序。

### mdc 共同报价、逐原子 tick 与普通程序边界

四原子是**候选作用类别**，不是四个已能执行的新元法术。每个作用都调用 [mdc-mana 的同一部分函数](./mana-ledger-design.md#共同报价函数及当前可表达域) `Quote(x)=(pM,pAttempt,Wmax,ΔQ[k]max,τmax,Smax,reserve,settle,certificate)`；`x` 必含公开版本化的目标/局部区域、材料前后态、反作用及耗散、来源和 `U` 前后界、授权/付款方、执行结构、模拟窗口与程序工作。`pM=ceil_1e-6(max(pFloor_D,F_D(x)))` 仅在已证明的正价下界、单调单位换算和有限证书域中有值；未登记 `F_D/pFloor_D/pAttempt` 为 `unknownPrice`，域外材料为 `unexpressible`，两者均不落成功账。当前没有经批准的 `M↔功/Q[k]` 兑换证书，所以以下有正做功或主动材料变化的“成功”都是**具备证书后的纸面条件**，不能借旧 `effectCost` 或高余额执行。

算法工作量统一计整数 tick：`τrequest=τAST求值+τ范围/权限检查+τ报价证书求值+τ实际世界搜索/求解+τ提交及记录`，每一项由描述符声明可复算的非负上界和输入大小；实际未做的项不得记已做 tick。列表/循环按声明容量和次数乘入，事件按允许唤醒数与并发峰值计；默认物理自然演化无玩家 VM tick，`castSpeed` 只改变 tick 偿付速度。静态 `τmax/Smax/毛 M` 对有限输入区间取保守上确界，不得小于实耗；动态但有运行限额的路径逐次复验，永久订阅总额报无界。一次已付尝试工作在成功 `pM/τ` 中只占一次，拒绝只保留实际已完成且事先可报价的尝试及 VM 工作。

| -------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |

`read→有限记忆→applyForce` 按目标新位置多次重算为追踪；从一载体获准读取、转入并给下一载体装载同一程序，可形成接力护送，前一主体死亡不转授私权。运动和材料阈值造成的碰撞损伤是自然 `C/X`，响应若要额外施力必须新 `T↔A`，不可从旧固定 `damage` 池二次释放。真实 `Q[k]` 供应下的外壳/墙面/机关连接修复由 `editMaterial` 完成。传送、任意物质变换、生命关键组织/记忆回路编辑、死者原 `LifeId` 复活及无限环境吸收均在当前 D 外；命名为“修复”“追踪”也不能偷开这些能力。

## 唯一程序合同与状态所有权

```text
源 DSL / 蓝图 ↔ 版本化 AST（唯一 IR，含 sourceSpan、类型、有限容量与作用 ID）
  → analyzer(AST, 载体能力上界, grant 范围, 价格目录版本)
      = 诊断 + 神识/结构峰值 + tick/法力毛支出界 + 动态/无界条件
  → compile(AST) = 可定位指令；不在编译器改写作用或价格
  → request(executor, programId, instructionId, targetOrDirection,
            simTime, grantId, payerAccountId, causeId, snapshotVersion)
  → authorize / quote / reserve / revalidate / atomicCommit / emit
  → VM 继续或停止；订阅器仅按已提交事实唤醒新 VM
```

AST 的作用节点引用同一版本的原子描述符：参数及材料域、目标能力与字段权限、结构要求、报价函数、动态边界、尝试价规则、提交与结果类型。分析器用符号范围调用同一报价定义，VM 用实参和最新世界状态调用它；事件订阅节点也在同一 AST 中声明事件类型、字段投影、过滤谓词、记忆槽和响应入口，不存在另一本订阅脚本或编辑器价格。`descriptorId/version`、`programHash`、`sourceSpan` 和每次 `requestId/causeId` 随编译指令、报价、事实与诊断传递；同一请求重试凭 ID 幂等，不能再收费或再施力。旧 [`pricing.ts`](../../../src/core/pricing.ts) 的 `effectCost`、`sensePrice`、`controlPrice` 与 [`vm.ts`](../../../src/core/vm.ts) 的调用付费、tick 债务是当前实现证据，尚未给新物理/材料价格。`unknown` 价不是 0，`dynamic` 有运行限额但不能声称有限静态总价，永久订阅/维持明示无界总额。动态目标、距离、关系、材料量、事件次数、可用余额和环境 `U` 均标条件；即使有转入或预计退款，毛支出不以净额抵消。

| 所有者                                 | 本模块交互与不变量                                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 程序/载体                              | `executor` 是有可运行结构的实体，程序 AST/有限记忆/订阅挂在它的结构容量上。owner 是所有权，controller 是当下控制权，二者均非提款权。装载需结构槽、计算/感知/作用能力和授权，容量按程序、最大活变量、列表容量、持久记忆、订阅及并发 VM 峰值累加；不足即拒绝装载或新会话，不按 Actor/Projectile 白名单放行。神识表示占用并可释放，不是可退法力。                                   |

程序执行成本分三层：指令和真实循环步计 VM tick，局部/持久状态与订阅计神识及实体结构容量，世界读取和作用另按不可折扣部分计法力及附加 tick。`castSpeed` 只改变偿还 tick 的模拟耗时，不能减少 tick 数；随机源和事件排序须可重放。优化只有确实减少观察次数、扫描范围、工作步数、状态峰值或物理作用时才降低相应价格，不按法术名称给折扣。分析按最坏容量及并发计算峰值；运行中每次调用、事件唤醒和共享账户竞争仍需动态重验。

### 有限记忆、容量和预算的统一核算

每个装载实例显式声明 `memorySchema`（固定槽数、每槽类型/最大长度、版本与初始化值）、最多订阅数、每订阅最大待运行响应数、并发 VM 上限及到期/卸载策略；持久值只能通过有权的本实例事务写入，不能从别的实体私有内存复制。列表容量和字符串/句柄集合上限计入静态峰值；句柄存储不延长目标寿命或授权。一次响应读到版本化记忆快照，提交写入时按实例序重验版本；竞争冲突返回 `staleMemory`，已付读取与 tick 留存，未提交的新值不留半写。死亡/结构瓦解时内存停止读写；只有事先独立的实例及授权可按自身到期条件保存可公开槽，死者私有槽清除或封存而不可继承。

容量分为载体物理可运行槽 `C_structure` 与当前可用神识 `C_shenshi` 两个同时必须满足的界：程序字节/指令、持久槽、订阅/事件引用及最大并发栈帧各有结构占量；运行中活变量、列表、响应快照、待派发引用和并发峰值各有神识占量。装载时分别证明 `结构声明峰值 ≤ C_structure` 与 `神识声明峰值 ≤ C_shenshi` 并预留常驻项，启动和每次扩容再对当前结构/共享神识重验；结构受损使容量收缩时按稳定实例序停止超额会话并释放占用，不删除既成世界事实。不得用 Actor/Projectile 类型或 `shenshiMax` 一个显示数代替实际结构证明。静态分析对有限调用路径给毛法力、总 tick、神识峰值和结构峰值的保守上界；动态范围有明确实参上限时按上限计，永久事件或维持报 `unbounded` 且逐窗口限流。若报价函数、材料承受或 `U` 无可信上界，报 `unknownPrice` 并拒执行，不输出虚假的零价或低报数字。

## 原子提交、事件与玩家可见结果

统一请求先验载体结构/能力、grant 的字段和目标范围、材料表达域，再用**不含私有值的可公开条件**报价；随后预留本笔余额/容量，在最新状态重验目标、来源、材料和权能，成功时同一个提交点记法力转出/接收、`A` 与 `X` 变化，并排入已提交事实。未提交本笔不留下部分付款或作用；若合法尝试费已单独完成，则其价与 tick 在 UI 逐笔可见，成功价不重复加算。先前读数、转入、自然 `C`、已做 tick 和其他响应不回滚。若目标在付款前消失、被遮挡或撤权，返回不泄密的相应拒绝；若获准查询范围内确无目标，返回成功空集合/空句柄和该次已发生的读取费，不伪造作用。拒绝结果不携带私有值，日志、报价和 HUD 均不可旁漏。

**合法尝试价规则**：语法/类型错、无结构或能力、无 grant、域外请求、报价未知、报价前已知的目标不可探查，均在成功世界观察/作用前拒绝，不扣世界法力；已经执行的 VM 指令 tick 与占用仍照实留账。通过能力、授权及公开参数预检后，若确需世界搜索或读取，先把该次有界观察作为独立 `read` 报价并获准付款，故获准空查询也收费；随后申请作用。申请作用时仅可按事先公开的 `attemptQuote` 为**实际完成的有界世界求证**结算一次，给独立 `attemptId/T` 与工作量，不得随私有目标状态变化，也不得从未提交的效果价中隐扣。成功价已含同一工作，失败从互斥预留结算已做尝试并释放剩余锁额。因最新状态撤权、目标消失、材料被抢或共享账户不足导致失败，均无成功 `A/X/T_effect`；未做世界工作则尝试法力为零。`P0/R0/K0/V0` 已有窄域候选尝试价；其他世界求证仍缺目录证书，禁止先执行后定价。重复 `requestId` 只返回原结果。

**并发余态**：同一 `C` 派两个响应 `S1/S2` 时依 `(simTime, worldSequence, subscriptionSequence)` 启动，每一原子提交前读最新 grant、记忆版本、结构、材料和共享账户。若 `S1` 已付读取、转入、改接并耗去最后材料或余额，`S2` 可以保留自己已付的读取/合法尝试工作，但释放未提交预留，返回 `missingMaterial` 或 `insufficientFunds`；`S1` 的 `T/A/X`、自然 `C` 和之后阶段⑤生命结果不回滚。若 `S1` 导致死亡撤权，`S2` 在派发前失去派生授权时直接丢弃/拒绝，不能凭旧快照提款或读私值。两者争写同一记忆版本时只有先提交者更新记忆；后者获 `staleMemory`。同刻遵循理论的①自然 `C/X`、②预先到期补源、③到期主动作用、④维持/失稳、⑤生命判定撤权、⑥事件派发；阶段⑥新补源不能倒救本刻阶段④。事件响应造成新的结构事实，在下一个响应边界前复判生命及撤权。

事件只引用已提交的 `C/A/交易/生命` 事实，给每名订阅者按提交和派发时权限分别裁剪字段；它不是免费主动监控。先完成物理/账本/生命提交及必要撤权清理，再按模拟时刻、世界事实序、订阅序派发独立 VM；共享账户逐笔竞争。**继续沿用 ADR 0020 的现行硬上限作本设计的安全边界**：因果根深度 0–8，根响应尝试 256，每个从世界起点对齐的 0.25 秒周期 256，世界待派发信封 1024，活跃订阅每账户 32/世界 256，活跃响应同账户同法术 8/全部 32，单响应 600 tick/200000 指令/调用深度 32；授权或实例可收紧，不能扩张。订阅、候选、记忆和响应占实际结构及共享神识，纯引擎队列另受 1024 配额。有效候选在领域拒绝/欠费前已占根与周期尝试次数，去重者不新开 VM；满额直接拒新派发项，不延到下一周期偷跑。若后续新 ADR 改这些数值，须同时改分析器与运行时合同。[当前测试](../../../test/core.test.ts)只证明旧事件限额路径，不证明玩家可给所有载体订阅。队列满只丢未运行的响应并累计有界摘要，不重做或回滚自然接触、阶段⑤撤权或清算，也不递归生成失败事件。暂停冻结模拟及派发；恢复先结到期，再按稳定序处理意图。

事件信封的公开基础域仅为 `{eventId, rootEventId, simTime, worldSequence, type}` 和订阅者本身有权知道的原因摘要；`C` 可选接触部位/方向/冲量区间，`A` 可选自身作用及结果，`T` 只给本人账户的毛扣与到账摘要，`LifeTransition` 只给被授权的阶段/终止摘要。对方句柄、精确位置/材料、账户余额/来源、私有 `LifeId`、记忆、授权及身份连续记录**默认不在载荷**；每个可选字段须由事件发生时和派发时的 grant 交集允许，并受订阅声明的字段上限裁剪。事件是否存在也可能泄密：对无权观测的他者事实不建可见订阅候选，不送区别性“被隐藏事件”提示；需要额外字段时另行获准付费 `read`。终止摘要的只读性不含死者私有身份；事件队列元素仅存事实引用、裁剪计划和有限因果键，不复制无限快照。

**碰撞到响应的稳定顺序。** 物理层先按连续扫掠求已证实的最早接触，`εt` 内共享实体/部位/约束路径的候选冻结同一接触前态并联立求解；组内以 `(最小实体 ID, 最大实体 ID, 部位 ID, 接触段 ID)` 规范键派事实序，而不靠数组/玩家顺序逐个解耦合碰撞。组提交后用新速度和 `X` 重算下一个组；同部位同组只有一个合计 `X`，其 `parents` 可引用多个唯一 `C`。未裁定擦边无 `C`、无碰撞事件。阶段⑤的生命事实和撤权完成后，阶段⑥按 `(simTime, worldSequence, subscriptionSequence)` 派发，订阅候选在事实提交时冻结，派发前复核，后注册者不追收旧 `C`。同根 `(rootEventId, 稳定绑定标识, type, sourceId, targetId)` 只响应一次；后继排在当前事实的全部候选之后，跨帧仍保留根与深度，不能借重建订阅或定时器洗根。`C` 事件只载获准的接触方向/部位/冲量区间等只读投影，不能重扣物理损伤。

**死亡屏障与独立授权。** 阶段⑤或响应后的生命复判确认死亡时，先提交一次性 `DeathBarrier`，使主体不可操作，原账户置 `closing` 并立即禁止提款、回复、转入和退款接收；再停主体 VM/维持/动态订阅与未来输入，撤销主体派生控制和提款 grant。已发射实体保留已付惯性；仍存活的独立主体凭自己的普通 grant 行动。ADR 0020 允许的独立死后主动行为在本轮候选首批关闭，按下文 `mdn` 合同拒绝。随后结清已做功、释放未提交预留，按来源凭证给**仍活且有效**的固定受益账户至多一次退款；死者账户不可接收，其份额进入具名终止损耗。最终原账户 `closed`，阶段⑥只给仍获准的观察者发裁剪终止摘要，死者自己的响应不启动。死亡清理先于队列检查，队列满也不漏撤权/清算；已提交 `T/A/X`、自然 `C` 不回滚。身份 `unknown` 时冻结仅凭旧 `LifeId` 的私权，但不伪造一次死亡。

**死亡后独立授权的待审期限合同**：以下是未来开放时的必要条件，不构成首批签发许可。须在仍有效的授权链下指定不可延长的模拟时刻 `expiresAt`、最多响应次数 `maxWakeups`、最多毛支出 `maxGrossDebit`、允许的事件/操作/字段/目标集合、独立付款来源及固定退款受益人；实际有效期取各限额、签发者明确撤销条件、载体结构存续和账户有效性的**最早结束点**。不得用 `0`、空值或“直到死亡后”表示无限期限，死亡后不可由死者 grant 续签、充值、扩大目标或转授；届时清理订阅/记忆引用与未用预留，清算按凭证一次完成。签发者若只是死者生命主体，其派生 grant 仍在死亡时撤销；真正独立的 grant 必须由另有权的来源预先签发并以独立账户/预付池担保。对于遗体，许可只能覆盖 D 内普通残余结构和公开终止摘要；原 `LifeId` 私有字段、旧记忆和死者账户始终禁止。`expiresAt` 的数值上限、是否允许何种独立签发者及遗体可见字段须随 ADR/整版评审定稿，未定前不开放死后运行。

## mdn 首批程序域、竞争与桥接移交

本节以 `mdc-spells` 的四类候选事实为基底，采用 [mdn-physics 的有限物理域](./physics-material-design.md#连续碰撞的规范化与精度边界)、[mdn-mana 的 `D0/P0` 纸面证书](./mana-ledger-design.md#单一-quote域与静态证书)和 [mdn-life 的死亡屏障](./life-identity-design.md#死亡与身份事实的程序授权和界面暴露)。这里的首批域是**待整版审核的纸面候选**，不是现行 VM 已能执行的入口。`P0` 仅给 `D0` 的正功施力、惰性 `k0` 改接和指定封闭来源转入证书；字段读取还须另有获准的 `read` 价与投影证书，不能挪用 `P0` 作用价或 ADR 0019 旧探查价。证书缺失、证书版本失效或物理结果未裁定时保持 `unknownPrice`/`unexpressible`/`contactUndetermined`，不编造成功。

**容量与稳定序。** 装载声明固定 `memorySchema`（槽数、每槽最大长度和初值）、有界列表、订阅数、响应并发数、`expiresAt` 与有限运行窗口；容量证明为常驻程序/记忆/订阅占量加并发 VM 栈、快照和待派发引用峰值，分别不超过当前 `C_structure` 与 `C_shenshi`。默认不递归，单响应不超过 ADR 0020 的 `600 tick/200000 指令/调用深度 32`；每账户订阅 `32`、全世界 `256`，同账户同法术并发 `8`、事件响应合计 `32`，每根和每 `0.25 s` 世界周期最多 `256` 次尝试，根深度最多 `8`，待派发信封最多 `1024`。声明可收紧，不可放大；永久订阅的**总价**为 `unbounded`，每窗口仍须证明配额与余额。记忆写入按实例稳定序复验版本，第二写冲突 `staleMemory`，前笔记忆与已付工作保留。物理先冻结同刻耦合接触组前态并联立求解，再按规范部位键给唯一 `C/X` 序；阶段①自然、②既有补源、③到期主动、④维持、⑤身份撤权、⑥事件派发。派发按 `(simTime, worldSequence, subscriptionSequence)`，跨帧续跑按稳定实例序；候选在事实提交时冻结，派发前再次验授权，后注册不追收。每个原子在最新版本上串行预留/复核/提交，同一账户没有各响应的余额副本；响应衍生事件等本事实候选尝试完再派发。

**合法尝试及账务。** `P0` 的 `pAttempt=1 M/τAttempt=2 tick/SAttempt=2` 仅用于能力、grant、公开参数及已知成功 `Quote` 预检后，真实完成了一次有界世界状态求证而本次作用未提交的请求。`Tx-attempt` 独立记录，数值不随隐藏状态变化；成功报价已含同一求证，不再加收。无权、域外、未知价、已知欠费或根本未做求证，均没有尝试法力交易，已执行 AST tick 仍计；若需先观察目标，另获准付 `read`，其快照和扣款不因后续失败退回。提交前复验余额、材料、结构和字段权；失败按[理论正文的互斥结算](./world-theory-draft.md#共同报价与唯一因果记录本轮策划推导)从本笔预留结清已做尝试并解锁其余，已提交的自然 `C/X`、来源 `Tx-transfer`、读取及 `Tx-attempt` 均不回滚。两项并发响应各用最新共享可用余额锁自己的互斥上界；尝试费显式列独立交易，不得从已结效果价暗扣或在失败后额外再扣。

**独立死后 grant：首批执行域关闭。** `mdc-spells` 所列 `expiresAt/maxWakeups/maxGrossDebit` 是必要字段，不足以签发：ADR 0020 的“账户本人签发”与“关闭死者账户”同时成立，而当前合同未指定可代签的独立账户主体、预付池的法律/账本所有者、最大模拟期限及遗体字段的最终许可。故首批 `surviveControllerDeath` 一律返回 `postDeathGrantUnavailable`，不存在可签发者或有效预付来源，最大可执行期限、毛额度和响应次数均为 **0**；不得把 ADR 0020 的 `1/4 s` 调度周期误当授权有效期。未来若开放，须由**死亡主体以外仍有效的付款账户本人**事前签发不可转授 grant，将毛额度从其有凭证的有限余额锁定或转入独立预付池，并由字段权利人独立签读取范围；明确正数且有限的最长模拟期限、总毛额、单笔额、响应次数和固定退款受益人，经新 ADR 审核后才能建立非零域。签发时必须列绑定载体/程序哈希、操作与目标、可读字段、撤销条件及来源凭证；死亡时不能补签、续费、继承死者私权。首批可见遗体字段仅公开终止摘要和获准的 `D0` 残余结构；原 `LifeId`、记忆、账户、身份连续记录和私有回路不在死后 grant 可读域。过期、次数/毛额用尽、签发者撤销或结构失效，以最早者先停新唤醒并清理未提交预留；已用毛额和已付工作不退，未用且有来源凭证的储备按固定受益人一次结算，死者账户不能收退款。`(lifeIdRef, terminalSequence)` 重复死亡通知只回原 `DeathBarrier/settlementRef`，不再撤一次、退一次或重派事件。

创建者死亡的信标余态因此取决于**独立于创建者生命主体的现有合法身份**：普通从创建者派生的信标主动订阅立即撤销，球壳/锚件和已付惯性保留，预留按凭证清算；不得继续 `B3/B2/B4`。另一个仍活且拥有自身账户与执行结构的人工生命或其他主体可按**自己的普通 grant**继续，不算死后豁免，也不得读创建者或遗体私值。遗体再损只增新 `C/X`，不重复死亡。关闭独立死后运行时，创建者存活只满足信标授权前提；`B3→B2→B4` 还须逐笔有来源转入、`R0` 获准公开壳体读取和 `P0/D0` 惰性改接报价。`mdo-mana` 已给此窄域读取候选价，不等于任意读取或本轮游戏代码可执行。创建者死亡后，派生程序只剩物理余态；不把其名称当作复苏或自动存续许可。

**交给 `mdn-bridge` 的规范接口。** 输入统一为 `{requestId, programHash, descriptorId/version, executorId, contextId, grantId, payerAccountId, targetOrDirection, fieldProjection, snapshotVersion, causeId, simTime, priceVersion, maxGrossDebit}`；设备、AI 或事件只形成同形 AST 请求，不能由 UI 帧改变顺序。结果至少有 `{requestId, status, reasonCode, quoteRef, actualGrossDebit, attemptTxRef?, effectTxRef?, C/A/XRefs, observedAt, worldSequence, remainingAuthorizedQuota?, visibleFields}`，所有余额/额度仅向有权查看者显示。拒绝码：`noStructure/noCapability/unauthorized/unexpressible/unknownPrice/contactUndetermined/insufficientFunds/missingMaterial/staleMemory/queueFull/grantRevoked/expired/postDeathGrantUnavailable`；同一不可见目标不以拒绝码或报价差别泄密。事件基础字段限 `eventId/rootEventId/simTime/worldSequence/type`；接触部位/方向/冲量区间、本人交易和获准生命阶段只按订阅声明及提交/派发时 grant 交集裁剪。无目标的获准读取显示带时刻的付费空结果；未裁定接触不发碰撞事件；失败反馈列已完成 tick、已付尝试与较早交易，绝不说“整条程序退款”。

旧 `创建弹道/设置法球追踪/伤害/life/HP/三池/owner` 不自动换算 `D0` 材料、`P0` 价、`LifeId` 或 grant；未证等价的 DSL/蓝图/存档保留原文和 `sourceSpan`，在新规则下拒绝或隔离预览。ADR 0020 的稳定派发、上限、双时点裁剪、共享余额和死亡幂等清算继续约束本候选；其三池预付、固定 damage/life、`surviveControllerDeath` 既有窄语义不授权通用死后 AST。开放 `D0/P0`、新的接触/生命事实或非零独立 grant 前须由整版审核及新 ADR 明确覆盖、迁移和回退；本任务不实现法术、预设或存档转换。

## `mdp-program` 首批载体容量、装载与桥接合同

**问题与范围**：`mdn-spells` 给出通用不等式，却没有证明修士、法球、机关和自维持人工生命各有多少真实感知、记忆、执行与待派发空间。此节只消费 [mdp-physics 的承力/回路证书](./physics-material-design.md#普通行动与两类生命结构的增量证书mdp-physics-候选)、[mdp-mana 的 `A0/K0/V0` 报价](./mana-ledger-design.md#普通行动代谢与封闭回收账mdp-mana-条件候选)及 [mdp-life 的两实体判据](./life-identity-design.md#mdp-life-两实体证书与逐格裁定)，界定纸面装载、逐笔授权和桥接输出。**非目标**是凭实体名称批准硬件数值、开发入口、关键回路编辑或新的死后授权。验收时必须拿到实体逐体结构证书、同一 AST 与同一报价版本，并逐笔复算成功、拒绝和保留事实。

### 逐体有限容量证书及拒绝顺序

神识加总按同一报价构成：驻留 AST `8 S`，程序记忆每槽 `1 S`，订阅/队列首引用 `2 S`；原 `mdq` 只按读快照、局部列表及 VM 栈 `8 S`，得到 M1/J1/A1 `20 S`、B1 `19 S` 的**基线**。下文 `mds-capacity-1` 将 B4 的 `9 S` 帧及第二在途引用计入，整路径峰值分别上修为 B1 `20 S`、M1/J1/A1 `21 S`，基线不可用于装载批准。AST 上限不是 AST 实际占用；此证书选择其驻留占量 `8 S`。响应独立有 `SRead=8`，已包含在峰值响应项，不重复相加。各自单响应 600 tick 上限含该请求全流程；H 的位置读取 `9 M/10 tick/S=8` 与屏障施力 `12 M/6 tick/S=4` 分属原子，须在同一帧中按序执行并按整响应预算验，或有另行排程证书才能分帧。储池 70/60 也只说明最大可持有，不给 H/B 所需资金或来源签证。

生命周期峰值按“常驻 + 同时活跃的有限状态 + 并发帧/信封”取和，而非把串行总消耗误算成同时占用。基础负载均为上表一帧/一信封。H 在 M1 运行时再需一个方向槽（表内记忆）及最多一个待响应信封，峰值为一引用 `20 S`、两引用 `21 S`；如果第二个旧响应仍占执行帧，则新 H 唤醒需等待，第三引用 `queueFull`，不能凭世界 1024 上限突破本体 2。B1 同刻接触 `C` 到达时，一个活动信封和一个执行帧占满本体 1；同刻第二个 `C` 不建立第二份 VM，返回 `queueFull`，已提交自然接触仍留存。J1/A1 各可有 2 个本体引用，但只有一帧，第二个在途请求排队占位，不并发执行；第三个拒绝。卸载/释放只在响应终结且事件引用清算后减神识，不能以卸载抹掉已提交 `Tx/A/X`。

每次结构损伤、连接/传感器/执行器变化、字段权限版本改变或储池边界变化，先冻结新装载和新唤醒，签新 `XVersion/structureVersion` 并重测分项；旧证不跨版本沿用。损坏后若结构尚存但峰值不足，按稳定 `(instanceId, subscriptionId, sequence)` 顺序保留可容纳实例并停其余会话，停派不撤回已提交接触、扣款、材料变化或已发事件事实；内存只保留仍具承载部位且版本兼容的槽，其余变 `staleMemory`/不可读。测量本身缺项或版本不一致返回 `capacityUnknown`；测得容量低于声明但仍可证返回 `capacityFull`；队列运行态无空引用返回 `queueFull`。不把损坏默认为容量零，也不把过期证书当满额证书。

**问题、范围、非目标与验收。** `mds-capacity-1` 的 21/20/21/21 S、4096 B 与 600 tick 是候选负载/安全上限，不是装载许可证。本节只消费 [`physical-mdt-1`](./physics-material-design.md) 的结构与 `EL-attack-01` 条件物理包、[`mdt-ledger`](./mana-ledger-design.md) 的 `AT0` 独立报价、[`mdt-life`](./life-identity-design.md) 的 `LifeAssessment/DeathBarrier`；不创造上游批次、100 M 攻击档、关键材料编辑或已运行游戏证据。验收要用同一 `entityId/XVersion/structureVersion/sourceLotId/energyLotId/materialLotId/programHash/ASTVersion/priceVersion/grantVersion/assessmentVersion/simTime/worldSequence` 重放下面每个边界，并保存实测原始值、仪器校准、误差、版本与失败事实。当前 `LoadTx=∅`、正功及攻击 `Tx/A=∅`，故所有正向链均为未来齐证时的**条件证书**。

### 逐体结构最小量与误差

对每个容量维度 `d`，由有权量测者签 `partId, measurementDomain, measuredLower_d, error_d, faultCase, expiresAt`；只在 `measuredLower_d−error_d≥required_d`、部位连通/校验读回成功、同版且其余共享占用已扣除时准入。整数位、AST 节点、字节、信封、帧和材料计件要求精确整数读回，`error=0`；不能量到这一精度时 `capacityUnknown`。神识及 M 池以自身单位记录保守下界和非负误差，不拿名义 `shenshiMax/manaMax` 代测值。物理能源四读各误差 `≤E0/12`，逐种材料计件误差 `0q`，仍须由物理模块证明取得和装载；程序容量误差不能抵销物理误差。下表“≥”是测试夹具的**最小承载需求**，并非实测结果；AST `256 节点/4096 B` 是此负载的双重上界，实际编码还须记录真实长度、哈希、索引/元数据字节与校验开销，结构页按总实占取下界。

## `mdu-program`：逐体容量、并发与程序预算纸面合同（范围修订 13）

**问题与范围。** 本轮只核对已完成的 [`mdu-source`](./tasks/module-design-mdu-source.json)、[`mdu-ledger`](./tasks/module-design-mdu-ledger.json)、[`mdu-life`](./tasks/module-design-mdu-life.json) 三个直接前驱，将其纸面包、逐笔账和撤权边界接到四体程序证。验收是逐部位可测下界、同刻峰值、有限路径静态式及反例余态；非目标是给无证 AT0 定价、将纸面向量写成现场读数、批准关键回路编辑或运行游戏。`mdu-source` 仅给 J1-H2 和 B1-B4 的有限取得/装载测试向量，实际四读与正向 `LoadTx` 未取得；M1 起步、M1-H2、K0/V0、AT0 仍缺各自包。`mdu-ledger` 的 `lJ/lB` 装载毛价未定，`p_AT0=unknownPrice`，旧 25/33 M、9/11 tick/S6 是历史候选。`mdu-life` 尚无 M1/A1 的自然响应、保存与三链实证，当前 `LifeAssessment/identityRelation=unknown`、`DeathBarrier=∅`。以下所有成功数字都是**假设每笔另行齐证**的纸面计算，不能作为已运行验证或当前可执行价格。

### `CarrierCapacityCertificate=mdu-program-1` 的逐体原读合同

### AT0 帧、最坏路径与同版静态式

AT0 只消费 `mdu-source` 要求但**尚未取得**的独立 `Acquire-attack-01/source-attack-01/EL-attack-01`、执行器—目标—锚或喷出物、材料/热/反作用与四读；不能借 `EL-J1-H2`、`EL-B1-B4` 或 K0。独立毛价只可写 `p_AT0=c0+cw·ceil(W_attack/E0)+cj·ceil(|J|/J0)+cn·n+ck·k`，其中系数和正功格须由 `mdu-ledger` 签定；目前 `p_AT0=unknownPrice`。攻击帧明确保留请求/授权/付款来源、目标和接触、逐种材料、反作用、正功/热闭合及预留/提交状态。令有界 AST 的分支集合为 `B`，每个分支的列表最大容量为 `L_b`、循环最大迭代为 `N_b`，**仅对原子目录 tick 之外的外层节点**按逐节点权 `t_i` 计数；`τ_AT0=max_b Σ_i N_{b,i}·t_i + tAuth+tContact·n+tMaterial·k+tWork·w+tCommit`，列表遍历取 `L_b` 次并计入 `N_{b,i}`，短路分支不得用平均路径，也不能把同一授权/求证节点双计。`S_AT0=max_b(同时活请求+来源+目标+材料+反作用+预留+栈+列表+快照)`；无列表容量、循环终界、递归禁令或帧实占读数则 `τ_AT0/S_AT0=unknown`，不能套历史 `9/11 tick/S6`。若一信封、一判断、一仲裁，响应外层再加 `2 入队+2 唤醒+1 判断+1 仲裁=6 tick`；第二在途引用另占位和 `1 S`。新 AST 或描述符、价版、执行器变化均重新枚举最坏路径。

### H、B 与普通行动的逐体装载条件

`H` 指获准位置 `read→有限记忆→applyForce` 的接力护送，`B` 指 `C-B1` 可见接触后 `transfer→read→D0 editMaterial` 的活跃信标；两者只是 AST 组合，**没有追踪或修复专名原子**。程序本体、订阅和必要记忆须先按上表装载，grant 必须绑定载体、程序 hash、付款方、字段、目标、单笔及总毛额、到期、撤销条件。装载有效不等于每次调用成功：每次唤醒和每笔提交在最新 `X`、容量、余额与 grant 上再验。`H` 至少要有可读位置的 `R0`、一个方向记忆槽、执行帧、队列位、逐次付费的 `A0/P0` 施力及真实反作用；`B` 至少要有可见 `C` 订阅、执行帧、队列位、封闭来源 `transfer`、获准 `R0` 外壳读取、`k0` 供应和 `D0/P0` 惰性改接。普通行动可不装订阅/记忆，但凡由 AST 请求仍要执行帧、相应部位和本笔 `A0` 证书；生命自身 `K0/V0` 窗口独立结算。

H2 的 `12 M` 只对应已登记屏障施力 `P0` 的一笔 `Tx↔A`。若修士须先起步/续步接近屏障，或机关须另以推杆推动球，该动作另按各自有证 `A0` 记 `12/19 M` 或对应推杆报价、接触段、反作用与 `Tx↔A`；不得拿 H2 的 `P0` 付款同时结算载体位移。缺脚地/推杆证书仅拒相应 `A0`，不自动否定已经独立获证的 H1 读取；缺 H2 的目标/反作用证书则不签屏障施力。两笔是否都在同一实例、同一窗口可用，还须逐体验证执行帧、tick、神识、储池与授权的合计峰值。

### 四原子报价、双时点授权与失败余态

### 给 `mdp-bridge` 的固定输入、可见结果与域表

程序 hash 取 `SHA-256("daoyan-ast-v1\0" || canonicalUtf8(AST))`：AST 用唯一 IR 的固定节点种类/类型/字面值/有界容量/操作 ID 与顺序序列化，键序、数值单位及字符串编码规范化；`sourceSpan`、注释、编辑器布局和输入设备标签不参与语义 hash。程序内容、容量声明或操作改变即换 hash，旧绑定/grant 不能默默沿用；`descriptorId/version`、`priceVersion`、载体结构版本、grant 版本、事件先史与模拟种子作为**同形复算键的独立字段**，不能用 hash 代替授权。桥接应固定 `{programHash, ASTVersion, descriptorId/version, priceVersion, executorId, carrierCertificateRef/XVersion, grantId/version, payerAccountId, sourceRef?, fieldProjection, targetOrDirection, requestId, causeId, simTime, worldSequence, seed}`，鼠标、手柄、AI 和实体事件只生成同一规范意图。

结果固定 `{requestId, programHash, status, reasonCode, quoteRef?, actualGrossDebit, attemptTxRef?, effectTxRef?, C/A/XRefs, observedAt?, worldSequence, visibleFields, priorCommittedRefs}`；`visibleFields` 只含本人获准的公开位置/运动/惰性外壳摘要、本人交易毛额及净到账、获准生命阶段/终止摘要和独立 `read` 的裁剪快照。事件基础域仍仅 `{eventId,rootEventId,simTime,worldSequence,type}`；接触部位、方向和冲量区间须双时点可见。余额来源、他人账户、原 `LifeId`、私有记忆、关键回路、grant 明细及身份连续记录默认隐藏；隐藏目标与不存在目标同形 `deniedOrUnavailable`，报价、时延和错误文本也不得泄露差异。失败输出可显示 `capacityUnknown/noStructure/noCapability/capacityFull/queueFull/unknownPrice/unexpressible/contactUndetermined/insufficientFunds/missingMaterial/staleMemory/grantRevoked/expired/postDeathGrantUnavailable` 及物理的 `undeterminedMass/undeterminedMaterial/undeterminedCircuit/undeterminedContact`，但私值越权合并为不可区分的拒绝。`priorCommittedRefs` 只引用观看者有权看的已付事实。

## 待整版审核的闭合点

推荐先用 `D0/P0` 的纸面候选检验有限惰性材料、可报价施力和封闭来源；玩家会看到域外“尚不可表达”诊断，代价是暂不能写生命组织、任意转化与开放吸收。**本轮已给候选规则**：四原子不可约反证及其 `D0/P0` 报价引用、记忆和并发容量、事件可见字段白名单、合法尝试价、共享余额逐笔余态与六阶段相对顺序；独立死后授权的首批执行域明确为关闭。**仍需整版审核或新 ADR 的硬缺口**：`D0/P0` 是否正式采纳、`read` 与更多转入价、结构/神识容量数值（队列与调度硬限沿用 ADR 0020）、独立死后签发者与非零期限/额度/字段、生命身份阈值及关键回路是否可编辑。未定处不得填入假数值；相应调用保持待定价/不可表达。若推荐限制使制作人期望的玩家体验无法成立，连同成功/失败/空状态和替代选项交主策整版复审，再走必要的制作人取舍与新 ADR；本文不启动游戏开发。

## `mdv-carrier-budget`：四载体容量与整程序预算复核

**问题、范围与验收。** 前述 `mdu-program-1` 给了需求，却未取得四体逐项原读，也没有把修正后的物理装载工作、独立 AT0 报价和 100/20 储池峰值放进同一准入判据。本节只读消费已完成的 [物理余量](./physics-material-design.md#封印份额残量处置与复现实测mdv-physical-residual范围修订-13)、[装载与攻击账](./mana-ledger-design.md#装载攻击及回收的可追溯交易合同mdv-action-ledger)及[生命临界](./life-identity-design.md#mdv-life-proof两体临界保存与唯一身份核证)；它们的任务状态不等于物理、价格、生命或程序证书已签。非目标是另定载体常数、给旧 100 M 攻击补价、开放关键材料编辑或宣称已实测运行。验收须逐体用同版原读、误差、可用下界对照同刻峰值，静态毛 M/tick/S 不低报，并保留每笔已付前序。

### 逐体量测矩阵与准入

为避免把夹具数字误读为四体已证容量，整程序证书对每个载体 `x∈{M1,B1,J1,A1}` 统一使用以下有界式。令 `A_x` 为 AST 节点上限、`b_x` 为每节点序列化上限、`I_x` 为索引/校验上限；`G_x` 为感官可见字段上限、`R_x` 为单次读取结果上限、`U_x` 为订阅数、`E_x` 为独立信封引用数、`F_x` 为本体 FIFO 位数、`Q_x` 为同时驻留引用数、`P_x` 为可恢复执行帧数、`Z_x` 为每帧栈/列表/快照/原子暂存 S 上限。则程序页 `Bytes_x≤A_x·b_x+I_x` 且 `AST_x≤A_x`；感官 `SenseBytes_x≤G_x·R_x`；有限记忆 `MemoryBytes_x≤Slots_x·SlotBytes_x`；订阅 `Subscriptions_x≤U_x`；信封表 `EnvelopeRefs_x≤E_x`；本体队列 `FIFO_x≤F_x`；`Q_x≤min(E_x,F_x)`，在途执行 `Frames_x≤P_x`；同时神识 `S_x≤Resident_x+Q_x+P_x·Z_x`。不得以引用容量代替帧容量，也不得把跨帧共存对象用 `max` 抹掉。若任一参数、编码字节、读取字段范围或峰值原读未签，相关项仍 `unknown/capacityUnknown`。

当前候选夹具的四体代入式为：`M1: (A≤256, page≤4096 B, G≤2,R0≤2, Slots≤2×64 B, U=1,E=2,F=2,Q≤2,P=1,S≤12+Q+8=22；AT0 栈/列表超过 8 时改为 13+S_AT0)`；`B1: (AST/page 同版实测且≤夹具上限, G≤2,R0≤2, Slots≤1×64 B, U=1,E=1,F=1,Q≤1,P=1,S≤11+9=20)`；`J1: (AST/page 同版实测且≤夹具上限, G≤2,R0≤2, Slots≤2×64 B, U=1,E=2,F=2,Q≤2,P=1,S≤12+1+8=21)`；`A1: (AST/page 同版实测且≤夹具上限, G≤2,R0≤2, Slots≤2×64 B, U=1,E=2,F=2,Q≤2,P=1,S≤12+1+8=21；AT0 超 8 时同样重算)`。`R0(1,2,2)` 的 1/1 感官、2/2 候选索引和 2/2 获准字段，是感官扫描夹具而非全程序感官总量；其它 AST 实际字节、感官映射及部位线路须实读封顶。表中 `M1/A1` 池候选 70 M、`B1/J1` 候选 60 M 仅为夹具容量目标，`L_M` 与余额 `B_M(t)` 分别测量；纸面准入关系为 `B_M(t)≥逐 payer 同刻毛锁额` 且 `L_M≥max_t B_M(t)`，任何未知原读均不得从候选数反推。

每个单元格写作 `所需可用下界 / 同刻峰值`；所有单元格的**当前原读 `r=∅`、仪器/校准和绝对误差 `ε=unknown`、实际可用下界 `L=unknown`、判定 `capacityUnknown`**，绝非表中数字的实测值。整数位需写入、读回、释放和故障注入均精确，`ε=0`；连续 S/M 记录逐时原值与 `ε≥0`，`L=min(r)-ε-已有占用`。程序页另含实际 AST 序列化、索引和校验字节，感官另量字段范围与真实线路；每个引用必须同时有独立信封引用和本体 FIFO 位。表中结构和池数字是待证夹具门槛，不能用另一体余位、世界 1024 信封限额、单响应 600 tick 或名义 `shenshiMax/manaMax` 代证。

### AT0 帧与静态毛 M/tick/S

物理前驱要求 AT0 独立 `Acquire-attack-01/source-attack-01/EL-attack-01`、装载辅源、四次双端原读、装载功 `w_load`、损耗 `l_load`、执行器/目标/锚链或喷出物、逐种材料与热/反作用。主源若与装载同源，保守可取下界须至少 `W_attack+l_load,high+w_load,high`；分源时主源至少 `W_attack+l_load,high`，辅源另覆盖 `w_load,high`。这些上界和取得事实均未测，`LoadTx-attack-01=∅`。账本要求单列 `Quote-load-AT0` 的已证零价或正毛 `lAT0`、payer/grant，再给 `AT0-contact-v1` 的 `p_AT0=c0+cw·ceil(W_attack/E0)+cj·ceil(|J|/J0)+cn·n+ck·k`；系数和算法上界未签，故当前 `p_AT0=unknownPrice`、攻击不可执行，历史 `25/33/100 M` 都不是报价。

攻击响应帧同时留 `{request/quote, programHash, grant/payer, sourceLotId/energyLotId/LoadTx, target/contact/anchor, Q[k]/fragment/heat, W/J/反冲, reservation/commit, stack, boundedList, snapshot}`；同刻各活对象并存求 `S_AT0`，不可把串行原子峰值与仍活的外层列表互相取 `max`。对每个有界分支 `b`，逐项列列表容量 `L_b`、循环次数 `N_b`、调用深度及展开后节点执行次数 `m_b,i`，禁止递归；`τ_AT0=max_b[Σ_i m_b,i·t_i+tAuth+tContact·n+tMaterial·k+tWork·ceil(W_attack/E0)+tCommit]`，其中 `Σ` 只数原子目录未含的外层工作，最坏真/假分支和空/满列表均枚举。一次信封入队、唤醒、判断、仲裁再加 `2+2+1+1=6 tick`；列表、栈、快照和原子槽逐时取和得 `S_AT0`。无有限 `L_b/N_b`、节点权、描述符工作量或实占读数时，攻击 `τ/S` 仍 `unknown`，不能把硬限 `600 tick` 当预算。

## `mdx-admission-bound`：J1→H2 逐载体纸面准入证书

**历史基线。** 本节的 `mdx-JH-v1` 四读价、`W-mdx-JH-1=4164 tick/23 S`、J1 `32→23→19→7` 与由其推得的准入，在 [`mdy-read-price`](./mana-ledger-design.md#逐读价格与付款重签mdy-read-price范围修订-13) 接纳十五读后均已失效；下节 `mdy-read-budget` 是本轮同一程序的现行纸面证书。下表的其他载体隔离原则继续适用，旧数字不得作为当前成功或实测结论引用。

**问题、范围、非目标与验收。** `mdv-carrier-budget` 只给四体条件容量与未知装载价；本轮消费已完成的 [`mdx-action-domain`](./tasks/module-design-mdx-action-domain.json) 和 [`mdx-decidable-price`](./tasks/module-design-mdx-decidable-price.json)，为 `J1` 杆推具名屏障 `H2` 给出从程序页装载、订阅、排队、读取、包装载到一次作用提交的有限证书。物理包 `EL-J1-H2` 的 `12/12 E0` 切片和 `Aux-J1-01`、付款价 `priceVersion=mdx-JH-v1` 的 `9+4+12 M` 均只按前驱同版引用；生命的 `DeathBarrier=∅` 现况和双时点撤权沿用生命合同。非目标是给 B4、D1/D2、K0/V0、A1 驱动或 AT0 补独立包与价，也不把纸面 `Acquire/LoadTx/Tx/A` 写成运行事实。验收要同时满足下述程序形状、逐部位可用下界、同刻资源峰值和最新授权/来源；缺原读时仍 `capacityUnknown`。

### `CarrierCapacityCertificate=mdx-JH-program-1` 的规范负载与工作界

理论重放固定 `ASTVersion=mdx-JH-AST-v1` 的**规范形状假设**：一个 `J1` 程序页，单个接触/定时可见事件入口，依次执行 `if(可见且 grant 有效) → R0/H1 指定双字段读取 → 写 64 B 内的方向槽 → if(目标与方向仍合格) → Load(EL-J1-H2, Aux-J1-01, slice=12/12 E0) → applyForce(H2,J0)`；任一假分支终止该响应。事件、两个判断、写槽、读、装载和作用只各出现一次；无递归、循环、列表扩张、重试或第二次作用。此为未来规范 AST 的语义骨架，**真实序列化 AST/hash 尚未生成**；准入前必须证实至多 12 个外层执行节点、总页（AST 编码+索引+校验）至多 `4096 B`，否则 `mdx-JH-program-1` 失效并重报。H1 的获准 `R0(1,2,2)` 只给半径档 1、2 个候选索引、2 项公开字段；感官与 `J1` 杆/底座/锚地的部位连通另签，不能由程序读到的名字推定接触或私权。

`W-mdx-JH-1` 是供开发后逐指令证伪的**设计上限假设**：装载页按每字节至多 1 tick 计 `4096`，至多 12 个 AST 节点逐一验证各至多 1 tick，页/槽/版本的固定检查至多 4 tick，登记一个订阅至多 1 tick，故一次装载及订阅 `τ_install≤4096+12+4+1=4113 tick`；装载校验同刻暂存至多 8 S。单次已入队响应的信封裁剪/入队 2、唤醒 2、稳定序仲裁 1、至多 12 个**不在原子目录内**的外层 AST 工作 tick，加 H1 原子读 10、四个有价装载 I/O 与至多八项校验 12、H2 十二项有价作用原子/校验 12，故 `τ_response≤2+2+1+12+10+12+12=51 tick`。外层 12 覆盖两个判断、一次持久写和剩余节点，不能在原子 10/12/12 内再藏外层循环；有界求证换版的 `2 tick/S2` 已在相应成功原子工作界内，成功和尝试互斥。响应 `51<600`，但 600 只是运行拒绝限，不是推导依据；装载在响应前独立执行，整个有限装载至一次响应的串行工作界 `≤4164 tick`。若编译器逐字节、节点或原子实测超过上述界，或将外层节点划入原子后重复/漏计，证书立即失效。`Acquire-J1-01` 是先史输入，若由另一 VM 执行，其工作需另立界，不含于 `4164`。

### 理论引用与开发后证伪

唯一世界理论可引用 `CarrierCapacityCertificate=mdx-JH-program-1`、`W-mdx-JH-1`、`ASTVersion=mdx-JH-AST-v1`、`priceVersion=mdx-JH-v1`、`EL-J1-H2@R3` 和固定的物理/授权版本：**条件**上界为一次装载订阅 `4113 tick/20 S`，单次响应 `51 tick/23 S`，合串行 `4164 tick/23 S`；J1 同 payer 成功毛锁额 `9+4+12=25 M`，先史来源 payer 毛转出 `32 M`，池峰值 `32 M`，两引用但仅一帧。理论重放须保留这些界的每一项及 `S0, simTime, worldSequence, seed`；任一版本换版即撤证重报。上述值只在规范负载与工作界假设内有效，**现况原读、实际 AST/hash、物理四读、真实交易均为空，不能称可执行成功**。

开发后先提取真实规范 AST、序列化字节、索引/校验、`programHash` 与每条分支节点次数，核 `≤12/4096` 且与本语义骨架同版；逐体读取上述每个具名部位的原始容量、已有占用、校准、绝对误差和可用下界，验证 J1 的订阅/两信封/FIFO/单帧/槽写后读、感官字段/范围、锚链和 M 池 `≥32`。用同一 seed 重放成功、假分支、空读、双响应、损坏、队列满、欠款及撤权，记录逐 VM 指令 tick 起止、原子工作与装载逐字节/节点计数；逐时记录常驻、引用、帧栈、列表、快照、装载/原子暂存 S 的**同时活量**和池容量/余额原读。逐 payer 对 `Acquire/ReadTx/LoadTx/Tx/A`、锁额、实扣、释放、不可取收款与物理包/热/反作用核对 `静态毛锁额≥实扣`，并核 `4113/51 tick≥实际相应工作`、`23 S≥逐时峰值`。任何超界、附加 VM 工作、包失效或与物理四读不合，撤销此纸面证书并重报；本轮没有这些开发后实测。

## `mdy-read-budget`：十五读 VM 工作映射与 J1 准入重签

**问题、范围、非目标与验收。** 物理 [`mdy-read-provenance`](./physics-material-design.md#mdy-read-provenancej1h2-逐读来源阶段与失证) 有十五个互不替代的读 ID，账本 [`mdy-read-price`](./mana-ledger-design.md#逐读价格与付款重签mdy-read-price范围修订-13) 已接纳 `priceVersion=mdy-JH-read-v1`。本节只把它们映射到 `ASTVersion=mdx-JH-AST-v1` 的**规范形状假设**、逐段 tick、逐时 S 和本体容量；不改读值、物理包、价格原子或他体权限，也不声称当前代码已执行新合同。验收是十五 ID 各有恰好一次新读或有效已付覆盖、付费方与 VM 工作不漏不重、条件上界能覆盖同刻峰值。旧四读 `4 M/12 tick` 不足：装载新增七个有价 I/O，热基线和作用后另有三个，作用前复用失效还可能新读一次。旧 `W-mdx-JH-1` 的 4164 tick、51 tick 响应与 23 S 准入均撤证。

### `W-mdx-JH-1` 的同版 M/tick/S 条件上界

沿用旧装载页本身 `4096+12+4+1=4113 tick`，它只扫描/验证页并登记一订阅，**不含任何物理读**。旧响应中的装载段 `12=4` 次旧主读各 `1 tick+8` 项其他校验；删去失效的四个读步，保留八项有界校验，加入十一读各 `≤10`，得到 `τ_load-segment≤8+11×10=118 tick`。旧 H1 `10`、H2 作用 `12` 和信封/唤醒/仲裁 `2+2+1`、外层 AST `12` 保持独立；外层 12 只数判断、方向槽写、控制流等节点，不重复收子读或原子 tick。后读两次各 `10`，作用前复用比较 `1` 或新读 `10`。所以单个入队响应 `τ_response≤2+2+1+12+10+118+12+20+1=178 tick`（同版复用），失证且具价新读为 `187 tick`。基线 `A_pre≤10 tick` 另列，整条有限链 `10+4113+178=4301 tick` 或 `10+4113+187=4310 tick`；这是前驱候选 `4160+14×10+1` 与 `4160+15×10` 的逐段复核。两已准入信封串行时，静态尝试工作可保守报 `10+4113+2×187=4497 tick`，每封仍各受 600 tick 限制；这不授权两次付款或两次物理切片，后封仍按实际前封提交余态拒绝。一次响应两分支均小于 ADR 0020 的 600 tick 硬限，但硬限不能代替静态预算。`Acquire` 的自然/其他 VM 工作仍是先史输入，不在 `W`；若由本程序额外执行，另报并重签。重试、版本失证后的重采是**新请求、新 Quote**，不在这一次上界中偷循环。

J1 本人池峰值仍须 `≥32 M` 且先史来源确已毛转 `32 M`；新版本人毛支出是 `9(H1)+11(十一装载读)+12(H2)=32 M`，纸面余额 `32→23→12→0`，不再是 `32→23→19→7`。`P0` 在 J1 到账前独立付 `1 M`，`P2` 在 H2 前足额预锁 `2 M` 并在后读分别结算；同版复用总毛额 `35 M`，分别由 J/P0/P2 出 `32/1/2 M`。失证新读若仍由 J 支付，会 `12→11` 而不足 H2 的 12，不能签成功；只有 `P1` 自有到账 `≥1 M` 与 `payerGrant-J-action-read` 或另一次有证转入后重报，才有 `36 M` 成功分支，J/P0/P1/P2 分别出 `32/1/1/2 M`。静态全链毛界取 `36 M`，**逐 payer** 还须有上述独立额度；`P0/P1/P2` 不是假定已有余额。`LoadTx` 的十一读已逐个结算，不能再收一次 11；H1 的 9 不覆盖物理读，H2 的 12 不覆盖作用后两读。物理 `12/12 E0` 切片与 M 分账。

按最大同时活对象重签 J1 的 S：旧常驻 `8 AST+2 方向槽预留+2 一订阅/首引用=12 S`，十五个固定读收据引用 `+15 S`，故新常驻 `27 S`；安装页验证暂存 `+8 S` 为 `35 S`，两个已准入信封中的第二引用 `+1 S` 且只开一帧，读/装载/作用/外层活对象、当前采样暂存与最多四端点比较必须共同装入帧界 `+10 S`，响应峰值 `27+1+10=38 S`。若任何子读需要在这十个帧 S 之外额外保留值、前序引用与当前快照重叠超过十五槽、页外索引有额外常驻或两个帧同开，即撤证重报，不把 `max` 用于共存对象。两信封是**同一个订阅**的两引用/FIFO 位，故基础 J1 仍须 `U≥1`、引用 `≥2`、本体 FIFO `≥2`、可恢复帧 `≥1`、S 可用下界 `≥38`、页和各部位结构/感官/方向槽分别有证；世界 1024 位不能替代本体位。第二订阅若另行申请，旧 `U≥2、S≥24` 只是失效前的最低反例门槛；新版须独立证明 `U≥2、S≥39`、两本体引用/FIFO 位、一帧及两条订阅各自 grant，额外 `1 S` 为第二订阅常驻，不借 M1/B1/A1 的神识、池或队列。

这些 `≥` 是规范负载**所需下界**而非 J1 实际可用值。每个整数原始结构读数与先前占用分别核 `L=min(rawReadings)−absoluteError−preexistingOccupancy`，页、十五索引、槽、感官字段/候选、订阅、引用、FIFO、帧、S、池和锚链各自取证；结构读 `absoluteError=0` 才能直接比较整数位。当前原读、占用、真实 AST/hash 均未提交，因此 J1 仍为 `capacityUnknown`，本证只给条件准入；其他三体即使有同名 AST 也须按本体重新证明并自付，不能借 J1 的 38 S、32 M 或物理/付款 grant。

## `mdz-carrier-admission`：M1/B1/J1/A1 逐体程序与事件准入（纸面设计）

**问题、范围、非目标与验收。** 本节承接 [`mdz-life-boundary`](./life-identity-design.md#mdz-life-boundary关键材料与账本后的生命边界纸面设计)、同版[逐行为物理包](./physics-material-design.md#逐行为来源与材料裁定mdz-action-sources纸面设计)和[逐行为账本](./mana-ledger-design.md#d1b4-同版价格与竞争账mdz-action-prices纸面设计)，为四个**不同本体**分别划首批装载、唤醒与作用域。验收是下列逐体页、程序工作证、事件证、六项反证与可执行脚本能以同一版本键和世界序复算。此处“候选”只表示 AST 和纸面描述符可组合；`OriginCertificate/LoadTx/Quote-success`、实际结构原读、真实 AST/hash 均未交，本轮没有一体可宣称运行成功。非目标是把 D1 扩成 D2、将 B4 修壳当醒回、给 K0/V0/AT0 定价、开放 `k_m/k_a` 编辑或批准新游戏版本。旧 `mdt/mds/mdv` 数值仅作历史条件；本节以 `mdz-D1-v1/mdz-B4-v1` 和 J1 自己的 `mdy-JH-read-v1` 分账，绝不横借 J1 的 `38 S`、一订阅、十五读或 35/36 M。

### 共同证书格式与工作口径

`CarrierAdmission(Z, programHash, ASTVersion, structureVersion, XVersion, capacityVersion, priceVersion, physicalVersion, grantVersion, simTime, dueAt)` 同时带 `Z` 的逐部位原读、已有占用、校准误差、可用下界和装载/派发时快照。每个整数结构位只在绝对误差 `0` 时直接比较；保守下界逐部位为 `L=min(rawReadings)−absoluteError−preexistingOccupancy`。页字节、≤256 节点、每个 64 B 记忆槽、感官线路与字段、订阅位 `U`、本体 FIFO、在途引用、可恢复帧、帧栈/列表/快照、同时活 S、M 池、物理接触/锚与封印各自有证，不能用世界 1024 信封位、角色种类或显示的 S 上限替代。本节候选统一要求规范 AST `≤12` 个外层执行节点、整页 `≤4096 B`（含收据索引、类型与校验）、无递归、列表有界；这是待序列化验证的**负载上限**，不是已生成的 AST。安装扫页、节点/索引校验、槽写后读和订阅登记的实际 tick 与 S 暂存须另计；旧 J1 `4113 tick` 只属于其已列 `mdy` 负载，不能作为别体安装工作界。

本节对 M1/D1、B1/B4 定义可审的**响应工作候选式**：同版账本完整物理链分别 `W_D1≤176 tick`、`W_B4≤232 tick`，含各自新读、装载、作用和 Quote，**不含** AST/事件/记忆工作。若至多 12 个外层节点各需至多 1 tick，且一次信封接纳、唤醒、仲裁合计至多 `2+2+1=5 tick`，无额外槽写、列表扫描或重试，则条件响应上界分别 `193`、`249 tick`；无信封的直接请求去掉实际未做的信封工作。任何外层节点实际多于 1 tick、记忆写/版本比较另耗工作、描述符读端点超过四、事后读增加或部分 `Acquire` 由本程序执行，都使此候选上界失效，须逐项加价重签，不能以 ADR-0020 的 `600 tick` 硬限填差额。`Mmax` 只数**同一 payer 的毛支出**，独立转入、物理取得、自然 `C/N→X` 和他人读价另列；无界订阅或无限维持总工作/总 M=`unbounded`，每次响应仍要有限上界和有效 `dueAt`。

**同时活 S 申报办法。** 下列 M1/B1 页为此轮新负载的**条件占位式**：固定 AST `8 S`、每持久槽 `1 S`、一订阅与首引用 `2 S`、每份在途额外引用 `1 S`、每个固定有价读收据索引 `1 S`，并为一个活帧连同采样暂存、列表、快照、原子暂存和外层工作**共同预留 `10 S`**。因此 M1/D1 两引用时 `8+2+2+1+14+10=37 S`，安装无引用峰须另测；B1/B4 一引用时 `8+1+2+19+10=40 S`。这些是拟用结构布局和同时活量的**最低设计需求及待证上界**，不是实测 S；若十四/十九读索引不能驻同页、某帧超过 10、读快照与索引额外共存、同刻开双帧，必须按逐时**相加**重报，当前结果 `capacityUnknown`。J1 只对它自己的十五读负载沿用 `mdy` 的条件 `38 S`；A1 因无可报价主动负载，`Smax/Wmax/Mmax=unknown`，不可套 M1 的 37。

### 逐体容量、纸面价格与拒绝边界
