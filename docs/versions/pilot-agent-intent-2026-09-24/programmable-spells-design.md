# 法术语言、原子作用与跨实体执行：模块详细策划

**版本与状态**：`pilot-agent-intent-2026-09-24`，策划修订 `2`、范围修订 `13`；`module-design / mdr-spells` 退回修订候选细则。直接承接 [mdr-life](./life-identity-design.md) 的生命/身份判据及六阶段顺序。制作人选择元法术 B（收窄可编辑材料域）及载体/授权 B（以实际结构容量判程序资格）。本文件不批准数值、游戏开发或覆盖已采纳 ADR。[世界理论](./world-theory-draft.md)仍是唯一可编辑的公理正文。

## 问题、范围、非目标与验收

当前玩家能在推演台编辑 AST/DSL，在演武场绑定法术；公开目录有 94 项入口，但玩家不能把普通程序、有限记忆和订阅交给任意有容量的实体。[现行编写指南](../../reference/spell-authoring.md#当前能力边界)也明确没有玩家事件订阅、跨次常驻变量或用户自定义实体类型。旧创建弹道、三池、固定伤害、寿命与专名追踪把多个世界作用捆在一起，不能直接解释自然碰撞、遗体或人工生命。

**范围**是定义同一 AST 的表达边界、分析/报价/VM/订阅接口、装载与运行规则、拒绝和跨实体反例，并逐项归位旧入口及十项属性。**非目标**是敲定材料系数、生命/身份阈值、环境回收公式、程序存储容量数字、旧存档自动迁移或实现顺序。**验收**是同一程序只因实际结构、权能、材料和付款来源而呈现可解释差异；每笔作用有资源/物理/生命去向，静态预算不低报且未知价不伪装为零；五种载体的六种边界和 ADR/旧数据影响均可复核。此处的“闭合”指给出可检验的候选规则和域外拒绝，未定数值仍需整版审核。

## 表达域与不可组合性

语言保留条件、定次循环、有界列表、函数调用、有限局部值及显式释放；默认禁止递归。程序以获准快照、计算、一次原子世界请求、有限持久记忆和事件/定时再启动组合行为。玩家预设、敌方战术和实体种类不得私有地增设效果。待开发的玩家流程是：推演台编辑同一法术书的 AST、查看权限/材料/动态预算诊断并单步推演；演武场将程序和有限授权装载到有容量的实体，显示逐笔付款与拒绝，返回推演台继续修改。当前 UI 未提供这条完整流程。

**材料编辑域 D 的候选边界**：只接收物理层登记为可编辑、已知 `Q[k]` 数量和来源的惰性固体部位与零件；首批用途限球壳、机关外壳、屏障和锚件。可操作的状态是有界材料分区、局部形状/尺寸、已登记的非生命连接边和承力部位。一次请求须列来源与目标分区、种类/数量上限、连接端点、前后结构版本、废料/热去向和目标能力；迁移、断开或接合不得增造 `Q[k]`，不得越过声明的部位范围。未登记种类或材料精度不足一律 `unexpressible`，不把任意数值写入 `X`。生命关键组织、调节/记忆回路、身份记录、任意物质变换、跨域传送、无限环境吸收及无损回收均在 D 外；“修复”只能改 D 内普通结构。即使后来生命模块认定某回路恢复，也只能基于另行获准的物理事实和 [mdr-life](./life-identity-design.md) 的连续证据，不能由本域推断复苏。D 的具体材料白名单、粒度和可报价价函数仍是设计评审缺口；在其确认前相应请求报待定价，不执行。

**候选最小原子及不可约反证**如下。这里的“不可组合”指在相同授权、价格、提交边界及失败余态下，任意有限次其他候选调用加纯计算都不能生成同一权威事实；未获价格证明的候选仍不开放执行。

| 原子与唯一新增事实                                            | 删除该原子后的反证及材料/价格边界                                                                                                                                                          |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 获准读取 `read`：带时刻与字段裁剪的观察快照                   | 其他调用只计算、移动法力或改变物理态；不能凭空获得受保护的最新字段。订阅只转交已发生且获准的事件摘要，不能代替主动范围观察。须按字段、范围、候选量与观测工作报价。                         |
| 账户转移 `transfer`：账本 `T` 的来源毛扣、净到账及损耗        | 读取、施力和材料改接不会给另一有限账户增加有来源的可用余额；施力内的付款只是消费，不能代替可再支用的到账。须含启动价、容量、可用性 `U` 和受益/退款凭证，禁从已付散逸回收。                 |
| 有反作用的施力 `applyForce`：物理 `A` 的双边冲量              | 读取和转账不改动量；材料改接最多改约束/形状，不能在相同瞬间给原有两体付费冲量并交代反作用。须证明有效质量、反作用路径、功及热上界；未知换算拒绝。                                          |
| D 内局部迁移/改接 `editMaterial`：物理 `A/X` 的材料与连接变化 | 读取、转账和施力可能导致自然碰撞破损，却不能在无接触且相同余态下把指定有源材料迁入指定连接并保持受控结构；随机撞击也不满足原子提交/权限。须证明 `Q[k]` 守恒、部位能力、热/废料与有限工作。 |

`断开` 与 `接合` 是同一 D 内改接原子的参数化方向；**结构建立**是从获准材料分区迁移、改接、装载有限程序、转入有限余额及可选初始施力构成的多笔流程，不增设“创建”原子。各笔分别提交，后一笔失败时已成材料结构仍按默认物理存在；不能宣称整条创建流程一次成功。若未来发现现有 `editMaterial` 无法表达某种新结构，先给出同权限/价格/余态的不可组合证明并交整版复审。事件登记、装载、记忆赋值是有容量的程序/权能管理，不自动成为新世界作用。

**追踪**＝获准读目标位置、比较快照与上次方向、付费施力、下次定时重启；失供后仅保留已付惯性。**碰撞伤害**＝[物理模块](./physics-material-design.md)一次自然接触 `C` 对两侧 `X` 的改变，生命损失是后续判读；碰撞响应若另施法须另付 `S/A`，同一动能不可经旧 `damage` 池二次释放。**自修复**＝获准读自身结构、取得有来源的余额、取得真实材料、付费局部迁移/接合，再由生命层判功能；缺任一前提不会得到专名豁免。[理论 B4](./world-theory-draft.md#跨实体与边界反例的交易明细)限定本程序只能修补窄域内结构：关键生命回路在域外时，复苏请求明确返回 `unexpressible`，已完成的接触、转入和读取各自保留，不以修补结果推断同一身份。接力护送、反制、定时护盾和失供告警同样是普通程序。

## 唯一程序合同与状态所有权

```text
源 DSL / 蓝图 ↔ 版本化 AST（唯一 IR，含 sourceSpan、类型、有限容量与作用 ID）
  → analyzer(AST, 载体能力上界, grant 范围, 价格目录版本)
      = 诊断 + 神识/结构峰值 + tick/法力毛支出界 + 动态/无界条件
  → compile(AST) = 可定位指令；不在编译器改写作用或价格
  → request(executor, programId, instructionId, targetOrDirection,
            simTime, grantId, payerAccountId, causeId, snapshotVersion)
  → authorize / quote / reserve / revalidate / atomicCommit / emit
  → VM 继续或停止；订阅器仅按已提交事实唤醒新 VM
```

AST 的作用节点引用同一版本的原子描述符：参数及材料域、目标能力与字段权限、结构要求、报价函数、动态边界、尝试价规则、提交与结果类型。分析器用符号范围调用同一报价定义，VM 用实参和最新世界状态调用它；事件订阅节点也在同一 AST 中声明事件类型、字段投影、过滤谓词、记忆槽和响应入口，不存在另一本订阅脚本或编辑器价格。`descriptorId/version`、`programHash`、`sourceSpan` 和每次 `requestId/causeId` 随编译指令、报价、事实与诊断传递；同一请求重试凭 ID 幂等，不能再收费或再施力。旧 [`pricing.ts`](../../../src/core/pricing.ts) 的 `effectCost`、`sensePrice`、`controlPrice` 与 [`vm.ts`](../../../src/core/vm.ts) 的调用付费、tick 债务是当前实现证据，尚未给新物理/材料价格。`unknown` 价不是 0，`dynamic` 有运行限额但不能声称有限静态总价，永久订阅/维持明示无界总额。动态目标、距离、关系、材料量、事件次数、可用余额和环境 `U` 均标条件；即使有转入或预计退款，毛支出不以净额抵消。

| 所有者                                 | 本模块交互与不变量                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 程序/载体                              | `executor` 是有可运行结构的实体，程序 AST/有限记忆/订阅挂在它的结构容量上。owner 是所有权，controller 是当下控制权，二者均非提款权。装载需结构槽、计算/感知/作用能力和授权，容量按程序、最大活变量、列表容量、持久记忆、订阅及并发 VM 峰值累加；不足即拒绝装载或新会话，不按 Actor/Projectile 白名单放行。神识表示占用并可释放，不是可退法力。 |
| 权能/付款                              | `grant` 明示签发者、持有人、操作/字段/目标范围、账户、额度、到期时刻、可转授性及撤销条件；`payer` 是该次实际被扣的有限账户。owner、controller、executor、payer、退款受益人可不同。余额和权限须在提交时重验；法球仅用预付池或显式有限预留，不能借创建者未来收入。                                                                               |
| [账本](./mana-ledger-design.md)        | 记录毛转出、世界/目标/环境接收、预留、可用性 `U`、已做工作和固定退款受益人。零余额信标先按预先授权来源转入，启动费从来源总转出量中支付；先前转入不随下次修复失败撤销。报价不泄露私有余额，未证明做功或吸收上界时拒绝。                                                                                                                         |
| 物理/材料                              | 自然 `C` 先由物理层提交，主动 `A` 有唯一作用 ID、反作用体、材料前后及热/废料去向；资源分录引用 `A`。程序不写位置、HP 或寿命捷径。缺材料/部位或无反作用路径时，本笔 `A` 不提交。                                                                                                                                                                |
| [生命/身份](./life-identity-design.md) | 生命层从已提交 `X`、实际供源与回路判临界、休眠、复苏或死亡；`M=0`、HP 摘要、实体句柄都不是死亡/同一身份证据。遗体可保有结构但原 `LifeId` 死亡，任何修复不自动恢复旧身份。                                                                                                                                                                      |

程序执行成本分三层：指令和真实循环步计 VM tick，局部/持久状态与订阅计神识及实体结构容量，世界读取和作用另按不可折扣部分计法力及附加 tick。`castSpeed` 只改变偿还 tick 的模拟耗时，不能减少 tick 数；随机源和事件排序须可重放。优化只有确实减少观察次数、扫描范围、工作步数、状态峰值或物理作用时才降低相应价格，不按法术名称给折扣。分析按最坏容量及并发计算峰值；运行中每次调用、事件唤醒和共享账户竞争仍需动态重验。

### 有限记忆、容量和预算的统一核算

每个装载实例显式声明 `memorySchema`（固定槽数、每槽类型/最大长度、版本与初始化值）、最多订阅数、每订阅最大待运行响应数、并发 VM 上限及到期/卸载策略；持久值只能通过有权的本实例事务写入，不能从别的实体私有内存复制。列表容量和字符串/句柄集合上限计入静态峰值；句柄存储不延长目标寿命或授权。一次响应读到版本化记忆快照，提交写入时按实例序重验版本；竞争冲突返回 `staleMemory`，已付读取与 tick 留存，未提交的新值不留半写。死亡/结构瓦解时内存停止读写；只有事先独立的实例及授权可按自身到期条件保存可公开槽，死者私有槽清除或封存而不可继承。

容量分为载体物理可运行槽 `C_structure` 与当前可用神识 `C_shenshi` 两个同时必须满足的界：程序字节/指令、持久槽、订阅/事件引用及最大并发栈帧各有结构占量；运行中活变量、列表、响应快照、待派发引用和并发峰值各有神识占量。装载时证明 `declaredPeak ≤ min(相应可用界)` 并预留常驻项，启动和每次扩容再对当前结构/共享神识重验；结构受损使容量收缩时按稳定实例序停止超额会话并释放占用，不删除既成世界事实。不得用 Actor/Projectile 类型或 `shenshiMax` 一个显示数代替实际结构证明。静态分析对有限调用路径给毛法力、总 tick、神识峰值和结构峰值的保守上界；动态范围有明确实参上限时按上限计，永久事件或维持报 `unbounded` 且逐窗口限流。若报价函数、材料承受或 `U` 无可信上界，报 `unknownPrice` 并拒执行，不输出虚假的零价或低报数字。

## 原子提交、事件与玩家可见结果

统一请求先验载体结构/能力、grant 的字段和目标范围、材料表达域，再用**不含私有值的可公开条件**报价；随后预留本笔余额/容量，在最新状态重验目标、来源、材料和权能，成功时同一个提交点记法力转出/接收、`A` 与 `X` 变化，并排入已提交事实。未提交本笔不留下部分付款或作用；若合法尝试费已单独完成，则其价与 tick 在 UI 逐笔可见，成功价不重复加算。先前读数、转入、自然 `C`、已做 tick 和其他响应不回滚。若目标在付款前消失、被遮挡或撤权，返回不泄密的相应拒绝；若获准查询范围内确无目标，返回成功空集合/空句柄和该次已发生的读取费，不伪造作用。拒绝结果不携带私有值，日志、报价和 HUD 均不可旁漏。

**合法尝试价规则**：语法/类型错、无结构或能力、无 grant、域外请求、报价未知、报价前已知的目标不可探查，均在成功世界观察/作用前拒绝，不扣世界法力；已经执行的 VM 指令 tick 与占用仍照实留账。通过能力、授权及公开参数预检后，若确需世界搜索或读取，先把该次有界观察作为独立 `read` 报价并获准付款，故获准空查询也收费；随后申请作用。申请作用时仅可另收目录中事先公开的**固定上界尝试工作** `attemptQuote`，且只在实际完成了不能由 VM 本地计算代替的可审计世界工作时扣一次，给独立 `attemptId/T` 与工作量，不得随私有目标状态变化，也不得从未提交的效果价中隐扣。成功时这笔已付尝试工作抵扣成功报价中同一工作项；失败时保留它，作用本金预留全解锁。因最新状态撤权、目标消失、材料被抢或共享账户不足导致失败，均无成功 `A/X/T_effect`；未做世界工作则尝试法力为零。具体每类工作单价尚待账本闭合，目录缺价时禁止执行该需要付费尝试的路径。重复 `requestId` 只返回原结果。

**并发余态**：同一 `C` 派两个响应 `S1/S2` 时依 `(simTime, worldSequence, subscriptionSequence)` 启动，每一原子提交前读最新 grant、记忆版本、结构、材料和共享账户。若 `S1` 已付读取、转入、改接并耗去最后材料或余额，`S2` 可以保留自己已付的读取/合法尝试工作，但释放未提交预留，返回 `missingMaterial` 或 `insufficientFunds`；`S1` 的 `T/A/X`、自然 `C` 和之后阶段⑤生命结果不回滚。若 `S1` 导致死亡撤权，`S2` 在派发前失去派生授权时直接丢弃/拒绝，不能凭旧快照提款或读私值。两者争写同一记忆版本时只有先提交者更新记忆；后者获 `staleMemory`。同刻遵循理论的①自然 `C/X`、②预先到期补源、③到期主动作用、④维持/失稳、⑤生命判定撤权、⑥事件派发；阶段⑥新补源不能倒救本刻阶段④。事件响应造成新的结构事实，在下一个响应边界前复判生命及撤权。

事件只引用已提交的 `C/A/交易/生命` 事实，给每名订阅者按创建和派发时权限分别裁剪字段；它不是免费主动监控。先完成物理/账本/生命提交及必要撤权清理，再按模拟时刻、世界事实序、订阅序派发独立 VM；共享账户逐笔竞争。每一根因果链的重入深度、每模拟窗口唤醒数、队列长度、每会话/总 tick 和神识峰值均有显式硬限及丢弃摘要。上限值须在实现前统一指定，不能把当前测试中的 8 层、256 次窗口当新策划定数。[当前测试](../../../test/core.test.ts)证明旧事件顺序、撤订和限额语义，不证明玩家可给所有载体订阅。队列满只丢未运行的响应并记录可见诊断，不重做或回滚自然接触，也不递归生成“失败事件风暴”。暂停冻结模拟及派发；恢复先结到期，再按稳定序处理意图。

事件信封的公开基础域仅为 `{eventId, rootEventId, simTime, worldSequence, type}` 和订阅者本身有权知道的原因摘要；`C` 可选接触部位/方向/冲量区间，`A` 可选自身作用及结果，`T` 只给本人账户的毛扣与到账摘要，`LifeTransition` 只给被授权的阶段/终止摘要。对方句柄、精确位置/材料、账户余额/来源、私有 `LifeId`、记忆、授权及身份连续记录**默认不在载荷**；每个可选字段须由事件发生时和派发时的 grant 交集允许，并受订阅声明的字段上限裁剪。事件是否存在也可能泄密：对无权观测的他者事实不建可见订阅候选，不送区别性“被隐藏事件”提示；需要额外字段时另行获准付费 `read`。终止摘要的只读性不含死者私有身份；事件队列元素仅存事实引用、裁剪计划和有限因果键，不复制无限快照。

死亡提交后先撤生命主体派生的控制/提款与订阅、终止其 VM 和维持会话、关闭账户接收，再发布经裁剪的只读终止摘要；不允许因死亡从其账户自动回复、退款或转出。独立法球、机关、信标或遗体残存结构的程序只有**事先独立签发**且明确持有人、操作/字段域、期限、额度、来源和终止条件的授权，才可在死亡后继续；它不继承死者身份、私有记忆或钱包。已提交 write 不随 VM 终止回滚；未用预付余额仅按来源凭证给固定有效受益账户一次性清算，接收不了的份额进环境损耗。授权与结构同时失效则不再唤醒。

**死亡后独立授权的期限合同**：签发时必须在仍有效的授权链下指定不可延长的模拟时刻 `expiresAt`、最多响应次数 `maxWakeups`、最多毛支出 `maxGrossDebit`、允许的事件/操作/字段/目标集合、独立付款来源及固定退款受益人；实际有效期取各限额、签发者明确撤销条件、载体结构存续和账户有效性的**最早结束点**。不得用 `0`、空值或“直到死亡后”表示无限期限，死亡后不可由死者 grant 续签、充值、扩大目标或转授；届时清理订阅/记忆引用与未用预留，清算按凭证一次完成。签发者若只是死者生命主体，其派生 grant 仍在死亡时撤销；真正独立的 grant 必须由另有权的来源预先签发并以独立账户/预付池担保。对于遗体，许可只能覆盖 D 内普通残余结构和公开终止摘要；原 `LifeId` 私有字段、旧记忆和死者账户始终禁止。`expiresAt` 的数值上限、是否允许何种独立签发者及遗体可见字段须随 ADR/整版评审定稿，未定前不开放死后运行。

## 同一程序的五种载体反证

固定程序 `R`：获准接触/定时事实唤醒，读取自身结构和获准目标位置，记上次方向；若需要，先从**预授权有限来源**转入；对有真实材料的目标局部接合，或对屏障施力并保留下一次订阅。每行使用同一 AST、报价目录和失败码；只改变真实结构、材料、授权及账户。表中“成功”均以报价已闭合且目标仍有效为前提，不等于本版本已实现。

| `perception`                                                       | 感官结构/范围摘要；看见不等于可读字段，扫描仍按观察量计价。                  |
| `armor`                                                            | 具体材料/护体吸收、偏转、隔离的摘要；不能在冲量/材料之外再扣固定伤害。       |

## ADR、旧程序与存档的非等价影响

| 已采纳合同                                             | 可继承边界；必须先由新 ADR 明确覆盖的差异                                                                                            |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| [ADR 0017](../../adr/0017-统一实体控制属性模型.md)     | 同一句柄、descriptor/binding、能力拒绝和原子控制可继承；直接属性写入、HP/寿命/回复及固定维持周期不等于材料、生命回路和结构容量程序。 |
| [ADR 0018](../../adr/0018-运动供能与命中守恒.md)       | 惯性、分池防双花和速度/朝向分离可继承；自动 `Wm`、无自然动能致伤、固定 `damage` 池及弹道寿命与物理 A、普通驱动 B 冲突。              |
| [ADR 0019](../../adr/0019-属性探查与资源账本.md)       | 付费字段权限、共享原子账、静态预算和幂等退款可继承；旧倍率、回复覆盖收益与三池换算不证明有来源 `M/U` 或材料作用价。                  |
| [ADR 0020](../../adr/0020-事件执行上下文与生命周期.md) | 确定派发、双时点权限裁剪、共享余额、终止去重可继承；玩家通用订阅、结构容量、生命身份及独立死后授权仍需新合同。                       |

旧法术的 `创建弹道`、`伤害`、`设置存活时间`、`设置法球追踪`、直接位置/回复/倍率写入，以及旧存档的 HP、三池余额、`life`、owner 与绑定，均不能凭名称映射获得新材料、来源、权能或 `LifeId`。只对**权限、结构、状态、价格及结果均证明等价**的 AST 做迁移；否则保留原 DSL/蓝图/存档字节及引用，逐节点标 `sourceSpan`、不等价原因和建议重写操作，在新运行时拒绝执行或隔离预览。不能静默降级成免费/较便宜法术，也不以旧兼容限制新原子设计。迁移规则、回退和存档版本须在 ADR 与整版策划审核后确定。

## 待整版审核的闭合点

推荐先用 D 内有限材料/连接、可报价施力和来源明确的账户完成跨实体纵向闭环；玩家会看到域外“尚不可表达”诊断，代价是暂不能写生命组织、任意转化与开放吸收。**本轮已给候选规则**：四原子不可约反证、记忆和并发容量公式、事件可见字段白名单、死后 grant 的最早到期规则、合法尝试费条件、并发竞争余态及六阶段相对顺序。**仍需整版审核或新 ADR 的硬缺口**：D 的最终材料白名单/粒度、`M→功/X` 和合法尝试工作的可信价函数、环境 `U`、结构/神识容量及队列数值、死后独立签发者与期限上限、遗体可见字段、生命身份阈值及关键回路是否可编辑。未定处不得填入假数值；相应调用保持待定价/不可表达。若推荐限制使制作人期望的玩家体验无法成立，连同成功/失败/空状态和替代选项交主策整版复审，再走必要的制作人取舍与新 ADR；本文不启动游戏开发。
