# 自洽的实体与法术世界：版本策划草案

- 版本 ID：`pilot-agent-intent-2026-09-24`；策划修订：`2`；范围修订：`8`。
- 状态：**制作人评审前的主 Agent 草案**。须经正式主策复核、独立审查和制作人立项评审；本稿没有授权详细策划或开发。
- 目标：先建立能解释实体存在、生命与死亡、法力吸收、变化、施法、消失的统一世界规则，并用反例检验；规则获得制作人认可后，再决定小范围实现切片。候选模型与属性审计见[世界底层规则](./world-foundations-draft.md)。

## 原话、推断和边界

上版[制作人原始方向](../../../.daoyan-agent/releases/versions/draft-2026-09-23-7af7515c-4ac5-47fe-9063-.json)要求属性驱动、统一实体、资源守恒、事件化法术和“万物皆法术”；修士、法球及未来实体复用能力语义，法球有注入资源、事件与行为法术，不自动回蓝，也不能凭空伤害或无成本持续运动。

制作人本次进一步明确：法球与修士的生成、施法、事件触发和资源消耗应按同一规则解释。法球碰撞造成伤害，是“碰撞事件 → 调用伤害法术”；修士受伤调用法术亦同。法球施法资源由创建者注入，法球自身不能恢复。飞行、爆炸、伤害、元法术价格和算法优化都需要因果与成本解释。更多预设法术应展示特性，敌方修士也要同步。**元法术只表示不可由既有元法术组合表达的原子操作**；读取敌人位置加移动可构成追踪时，追踪应是普通组合术。法球与追踪是检验整体框架的例子，不是封闭的开发清单。

制作人对上稿的反馈：统一执行和计费方向正确，但仍未解释法球为何只存在一段时间；**所有实体为何存在、如何维持和为何消失也必须用统一规则解释**。此前推荐的具体开发闭环暂不采纳，先确定规则。当前仍是原型验证期，旧法术、旧元法术和旧存档的兼容不是设计约束，可以根据新规则重做。

制作人进一步要求从元法术、法力和耗时这三项已认可核心出发，重新审视全部属性及施法的根本：恢复法力可考虑成为元法术；血量与死亡、不同吸收能力、施法速度、非生命法球施法、碰撞后消失均须由共同原理推出。**规则没有想明白并取得制作人信任前，不开始开发。** 先前“法球不能自行恢复”的类别禁令在新方向下也需复核：候选解释是默认法球缺少吸收结构和来源，具备相同能力的造物应能按同一法则吸收；此推断尚未获制作人确认。

制作人现在确认：生命与实体存在必须分开，但生命定义仍需讲清；**法力只能从一处转移到另一处**，所谓消耗也必须有接收处；没有法术时世界按默认规律运行，法术是实体向世界或其他实体付出法力以改变状态。还须区分世界规则与现实交互桥接：鼠标左键只表达施法意图，不能进入世界公理。主策需主动审计键位、瞄准、AI、墙钟、界面探查、编辑和重开等同类入口。候选生命定义、分层与代码边界见[生命及世界边界草案](./life-and-world-boundary-draft.md)；这些尚未全部获批准。

制作人认可人工造物若具备完整自维持能力也可算生命，并提出**不可逆的世界熵方向**作为探索想法：法球的凝结和修士对生命过程的维持都需转移法力、运行法术；缺乏维持时，特定结构沿默认演化逐渐消散。主策据此提出[熵方向候选模型](./entropy-direction-draft.md)，重点反证稳定物体无需持续付款、法力付给世界后不可无损循环回收、局部有序可以来自外部差异、生命维持不是隐藏免费回复。这个模型尚未被制作人定稿；不得把“所有实体每秒掉血”或“支付一次就永久造物”当成总规律。

以下是主策待验证的系统推断，并非制作人已批准的设计：

1. **存在有共同条件。** 所有实体都要回答构成从何而来、维持什么状态、何种作用使其受损或消失，以及能否修复。寿命不能因为实体名叫“法球”就成为倒计时；若有时限，须由明确的结构衰减、供能/维持期限或其他普适机制推导，修士及未来实体也应服从同一机制。
2. **统一实体合同，能力显式声明。** 修士、法球和未来实体共享身份、创建、授权、事件、施法、账本、失效和审计规则；可拥有不同的构成、能力及资源来源。差异必须从这些条件推导，不能靠实体类型的隐藏特例。
3. **世界行为由法术组合。** 普通法术编排原子读取与效果形成运动、命中、爆炸等行为。离散事件选择已绑定法术；持续行为的调度、感知与做功需有界付费。惯性和物理模拟不必每帧运行玩家 DSL。
4. **元法术原子且价格可解释。** 组合能实现的追踪、爆炸流程或战术不得因方便而成为新元法术。读取、状态占用、世界效果和执行工作分别定价；更优算法因减少真实工作而省资源，不能无依据打折。静态上界仍不低于实扣。
5. **资源有来源与终点。** 创建者向法球注入有限资源；法球按获准账户付款，耗尽即失败或停止，不借用创建者未来法力。事件、感知、运动、伤害、范围效果、损耗与退款都须可追溯。
6. **事件语义跨实体一致。** 受伤、碰撞、耗尽、消失等事件先提交事实，再按稳定顺序运行绑定法术；上下文、信息权限、重入边界、死亡/消失后的授权和失败语义统一。

代理审核只验证证据和内部一致性，不能代替制作人确认这些隐含意图。

## 相邻情形检验

- 修士受伤与法球碰撞都能绑定普通法术。事件只交付获准事实；响应使用同一 VM、授权、付款和失败合同。
- 敌方修士创建法球，与玩家使用相同的创建、注能、绑定、耗尽和死亡规则；AI 只决定何时选择施法。
- 爆炸、陷阱或护盾也应能从事件和原子效果解释其触发、范围、付款、占用及结束。本版不因此承诺全部实现。
- 多响应争用一笔余额时按稳定顺序原子扣款；创建者死亡后只允许预先声明的有限授权继续，不能免费施法或重复退款。
- 被注入更多资源的法球、无人供能但材质稳定的造物、持续自我维持的修士及失去维持能力的修士，应能由同一存在规则推导存续或消失，而不是各给一个任意倒计时。
- 法球碰撞、越界、创建者死亡与资源耗尽是不同事实；它们可能分别导致受损、失去控制、停止施法或消失，不能一律等同“法球过期”。

## 候选的统一存在模型：待论证，不当作既定规则

策划建议先检验这一解释：**实体的存在由其结构状态与维持条件决定，消失是这些条件失效后的结果，不是按种类附加的计时器。** 世界创建任何实体时，都要记录构成来源、初始结构、可用供能与维持方式。结构可能在碰撞、伤害、自然耗散或主动法术下变化；修复和补给也必须有来源、权限与价格。修士和法球使用同一套状态变化与终止判定，差异来自具体构成和供能能力。

较有解释力的候选是“**结构完整度 + 构成材料的稳定性 + 可追溯维持来源**”：灵力聚成的法球若会在环境中散逸，创建时投入的结构资源决定初始完整度，散逸按统一环境规律削减，额外供能或维持法术可以延长存在；完整度归零才瓦解。修士的肉身若由更稳定的物质构成，可通过同一完整度规则长期存在，受伤、代谢和修复仍有来源与代价。由稳定物质构成的法球或其他造物也可能长期存在，不应因为叫“法球”就过期。**施法余额与结构完整度须区分**：法球用完施法资源可以停施法但继续存在，除非它明确把同一笔有限资源用于维持结构。以上只是待主策证明的候选机制，尚未决定材料种类、散逸速率或具体数值。

这尚未回答“法球为什么衰减”，不能把“法球是法术造物”当作充分解释。主策须在不同候选机制间给出理由：若法球是会自然失稳的术式结构，说明失稳量、速率及可付费稳定方式；若它由稳定物质构成，可能根本不该自动消失；若时限来自预付维持，说明到期后是结构瓦解、停止施法还是只解除控制。修士能够长期存在，也须由同一机制解释其稳定构成或持续补给；不能给修士一个无条件豁免。更大的预付资源应如何改变存在时间、额外补给能否延长、停止供能后是否留下惰性实体，都由模型推导，不能先写固定答案。

策划先形成可核对的**世界规则表**，对修士、法球、敌方修士及至少两种相邻实体逐一填写：

| 要解释的问题 | 应有的统一答案                                                             |
| ------------ | -------------------------------------------------------------------------- |
| 创建         | 构成、状态容量与初始资源从哪里来，谁付款、谁取得控制权？                   |
| 存续         | 哪些状态必须保持；维持消耗什么、何时扣费，稳定实体能否无需主动施法而存在？ |
| 变化         | 运动、感知、伤害、恢复、爆炸如何由原子效果和环境规律产生？                 |
| 事件与施法   | 谁订阅、谁执行、谁付款；资源不足或权限失效后发生什么？                     |
| 消失         | 哪个条件失效，剩余结构或能量去向何处，何时发送消失事件？                   |

同时列出每条元法术的不可再组合理由和成本依据；可由既有原子能力组合的追踪等行为降为普通法术。用反例主动检验规则：长期供能法球是否仍强制过期、稳定造物为何消失、修士不回蓝后是否也凭空消失、碰撞是否必然爆炸、创建者死亡时实体与施法授权是否必须同时终止、预设与敌方 AI 能否只靠通用规则工作。每个反例都必须给出因果链和资源流；解释不了就回头修改规则。

**当前阶段不选开发切片，不排具体预设或敌方技能实现。** 主策先提交候选规则、相互冲突的解释、反例结果及推荐模型，与制作人对齐；规则稳定后才选能验证它的最小可玩路径，再确定预设和敌方修士怎样展示不同机制。原型期可重做旧元法术、法术书和存档；只需如实说明会失去哪些旧原型内容与数据，不为维持旧行为扭曲新规则。难以撤销的架构选择在设计确定时写新 ADR，并明确覆盖旧 ADR 0017–0020 的条款。

本阶段验收是：至少对“为什么法球会消失”给出与修士和相邻实体同源的可推导解释；若仍有无理由的固定 `life`、隐形免费维持、实体种类专用施法或可组合元法术，策划不得称为自洽。非目标是现在实现任何法球行为、确定战斗数值、完成旧内容迁移或发布游戏版本。

## 制作人对齐状态

制作人已确认生命与实体存在分开、人工造物可成为生命、法力转移守恒、无施法时的默认世界演化及现实输入只是意图桥接；熵方向由制作人提出供探索，尚未定稿。具体生命定义、存在模型和完整桥接接口仍需论证。原型期无需旧内容兼容方案。[世界底层规则](./world-foundations-draft.md)、[生命及世界边界草案](./life-and-world-boundary-draft.md)和[熵方向候选模型](./entropy-direction-draft.md)继续用反例核对推导。未完成论证和制作人评审前不进入开发；不重复询问已回答的取舍。

本版同时记录 PM 交接、调用、已知 token 下界、重复读取、返工和耗时，以验证新流程能否保持意图。这些是过程数据，不是游戏主题。制作人立项前不进入详细策划或开发。
