## 相比上一轮仍需补全的具体设计合同

上轮退回的**独立读取/维持报价、有限身份判据和 H/B 逐笔链**已有候选，不再以同一缺口退回。本轮请主策与相应策划在已批准方向内补下列可验收纸面成果：

1. **普通行动和资源流的首批成功域。** 为至少一种修士起步、持续行动和生命代谢，以及同一规则下法球/机关的适用或拒绝条件，给出实际施力或调节结构、物理反作用、付款账户与补源、正价/合法尝试价、算法工作和静态毛界。把环境可取分区与已付散逸分开，用“来源→作用→回收→再作用”复算无套利。域外读取和开放回收可继续明确拒绝，但须在首批玩家流程中标明哪些请求成功、哪些 `unknownPrice`，不能把常规行动留作无源自动驱动。[现有有限价域](./mana-ledger-design.md)、[主策缺口](./design-review-findings.md)。
2. **具体生命与恢复证书。** 为首批修士和一个自维持人工造物各登记可测的关键回路功能、材料/扰动域、失供 `N→X`、救援截止、保存容损及结构/记忆/控制连续证据。逐格推演 `100/20` 最后一击、及时/逾期补源、遗体外壳修复和复制分叉，输出生命状态、`LifeId`、撤权与玩家可见的 `unknown`。若关键回路仍在 `D0` 外，首批明确展示“不可修复原身份”的失败路径和可表达的惰性修壳路径；不得把样例阈值套作所有生命常数。[生命判定候选](./life-identity-design.md)、[物理域](./physics-material-design.md)。
3. **把有限成功域接成可执行的后续验收。** 用同一初态、程序 hash、授权、模拟时刻/序号和种子，为护送 H、活跃信标 B、普通行动各给出推演台→演武场→回编辑的成功、欠费、空结果、越权、接触未裁定与域外拒绝表。写明程序载体的结构容量条件、暂停/恢复输入边沿、事件与读取权限、已付事实不回滚，以及旧法术/存档如何隔离和定位。纸面脚本只能承诺首批证书内的结果；实际运行、手柄和敌方修士同规则验证留到获准开发后的验收。[桥接矩阵](./player-bridge-design.md)、[程序边界](./programmable-spells-design.md)。

这是从已批准方向继续推导的设计任务，不要求制作人现在选择技术参数。推荐首批保持有限有证来源、有限感知与材料域、证据不足报身份未知、死后独立授权关闭；部分自由吸能、远距探查与原身份复苏暂不可用，但每笔世界作用可追溯。如补全后仍需扩大这些玩家规则，再附通俗的两案体验、优点、代价、跨模块影响和推荐理由请制作人取舍；本轮没有必须立即升级的新增方向冲突。
