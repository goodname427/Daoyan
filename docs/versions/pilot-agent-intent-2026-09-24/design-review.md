**版本**：`pilot-agent-intent-2026-09-24`；范围修订 `13`，策划修订 `2`。

**结论：退回详细策划补全（`changes-requested`）。** 本轮 `unified-world-review` 已交付复审证据；任务完成不等于策划通过。同刻六阶段相对顺序与信标窄材料域的拒绝边界已有一致解释，但共同价函数、材料精度、生命身份和授权仍不足以形成可实施合同。制作人已选定六类方向 `A/B/B/B/B/B`，并委托主策和策划推敲剩余细节；本次不要求重选方向，不批准游戏开发。

## 已核对的设计

- [意图对齐记录](./intent-alignment.json)把属性驱动、统一实体、资源守恒和事件化法术作为共通原则；减速、破防、法球碰撞与追踪只是检验例子。[唯一世界理论](./world-theory-draft.md)及[五份模块细则的汇总](./module-design.md)分别说明自然接触与付费作用、资源来源与去向、实体存在与生命、程序能力与授权、现实输入与世界请求。旧[整版策划](./world-rule-design.md)仅是待复核的历史解读。
- [主策审核记录](./design-review-findings.md#相邻玩法及指定反例账本)逐笔核对接力护送、自修复信标、`100/20` 储备挪用、失供与额外注能、创建者死亡、场外及连续碰撞、遗体再损和回收套利。修士、法球、稳定物、机关与人工生命按结构、来源、权限和事件判断，不由实体名称获得免费效果。[理论正文](./world-theory-draft.md#同刻权威顺序f3f4-的共同因果合同)的自然接触、预授权补源、主动作用、维持、身份撤权、事件派发顺序已与五份细则核对一致；具体阈值与价格尚未决定。
- [玩家往返合同](./design-review-findings.md#推演台演武场同一法术书)涵盖推演台编辑、预算、单步推演，演武场绑定与观察，再回同一法术书修改，以及成功、拒绝、空状态和鼠标、键盘、手柄、AI、实体事件的等价请求。现有代码与测试只证明旧原型的局部入口；本节点没有新规则的可玩体验证据。
- [旧实现与 ADR 对照](./design-review-findings.md#旧策划代码测试体验与-adr-对照)标明统一句柄、原子账和确定事件的可复用部分，也标明固定寿命、自动回复与驱动、动能致伤、三池换算及死亡后授权的冲突。新语义若获批准，必须先以 ADR 明确覆盖现行合同；旧法术与存档不限制原型期设计，但不等价转换须定位拒绝或隔离。

## 退回原因与补全要求

1. **共同价格和资源闭合**：[资源细则](./mana-ledger-design.md)与[程序细则](./programmable-spells-design.md)已有毛支出、来源、去向和失败余态的相对账序，仍须给出法力到做功与材料改变、合法尝试价、环境可用性和静态上界的可信共同合同。未知价格保持“待定价”，不能作为零价效果或用旧池折算。
2. **生命、材料与可表达域闭合**：[生命细则](./life-identity-design.md)的休眠、死亡和同一身份阈值仍未定义；[物理细则](./physics-material-design.md)的接触、材料粒度和容差尚无验收尺度。信标仅承诺窄域结构修复；域外关键回路的同一生命复苏已明确标为“不可表达”，不得暗加专名能力。策划须说明这一边界是否足以支撑拟议体验，并给出连续身份的判据。
3. **事件、授权与完整体验闭合**：六阶段相对顺序已闭合，碰撞稳定排序、生命临界阈值和合法尝试价仍须反例验证；死亡后独立程序的签发者、期限、额度、字段权限及容量尚未形成统一合同。[桥接细则](./player-bridge-design.md)已有推演台到演武场的纸面成功、拒绝和空状态流程，仍须把新规则下可见账目、隐私与旧存档隔离落实为完整验收。现行入口不能当作新规则实际可玩证据。

[审核记录的六类比较](./design-review-findings.md#六类已选方向后的闭合问题)是主策继续推导的候选，不是制作人对参数和新语义的批准。主策应在已选方向内自行采纳或修正推荐，补齐阈值、报价、反例、原子不可约性和跨模块接口；只有推导后确实出现超出已批准方向的产品冲突或不可逆取舍，才连同通俗的两案规则、玩家体验、优点、代价、跨模块影响、推荐及未决阻塞范围升级。补全后的**同一篇**世界理论和模块方案再交制作人审阅。此前不选开发切片、不制作预设、不改敌方修士或游戏代码。
