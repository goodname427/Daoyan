# 策划审核节点公开结论

版本：pilot-agent-intent-2026-09-24；范围修订 13，策划修订 2。

**结论：退回详细策划补全（changes-requested）。** 六项 mdc 模块修订与本轮主策复审均已交付。共同因果、封闭来源守恒、窄材料域拒绝和同刻六阶段相对顺序在纸面上贯穿修士、法球、稳定物、机关和人工生命；但正做功与材料编辑没有可报价的成功域，部分生命和授权结果仍缺少可判定边界。这还不是可提交制作人审阅的完整版本方案。制作人已选 A/B/B/B/B/B 方向，并委托主策和策划推敲细节；本次不要求重选方向，不批准游戏开发。

## 已通过的纸面核对

- [意图对齐](./intent-alignment.json)把属性、统一实体、资源守恒、事件和可编程涌现作为系统原则；法球碰撞、追踪和减速只是例子。[唯一世界理论](./world-theory-draft.md)与[六模块汇总](./module-design.md)使用同一自然接触、获准转入、付费作用、维持、身份撤权、事件派发次序；鼠标输入和实体名称均不赋予世界特权。
- [本轮主策复审](./design-review-findings.md)核对接力护送、自修复信标、100/20 最后一击、失供、额外供能、创建者死亡、连续碰撞、遗体再损及回收套利。已付惯性不再收费；域外关键回路的复苏不能冒充普通材料修复；同刻事件产生的新钱不能倒救先前维持。
- [玩家桥接](./player-bridge-design.md)给出推演台编辑、预算和单步，演武场绑定和观察，再返回同一法术书修订的纸面流程，覆盖成功、拒绝、空状态及鼠标、键盘、手柄、AI、事件的等价请求。策划审核核对流程和后续验收；本次退回不以新规则尚未实际可玩为理由。
- [旧实现对照](./design-review-findings.md)区分可复用的统一句柄、AST、原子账和入口，与自动回复、固定球寿命、旧伤害池及授权的冲突。获准后须明确覆盖 ADR 0017–0020 的条款与旧原型、存档影响；原型兼容不限制理论。

## 相比上轮仍须补齐的合同

上轮退回项中的**六阶段相对顺序、封闭账户的无套利证明、窄材料域的域外拒绝、跨入口纸面往返**已有进展，不再笼统退回这些项目。下一轮须提交下列可验收补全。未纳入首批表达域的作用可明确拒绝，但至少应有一个完成自然运动、付费作用与玩家编辑的正向闭环。

1. **共同报价与资源流**：在[理论共同报价](./world-theory-draft.md)、[法力账本](./mana-ledger-design.md)和[程序预算](./programmable-spells-design.md)中，为首批有限施力和材料编辑作用域给出单位、正价下界、共同价函数、合法尝试价、材料与做功的去向、tick、神识和毛法力静态上界证书；逐笔重算一例成功、一例欠费和一例未知价。未知价保持拒绝，不能用 100/20 示意数字或旧三池倍率替代实价。环境先限已登记、预授权、有限且可报价的来源；开放回收留在域外，用创建、使用、退款、再创建证明余额不增长。
2. **接触和材料的可判尺度**：在[物理材料细则](./physics-material-design.md)明确首批形状、承力部位、材料粒度、接触容差及同组多解规则；给同初态不同模拟步长的擦边、墙、两目标和场外用例，指出何时有接触与结构变化、何时未裁定、如何避免数组顺序造成重复伤害。未裁定不能暗示无伤或必碎。推荐有限二维形状和少量承力部位，策划须给尺度候选及反例，而非将参数空白直接交制作人。
3. **生命与身份的有限判定域**：在[生命细则](./life-identity-design.md)为首批修士和人工生命给关键回路功能、维持窗口、失供临界、休眠保存、不可逆损坏与生命身份连续性的最低证据或明确域外返回；对 100/20、及时补源、遗体外壳修复、复制分叉分别算出生命状态、身份关系和权限余态。推荐有证据的临界救回；窄材料域外的关键回路复苏继续拒绝，普通修壳不得写成同一身份复活。若最低连续条件确实引出新的生命产品定义，再附制作人可比较的选项。
4. **程序、事件与授权的首批合同**：在[程序细则](./programmable-spells-design.md)和[桥接细则](./player-bridge-design.md)把首批原子的不可组合事实、有限记忆与订阅、队列上界、合法尝试工作价、同刻并发顺序和字段裁剪接到共同报价及失败余态。死者派生权立即撤销；若允许独立残余程序，须给签发者资格、有限期限和额度、付款来源及可读字段，检验创建者死亡、过期、队列满、遗体私值与重复事件。无法闭合则明确首批关闭该能力，不能同时暗示信标死后仍可执行。推荐严格预签的有界授权，具体边界由主策从已选方向论证。

共同公理和反例继续维护在**同一篇世界理论正文**；模块细则写接口、参数与玩家结果。下一轮主策核对各项成功、失败、空状态、域外用例及推演台到演武场再返回的可执行验收，并标明 ADR 覆盖和旧原型隔离。若出现真正超出已批准方向的产品选择，再给制作人通俗的两案规则、玩家体验、优点、代价、跨模块影响、推荐及未决阻塞；本轮未发现必须现在由制作人取舍的冲突。
