# 世界的演化方向：熵模型候选

- 版本：`pilot-agent-intent-2026-09-24`；范围修订：`8`；状态：**制作人提出的探索方向，经主策推演的候选模型，未定稿**。
- 已确认：法力只能从一处转移至另一处；无施法时世界按默认规律演化；法术由实体支付法力来请求世界效果；人工造物若真正具备生命条件，也可以是生命。
- 本稿要回答：为什么术式法球不能无源凝结、为何会消散，生命为何需要维持，为什么付给世界的法力不能无损取回，以及稳定石头为何不必每秒施法。
- 非目标：不模拟完整现实热力学，不规定具体数值、材料、生态或战斗实现；本稿不是新 ADR，也不授权开发。

## 建议的一条总规律

**世界有一个不可逆的默认演化方向。** 在封闭范围内，无干预过程会耗散可利用的差异，趋向该环境允许的稳定状态。这里借用“熵方向”描述这一约束，不把真实物理熵直接当作玩家的一条数值。一个局部结构可以自然变得更有序，但只要它利用了外部已有的差异、让整体演化仍沿这个方向前进，就不是凭空逆转世界。

法术让实体**有意使局部状态偏离默认演化**：先向世界或目标转移法力，世界按元法术合同完成有界效果；执行要花时间。建立会自然散逸的精密结构、维持活体关键组织、持续推进法球都属于可能需要付款的干预。停止干预后，结构重新按默认规律演化。伤害法术也付法力，尽管它可能加速局部失序；法力不是只为“降低熵”收费，而是实体主动取得世界效果的统一交易媒介。

这条总规律仍需要材料、相互作用和结构阈值来决定**具体怎样**演化。仅说“熵增加”不能算出法球散逸速度、修士何时死亡、元法术价格或伤害量；若不补这些规则，只是把旧的 `life` 倒计时改名。因此建议把它作为所有实体共享的**方向与禁止套利约束**，再建立可观察的局部转移规则。

四者的关系可以简写为：**世界**提供默认演化和付费干预的规律；**实体**是世界中暂时可辨认的局部结构；**生命**是能主动取得来源并维持自身关键组织的一类实体过程；**法术**是具备执行能力的实体通过转移法力改变世界演化路径的手段。熵方向约束四者，但不把实体、生命或施法混为一项。

## 最小状态与转移账本

为每个实体记录构成与关键组织 `Q`、可用法力所在账户 `M`、运动状态、程序/执行结构及授权；世界还要记录环境状态、各处法力分布和默认演化规则。`Q` 是多维的结构关系，不等同单一 HP。候选约束可写成：

```text
无施法：Q' = Q + 自然形成 - 自然散逸 - 碰撞损伤
有施法：Q' = 无施法的结果 + 已付款且被授权的元法术效果
法力转移：来源账户减少 m；目标或世界账户同时增加 m
```

普通运动和碰撞按默认规律结算；付费术式可以改变运动或结构。若按热力学比喻，局部维持有序结构时，世界其他部分须承接更大的耗散；法力交给世界后的**总量仍在**，只是分布、可取得性及可利用的差异变化。于是“法力守恒”与“可用性下降”是两项不同约束：前者禁止凭空出现或消失，后者禁止同一笔法力在封闭循环中无限次免费做功。环境可以有地脉、食物或灵石等来源，但它们都须是已有账户；开放世界的边界流量也要入账。

这不要求给玩家额外增加一根“熵值”条。法力的**位置、浓度、可达性和收集速率**已经足以表示为何散到环境的法力难以原样取回；是否还需要显式的品质/位势变量，需在闭环反例中判断。若允许“付给世界 1 法力，立即从同一世界池无损吸回 1 法力，同时保留效果”，模型就失败，必须收紧环境分布、转移成本或效果合同。

这也带来一个世界尺度的问题：若整个世界完全封闭且所有可用差异只会下降，生命和持续施法最终都会缺少可收集的法力。若希望世界长期繁衍，必须明确地脉等**已有、有限且会变化的高可用来源**，或定义可审计的世界边界输入；不能只写“天地灵气每秒自动刷新”。这决定生态与修炼的上限，但不要求本轮确定世界寿命和数值。

## 同一规律推导六类对象

| 对象或过程         | 初始来源与维持                                                                                                                     | 停止供给后的结果                                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **稳定石块**       | 材料在当前环境下接近稳定状态；它可以由自然过程形成，不需不断逆势维持                                                               | 继续存在。若环境改变、受撞击或被法术作用，才按共同规则变化。                                                               |
| **普通术式法球**   | 修士转出法力：一部分形成并组织球体结构，一部分注入施法储池，施法过程的费用转给世界；构成材料也须有来源                             | 若构成会自然散逸，结构逐渐失稳；到阈值时解体，残余法力转入环境或其他明确账户。耗尽施法储池与解体是不同事件。               |
| **稳定材质的球**   | 制作时有材料和施法成本，但其完成后的结构在环境中稳定                                                                               | 可以长期存在，不因名字叫“法球”而过期；失去法力可能只使其无法施法。                                                         |
| **修士生命**       | 关键组织自身运行维持循环，从来源吸收法力，并按周期付费抵抗自然损耗、修复偏差；它不需要玩家每帧按键，但执行、授权和账本同属世界规则 | 停止补给先使维持过程失效，关键组织随自然演化受损；跨过不可自行恢复的阈值才死亡，肉身仍可能存在。瞬间零余额不等于瞬间死亡。 |
| **人工生命**       | 若造物具有同样的自主调节、摄取、修复和维持循环，也按相同规则付法力                                                                 | 与修士一样可能休眠、失调、死亡或被修复；是否为血肉不构成豁免。                                                             |
| **尸体、停机机关** | 原有物质与回路仍可存在，但关键自维持过程已停；独立授权的术式可能仍有有限余额                                                       | 按材料稳定性继续变化，不因为“已死亡/停机”立即删除。                                                                        |

这里的**生命**仍由“自主维持关键组织的过程”界定，持续付法力解释这个过程为何能在耗散世界中维持，却不能反过来把“会花法力”当成生命定义：一颗被外部持续供能的法球也会花法力，但它未必具有自主的生命组织。人工生命可成立是制作人本轮认可的方向。休眠、魂魄与复苏的具体条件仍待世界设定；低耗休眠若发生，也要有剩余供给、环境稳定条件或有限储备，不能靠暂停计时偷渡。

**维持生命不等于解释第一种生命如何出现。** 候选世界允许两条需要分别证明的来源：某种环境差异沿默认演化自然形成可自维持的组织，或者已有实体用法术和明确材料把这种组织造出。两条路径都必须交代初始结构、程序/调节能力、法力来源及后续自维持；不能把“有熵方向”直接当作生命起源的答案。后代产生或人工复制也遵守同一创建与资源规则。

## 必须守住的三条边界

1. **稳定不需要持续付费。** “万物朝熵方向演化”不等于一切物体线性掉血。不同材料和结构有不同稳定区间；自然形成的晶体、石块和惰性残骸在其环境中可以长期存在。若说每个实体每秒都要付法力，就会让石头、地形和世界本身也陷入无源维持。
2. **付款不是抹掉法力。** 修士向世界付款后，世界账户收到法力；向法球结构和储池注入后，球体账户收到法力。散逸、退款失败和转换损耗同样有接收处。世界可利用这笔输入产生效果，但不能把物质、法力和运动单位混为一项。
3. **不可逆性阻止循环套利。** 一次法术可以局部维持秩序，但要让施法者、目标、环境和所有账户完全回到原状态，不能同时保留一个额外效果。回收散在环境中的法力需要收集条件、时间和可用差异；一个封闭的“造球→球消散→回收全部法力→免费造球”循环必须失败或失去其他资源/可用性。

现有实现已有待重审的反例：[`World.tickActor`](../../../src/core/world.ts) 以 `manaRegen × dt` 给 Actor 加法力，没有来源账户；角色普通运动使用会按时间自动补回的 `movePower`，其供能来源也未接入本候选模型；[`Battle.updateProjectiles`](../../../src/game/battle.ts) 则以固定 `life` 递减移除法球。这些是旧原型机制与新方向的冲突证据，不在世界规则获得确认前逐点修补。已采纳 ADR 0017–0020 对资源和运动有历史约束，定稿前须另写 ADR 说明哪些条款被覆盖，不能仅修改策划文字就宣称实现已统一。

## 下一轮应如何证明或推翻

主策应给出至少四类结构的初始状态、默认转移与付费转移，并演算：无供给、补给不足、刚好平衡和超过需求；稳定球、散逸球、修士、人工生命各自在余额归零、结构受损和环境变化后的状态；世界法力池是否能无损回流并产生免费循环；法术伤害为何仍需付款；法球是否可在自然过程中无源出现。若每个答案都需要再加一个按类型命名的例外，说明这条候选规律还不够深。

**推荐取舍：**采用“不可逆默认演化 + 法力转移驱动有意偏离 + 结构稳定性决定是否需要持续维持”作为下一版世界公理的候选框架；把生命视作其中一类自主维持过程。暂不采用“一切实体每秒都消耗法力”或“支付一次法力就能永久制造任何结构”这两种过度简化。只有闭环账本、稳定物反例与生命阈值说通，并经制作人审阅，才定稿或安排实现。
