# 详细策划退回后的当前节点任务（范围修订 13）

**问题**：[最新主策复审](./design-review.md)已确认六项 `mdq-*` 和 H1/A0 耗时、J1 方向槽修订，但包的上游装载、M1/A1 关键修复与身份连续、逐体容量和整程序上界尚缺纸面证书。**范围**：仅补这四项退回合同及必要的理论、桥接接线。**非目标**：重派历史任务、扩写版本策划、预拆 Feature PM 步骤、定开发切片、改游戏/测试/ADR、取得实际可玩证据。制作人既定 `A/B/B/B/B/B` 方向是修订输入，完整方案仍待主策复审及制作人审阅。

| 真实受影响模块与独占任务                                       | 本轮新增判断、反例与直接验收                                                                                                                               |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [物理材料](./physics-material-design.md) · `mds-supply`        | 为 H2、B4、A0、K0/V0 的工作/摄取包给上游库存、封印读数和精度、结构与材料去向；反证无包、无支点、已损材料、连续碰撞及第二次回收。只签有来源的有限物理证书。 |
| [法力账本](./mana-ledger-design.md) · `mds-ledger`             | 独立核 M 来源授权、装载/补充/回收事务、Quote/Tx、不可取分区和循环毛界；检验余额足却缺包、并发付款、来源到期及重复回收，条件价不等于成功价。                |
| [生命身份](./life-identity-design.md) · `mds-life`             | M1/A1 分别给关键材料、首损/终界、获准关键修复和截止测量、唯一三链；逐 tick 反证最后一击、迟到补源、休眠、修壳和复制。缺证保持 `unknown`。                  |
| [可编程法术](./programmable-spells-design.md) · `mds-capacity` | 从四体结构求代码/槽/队列/帧/神识/储池与同刻峰值，加入 AST/记忆/事件工作求整路径 `τmax/Smax`；检验满额、损坏换证、同刻第二信封及死亡撤权。                  |
| [唯一世界理论](./world-theory-draft.md) · `mds-theory`         | 只将四份新证书按同一 ID 与时序接到已有因果链；对 H/B、普通行动和 `100/20` 标明成功前提、已付余态及未证攻击价，不另立公理。                                 |
| [玩家桥接](./player-bridge-design.md) · `mds-bridge`           | 只把同版结果转成推演台→演武场→返回及六入口的成功、失败、空、未知、域外纸面验收；列公开字段、实扣、事件、暂停边沿和旧内容处理，不登记运行通过。             |

**跨模块合同**：物理持有 `C/N→X`、工作/材料包和反作用；资源持有 `M` 来源、付款及 `Quote/Tx↔A`；生命消费同版结构与净到账，持有 `LifeAssessment/LifeId/DeathBarrier`；程序消费结构、账本与撤权，持有容量和整程序上界；唯一理论按同一请求/批次/版本/事实 ID 接线；桥接消费其结论，比较同规范意图。直接依赖及独占写入见[机器合同](./module-design-tasks.json)。旧 `mdq-*`、既有条件账和已闭合规则仅作只读前驱；共享 `module-design.md`、`docs/status.md` 与最终一致性核对留给 Version PM。

如有限已批准域不能签正向证书，明确拒绝或未知。只有需要法力无源生功、开放环境回收、死后独立授权等新解释时，另向制作人提交各方案的玩法效果、优势、代价和推荐理由；本轮不代为批准。策划只定义以后可执行的验收，开发与候选阶段才取得实际可玩证据。
