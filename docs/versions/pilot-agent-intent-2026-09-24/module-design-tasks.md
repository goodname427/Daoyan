# 详细策划重入任务（范围修订 13）

**问题**：最新[主策复审](./design-review.md)认定旧六项文档均已交付，但共同价函数、接触与材料精度、生命同一性、原子不可约性、死亡后授权和新规则可见反馈仍未闭合。上轮规划复用旧任务 ID，无法作为新的阶段交付。**范围**：只为未闭合合同建立新的模块设计成果。**非目标**：重选制作人 A/B/B/B/B/B 方向、扩写整版策划、改游戏实现或测试、规划后续节点、选开发切片或宣称可玩。

| 受影响模块           | 新独占任务    | 策划交付物                                  | 上下游合同与直接验收                                                        |
| -------------------- | ------------- | ------------------------------------------- | --------------------------------------------------------------------------- |
| 统一世界理论         | `mdc-theory`  | [唯一正文](./world-theory-draft.md)         | 统一价函数和因果术语、反例总账及认识状态；给五模块共同原则，不复制细则。    |

六阶段相对顺序及窄材料域外拒绝已由复审核对，本轮以其为输入，不重复派交旧六项。新 ID 均未见于历史 `stageTasks`，各任务独占一份细则；依赖按理论→物理→资源→生命→程序→桥接传递合同。共同接口须同时写清作用 ID、交易 ID、结构和身份事实、授权字段、模拟时刻及失败余态，随后由 Version PM 核对一致性。[节点总报告](./module-design.md)和 `docs/status.md` 留给 Version PM 收束。

策划只定义可执行验收，不把现行原型当成新规则可玩证据。若已选方向内仍无法推导价格、身份或权能，应标明待定价、不可表达或未决；确需新产品解释或不可逆 ADR 覆盖时，以通俗文字说明每案玩家效果、优势、代价、推荐及理由交主策和制作人。完整方案获制作人审阅前不进入游戏开发。任务 ID、验收、依赖及独占读写路径以 [JSON 清单](./module-design-tasks.json) 为准。
