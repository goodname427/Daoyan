**跨模块合同**：物理交来源、余量与自然事实；账本消费已签可用份额并交付款和不可取账；生命消费自然事实与到账资源并交身份、终界和撤权；程序消费结构、价格与撤权并交容量上界；桥接只映射意图和暂停边沿；唯一理论统一这些规则与同版重放。[机器任务合同](./module-design-tasks.json)列直接依赖和独占写入路径。既有已闭合因果只读复用；`module-design.md`、设计评审与 `docs/status.md` 由 Version PM 收束，不交模块任务改写。

本节点仅交可审阅的规则、反例和未来执行验收。若需关键生命回路编辑、法力直接生功、环境回收、独立死后提款或覆盖暂停 ADR，先由主策用通俗玩法效果、优势、代价及推荐理由升级制作人。主策复审前不提交完整方案给制作人，也不进入开发。
