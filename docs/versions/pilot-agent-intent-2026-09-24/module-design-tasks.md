**跨模块合同与依赖**：物理交合法来源、材料及自然事实 → 账本交装载/作用报价和已到账资源 → 生命交保存、身份与撤权 → 程序交四体容量及整链界 → 桥接交规范意图与公开投影 → 理论在唯一正文收束。桥接沿用已闭合暂停合同；各模块只写自己的细则，已闭合成果为只读前驱。[机器合同](./module-design-tasks.json)列直接依赖、必要输入和独占写入；共享 `module-design.md`、评审文档及 `docs/status.md` 留 Version PM 汇总。

本节点交纸面初态、参数、逐笔账、反例与未来可执行验收；真实四读、自然响应、容量峰值、报价实耗及双场景实玩留开发后和候选验收。若需扩展关键回路、法力生功、环境回收或死后独立提款，由主策判断是否升级制作人。策划未获认可前不进入游戏开发。
