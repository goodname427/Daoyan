# 详细策划退回任务（范围修订 13）

**问题**：[最新主策结论](./design-review.md)与[逐项发现](./design-review-findings.md)确认六项 mds 成果已交付，但正功/摄取包上游、M1/A1 关键修复与身份连续、四载体容量、独立攻击价及整链预算未闭合。**范围**：只补这些合同并在[唯一理论](./world-theory-draft.md)同版收口。**非目标**：重派历史任务、扩写版本策划、拆 Feature PM 内部步骤、开发游戏/测试、选择切片或宣称实际可玩。以[意图对齐](./intent-alignment.json)及制作人已选 A/B/B/B/B/B 为边界；新产品解释先升级。策划只定义未来可执行验收。
