# 详细策划补全任务（范围修订 13）

**问题**：[最新主策结论](./design-review.md)确认上轮六项细则已交付、统一因果和封闭来源等已纸面闭合，但首批正做功及改料报价、接触材料尺度、生命身份判定域、程序并发和死后授权仍不足以提交完整方案。**范围**：只补未闭合的模块合同和可执行纸面验收。**非目标**：重开已选 A/B/B/B/B/B 方向、重做整版理论、修改游戏或测试、预拆 Feature PM 内部步骤或规划后续节点。策划完成仍须主策复审、制作人审阅；不批准游戏开发。

| 受影响模块 | 独占任务与交付物 | 相对上轮新增的判断、反例和直接验收 |
| --- | --- | --- |
| 接触与材料 | `mdn-physics` · [物理细则](./physics-material-design.md) | 给有限形状、承力部位、粒度与容差候选；用不同步长擦边、撞墙、同刻两目标及场外反证可判性，交可报价作用与材料差量。 |
| 共同报价与法力账本 | `mdn-mana` · [账户细则](./mana-ledger-design.md) | 建正做功和域内改料共同 Quote 与 tick/神识/毛支出证书；复算成功、欠费、未知价及创建回收循环。 |
| 生命与身份 | `mdn-life` · [生命细则](./life-identity-design.md) | 给修士与人工生命共用的临界、休眠、不可逆损坏和 LifeId 最低证据；逐刻判 100/20、补源、修壳、复制分叉及撤权。 |
| 实体程序、事件与授权 | `mdn-spells` · [程序细则](./programmable-spells-design.md) | 定首批原子域、有限记忆/队列与同刻竞争；以创建者死亡、过期、遗体私值和队列满检验独立授权，不能闭合则首批关闭。 |
| 玩家意图与反馈 | `mdn-bridge` · [桥接细则](./player-bridge-design.md) | 将新证书、身份与授权映射成推演台—演武场—返回的成功、拒绝、空与域外流程；纸面比较鼠标、键盘、手柄、AI、事件同一请求。 |

依赖顺序为物理→报价→生命→程序→桥接，每个模块仅由对应任务写一份细则。[唯一世界理论](./world-theory-draft.md)、旧六项交付和[审核记录](./design-review-findings.md)为只读前驱。物理交作用与材料差量，法力交 `Quote/Tx`，生命交状态与撤权，程序交规范请求及获准字段，桥接只表达意图和反馈；已付事实不回滚。Version PM 收束时核对接口与 ADR 影响，并独占更新 `module-design.md` 和 `docs/status.md`。

若具体解释超出已批准方向，策划先列通俗方案的玩家效果、优势、代价、推荐理由和跨模块影响，再由主策决定是否交制作人。实际可玩证据属于后续开发及候选阶段。[JSON 清单](./module-design-tasks.json)给稳定 ID、依赖、验收和独占写入路径。
