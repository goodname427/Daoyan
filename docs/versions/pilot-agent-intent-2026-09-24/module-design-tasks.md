# 详细策划退回后的模块任务（范围修订 13）

**问题**：[主策最新复审](./design-review.md)已认可上一轮有限 `R0/K0/V0` 报价、身份表与 H/B 逐笔纸面链为候选；普通行动有源报价、具体生命物理证书和首批完整可执行验收仍未闭合。**范围**：只补这些合同，沿用[制作人意图](./intent-alignment.json)和既定 `A/B/B/B/B/B` 方向。**非目标**：重做已交付的有限接触、读取报价或 H/B 算术，扩写版本策划，修改游戏、测试或 ADR，规划后续节点。本轮交付纸面设计与可执行验收定义，完整方案仍待主策复审及制作人审阅。

| 真正受影响的模块与独占任务                                               | 相对上一轮新增的设计判断、反例和直接验收                                                                                                                            |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 物理材料 · `mdp-physics` · [物理正文](./physics-material-design.md)      | 普通起步/持续作用的承力、反作用、功和热；修士及自维持人工生命的 `N→X`、扰动及容损证书。检验无落脚、无推杆、接触未裁定与惰性外壳修补，交资源作用投影和生命结构快照。 |
| 法力账本 · `mdp-mana` · [资源正文](./mana-ledger-design.md)              | 普通行动/代谢的有源 `Quote`、尝试价、tick/神识和静态毛界；来源→作用→回收→再作用逐笔无套利，域外读取和开放回收有稳定拒绝。既有 `P0/R0/K0/V0` 只作前驱。              |
| 生命身份 · `mdp-life` · [生命正文](./life-identity-design.md)            | 将样例阈值落到两种具体实体的回路、截止和三链连续证书；验 `100/20`、及时/逾期补源、休眠、遗体修壳与复制，输出身份、死亡屏障、撤权或 `unknown`。                      |
| 可编程法术 · `mdp-program` · [程序正文](./programmable-spells-design.md) | 载体的感知/记忆/执行器/队列容量及 H/B/普通行动装载条件；验缺结构、容量满、越权、死亡撤权与已付不回滚。既有原子及首批死后关闭只作前驱。                              |

| 玩家桥接 · `mdp-bridge` · [桥接正文](./player-bridge-design.md)          | H/B/普通行动的推演台→演武场→回编辑成功、失败、空与域外验收；暂停/恢复输入边沿、五入口等价、旧原件隔离和敌方修士同规则。实际可玩验证留后续。                         |

**跨模块合同与顺序**：`mdp-physics → mdp-mana → mdp-life → mdp-program → mdp-theory → mdp-bridge` 是有效拓扑；生命同时消费物理证书，程序消费物理/资源/生命，理论消费四份模块结果。每项只写自己的正文，写入路径互不重叠。物理持有 `C/N→X` 与作用投影，资源持有 `Quote/Tx`，生命持有 `LifeAssessment/LifeId/DeathBarrier`，程序持有载体、事件与授权，理论维护唯一六阶段因果，桥接只投影获准事实。[机器合同](./module-design-tasks.json)列稳定 ID、交付物、验收、直接依赖及读写范围。Version PM 独占 `module-design.md`、`docs/status.md` 和最终一致性核对。

候选数值仍待整版审核。若具体证书逼出新的产品取舍，先以通俗文字列玩法效果、优势、代价、推荐理由及 ADR/旧原型影响，再升级评审；任务完成不批准游戏开发。
