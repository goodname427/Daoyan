# module-design 退回重入任务（范围修订 13）

**问题**：[最新主策复审](./design-review.md)确认 mdac 桥接已修 D1/B4 物理摘要，但[唯一世界理论](./world-theory-draft.md)仍在相同事实键下使用旧包账与 B4 第二响应简写。**范围**：理论定点勘误，随后桥接按修订理论核三路径和六入口。**非目标**：重做已闭合模块、替制作人选择 A/B/C、实施或实测游戏。**验收**：共同初态、单位、事实键、逐步账与反例在两项交付和只读权威来源间一致。

| 受影响模块与独占任务 | 相对上轮新增判断及反例 | 直接验收 |
| --- | --- | --- |
| [唯一世界理论](./world-theory-draft.md) · `mdad-theory-reconcile` | D1 撤旧 `3→2 E0`，按 `16/12→4/12`、动能/热各 `6/12`；B4 撤销 `2 E0` 全入壳另加 `1 E0` 热，按 `32/12→8/12`、结构功/热各 `12/12`。第二响应区分本体实满、先序换版、容量未读。反例含再撞、POST 失证、同源后笔、普通壳修复却宣告复苏。 | 对照物理、账本、程序、生命及桥接的现行结论修齐六阶段、正例、失败余态；逐包 E0/12、材料 q、反冲、逐 payer M、容量前提和已付事实可复算。 |

**跨模块合同**：物理正文权威签 `S0-physical-v1/seed-physical-v1`、`D1-v1/B4-v1`、来源/读/切片、E0/12、q、热及反作用；账本正文权威签 `readId/payerId/PriceVersion/receiptId`、J1 本人 32 M、P0/P2 1/2 M、可选 P1 1 M 与跨账户 35/36 M，以及 D1/B4 独立 26/34 M；程序正文权威签 `book-mdu-01/v1`、J1 纸面 AST 别名、D1/B4 独立程序与容量范围；生命正文权威签修壳的生命边界。理论整合同一事实的六阶段，桥接只投影获准字段，Version PM 在共享节点报告核联签。物理、账本、程序、生命只作只读前驱；若理论勘误改变它们的权威事实，须撤受影响证并重新规划对应模块成果。

本节点只验收明确初态下可复算的纸面规则及未来可执行验收定义。真实原读、逐账户实扣、规范 AST/hash、容量/占用、VM tick/S 和两页实玩待方案获批开发后取证。A/B/C 首批范围仍由主策在方案完整后交制作人选择。机器合同见 [module-design-tasks.json](./module-design-tasks.json)。
