# module-design 退回重入任务（范围修订 13）

**问题**：[最新主策复审](./design-review.md)确认 mdy 的共同初态四格和十五读价/工作映射已在纸面闭合，J1→H2 仅有一次有源杆推的条件正例；完整护送、信标、普通驱动、维持/攻击、生命醒回及逐体准入尚无同级合同。**范围**：只补拟开放行为各自的模块设计，或形成明确缺席体验的完整窄域候选，供主策复审及必要时制作人选择。**非目标**：重做 mdy 证书、确定首批缩窄、批准新公理或开发、修改游戏/测试、索取现场读数。

**跨模块合同与顺序**：物理来源/材料 → 法力价格/账户 → 生命身份 → 程序逐体准入 → 唯一理论候选范围 → 玩家桥接。物理不定 M 价，账本不造功，生命独占身份判定，程序不借他体容量，入口不改变世界规则。每项只写自己的模块正文；已闭合 J1 四格、十五读与旧任务只读，`module-design.md`、审核及 `docs/status.md` 由 Version PM 收束。稳定 ID、直接验收、前驱、必要读取与独占写入见[机器合同](./module-design-tasks.json)。

所有正向格注明设定初态、参数、逐步账及失败余态；无法在已批准原则内签证的行为明确缺席。真实原读、AST/hash、容量、实扣与实玩只列开发后验收。新公理、关键回路编辑、法力生功、环境回收、无锚转向、死后提款及首批范围缩窄交主策判断是否需制作人取舍；主策复审前不进入开发。
