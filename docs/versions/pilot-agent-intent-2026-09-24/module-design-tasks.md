**跨模块合同与依赖**：物理交合法包和拒因 → 账本交毛价、授权和余额 → 程序交准入上界 → 理论在唯一正文重放 → 桥接交玩家脚本。生命身份、暂停边沿及既有来源残量只读沿用。各任务仅写自己的细则；共享 `module-design.md`、评审文档及 `docs/status.md` 留 Version PM 收束。完整 ID、交付物、验收、直接依赖和独占路径见[机器合同](./module-design-tasks.json)。

本节点交明确初态、参数、逐步账、反例和未来可执行验收。四读、实耗、容量原读及实际推演台—演武场体验留开发和候选阶段。若缺的是未批准的世界规则，交主策判断是否升级制作人；完整方案复审前不进入游戏开发。
