# 详细策划复审退回后的模块任务（范围修订 13）

**问题**：[最新主策结论](./design-review.md)认定六项 `mdp-*` 已交付，统一因果、有限账本、双时点授权和跨入口纸面流程有条件式方案；正功及材料来源、M1/A1 逐体回路与恢复截止、M1/B1/J1/A1 合计容量缺可核验证书，旧桥接矩阵也尚未接入这些新证书。**范围**：补齐纸面合同，接回[唯一世界理论](./world-theory-draft.md)与[桥接矩阵](./player-bridge-design.md)。**非目标**：重派旧成果、扩写版本策划、选开发切片、修改游戏/测试/ADR 或取得实际可玩证据。完成后仍须主策复审与制作人审阅。

**跨模块合同与顺序**：物理持有 `C/N→X` 和材料/功证书，资源持有 `Quote/Tx` 与来源，生命持有 `LifeAssessment/LifeId/DeathBarrier`，程序持有载体、事件和授权，理论只整合共同因果，桥接将新证书映射到玩家步骤。`mdq-physics → mdq-mana → mdq-life → mdq-program → mdq-theory → mdq-bridge` 为有效拓扑；具体直接依赖与独占写入见[机器合同](./module-design-tasks.json)。每项只写本模块正文，旧桥接脚本、四原子和旧条件账作只读前驱；新桥接任务独占桥接正文。Version PM 留用 `module-design.md`、`docs/status.md` 与最终一致性核对。

若证书要求法力无源生功、开放热/环境回收或死后独立授权等新解释，先用通俗文字列玩家效果、优点、代价、推荐理由及 ADR 影响，再升级评审；不得把候选值或纸面通过当成制作人批准、代码实现或实际体验。
