# module-design 同版联签重入任务（范围修订 13）

**问题**：[最新主策退回](./design-review.md)确认 `mdz` 的 D1、B4 独立物理账、`26/34 M` 逐原子报价及 `37/40 S` 候选负载已有纸面成果，但[唯一理论](./world-theory-draft.md)仍以旧价称 J1 为唯一首批正例，[玩家桥接](./player-bridge-design.md)又排除 D1/B4。三者未在同一初态、版本和首批范围闭合。**范围**：仅补尚未联签的模块接口、统一理论和玩家纸面验收。**非目标**：重派 `mdz` 六项、重做已闭合生命边界、暗定首批缩窄、批准游戏开发或索取运行读数。

**跨模块合同与依赖**：物理事实/结构版 → 法力收据/价格 → 各体程序容量 → 唯一理论同版重放 → 玩家桥接公开投影。五项分别独占自己的策划正文；已闭合的[生命三分判](./life-identity-design.md)只读。每项稳定 ID、交付物、验收、前驱与读写路径见[机器合同](./module-design-tasks.json)。`module-design.md`、共享审核与 `docs/status.md` 由 Version PM 收束。

纸面设计须明示公理、初态、设定参数、逐步账和反例；真实原读、实扣、AST/hash、部位容量及实玩只列获批开发后的可执行验收。若拟缩窄已批准范围、增加公理或作不可逆取舍，先交主策判断是否升级制作人。主策复审与制作人确认前不进入开发。
