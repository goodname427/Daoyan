**跨模块合同**：物理材料正文负责能量、材料、热、反作用与 slice；法力账本负责报价和逐 payer 收据；程序正文负责 AST 别名、版本与容量证书；唯一世界理论联签共同初态及世界序；生命正文界定 B4 仅修惰性壳。桥接消费同一 `S0-physical-v1`、`seed-physical-v1`、`book-mdu-01/v1`、事实/读 ID、payer/grant、价格/物理/容量版本并按授权裁剪展示。J1 本人 `32 M`、其他付款方 `1+2` 或 `1+2+1 M` 与跨账户 `35/36 M` 分列。所有前驱只读；本轮只有桥接一个写入任务，没有同节点依赖或重叠写入。Version PM 在共享 `module-design.md` 汇总，主策随后复审整版一致性。

本节点仅验收纸面设定、逐步账、反例和获批开发后可执行的验收定义；真实原读、实扣、规范 AST/hash、容量、VM 用量和玩家实玩留后续阶段。若出现新的世界规则或首批范围取舍，交主策判断是否升级制作人。机器合同见 [module-design-tasks.json](./module-design-tasks.json)。
