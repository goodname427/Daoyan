Version PM 在两项收束时负责共享 `development.json`/`development.md`、`docs/status.md` 和 `roadmap-handoff.md`，汇总独立审查、最终集成树的一次完整门禁及实际体验。候选体验前同步 `docs/roadmap.md`；交接逐项连接已确认规则、实测、待验证候选、依赖、返工/重设计触发及 ADR/迁移回退状态。该交接不自动批准未来候选或下一正式版本。
