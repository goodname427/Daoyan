# 生命维持与身份连续性：模块详细策划

**边界**：`pilot-agent-intent-2026-09-24`，承接范围修订 `13`、策划修订 `2`、已批准的六项 A/B/B/B/B/B 方向和主策 `changes-requested` 退回意见。本文件在已批准 `mdp-life` 合同内补齐两种具体实体的逐格生命身份判定；直接前驱 `mdp-physics` 提供条件式已提交结构/X 证书，`mdp-mana` 提供 K0/V0 与来源账本，统一世界理论独占共同顺序与反例总账。下文阈值和身份规则是待整版审核的候选合同，不修改已采纳 ADR，也不授权开发。

## 问题、范围与验收

**问题**：生命不能等同于实体存在、HP 或法力余额；若新生命来自真正自维持的人工造物，必须说明它何时成为一个新的生命、旧生命是否延续，以及死亡事实如何撤销程序权限。**范围**是定义生命回路的状态所有权、失供/临界/休眠/复苏/死亡状态机、身份事实及交给程序和界面的接口。**非目标**是给出生命数值、材料白名单、复苏手段价格、存档迁移方案或改写旧 ADR。

验收为：同一套判据适用于修士和人工造物；区分修士、人工生命、法球、稳定物与遗体的存在、生命和可施法；列清结构、回路、供能、控制权的归属与跨模块接口；用 100/20 最后一击、及时补源、死亡后再损和信标修复逐项核验成功、失败及空状态；向程序和界面发布有权限的死亡/身份事实；显式定位旧 HP、自动回复、固定寿命和 ADR 0017/0020 冲突。

## 设计原则与认识状态

制作人已确认生命与实体存在分开，真正能自维持的人工造物可算生命，并选择允许休眠及修复后复苏、身份规则另定。策划采用的推荐原则是：**生命是由有边界的关键组织和回路持续实现的过程；身份是跨状态变化的连续性记录；施法资格是独立的能力、授权、程序和可支付来源判定。** 活着不自动等于能施法，能施法也不证明是生命。

以下是待评审模型，不是代码现状或已批准的不可逆公理：

1. 生命实例 `LifeId` 在自取来源、反馈调节和关键组织维持回路经事实确认成立时创建；实体 `EntityId` 标识当前可辨认结构。创建者、所有者和材料来源都不是 `LifeId`。复制承接按本稿的唯一连续枝判据；无法证明唯一交接时输出 `unknown`，不直接复用实体 ID 充当生命身份。
2. 生命周期候选为 `nonliving`、`viable`、`critical`、`dormant`、`dead`，判定不足时另记 `unknown`，不把未知伪作死亡。实体结构状态另记 `intact`、`damaged`、`fragmented`、`dissolved`。生命判定取决于实际回路、关键组织、已完成的有源维持、可逆储存条件和连续证据，不由 `hp == 0` 或 `mana == 0` 单独触发。
3. 失供先造成可记录的维持缺口与功能退化。`critical` 表示关键功能已有危险，但尚未证明身份不可恢复；`dormant` 表示主动功能暂停且保存义务仍可履行、回路与连续记录仍可追踪。两者均须保留有效的后续补源或修复路径，不能靠界面文字制造可逆性。越过经未来规则定义的不可恢复界后 `dead` 为原 `LifeId` 的终态；一般修复不撤销死亡。
4. “复苏”在策划中只指未确认死亡的原 `LifeId` 从 `critical/dormant` 恢复到 `viable`。死亡后旧材料若再形成自维持闭环，先判新生命和新 `LifeId`；是否存在例外的同一身份复归仍是理论缺口，不能从材料、记忆或名称相似自动推断。修好非生命结构而未闭合回路，仍为 `nonliving`。

### 同一身份所需的连续记录

建议把**过程连续而非材料相似**作为同一身份的默认判据：初次成立时签发一次不可复用的 `LifeId`，随后每次结构、维持和生命阶段变化沿同一因果链追加记录。至少保留 `{lifeId, entityId/部位映射, 关键回路版本, 记忆与调节载体的保存状态, 供能/维持交易 ID, 结构变化 X ID, prior/next, causeId, simTime, worldSequence, 证据完整性, 授权变化}`。死亡、遗体瓦解或跨域移交不删除既有链；换壳、修补只改变映射，不能重签旧 ID。隐私字段留在生命模块，普通事件只给获准摘要。

判 `same` 的必要条件是：原 `LifeId` 尚未确认不可恢复死亡，关键回路或其可验证保存态从前一状态连续承接，记忆/调节载体没有无来源的复制跳跃，材料变化和供能交易可顺序追溯，且修复后的回路实际重新承担维持。满足这些条件才可从 `dormant/critical` 发布同一身份复苏；材料相同、程序脚本相同、控制者相同、余额充足都不足以单独证明。已确认 `dead` 后形成闭环或独立复制体，默认 `new`；缺记录、跨域断链、复制/分裂无法区分时标 `unknown`，冻结旧身份私权，等待产品与架构决策，不擅自归 `same`。`none` 只用于确知无生命身份的结构。回路最低保留度、记忆损失容许度、断链重建与死亡例外均未获批准，故此为候选证据门槛而非最终阈值。

建议的模块消息为：`LifeTransition {lifeId, entityId, priorState, nextState, causeId, simTime, worldSequence, irreversible?, identityRelation, continuityRecordRef, revokedGrantIds}`。事件引用已提交的物理 `C/A/X` 事实或资源 `T` 交易，不重复扣款或改结构。`identityRelation` 仅使用经规则确认的 `same`、`new`、`none` 或 `unknown`；未知时不得向玩家/程序谎报同一身份。维持请求为 `MaintenanceDemand(lifeId, circuitId, dueAt, requiredSupply?, allowedSources, authorityRef, preservationMode)`；生命模块提出真实义务，法力账本报价并办理付款，未知价为待定价而非零。账本返还 `TransferResult(transactionId, sourceId, grossDebit, netCredit, lossDestination, availability, refundBeneficiary)` 和维持结算；**预留、未来退款、环境总量都不是已到账供能**。物理层以 `RepairResult(causeId, changedPartIds, materialLedgerIds, structureVersion)` 回报实际域内结果后，生命模块才复核回路。

同一模拟时刻继承[唯一世界理论的六阶段权威候选顺序](./world-theory-draft.md#同刻权威顺序f3f4-的共同因果合同)：①自然接触及结构 `C/X`，②在此刻之前获准且到期的补源，③到期主动作用，④到期维持及默认失稳，⑤生命/身份判定与撤权，⑥事件派发。阶段内按单调 `worldSequence` 对最新状态逐笔复检；生命模块在阶段⑤统一发布事实，事件响应若另行改变结构，须在下一响应/逻辑边界前重判并撤权。阶段⑥由本刻接触唤醒的信标补源不能倒流到阶段②救本窗口；已提交攻击或接触不因后死回滚。确切回路阈值、数值容差、死亡后独立授权范围尚未闭合；这套顺序是候选策划而非 ADR 0020 已被覆盖。

## 存在、生命与施法是三个维度

“有实体句柄”“能被目标选择”“有法力余额”“当前在场”都不是生命证明。实体移除/范围外未知也不自动等于死亡；死亡与瓦解必须分别报告。

## 失供、临界、休眠与恢复流程

建议的判定顺序是：结构/回路改变 → 计算此刻可用供给及已提交维持 → 更新欠账/功能退化 → 判定是否仍可维持关键组织 → 发出阶段变化 → 程序权限按变化处理。生命模块不把待结算的来源转账视为已到账。回路、组织、材料供给和控制者是不同事实：创造者可以消失而独立预授权回路继续工作；创造者的控制权不得因此转移给回路或尸体。

- **失供与临界**：供给低于真实义务时只记录短缺并按回路受影响次序退化。部分功能丧失不等同死亡；显示具体回路/能力降级及未知阈值。若请求的驱动/术式仍有执行结构和授权，可按剩余来源付款；生命维持不可从未经授权的其他账户暗扣。
- **休眠**：尚未确认死亡且组织可保存的生命可进入休眠候选态。主动取源/行动回路可以暂停，保存组织和连续记录的回路仍须说明真实材料条件、环境及有来源的持续义务；仅有“休眠”标记而保存条件已断不算可逆。原生命主动程序和生命派生控制权按休眠限制停用，独立预授权按自身期限与来源另判。休眠不冻结物理世界时间。保存价引用 `mdo-mana` V0，保存窗口与恢复截止必须由逐实体证书给出且有限；进入方式依然是物理/整版待审参数。
- **及时补源**：在阶段②之前已有授权的转入可用于本刻阶段④维持；转入的毛支出须覆盖净到账、启动价和散逸。若缺口已发生而原身份尚未死亡，补源只阻止后续退化或为修复创造条件，不回滚已发生损伤。阶段⑥事件才触发的转入仅供下一逻辑边界使用；即使同一 `simTime` 也不能撤销阶段⑤已提交死亡。
- **修复复苏**：修复先由材料系统核验来源、权限、域和结算并提交结构变化，生命系统再检查回路和身份阈值。缺材料/越权/报价未知时不产生结构修复或生命变化；修好一般结构不保证重建生命回路。若关键回路落在已选窄材料编辑域之外，信标可完成域内修补，但复苏请求仍属不可表达，不能从修补结果推断同一身份；此边界与[理论 B4](./world-theory-draft.md#跨实体与边界反例的交易明细)一致。

**人工造物的 B 路径**：创建只迁移有来源材料、付费形成结构，初始仍为 `nonliving`；外部注能或持续脚本也只证明账户/程序存在。它实际具备可追踪的自主取源接口、反馈调节、关键组织回路，且能从有限获准来源逐笔付维持义务时，生命模块才建立新 `LifeId`。源断后沿与修士相同的真实材料失稳进入 `critical`，若保存结构和供能义务能成立才可转 `dormant`；在未死窗口内补源并域内修好回路后，沿连续记录复苏为同一身份。若回路不可恢复或连续记录断裂，分别为原生命死亡或身份 `unknown`；在死后重组的新闭环默认新身份。创造者的控制 grant、人工生命自己的取源许可及其 `LifeId` 各自独立：创造者死亡只撤其派生权限，不凭血缘/所有权抹除人工生命或转移其账户；造物失去授权也不等于立即死亡，但它不能越权取得下一笔维持来源。

以下量值都未获批准：临界前允许欠供时长、每种回路的关键阈值、休眠保存需求/最长时间、复苏材料域、死亡不可逆判据、身份记忆/组织最低连续度。**相对同刻顺序已由世界理论给出候选结论**，不能再列为全然未知；物理容差、具体价/工作上界和身份阈值仍须设计评审及必要的新 ADR 闭合。下节进一步固定可复核的判定方法，不把未获批数值写成事实。

## 本轮临界、窗口与 LifeId 判定合同

### `mdo-life` 承接的 K0/V0 证书与阈值

生命模块消费 [mdo-mana 的 K0/V0 证书](./mana-ledger-design.md#k0v0关键回路维持与保存不借控制租约)：`K0` 为已登记活跃回路的维持窗口，`V0` 为已有连续保存结构的暂停窗口。毛价、合法尝试价、tick、神识、静态上界、来源与分区均由账本证书所有；生命模块不复制或重定价这些字段，只消费成功 `Tx-maintain/Tx-preserve`、净到账量、所引用 `CircuitCertificate` 版本以及物理提交的 `N/C/X/A`。账本候选价（例如 K0 样例 20 M、V0 样例 8 M）仅是该证书的条件报价，不能当作物种固定价格或本设计新定价格。

为使判据有限可复算，每个回路证书必须给出单位化的功能裕度 `h`、最低主动功能界 `hActiveMin`、保存裕度 `v`、最低保存界 `vPreserveMin`、下一 `dueAt`、有限 `recoveryDeadline`、以及将裕度变化映射到部位/连接的物理 `X` 条件。沿用 K0/V0 样例 `h=2`、`hActiveMin=2`、`v=2`、`vPreserveMin=1`：按证书确认的欠供退化 `X` 使 `h:2→1` 时，主动功能已低于界，若截至时间内存在已报价、获准、材料与结构均可达的补救路径则为 `critical`；若主动功能暂停且保存证据持续、保存付款按 V0 结清或有证的无源稳定成立，则为 `dormant`；再次失供只有在物理 `X` 正证使关键连接断裂（样例 `h:1→0`）或保存承载/记忆实际越过保存界并不可逆，才可能越过不可恢复界。数字是 mdo-mana 的候选复算夹具，不是整版批准的通用生命常数。截止时刻用于关掉该项补救路径；仅时钟越过而无实际不可逆损坏证据仍返回 `unknown`/缺证，不自动签死亡。

最低功能裕度不以单一生命总分替代：候选关键回路逐项要求边界组织连续、至少一条可核验自取源路径、反馈调节能完成一次有界扰动响应，以及足以保存该反馈的承载裕度；任一关键项低界即不为 `viable`。同一生命可以有非关键部位损失，但必须把每项阈值和 `X` 版本写入证书。失供、转入、主动作用、维持、保存及物理结果的时间/交易引用逐格输入，生命模块只做阶段⑤判定，不从余额、请求或 UI 推断实际功能。

### 最低连续证据与分叉唯一承接

`same` 的最低证据拆为三条都不可缺的链：**结构**须有前后关键部位/连接映射、每个改变的提交 `X` 与连续承载体；**记忆**须有版本化记忆/调节载体、迁移或损失 `X`/`Tx`，并保留至少完成下一次已证反馈调节所需的状态；**控制**须有逐窗 `Tx-maintain/Tx-preserve` 或有证无源稳定、内部反馈状态交接及 grant 签发/撤销序列，能唯一说明该过程由哪个连续载体承担。这里的“至少一次反馈”是可审计功能门槛，不要求全部回忆无损；三个链都必须绑定同一 `LifeId`、世界序号和结构版本。任一链断、冲突、超出证书域，关系就是 `unknown`，原身份私权冻结。

复制/分裂时仅当证书证明一条枝独占原关键承载体和连续记忆/控制链，且另一枝是其后新建结构并通过自己的首次闭环验证，才允许唯一分配：承接枝 `same(L)`、新枝 `new(L2)`。若两枝同时从同一状态快照形成、原载体被复制/销毁而不能证明唯一交接，或多个候选都声称继承，所有候选相对 `L` 均为 `unknown`，不得任选、共享或复制 `L`；各枝是否已构成新生命独立按回路证书判定。已终结的 `L` 永不复用，死亡后新闭环为 `new`，无生命结构为 `none`。

### 先判存在，再判生命，最后判身份

每个模拟边界先用物理提交的结构版本判**实体存在**：有可追溯的材料部位及连接构成一个可辨认局部组织时，`EntityId` 指向这份结构；局部受损、停机或生命死亡均不销毁句柄。结构确已失去可辨认边界时，句柄终止，但材料和历史 `LifeId` 留在各自账本。只知目标离开模拟域或缺结构快照时返回 `existence=unknown/out-of-scope`，不能写“瓦解”。物理 `X`、材料去向及跨域接收凭证是存在判据的证据，HP、余额、动画计时与可被选中均不是。

对存在的结构，生命模块登记候选**关键回路集合** `K`：可辨认边界和关键组织、从有限合法来源自行取得维持所需供给的结构、感知自身偏差并调节的反馈通路、保存这些功能所需的组织与控制状态。外部操作者逐刻直接指挥、单纯预装脚本、持续注能或余额充足都不能代替自取源与反馈。每条回路记录物理部位/连接版本、输入来源及权限、输出与废物去向、可测功能裕度和可验证的维持义务。修士的代谢/调节与人工生命的构造回路逐项使用**同一个字段和状态机**；材料种类、意识、主人或 `Actor` 类型均不成为身份捷径。新结构首次通过闭环、实际付清首个需要付款的维持窗口，并能对一次有界扰动反馈时，才创建新 `LifeId`；若当时尚无到期窗口，只能标 `candidate/unknown`，不能由空账推成活着。没有自取源和反馈的球、机关、石块仍是 `nonliving`，即使它们执行程序。

每个回路 `k` 的候选配置须公开版本化的 `requiredFunction(k)`、维持周期或到期时刻 `due(k)`、已结算供给 `settledSupply(k)`、可保存裕度 `reserve(k)`、不可逆结构界 `fatalBoundary(k)`、保存环境范围和最长可恢复时限 `recoveryDeadline(k)`。临界不是一个通用 HP 数，而是**下一到期窗口**内至少一条关键回路的实际功能或已付款供给低于其已声明最低界，同时尚有经过物理与账本证明的保留/补救路径。`viable` 要求本窗口全部关键回路功能达界，已到期的维持已结清，并能由自身取源/反馈继续调节。`critical` 可失去主动能力，但仍有连续承载体，且存在在截止前获准、可报价、有材料与结构能力的恢复路径。若只有“也许有办法”而无证书，回报 `unknown` 和缺失证据，不宣称可逆。

**维持窗口**从上次实际完成维持的 `simTime` 到下一 `due(k)`，不是显示帧或 ADR 0017 的统一 `0.25s` 控制租约。窗口需由真实结构、供给率、耗散与环境给出有限上界；每次 `C/X`、供给 `T` 或环境变化按新版本重算，不追改已提交交易。到期欠费只形成带时间戳的缺口及默认失稳，随后查功能裕度；欠费一瞬不自动死。可逆休眠必须有意或被动进入的物理机制、仍连续的关键承载体、已证实的保存环境和到期保存成本、下一检查/救援截止时刻。允许调节与行动停顿，但每一保存窗口仍付清真实义务或由有证据的无源稳定条件承担；不能用 `dormant` 标签暂停世界时间或免费冻结组织。保存条件失效则重新判 `critical/dead/unknown`。具体周期、裕度、环境界及保存价均尚未获批，不能在运行合同中填默认零或无限期。

**不可逆损坏**须由已提交 `X` 及版本化材料/回路证书证明：关键组织的连续承载体已断且没有在已声明恢复域、剩余材料和截止时限内可行的因果延续路径，或有记录的保存时限已越过并造成无法保留控制/记忆载体的实际退化。满足该正面证据才把原 `LifeId` 判 `dead`，一次提交终止序号；以后同一 ID 绝不返回 `viable`。仅因当前窄编辑域不能修关键回路，结论是“该操作不可表达”，**不自动推出宇宙中不可恢复或已经死亡**。材料响应、合法来源、窗口参数或域外历史未知时，身份/生命判定分别给 `unknown`；对已知结构缺陷仍可报告 `critical` 风险，但不得伪造死亡时刻。`dead` 不等于遗体瓦解，死亡后 `X` 仍按物理事实追加。

### 同一 LifeId 的连续性证明

`LifeId` 在首次确认闭环时由生命模块签发，永不复用；`EntityId` 可以因换壳或跨域映射改变。每一次迁移、损伤、休眠与修复在前一记录上追加 `{lifeId, previousRecordId, worldSequence, simTime, entity/partMap, X/C/A/T refs, circuitVersion, preservationWindow, memoryCarrierVersion, regulationStateVersion, controlLineage, grantChanges, evidenceStatus}`。其中**记忆**包括可保存的调节/学习状态与其变更来源，不要求每条个人回忆完好；正常遗忘、受伤与合法改写可有损，但损失必须被记录且剩余调节载体能够承接原过程。**控制**指维持回路的内部控制状态连续及外部 grant 的签发/撤销谱系，不能把创建者控制权当作生命身份。物理部位替换须有原载体到新载体的实际迁移或在线交接记录；复制出两个同时自维持的分支时，不能给两者同一个旧 ID。

同一身份复苏须同时证明：原 ID 没有已确认的 `dead` 屏障；关键组织/保存态沿唯一因果链跨过全部窗口；记忆与调节状态有逐版来源且没有无法区分的复制分叉；控制谱系能说明谁在每段维持及修复中有权操作，死亡/休眠限制没有被绕过；修复后的回路已实际承担新的维持，而非只把外壳接好。满足后从 `critical/dormant→viable` 仍用旧 ID。若旧 ID 已正证死亡，后来形成闭环须签新 ID；若旧 ID 是否死亡、迁移是否连续或复制分支归属缺证，标 `identityRelation=unknown`，隔离依赖旧身份的私有权能，不据材料相似、姓名、脚本或记忆内容推 `same/new`。确知从未有生命闭环才是 `none`。此判据给出候选可审计门槛：结构链、下一反馈所需记忆/调节状态、逐窗控制/授权链三者缺一即 unknown；候选功能裕度夹具及损失容限仍需整版与制作人审核，不是已批准生物学常数。

### `mdn-life` 首批判定域、报价与窗口

相对 `mdc-life` 的“有回路、有连续证据”概念，首批登记 `CircuitCertificate`，每个修士或人工造物使用相同的四项**可测功能**：`boundary`（关键组织和外界分界、真实材料与连接）、`intake`（凭有效权限从有限来源取入并记录净到账）、`regulation`（观察自身偏差后能改变下一次取源或维持请求，而非仅由外部逐刻操控）、`preservation`（主动停机时仍能维持承载体、调节状态与记录）。证书逐项列部位/连接的 `structureVersion`、输入输出与废料、扰动前后读数、功能下界、损伤规则、报价描述符与适用域；实际首个到期维持 `Tx` 和一次有界扰动反馈成功后才承认新生命闭环。固定脚本、单笔注能、余额或 owner 授权均不能代替其中一项。证书缺任一必要量时返回 `lifeState=unknown`，超出首批材料、来源、环境或扰动域时返回 `out-of-scope`，不得假造默认正常值。若完整证书正证自取源或反馈功能不存在，则为 `nonliving`。

每个窗口 `W(k,n)=[lastSettledAt,dueAt]` 有版本化的 `Quote(maintain,k,structureVersion,environmentVersion,window)`，返毛法力、工作 tick、神识峰值、来源权限、净到达需求、损耗去向、静态毛上界及成功域；保存态使用单独的 `Quote(preserve,...)`。生命模块只提出义务、核验真实 `Tx` 净到账和已提交维持 `A/X`，不能自行铸币；账本/VM 按[共同报价](./mana-ledger-design.md#共同报价函数及当前可表达域)在最新结构下复验付款，未知价拒付并标明判定缺口，不能将 `mdn-mana` 的惰性壳价 43 或旧三池倍率借作生命价。`0.25s` 是 ADR 0017 的控制维持周期，**不是**生命窗口默认时长。`Tx` 仅证明到账，尚须检查维持作用确实在本窗口完成；预留、预计转入与日后退款均不算到账。到期无付费时仅记录欠供，默认失稳由物理提交 `N→X`；每次 `X` 后重算功能裕度、窗口和可逆路径，不凭欠费直接签死亡。

状态判定按同一时刻的证据依次进行：①若原 `LifeId` 已有终结屏障，保持 `dead`；②若有已提交 `X` 与回路证书**正证**关键承载体不可再因果延续，或有截止后的实际退化正证不可恢复，签一次 `dead`；③全部关键功能过界、到期窗口实付并有自调节能力，判 `viable`；④主动功能暂停但承载体/记忆与控制记录连续、保存环境在域内、每个到期保存窗口已有真实付款或有证无源稳定、救援截止有限且未过，判 `dormant`；⑤功能低于界而在**当前域内**有已报价、获准、有材料且在截止前可完成的修复/补源路径，判 `critical`；其余 `unknown/out-of-scope` 并给缺证原因。`critical` 是已证可救的危险态，`dormant` 不是免费冻结。截止时刻经过本身不够判死，必须有相应不可逆 `X` 或保存态实际消失的证据；仅因窄材料域 `D` 不能操作关键回路，只能拒本次修复为 `unexpressible`，不能推定生命必死。

| --------------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------- |

## 死亡与身份事实的程序授权和界面暴露

死亡事件向程序模块提供获准的最小事实：实体句柄或不可见目标、`lifeId`（仅获准者）、`prior/next`、`identityRelation`、不可逆判定或 `unknown`、原因 `C/A/X/T` ID、模拟时刻/世界序号和撤销摘要。连续记录的私有细节只通过另行授权的查询接口取得；不得把记忆、账户、grant 令牌或遗体私有字段塞进通用事件信封。订阅在创建时声明字段、对象、期限和配额，提交与派发时复检；死亡/结构失效的撤权在事件响应前提交且不能因队列满漏掉。仍存活的独立主体使用自己的普通授权；为死者残余程序预签的独立死后 grant 首批关闭，即使写有持有人、期限、额度和操作域也不可签发或执行。

推荐权能规则：死亡提交后停止死者作为生命主体的主动程序调度和新权限签发；取消其拥有的维持/持续控制会话；阻止向死者账户提款、自动回复和死亡退款；清理由旧 grant 派生的子权限。物理实体可继续运动/受损。仍存活的独立主体凭自己的普通授权、结构和来源继续；死者派生的法球/信标不能靠预付资源启用首批已关闭的独立死后响应。程序只能依据可见事件采取后续行动，不能把 `dead` 状态写回 `alive`；新生命须走新身份创建/确认合同。

界面按查看者权限分别呈现 `结构存在/范围外未知/已瓦解`、`生命阶段/无生命/不可探查`、`身份关系 same/new/none/unknown`、`施法能力/授权/余额是否可用`；每条已知事实标注观察时刻、来源和待定阈值。临界与休眠显示实际缺失的回路/供能及“可逆条件待定”，死亡显示原身份终止而遗体仍可受损；域内结构修复显示“结构已修复，生命/身份未确认”。无目标、无读取权或记录断链时显示空结果/不可探查/身份未知，不用过期 HP 条、所有权颜色或画面消失推断死亡，也不泄露私有状态。

### 交给程序模块的事实与桥接投影

生命模块只签发已提交、版本化的 `LifeAssessment`：`{entityRef, existence, lifeState, lifeIdRef?, identityRelation, circuitVersion?, structureVersion?, continuityRecordRef?, memoryCarrierVersion?, controlLineageRef?, dueAt?, preservationDueAt?, recoveryDeadline?, quoteRef?, settledTxRefs, deficientCircuitRefs, evidenceStatus, causeRefs, simTime, worldSequence}`。`lifeIdRef` 对无权订阅者是不透明引用；`unknown` 不编造一个待继承的 ID。死亡另给一次性 `DeathBarrier {lifeIdRef, terminalSequence, terminalSimTime, reasonRefs, finalStructureVersion, residualEntityRef?, revokedSubjectGrantRefs, revokedSessionRefs, revokedSubscriptionRefs, capacityAfter, accountCloseRef, settlementRef}`，以 `(lifeIdRef, terminalSequence)` 幂等；已死遗体再损只更新 `ResidualStructure {entityRef, structureVersion, remainingExecutionParts, materialRefs, causeRefs}`，不重发 DeathBarrier。休眠/临界也向程序送能力变化和下次维持窗口；这些消息均在阶段⑤撤权后、阶段⑥可见事件之前提交，不依赖队列容量完成清理。

程序模块必须在每次尝试、订阅派发和提交前读取**当前**结构能力与 `capacityAfter`：实际执行部位、有限记忆/神识承载、感知与施力部位、付款账户及其额度、有效 grant。生命状态不是免费容量；`viable` 也可能没有执行结构，遗体若保有执行结构也不取得死者主体权限。`dead` 立即撤销以该 `LifeId` 为主体的控制、未来输入、动态订阅、监控、维持会话和提款，关闭原账户并幂等清算；已经提交的 `A/X/T` 与惯性存续。ADR 0020 允许独立死后主动行为，是当前已采纳合同；本轮**候选新规则**首批对此返回 `postDeathGrantUnavailable`，不得仅凭生前预付与执行结构运行。实施前须以新 ADR 明确覆盖旧条款。仍存活的独立主体可按自己的普通授权行动，创建者、owner 或残余材料不自动签发新 grant。`unknown` 时禁用仅凭“同一生命”才能行使的私权，保留不依赖该身份且仍有效的独立能力；缺证不能被程序层默认为 `same` 或 `new`。

桥接只按当前查看者的字段权限输出 `LifeDiagnostic {observedAt, entityExistence, lifeStateOrHidden, identityRelationOrUnknown, dueWindowOrHidden, deficientCircuitOrHidden, preservationDeadlineOrHidden, repairDomainStatus, capabilityReason, evidenceFreshness}`。公开诊断优先给“下一窗口何时到期、已知缺的是供能/结构/权限、结构修复是否仅在窄域、身份连续性是否缺证”；不公开他人记忆载体细节、具体账户来源、完整 grant 或隐藏关键回路。权限不足显示 `不可探查`，证据不全显示 `unknown`，范围外显示 `范围外未知`，三者不同；若获准读取到“外壳已修、回路未恢复”，分别显示两项，不合成“已复活”。推演台/演武场只投影这些事实，不按 HUD 计时、动画或旧 HP 推导状态。

## `mdp-life` 两实体证书与逐格裁定

本节把 `mdp-physics` 登记的 **M1 修士**与 **A1 自维持人工造物**接到 `mdp-mana` 的 K0/V0 交易上。它们是具名、有限扰动域内的候选物理证书，不是物种常数或已批准运行规则。物理前驱给出的共同初态为 `h=2,v=2`、有限内部梯度 `2 E0`、关键连接与保存承载 `X_m0/X_a0`；每个成功失供窗只有在梯度和材料响应确证后，才允许记 `N→X` 及 `h:2→1`、`h:1→0`。第一笔热为 `1 E0`；第二次关键连接断裂另有具名 `q Q[k_m]` 或 `q Q[k_a]` 残片和 `1 E0` 热。`k_m/k_a` 未登记时这些不是已证结果，应改判 `unknown`。主动阈值沿用账本证书样例 `hActiveMin=2`，保存阈值 `vPreserveMin=1`；首次失供后仅可容许一次实证 `v:2→1`，V0 每个已到期保存窗必须实际结清。物理合同没有给两实体虚构一个统一秒数：`dueAt`、`preservationDueAt` 与有限 `recoveryDeadline` 必须由该实体的 K0/V0 与物理可逆性证书共同签出；登记缺失则相关截止为 `unknown`，不能偷用样例 `1 s/2 s` 或 ADR 0017 的 `0.25 s`。截止过期关掉该救援证书，但没有不可逆 `X`/保存载体实损仍不得签 `dead`。

**不可逆 X 死亡证书**不是“第二次欠费”或阈值数字本身：M1 必须引用 `N-m2→X-m2`、`m-link` 的不可逆断裂、组织/记忆保存载体已失去经证的连续承载且无当前 D0 内路径；A1 对应 `N-a2→X-a2`、`a-link` 与 `a-store`。证书还要绑定前一 `N-m1/X-m1` 或 `N-a1/X-a1`、部位和材料映射、梯度/热/残片去向、时间/世界序号，以及结构、记忆、控制三链的最终连续性结论。物理前驱只在 `k_m/k_a` 与其响应实测后能提交上述 X；材料或响应未裁定、只有余额归零、欠费、窗口逾期或修复价未知，均不能组成 X 证书，生命状态和身份回 `unknown/unknown`。只有整份证书验证成功才签一次 `dead/none` 与 `DeathBarrier`；它是逐体证书，不可把候选 `h=0` 套作其他修士、人工生命的普适死亡线。

对 M1，连续承载链为 `m-intake→m-reg→m-link`，记忆/保存承载为 `m-store`；对 A1 为 `a-intake→a-sense→a-reg→a-link`，承载为 `a-store`。生命证书只在“至少一个已获准取源接口、反馈对有界扰动的实际响应、关键组织/连接达主动界、到期 K0 净供给已结清”均有版本化证据时给 `viable`。若首个 `N-1→X-1` 已确证，且在本体自身有限 `recoveryDeadline` 前存在域内获准补源/修复路径，则为 `critical`；若主动功能停、`v≥1`、记忆和控制链仍连续且每个到期 V0 已付款（或有独立物理证书证明无源保存），则为 `dormant`。第二次 `N-2→X-2` 只有在 `m-link/a-link` 不可逆断裂、记忆或调节载体实际丢失且无证书内延续路径时，才可签一次 `dead` 与 `DeathBarrier`；只有欠款、余额零、截止时间走过、材料种类未知或域外拒绝都只产生 `unknown`/待证，冻结旧身份私权。

## `mdq-life` 逐体签证：从物理与净到账导出判据

**适用域与认识状态。** 本节以 `physical-mdq-1`、[mdq-mana 的同版报价与结算](./mana-ledger-design.md)更新上节 `mdp-life` 的条件复算；上节 `h/v=2→1→0` 和 K0/V0 数字只作旧夹具读数，不能用作生命总分、通用时长或已执行事实。下表的成功态均以所列输入实际签证为条件。目前 `k_m/k_a` 的材料响应、预存摄取包的上游装载、关键回路修复及保存层独立损伤梯度尚未齐证，故现实可接纳结果是相应 `unknown` 或 `unexpressible`，不是纸面成功。

首次 `X-i1` 后的 `recoveryDeadline_i` 是同时满足以下条件的最后已测模拟边界的最小值：松弛部位与关键连接仍可由**获准且已报价**的材料编辑复位、`i-store` 及反馈记录仍有可验证承载、下一次有证失供/环境扰动尚未越过不可逆连接界、下一 V0 或无源保存仍可履行。每一项须有自身版本、测量误差、有限有效区间及 `reversibleUntil`；任一缺失则截止为 `unknown`，不能把“过期”当死亡正证。当前 D0 只编辑 `k0`，对 `k_m/k_a` 没有获准修复路径，因此 `X-i1` 后的同身份活跃复苏在本域为 `unexpressible`；仅补 M 或及时转入最多阻止下一笔已证退化。`critical` 若要求可达修复路径，目前不能作为无条件输出；若 `P_i` 和 V0 齐证可评 `dormant`，否则 `unknown`。

**可逆/不可逆 X 签名方法。** 对 `N-i1→X-i1` 用同一仪器版本前后测梯度 `2→1 E0`、热 `+1 E0`、同体 `q` 位移及 `F_i` 反馈失败，复测 `i-store` 与三条连续链；材料没散失只支持“可逆候选”。对 `N-i2→X-i2` 测梯度 `1→0`、热 `+1`、连接位 `−q` 与具名同种残片 `+q`、旧反馈链确已断，同时单独测保存记录不可逆丢失或经证的所有恢复路径已闭合。`E0/12` 能量量化与误差界、`q` 逐种材料精度、时间 `εt=1/4096 s` 和物理域外/未裁定返回值继承 `physical-mdq-1`；不能把误差内“未见信号”当作不可逆证据。保存层 `v:2→1` 还需额外封印、来源与最多 `E0/4` 的独立损伤证书，本夹具初态没有它，漏付 V0 不产生虚构 `X`。只有不可逆 X、保存/调节承载无延续路径、结构/记忆/控制三链终局及有限截止一同正证，才对旧 ID 签一次 `DeathBarrier`；缺任何一项为 `unknown`，`h=0`、欠费或截止过期不能补证。

**版本化输入与输出。** `CircuitLifeCertificate v=mdq-life-1` 每体至少绑定 `{entityId, lifeId?, physical-mdq-1, XVersion, materialLotIds, energyLotIds, environmentVersion, instrumentAndErrorVersion, K0/V0 quoteVersion, grantVersion, sourceVersion, committedTxIds, packageBeforeAfter, F_i/P_i testVersion, dueAt?, preservationDueAt?, recoveryDeadline?, reversibleUntil?, N/X causeId, simTime, worldSequence, structureLineageRef, memoryLineageRef, controlLineageRef}`。阶段⑤仅消费与阶段①至④**同一版本**的已提交 `X/Tx/A`；不同版或任一关键回路、材料、截止、三链缺证，输出 `LifeAssessment {lifeState:unknown, identityRelation:unknown, missingEvidence}` 并冻结旧身份私权，不把缺证静默当安全或死亡。可独立证明状态而身份链缺证时保留已证 `lifeState` 与 `identityRelation:unknown`。输出另含 `{assessmentVersion, prior/next, observedAt, DeathBarrierRef?, revokedGrantIds, authorizedPublicProjection}`；`DeathBarrier` 以 `(lifeId, terminalXVersion)` 去重，撤主体与派生提款、控制、订阅、会话并关闭以该身份提款的账户，清算未用预留但不退款已付作用。独立仍有效的 A1 自身授权不因创造者死亡而被继承或撤销。

### `100/20` 与边界事件的逐 tick 双体复算

## `mds-life-1`：关键回路与同一身份的逐 tick 纸面证书

### 唯一身份三链与逐 tick 证书

`structureLineageRef` 串 `partId/connectionId`、`Xm/Xa`、`N/X`、材料批次；`memoryLineageRef` 串 `store` 原始校验、连续写序、暂停/唤醒迁移与实际损失；`controlLineageRef` 串本体自取/反馈、每窗已结 `Tx`、主体及派生 grant 的签发/撤销。三链都要有同一 `prior→next`、`causeId`、`simTime/worldSequence`、完整性和**唯一旧承载枝**，且未有终界，才能判 `same(L)`。复制只给内容相似，不给交接。未来若唯一原枝连续且另一枝**独立首次自维持闭环**齐证，原枝才 `same(L)`，新枝只能获新 `L_M2/L_A2`；两枝同时索取同一旧链或任一链缺口时两枝 `identityRelation=unknown`，旧私权冻结。`DeathBarrier(L,terminalXVersion)` 仅由终界四证在阶段⑤签一次；死亡后遗体再损只增 `ResidualStructure/X`。下表每行从各自已获证 `T0` 独立开夹具，写“承接”才沿上行；`LA` 表示阶段⑤ `LifeAssessment=lifeState/identityRelation(LifeId)`，最右格给当刻屏障及撤权，⑥只派已裁剪事件。所有肯定式均为**条件证书**，当前缺证实况在表后单列。
