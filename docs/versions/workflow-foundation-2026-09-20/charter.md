# Agent 工作流基础版本策划案

- 版本 ID：`workflow-foundation-2026-09-20`
- 状态：制作人已批准
- 批准日期：2026-09-20

## 版本目标

把原有 Feature 批量调度升级为真正的版本生产流程，并提供一个制作人可以直接查看状态、处理待办和与常驻秘书交流的本机可视化界面。

## 重点模块

1. 正式版本生命周期、审批、范围冻结、测试和缺陷数据模型。
2. 常驻秘书与正式版本状态的统一公开视图。
3. 当前阶段、节点详情、制作人待办、任务和缺陷看板。
4. 通过 notice guard 提交并查看自然语言对话。

## 非目标

- 不改动游戏玩法。
- 不接入公网聊天平台。
- 不在本版本发布新的游戏大版本。

## 版本验收

- 制作人无需阅读运行目录即可知道版本在哪里、谁在负责、下一步是什么。
- 制作人可以在一个页面进入节点、查看证据、处理待办和发送消息。
- 系统能表达评审驳回、Bug 修复回环和最终体验门禁。
- 原开发批次不再冒充正式版本。
