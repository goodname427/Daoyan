# 测试计划

## 新增能力

- 生命周期合法推进、制作人驳回回环、待办关闭和缺陷统计。
- 看板状态 API、消息提交和文档访问边界。
- 桌面与窄屏布局、节点详情和对话主流程。

## 主线回归

- 常驻秘书启动、状态、停止和自然语言收件。
- Feature PM 任务节点读取和跨重启去重。
- 游戏推演台、演武场及完整生产构建。

## 发布阻断

- 看板无法连接 notice guard。
- 制作人待办或当前阶段显示错误。
- 能读取版本档案之外的本机文件。
- 新状态模型导致既有秘书状态丢失。

## 执行结果

- `npm run verify:full` 通过：101 个 Vitest 测试、覆盖率门禁、无头沙盒、18 条既有 Playwright 主路径和生产构建均正常。
- 新增看板 Playwright 验收通过：读取版本、点击节点、查看策划证据、发送消息、收到秘书答复，并验证 390px 窄屏无横向溢出。
- 文档读取接口拒绝档案目录外路径和指向目录外的符号链接或联接。
- 独立 Terra 复审最终通过；发现的审批角色、历史审批、新方向误吞和待办生成问题均已修复并补回归测试。
- 当前未登记阻断或高优先级缺陷，版本可进入制作人体验。
