## 本次修订与前置约束

1. 基础移动的驱动成本由有界、可审计、不可转成法力或伤害的世界运动功率承担；运动 ADR 须确定其容量、补给、阻力及与当前走位体验的等价边界，防止把每帧物理积分误当免费主动推进。
2. 私有探查拒绝的尝试价与返回信息均不能暴露抗性或精确状态。旧 `探查`、`生命`、`自身法力率`、`快照` 都要纳入权限与价格；旧具型调用无法表达拒绝时，迁移需给可判定结果或定位诊断。
3. 降耗可真正减少普通操作的正成本；控制、注能、监控、退款与资源产出不可折扣。自增回复按额外产量逐周期收取更高的不可折扣费用，防止净产法力。账本区分法力与实体能量单位；碰撞若转伤害，须同时消耗相应动能。
4. 法力耗尽只在可支付状态跨越到不足时触发一次；事件链有有界深度及稳定顺序。蓄时瞬发提前松开取消且不产生部分效果；暂停缓存输入、恢复后先处理已到期会话，终止与退款幂等。
5. 任务拆分前先论证并采纳运动/供能、事件/执行上下文、属性/探查/账本的覆盖 ADR。特别核对 ADR 0011 对合法有限效果不人为封顶与新增倍率安全域、ADR 0017 的位置 commit 和五参即激活创建、ADR 0007 的槽位占用，以及旧存档和旧法术的可证明等价。若论证发现必须改变已承诺产品体验或只能丢弃用户数据，再携带取舍和回退方案升级制作人；不能以普通实现选择绕过。
