## 问题、范围与模块责任

玩家目前能用统一句柄控制部分属性，却不能从一枚法球的创建费用推导持续运动、命中伤害和退款；当前 `speed` 混合移动倍率与弹道标量，探查持有句柄即能取位置或生命，事件主要是战斗层 `onDamage`，按键槽位持有施法实例。版本目标是让世界效果经能力、权限、可审计账本结算，兼容原法术书，并让推演台和演武场完整呈现结果。

| 模块 | 状态所有者及对外合同 | 非目标 |
| --- | --- | --- |
| 世界实体/物理 | 核心世界持有不复用句柄、能力、位置、朝向、`velocity`、`speedMax`、运动来源和有界事件历史；物理积分消费已授权的力/冲量 | 强制完整 ECS、每帧执行玩家 DSL |
| 效果/属性/探查 | descriptor 定义属性含义；binding 提供能力、权限、抗性和合法效果；探查按允许的信息级别结算 | 通过实体种类分叉语义、把面板当全知调试器 |
| 账户/执行 | 共享施法者账户、实体储能账户及同一交易账本；VM 记录法力、tick 和神识峰值 | Projectile 自动回蓝或拥有免费施法意识 |
| 意图/事件/会话 | 战斗适配输入意图；核心按稳定事件序和执行上下文派发；会话持有蓄力、订阅与维持 | 按键决定唯一生命周期、免费持续观察 |
| 编辑/实战/持久化 | 推演台查询合同和预演；演武场绑定、操作、观察；上层法术书单一所有者与隔离迁移 | 在演武场维护第二份源码、处理工作流控制面 |

跨模块实现须遵守核心无 UI 依赖、AST 唯一 IR、共享账户、玩家/妖兽同一施法管线。旧属性、弹道与事件状态不可通过迁移伪造历史。普通缺陷在版本 QA 和修复阶段登记。

## 1. 实体状态、效果和可见性

每个实体内部审计记录包含 `id/capabilities/owner/faction`、位置、朝向、实际二维速度、上限、最近力/冲量来源、当前/上限生命与法力（仅能力存在时）、神识上限与已占用（仅有账户时）、对应抗性、控制会话/效果层、事件序号与有限摘要历史。存储可仍为 Actor/Projectile 集合；所有操作经能力查询。同一能力组合在 Actor、Projectile 和合成实体上必须同价同失败语义。Projectile 默认只有变换/运动、寿命、所有权及显式注入的储能和行为，不默认具有生命、法力回复或 Caster；行为 VM 的状态占创建者授予的有界额度。

`velocity` 是每秒世界单位的实际向量；`speedMax` 是主动驱动允许的速率，取代旧 `speed` 的新法术语义。已在运动的实体被降 `speedMax` 时不瞬间抹去速度：新主动推力受上限约束，既有惯性按物理阻力或碰撞衰减。角色常规移动由已授权运动效果产生有来源的驱动力；按键只提供意图。一次冲量预付能量后滑行不逐帧扣法力；持续推进、转向、追踪每个模拟周期消耗储能。位置只能经积分、碰撞或单列的高价传送改变；传送在效果前检查权限、边界和落点碰撞，失败不部分移动，不能假装成零距离 `设置位置`。朝向变化不偷改速度。

| 状态 | 本人/自有读取 | 他方允许探查的精度 | 唯一合法改变通路与失败 |
| --- | --- | --- | --- |
| 位置、朝向 | 正价自身/自有读取；所有权仍需验证 | 可见且在范围内的坐标/朝向 | 运动/明确朝向效果；传送单列。越界、遮蔽、缺 Transform 拒绝 |
| `velocity`、`speedMax` | 有 Movement 可读；来源详账只归参与账户 | 可见时速度向量与上限；来源详账不开放 | 力/冲量/碰撞改实际速度；限时 binding 改上限；缺能力拒绝 |
| 当前/上限生命 | 有 Vitality 可读 | 逐项获准后精确数值 | 当前值仅伤害/治疗；上限控制不治疗、不复活，下降裁剪不返还 |
| 当前/上限法力、回复 | 有 Mana 账户可读 | 上限/回复可逐项探查；敌方精确余额默认拒绝 | 当前值仅支付、注能/转移、退款、世界时钟回复；降上限裁剪不返还 |
| 神识上限/占用 | 有 Caster 账户可读 | 上限可获准；占用与 VM 栈私有 | 上限控制不删除已占用；超额禁止新分配，允许释放 |
| `castSpeed`、`manaCostMul` | 有 Caster 可读 | 分别获准才读 | 只影响以后工作/可折扣项；拒绝非正或越安全界的效果 |
| 护体、伤害、感知、逐项抗性 | 有对应 binding 可读 | 护体/伤害/感知可逐项探查；抗性数值默认拒绝 | 原控制 binding；抗性只由专用授权效果改变，不可借普通控制覆写 |
| 归属、会话、事件历史 | 自有会话与必要摘要可见 | 阵营与公开命中摘要可见；私有订阅/账户/来源不开放 | 权威创建/转移/结算；历史追加有界摘要，不能回写 |

探查先判能力、权限、可见性、距离和信息级别，再执行收费读取。允许探查的目标有有效距离上限 `R = 240 × 探查者有效感知`；自身不受距离限制；自有物仍需能力和正价。一次精确允许读取的建议价：法力 `ceil(1 + d/120 + 2L + max(0, Rt-Sa)/8 + r)`，tick `ceil(1 + d/240 + L + max(0, Rt-Sa)/16 + r/2)`；`L` 为公开/一般/敏感级 `0/1/2`，`Rt/Sa` 是目标/探查者有效神识，`r` 是目标对应感知抗性。两价都正，敌方关系再沿用 `1/2/8` 倍率和固定门槛；自身私有探查用正基础价。高抗性使价格单调上升，隐藏级别直接拒绝。由于身份、能力、距离、抗性可动态变化，分析只对全已知条件给有限上界，否则显式动态。拒绝返回统一的不可探查状态，不返回真实值；错误文案、计价反馈和面板不能透露被拒绝的精确属性。现有 `探查`/`生命` 的无条件读取、`自身法力率` 的零法力读取和 `快照` 坐标列表必须纳入此边界或保留只显示获准公开信息的兼容行为，不能作为旁路。

属性面板分“自己”“已获准目标”“必要事件”三块：未有读取权的行显示未知，探查成功显示带模拟时刻的快照而非持续真值；目标消失后保留获准的有界历史摘要。推演台的调试内部视图需标记为沙盒调试，不把它作为战斗角色已知信息。拒绝、空结果、过期快照和页签往返均可观察。

## 2. 六项补全属性及定价

六项均为 `(目标, 效果, 时间) -> bool` 的能力 binding；正有限秒数到期，`0` 表示会话有效期间无限维持且持续收费。首周期在发布效果前收费，之后每 `0.25` 秒按模拟时间先收费再发布，尾段按已覆盖周期结算；暂停不推进，目标或会话失效时幂等清理。自身/自有/友方/非己方关系倍率沿用 `1/1/2/8`，敌方起手另加两资源正门槛；抗性为非负有限并单调增加两资源价。同源更新先移旧层测实际新效果，多来源由 descriptor 固定合成顺序和安全域；无变化仍付正尝试价。资源不足在效果前失败；领域拒绝返回 `false` 且无部分效果。明确选择正界而不允许无限倍率：这是防套利和数值安全域，并非 ADR 0011 中对合法有限效果的任意价格封顶；改变该旧约束需新 ADR 说明。

| 属性 | 效果/安全域与期限 | 抗性和法力、tick 锚点 |
| --- | --- | --- |
| `hpMax` | 有 Vitality；有效上限 `>0`，只影响可容纳生命；下降裁剪，恢复上限不恢复生命或复活 | 按 `abs(新旧上限差)/10` 加起手强度、每周期按保持的上限增量/10 收费；敌方同价关系门槛与生命抗性 |
| `manaMax` | 有 Mana；有效上限 `>0`，不注入法力；下降裁剪且损失不可退 | 增量/10 计起手与维持；当前余额不能由上限变化增加 |
| `manaRegen` | 有 Regen；有效率 `>=0`，只在模拟时间结算至 `manaMax` | 每周期不可折扣费至少为该控制产生的最多额外回复 `max(0, Δ率)×0.25 + 1` 法力，并有正 tick；多层按总额外回复量结算，控制费先于回复 |
| `shenshiMax` | 有 Caster；有效容量 `>0`；超额时不销毁既有 VM 状态 | 增量与控制记录占用计入神识峰值，起手及周期为正；抗性只加价不免状态占用 |
| `castSpeed` | 有 Caster；安全域 `0.25..4`；仅改变后续 tick 的真实推进，不减少已欠 tick，也不改变世界收费周期 | 对速度变化和可用加速时段计起手/周期正价；加速的 VM 工作仍逐 tick 付账 |
| `manaCostMul` | 有 Caster；安全域 `0.25..4`；只作用后续可折扣调用，不改已付费 | 控制、注能、监控、转移、退款相关操作用不可折扣价；可折扣调用保留至少 `25%` 原价及正固定世界 I/O，折扣收益由相应效果维持费覆盖，不能折扣自身维持 |

共同建议公式按法力和 tick **分别**使用 ADR 0017 的 `起手 = G + A×(B+S+D)×(1+r)`、`周期 = A×(M+S′+Q)×(1+r)`；正基础 `B/M` 对法力取 `2/1.25`，对 tick 取 `1/1` 并向上取整，敌方 `G=4`，`S/S′` 用表中强度及可实现收益的上界，有限时间项 `D/Q >=0`。自回蓝项的不可折扣增量下界覆盖通式不足之处；法力折扣不能作用控制费。具体系数通过新资源 ADR 和反例测试校准，但公式必须同时供分析和实扣，不能由 binding 再私写价格。无限或未来事件次数未知显示无界/动态；静态已知总价不得低于实扣。动态峰值由共享神识账户管控，记录、订阅、法球行为 VM 和历史缓冲均占有界容量。

反套利验收：自增回复每 `0.25` 秒多回 `5` 法力时，同周期不可折扣控制费至少 `6`，净可用额不增加；并发两层按总额外回复逐期结算。`manaCostMul=0.5` 不减少自己的起手/续费、注能或监控费；折扣所得不能超过预先收取的可实现收益价，若未来调用不可知则每笔调用附加不可折扣守恒差额。`castSpeed=2` 只把后续 10 tick 的真实时间从 100ms 缩到 50ms，仍产生 10 tick 工作债务。上限控制降后再升不能制造当前生命/法力。以上按实际账户流水断言，不只检查显示公式。

## 3. 能量账本、弹道与世界效果

账本以稳定 `effectId/entityId/payerId/sessionId` 关联，每笔记录模拟时刻、来源账户、去向账户、类别、法力与 tick、神识保留/释放、能量单位、不可逆损耗、余额和结束原因。创建费是世界 I/O，不自动成为存能；注能从明确付款人账户原子扣法力，扣除转换损耗后记入实体的 `motion/damage/scan` 专用余额。余额不能为负，同一单位不能同时入多个池；不可用池的转化须明确转换费和损耗。已做功、已扫描、已命中及创建费不可退；取消/销毁只退有归属且尚未使用的可退余额，控制者死亡后按建立时的退款受益人规则结算，目标消失不得向新账户猜测退款。账本总式：`付款注入 = 当前各池余额 + 已做功 + 已转伤害 + 已扫描 + 损耗 + 已退款`，按每笔和整场复核。

法球三种可见模式：一次付费冲量后按惯性/阻力滑行，不逐帧扣；持续推进逐 `0.25` 秒消耗 `motion` 余额，耗尽停止主动推力但已有速度按物理规则继续；追踪同时消耗扫描与转向/推进余额，任一余额不足便停止对应主动行为。玩家若希望“耗尽即停球”，须另付制动效果或依赖既定阻力，不能暗中抹去惯性。命中以 `damage` 池可用能量为上限换算伤害，穿透每次命中单独扣；护体减少实际生命损失却不返还已经释放的命中能量。碰撞动能转伤害必须声明转换率和运动能量减少，不能同时保留全动能与全额伤害。默认 `Projectile.damage` 固定命中值在迁移后需预留足额伤害池，余额不足时降低伤害或拒绝发射，绝不凭空补额。

投射物执行上下文有 `owner`、付款授权、能力白名单、固定最大工作/tick 和神识额度；它只能花自身余额或创建时明确授予的有限提款额度，不因有句柄就能花所有者未来法力。玩家和妖兽的普通移动也经同类授权效果通路，基础移动预算、阻力和再生能源来源须在运动 ADR 明示；自然物理积分、碰撞检测和 UI 刷新不另造玩家元法术。该处影响现有 ADR 0006，不能仅以新价格替换代码。

## 4. 事件、会话及两种蓄力

离散事件为受击、碰撞、法力耗尽、实体消失；每个携带权威发生序号、模拟时刻、源/目标句柄、发起账户及只含获准信息的载荷。世界先完成原子效果与账本，再按 `(时刻, 世界序号, 订阅序号)` 派发；同事件多法术依序取得共享账户，每个有独立 VM 与失败结果，前一法术的消耗对后一法术立即可见。默认同源事件在当前派发链只响应一次，嵌套深度和每周期派发量有静态声明与运行上限；超限明确终止/丢弃并记摘要。实体消失在撤销权限与清理会话后派发只读终止摘要，不允许对已失效实体重新生效。离散被动事件本身不为“持续看世界”收费，订阅状态占神识，响应 VM 和效果照常付费。主动监控要显式开启范围、频率、信息权限与持续周期，扫描先支付法力/tick，关闭、耗尽、死亡、越权或目标失效后停止；不得用每帧被动事件伪装监控。

按键按下/持有/松开只是输入适配器产生的意图。会话状态 `idle → preparing → held → releasing → settled`，任何活跃状态可去 `interrupted/cancelled/exhausted`，这些终态幂等；暂停冻结模拟时间、续费、输入边沿与事件派发，继续后按已缓存意图的原序处理且不重复触发。

| 模式 | 按下 | 持有 | 松开 | 失败/终止 |
| --- | --- | --- | --- | --- |
| 蓄时瞬发 | 建立会话、预留状态并付起手费 | 按模拟 tick 执行工作、按合同收费，可取消 | 已完成则一次性结算效果；未完成按显式提前释放规则失败/弱化 | 打断/死亡/耗尽不返已做工作；可退未用授权余额 |
| 持球注能发射 | 创建未发射且有寿命/数量上限的实体、付创建费 | 每周期从付款人向指定池注能、记录存能及维护费 | 校验余额和权限后付发射/冲量费并激活；只发生一次 | 取消/死亡/耗尽/目标消失清理会话与实体，按池余额及退款受益人结算 |

同一事件可绑定多个法术；槽位只对外部输入做去抖，同一法术可由不同合法事件独立触发，受共享账户、神识峰值和重入上限约束。旧 `onDamage` 的战斗打断先后、旧按槽位独占规则、旧 `创建弹道` 五参即激活的语义，均在新事件/生命周期 ADR 固定兼容次序。

## 5. 发现、示例与迁移

推演台元法术目录按“探查、效果/控制、实体与供能、事件/会话”说明能力、权限、参数、起手/周期价、动态/无界和拒绝原因；旧名搜索指向新入口与迁移说明。对手减速示例使用 `speedMax` 的限时敌对控制，破防示例使用护体负向控制；两者是可预览、选择性导入的**用户法术**，不重新暴露旧 `迟滞`/`破防` 元法术。示例须处理目标为空、不可见、抗性导致费用增加、拒绝和效果到期，给推演台可复现配置。重名导入先预览差异，默认保留原法术并建议新名；已有绑定不被覆盖，重复导入可识别，演武场只消费共享法术书。

迁移按 AST 到 AST 规范化一次完成；旧 `speed` 对 Actor 的移动倍率与 Projectile 的绝对速度必须按上下文证明等价，不能无条件映射 `speedMax`。旧两参位置、五参即激活创建、旧固定伤害、旧连续按键与旧法力倍率逐项验证效果、顺序、法力/tick、退款和存能；不能证明者给定位诊断，保留原 DSL、原始存档和最后可运行 AST，不执行隐藏兼容折扣。新存档只持久化法术书、演武设置和可恢复的显式配置；运行中会话、事件队列与法球余额不从普通存档猜造。导入在隔离副本全量校验后一次替换；损坏、未来格式或旧法术局部不兼容都不能覆盖原件或当前可运行状态。旧代码回退只使用兼容检查通过的迁移前副本，新版增量另存，避免旧格式覆盖。

本阶段识别而不采纳架构变更：

| 现有决定 | 必须在实现前提交的新 ADR 议题与回退 |
| --- | --- |

| [ADR 0007](../../adr/0007-并发施法与共享资源账户.md) 的槽位实例、[ADR 0009](../../adr/0009-统一实体句柄与能力判定.md) 的有限寿命与所有者 | 事件/执行上下文 ADR：多订阅排序、共享账户、重入、法球授权、死亡退款和旧槽位语义；不破坏统一句柄 |
| [ADR 0011](../../adr/0011-无界效果与动态资源预算.md)、[ADR 0017](../../adr/0017-统一实体控制属性模型.md) 的动态价、周期、`speed` 倍率、位置 commit 与五参即激活 | 属性/探查/账本 ADR：明确覆盖条款、合法数值域、不可折扣费、静态/实扣和迁移诊断；保留 AST 唯一 IR 与旧副本 |

三期是**同一正式版本**的纵向闭环，前期不等于全版验收：

1. 状态、权限和运动：Actor、Projectile 与组合能力实体以相同能力合同运行；一次冲量法球、上限减速、自身/获准探查及面板可在推演台和演武场往返观察，旧读取入口无旁路。
2. 账本和属性：注能、持续推进/追踪、碰撞伤害与退款可对账；六属性、防套利、减速和破防预设、旧书/存档迁移均形成可体验流程。
3. 事件和蓄力：四类离散事件、多绑定、付费监控、两种蓄力及全部终止路径可复现；全版跨期迁移、窄屏与实战回归后交版本 QA。

每期完成标准是可无头复现的核心合同、推演台可解释预算与失败、演武场实际流程及当期兼容迁移，而非只铺底层。若同版容量不足，公开保留全部核心目标的重排和风险，走制作人范围评审；不得暗删事件或能量目标。

| 端到端验收 | 可测证据与边界 |
| --- | --- |
| 运动与耗尽 | 三种模式法球轨迹、周期扣费、停供惯性、追踪/推进余额耗尽、命中后余额与损耗满足守恒式；生命伤害不超可用池 |
| 探查与面板 | 自身私有正价读取；越距/遮蔽/缺能力/抗性/权限分支；角色、法球与组合实体同能力同语义；日志及错误不泄漏，过期快照不自动刷新 |
| 事件/监控 | 四类被动事件、单事件两法术稳定顺序与共享资源竞争；重入/超限/死亡清理；监控显式启动、持续扣费、停止后零扫描 |
| 两种蓄力 | 按下、持有、松开及提前松开、打断、取消、死亡、耗尽、暂停/继续；账本对已付工作、未用存能和退款逐项相符 |
| 六属性/资源 | 各属性对自身、自有、友方、敌方的能力/抗性/时间/拒绝；上限裁剪、超额神识、提速债务、自回蓝与自降耗反套利；已知静态价不小于 VM 实扣 |
| 连续性/迁移 | 旧名可发现、两示例选择导入、同名保护、编译推演绑定实战及两页往返；旧合法法术与存档迁移、不可证明等价时定位拒绝及原件保留；未来格式拒绝 |

本阶段不适用：代码实现、代码完整门禁、UI 实际体验、正式范围冻结、版本 QA 与候选验收。后续阶段据此形成新 ADR、工作项和可执行测试；本文件只给规则、交互、边界和验收合同，不宣称任何新能力已经交付。
