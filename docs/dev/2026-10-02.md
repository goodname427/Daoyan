# 2026-10-02：模型路由更新

## 问题、范围与验收

制作人要求在恢复正式工作流前更新新模型策略。此前常规及高级任务和审查仍使用 `gpt-6-sol`。本次只把这些活动路由更新为 `gpt-6.1-sol`，保留原有推理等级、Luna 轻量路由、Astra 关键决策路由及故障备用模型；不改变已批准的游戏范围、任务验收或权限边界。验收是策略校验、路由测试和最终控制面树门禁通过。

OpenAI 官方模型与迁移指南支持 GPT-6.1 Sol 进行复杂编码，并支持当前 `low`、`medium`、`high` 推理等级。当前仓库通过 Codex CLI 调用模型，不直接设置 API `service_tier`。Fast mode 是否能用于本机登录账户及其额度倍率须按 Codex 账户和客户端实际可用性判断，不把 API 计费规则写进项目路由。

旧模型路由的运行恢复点仍保留原配置证据；恢复时如模型配置变化导致执行/审查会话不匹配，按现有会话安全规则新开相应会话，不将旧推理上下文强行复用。
