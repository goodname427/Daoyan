## 踩坑记录

1. **for 循环的栈残留**：用 `PEEK` 复制栈上元素计算 `i < len` 时，
   `len` 会残留在栈上，导致后续 `PEEK` 取到错误位置。
   解决：加 `SWAP` 指令，比较后交换并弹出残留值。
   → 教训：栈式 VM 里「复制」语义很容易留下垃圾，改循环结构要重新数栈。
2. **循环退出跳转未回填**：`JMPIFNOT` 默认跳到 0 号指令，表现为函数反复重入。
   → 教训：所有占位跳转都必须在生成结束时回填，最好有单测覆盖循环。
3. **静态分析与 VM 必须逐项对齐**：漏算 `CALLUSER` 的 1 tick、循环的 3 tick 开销，
   会导致「静态上界 < 实测」，玩家就不再信任消耗面板。已加单测守卫。
4. **分析器漏算 return 表达式**：`case 'return'` 直接 break，导致函数消耗统计偏小。
5. **Electron 打包卡在 winCodeSign**：解压时需要创建符号链接，普通权限的 Windows 会失败。
   解决：`build.win.signAndEditExecutable = false` 跳过签名步骤。
   → 需要正式签名时，再开启 Windows 开发者模式或改用管理员权限打包。
6. **打包偶发 "output file is locked"**：杀毒软件或上次残留进程占用，重试即可。
