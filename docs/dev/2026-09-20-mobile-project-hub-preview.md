# 2026-09-20 手机版项目中枢预览

## 背景

制作人希望离开电脑后仍能用手机查看项目进度。现有中枢已有窄屏布局和完整状态接口，但只监听本机，无法从手机直接访问。

## 实现

- 复用 `secretary-dashboard/`，增加本机实时 API 与静态快照双模式。
- 增加 `scripts/build-secretary-site.ts`，从运行中的 notice guard 导出当前及历史正式版本，并打包全部关联文档。
- 导出时移除 Agent PID、绝对运行目录、原始运行输出和秘书内部队列，只保留制作人可审计信息。
- 云端快照显示生成时间和离线边界；手机留言存入浏览器本地存储并标记“待同步”。
- 增加移动安全区、触控尺寸、PWA 清单和道衍项目图标。
- 使用 `.openai/hosting.json` 绑定所有者私有的 ChatGPT Sites 项目，生成目录 `.output/public/` 不进入 Git。

## 验证

- 新增脱敏单元测试。
- E2E 覆盖 API 不可用时回退静态快照、手机留言待同步和窄屏无横向溢出。
- 在 390 像素宽手机视口检查流程、详情和控制台切换，并生成实际截图复核。
- 完整门禁通过：111 项单元与集成测试、覆盖率检查、沙箱、19 项浏览器 E2E 和生产构建。
- Sites 版本 1 已以所有者私有模式发布到 <https://daoyan-project-hub.goodname427.chatgpt.site>，线上状态为 `active`，未登录访问会进入 ChatGPT 身份验证页。

## 发布记录

- Sites 静态目录只接受标准产物路径；将自定义的 `site-dist/` 调整为 `.output/public/` 后完成版本保存。
- 当前默认代理节点无法与 Sites 源码仓库完成 TLS 握手；临时切换可用节点完成推送后恢复原节点。后续发布遇到同类错误应先验证出口节点，不要重复创建站点。

## 边界

- 本轮是可访问的移动预览，不是实时远程控制台。
- 远程信箱接通前，手机留言不会进入本机秘书队列。
- 电脑关机时站点仍可查看最后一次部署的快照，但无法执行 Agent。
