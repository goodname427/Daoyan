# 并发施法

## 背景

演武场原先以 `actorId → CastInstance` 保存施法状态，任何第二个法术都会被拒绝。需求是让修仙者可以同时维持或释放多个法术，同时保持资源约束真实可信。

## 实现

- 施法容器改为 `actorId → slot → CastInstance`，不同槽位可并发、同槽位不可重入。
- VM 增加可选共享资源钩子和显式取消能力。
- 战斗层在元法术执行点原子扣除共享法力，在变量生命周期内实时占用共享神识。
- 受击批量打断可打断实例，移动减速取所有实例中的最严格倍率。
- HUD 展示并行施法数量、各槽位法术进度和总神识占用。
- 真实窗口体验发现右侧 HUD 会裁掉下方并行状态，改为面板内滚动。
- 每个施法实例增加跨帧 tick 信用，修复低施法速度仍每帧至少执行一个计费指令的问题。
- 修复 `repeat` 的数字计数器被 `JMPIFNOT` 当作假值、导致循环不执行的问题。

## 验证

- `npm test -- --run test/combat.test.ts test/core.test.ts`
- `npm run verify`
- `npm run verify:full`
- Playwright 手工体验：低施法速度下连续触发 2、3 槽，观察两个进度同时存在；暂停、继续和重开后状态正确。
