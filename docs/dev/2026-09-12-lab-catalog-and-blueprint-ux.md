# 推演台法术目录与蓝图体验修整

## 反馈

- 左侧法术列表无法滚动，后面的法术不可见。
- 元法术无法在法术目录中选择和查看。
- 蓝图节点与端口缺少语义提示，入口、出口和值连接不易区分。
- 自定义法术不能新建或删除。
- 推演台三栏高度不齐，蓝图重复渲染导致空白和溢出。
- 蓝图编译栏与索引错误信息存在乱码。

## 实现

- 法术目录改成独立滚动区，按“自定义法术 / 元法术”分组；移动端选择器也包含两组。
- 增加自定义法术的新建与删除操作，新法术立即进入单法术 DSL 编辑器。
- 元法术详情展示函数说明、签名、输入说明、返回类型、法力与耗时。
- 推演台只渲染一个蓝图编辑器；三栏使用同一可用高度，画布和节点调色板各自约束滚动与溢出。
- 控制流入口、控制流出口、分支体、值输入和值输出使用不同形状；节点、元法术选择器和端口均提供悬浮提示。
- 修复蓝图中的乱码、列表索引双输入端口和索引节点缺少值输出的问题。

## 验证

- 增加 E2E 覆盖：目录滚动、元法术查看、自定义法术增删、三栏对齐、单一蓝图实例与节点提示。
- 完成后执行 `npm run verify:full`，并在真实浏览器视口中检查推演台与蓝图布局。
