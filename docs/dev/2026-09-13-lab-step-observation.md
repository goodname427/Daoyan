# 推演台单步观察

## 问题与验收

单次推演只有最终结果，无法观察指令、变量与资源变化。本次新增“重置单步 / 执行下一步”，验收为逐步可见当前指令、具名变量和资源时间线，且不改变既有施法语义。

规格见 [`../specs/2026-09-13-lab-step-observation.md`](../specs/2026-09-13-lab-step-observation.md)。

## 实现

- 编译器将变量名保留为 `CompiledFn.slotNames` 调试元数据，不参与 AST、分析或执行决策。
- VM 新增 `snapshot()` 和 `step()`；它们复用现有 `execOne()`，输出当前调用帧、资源账本、指令与变量槽位。
- 推演台每次重置创建独立世界与 VM，防止它影响一次性推演或演武场；资源时间线随每次单步追加。
- 修复观察快照只枚举尚未 `FREE` 的槽位；`DECL` 记录本次生命周期的变量名，作用域退出会对循环临时变量也发出 `FREE`，因此显式释放、分支/循环退出和槽位复用均不会保留失效值。

## 验证

- 核心测试覆盖具名变量、资源变化、完成状态，以及显式释放、分支/循环作用域退出和槽位复用后不再展示失效变量。
- 槽位在普通变量重新声明时先恢复为“未赋值”，避免短暂泄漏上一个生命周期的旧值；函数参数声明则保留调用帧已经写入的实参。
- 浏览器 E2E 覆盖重置、单步、时间线追加、失效变量隐藏，以及改写源码后清除过期观察结果。
- 已通过 `npm run verify:full`：45 个 Vitest、11 个 Playwright E2E、覆盖率、沙盒和生产构建全部成功。
- 已在本地浏览器实际操作“重置单步”和连续“执行下一步”，确认指令、变量与资源时间线同步变化，控制台无错误，桌面三栏无新增溢出。
