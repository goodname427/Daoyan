# 2026-10-01：审核退回的上下文续接

制作人发现开发和独立审查反复打回时，工作流只有详细策划单文档能续接 Codex 会话；开发执行、修复和独立复审仍每次新开，导致重复取证与推理。制作人要求先暂停当前正式开发，完成控制面修复并同步到版本分支，再从原恢复点继续。

本次范围仅为调度器的会话归属和恢复：正式任务按版本、节点、范围修订及任务或文档产物划定作用域；普通 Feature 限于原运行目录。执行与修复共用写入会话，独立审查使用单独只读会话，增量复审续接同一审查者。模型、推理配置或作用域不符时新开；`fresh` 隔离旧任务，但同一任务的后续修复仍可续接。当前合同、权威文件和最新审核始终优先。原开发任务已有的一次性会话无法追溯恢复，原草稿和 Feature PM 恢复快照仍保留。

验收检查作用域隔离、`fresh`、审查者与写入者分离及恢复调用参数，并在控制面树运行类型、格式、文档、定向测试和实现阶段门禁。正式版本的游戏合同、真实 World/VM 实测及候选体验仍由原工作流验收；本次控制面改动不把开发草稿判为完成。
