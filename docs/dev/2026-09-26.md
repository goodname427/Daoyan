## 制作人校准：先解释存在，再选切片

制作人认可统一执行和计费的方向，但明确指出法球固定寿命仍无法用同一世界规则解释，要求所有实体的存在、维持与消失都有共同因果；先前推荐的开发闭环暂不采纳。项目仍处原型验证期，旧内容兼容无需成为设计约束。主 Agent 使用正式生命周期 API 合并范围修订 4，旧范围修订 3 的任务合同自动失效；守卫保持暂停，旧 `tracking/missing` 运行证据保留，不触发旧合同续跑。
