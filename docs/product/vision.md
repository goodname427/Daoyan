# 产品愿景

道衍是一款修仙编程 Roguelike。玩家不是选择预制技能，而是编写法术程序，在有限的神识、法力和施法时间中组合感知、运算与行动。

## 核心承诺

- 程序写法会真实改变战斗效果和资源成本，而不是只改变表现。
- 不存在对所有场景都最优的法术；环境、属性和资源上限会改变最佳方案。
- 玩家能在推演中理解失败原因，在实战中验证，再带着反馈继续改写。
- DSL 与蓝图是同一套法术系统的两种表达，不形成平行且互不兼容的玩法。
- 玩家能把共同的感知、判断、世界作用与事件规则组合成策划未逐项预设的法术和实体行为；预设法术展示底座能力，不限定玩家可创造的玩法。

## 设计边界

- 复杂度必须能被玩家理解和预估，不能靠隐藏惩罚制造难度。
- 优化应产生策略选择，而不是把玩家逼向唯一模板。
- 表现层服务于可读性和反馈，不改变核心计费规则。
