# 核心体验循环

```text
在推演台选择或新建法术
→ 用 DSL 或蓝图编写
→ 查看静态资源上界并单次推演
→ 进入演武场设置基础属性和法术绑定
→ 开始、暂停并观察实战结果
→ 返回推演台修改
→ 重复验证
```

## 场景职责

### 推演台

- 自定义法术的新建、删除、DSL 编辑和蓝图编辑。
- 元法术签名、输入语义、返回类型和资源定价查看。
- 静态分析与可控条件下的单次推演；可逐条执行并观察当前变量和资源轨迹。

### 演武场

- 玩家基础属性、法术槽位和测试场景设置。
- 开始、暂停、继续和重新开始实战。
- 通过不同法术槽位同时释放多个法术，并观察共享法力与神识的竞争。
- 观察施法时间、资源变化、命中、打断和敌我行为。
- 不提供任何法术源码或蓝图编辑能力。

## 连续性要求

- 两个场景必须读取同一个法术书状态，推演台的有效修改应立即可用于演武场。
- 切换场景不能丢失本次会话中的演武属性和绑定。
- 编辑失败时保留可诊断的信息，不能用无提示回退掩盖错误。
