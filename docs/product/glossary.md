# 术语表

| 术语       | 含义                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 法术       | 玩家编写、可绑定并执行的程序。                                       |
| 元法术     | 能读取或改变世界、执行基础运算的系统函数，是法术组合的最小能力单位。 |
| Actor      | 当前可施法、受伤并拥有完整属性的实体实现；玩家与妖兽都属于 Actor。   |
| entity     | DSL 中不透明的实体句柄；Actor、Projectile 与未来对象共用且不会重号。 |
| Projectile | 具备弹道能力的实体；可先创建、由所有者配置，再激活、探查和命中。     |
| 法术书     | 当前所有自定义法术的集合；推演台与演武场共享。                       |
| 神识       | 同时持有状态的空间成本，主要由变量与列表容量决定。                   |
| 法力       | 与世界交互的成本，主要由元法术调用决定。                             |
| 耗时       | 程序执行与施法推进的时间成本。                                       |
| 静态上界   | 编译前依据 AST 与容量算出的最坏资源消耗。                            |
| 实测消耗   | 特定世界状态下 VM 实际执行产生的消耗。                               |
| 能力       | 实体可被执行的操作集合；统一句柄不代表每个实体拥有全部属性。         |
| 推演台     | 编写、分析和受控测试法术的工作区。                                   |
| 演武场     | 配置属性、绑定法术并进行实时实战测试的工作区。                       |
| 蓝图       | 产出同一 AST 的可视化法术编辑方式。                                  |
| 神识上限   | 法术执行时可同时持有的变量空间；不同于拟议中的“神识强度”。           |
