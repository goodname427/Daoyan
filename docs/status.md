# 当前状态

- 状态：持续开发
- 当前版本：0.2.0
- 最后更新：2026-09-13
- 主分支：`master`

## 已具备

- 纯 TypeScript 无头核心：DSL、AST、静态分析、编译器、VM、世界与资源计量。
- 元法术注册、按类别拆分、属性系统、法术生命周期和外部扩展入口。
- 推演台：单法术 DSL 高亮编辑、蓝图编辑、元法术查看、静态分析与单次推演。
- 演武场：基础属性、法术绑定、开始、暂停/继续、重开与实时战斗。
- 演武场支持不同槽位并发施法，并对并发 VM 实时共享法力与神识账户。
- 推演台与演武场共享法术书，演武场配置在页签往返期间保留。
- Vitest、Playwright、覆盖率、沙盒、构建、Git hooks 与 GitHub Actions 门禁。
- 制作人到秘书的单一入口，以及按风险选择 Luna、Terra、Sol、Astra 的仓库级调度器。
- 玩家法术编写指南、由代码生成的元法术参考，以及当前实体与属性模型说明。

## 已知债务

- 蓝图编辑覆盖了主要节点，但高级控制流和编辑器历史仍不完整。
- 元法术当前仍为 6 个实现分组和固定价格，距离、目标强度与输入强度不参与成本。
- Projectile 与 Actor 分离，DSL 的 `entity` 句柄不能引用或控制 Projectile。
- 冷却字段和冷却倍率仍在现有法术与运行时中生效。
- 推演台静态法力上界使用基础价格，尚未结合演武场的法力消耗倍率。
- 当前状态只在会话内共享，尚未持久化到用户存档。
- UI 自动化已有主路径覆盖，视觉快照应在布局进一步稳定后逐步加入。
- Agent 调度仍按顺序编辑同一工作区；已记录每次模型调用的 token，但尚未汇总历史通过率，CLI 也不支持调用中的硬 token 上限。
- 仓库历史尚无版本 tag；发布脚本暂以阶段四完成提交 `e4e71fe` 作为 0.2.0 基线，下一个正式 tag 建立后自动改用 tag。

路线优先级以本文件和已批准的功能规格为准；[`roadmap.md`](./roadmap.md) 用于中期方向，不作为当前任务清单。
