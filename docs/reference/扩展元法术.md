# 扩展元法术

元法术（基础术式）是游戏的最小能力单元。本页面面向引擎开发者和扩展作者；玩家编写普通法术请阅读 [`spell-authoring.md`](./spell-authoring.md)。

## 方式一：放进内置目录（开发期，推荐）

在 `src/core/metas/` 下新建一个 `.ts` 文件，默认导出 `register()`：

```ts
// src/core/metas/mySpell.ts
import { T } from '../types';
import { asNum, defMeta } from '../meta';

export default function register(): void {
  defMeta({
    name: '裂空斩',
    group: '自定义',
    params: [
      { name: '方向', t: T.vec2 },
      { name: '威力', t: T.num },
    ],
    ret: T.void,
    mana: 30,
    ticks: 4,
    desc: '朝方向斩出一道空间裂隙',
    impl: (c, a) => {
      // c.world  —— 世界（可生成弹道、造成伤害、查询单位）
      // c.caster —— 施法者（可读取属性、位置、阵营）
      // c.log    —— 施法日志，会显示在推演台
      const d = a[0] as { x: number; y: number };
      const power = asNum(a[1]) * c.caster.attr.power;
      const hit = c.world.raycast({ x: c.caster.x, y: c.caster.y }, d, 260, 26, c.caster.faction);
      if (hit) c.world.damage(hit.id, power);
      return null;
    },
  });
}
```

Vite 与 Vitest 会通过 `import.meta.glob` 自动收录目录内文件。为了让纯 Node 沙盒也能运行，还必须在 `src/core/metas/index.ts` 的 `fallbackModules` 中增加一行；完成后运行 `npm run docs:generate` 更新玩家参考表。

## 方式二：外部目录（打包后，用户扩展）

打包成 exe 后，程序会在**可执行文件旁边的 `metas/` 目录**扫描 `.js` 文件并动态加载。

目录示例：

```
道衍.exe
metas/
  裂空斩.js
  五行术.js
```

`metas/裂空斩.js` 的写法与上面一致，但需要是纯 JS（ESM）：

```js
export default function register() {
  // 通过全局注入的 DAOYAN 获得注册能力
  const { T, defMeta, asNum } = globalThis.DAOYAN;
  defMeta({/* ... */});
}
```

宿主会保证 `globalThis.DAOYAN` 在调用 `register()` 之前已就绪。

## 定价覆写（调平衡不用改代码）

```ts
import { applyMetaOverrides } from './core/meta';

applyMetaOverrides({
  快照: { mana: 60 }, // 把快照从 70 降到 60
  探查: { mana: 8, ticks: 1 },
});
```

也可以在游戏启动时从一份 JSON 配置读取，方便不重新编译就调参。

元法术可声明固定基础价格与动态价格，涉及距离、目标属性和请求效果的能力必须由运行时价格覆盖实际消耗；当前迁移范围与后续方向见 [`meta-spell-and-entity-model-vnext.md`](../proposals/meta-spell-and-entity-model-vnext.md)。

## 约定

| 项   | 约定                                                               |
| ---- | ------------------------------------------------------------------ |
| 文件 | `src/core/metas/*.ts`，默认导出 `register(): void`                 |
| 收录 | Vite 自动收录；纯 Node 需同步 `src/core/metas/index.ts` 的兜底清单 |
| 注册 | 用 `defMeta()`；**同名会被覆盖**（幂等，热更新安全）               |
| 分组 | `group` 决定推演台元法术列表中的实现分组                           |
| 定价 | 当前神识内运算法力为 0；读世界和改世界使用固定基础法力             |
| 属性 | 伤害类效果当前乘 `caster.attr.power`，扫描半径乘 `attr.perception` |
| 类型 | 只能使用 `num / bool / vec2 / entity / list` 五种                  |
| 文档 | 修改注册项后运行 `npm run docs:generate` 和 `npm run docs:check`   |
