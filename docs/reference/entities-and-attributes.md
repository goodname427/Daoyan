# 实体与属性（当前工作树实现）

本文说明当前工作树中的实体、属性和统一控制入口。项目版本中的整体能力仍以对应工作项验证为准；本页不代表该版本已完成集成或验收。

## 实体与句柄

玩家和妖兽都是 `Actor`，共用属性结构与施法管线。`Projectile` 是弹道。DSL 的 `entity` 是统一、不透明的数字句柄，可指向 Actor 或 Projectile；句柄在所属 `World` 中不复用，不能跨 World 传递或持久化。操作按目标声明的能力判断，不通过实体种类决定同一属性控制的语义。

`创建弹道(起点, 方向, 速度, 基础伤害, 存活时间)` 是新法术的统一创建入口。它一次完成参数校验、创建和激活，成功返回句柄，失败返回 `空`。参数应为有限坐标、有限非零方向以及正的有限速度、基础伤害和存活秒数；方向会归一化。施法者的 `power` 乘到基础伤害一次。每位所有者最多保有 16 枚弹道。旧 `发射` 语法仅供兼容迁移，不是新法术入口。

实体控制成功返回 `true`。失效句柄、缺少目标能力、权限不符、非法效果或不支持的时间会拒绝并返回 `false`，不留下部分效果。调用仍按尝试规则计价；法力不足、非法动态价格或 VM 执行上限错误会终止施法。

## Actor 属性

基础属性及默认值来自 `src/core/attributes.ts`：

| 中文名   | 字段          | 默认值 | 用途                         |
| -------- | ------------- | -----: | ---------------------------- |
| 生命上限 | `hpMax`       |    100 | 生命上限；当前生命单独保存   |
| 法力上限 | `manaMax`     |    200 | 法力上限；当前法力单独保存   |
| 法力回复 | `manaRegen`   |     20 | 每秒法力回复                 |
| 神识上限 | `shenshiMax`  |     48 | VM 变量和列表空间容量        |
| 移动速度 | `speed`       |    140 | 战斗层连续移动速度           |
| 施法速度 | `castSpeed`   |      1 | 每秒推进的 VM tick 倍率      |
| 术法威力 | `power`       |      1 | 伤害与创建弹道基础伤害倍率   |
| 法力消耗 | `manaCostMul` |      1 | 实扣法力倍率                 |
| 感知半径 | `perception`  |      1 | 扫描半径倍率                 |
| 护体减伤 | `armor`       |      0 | 受伤时固定减免，最低伤害为 1 |

同一 Actor 可由多个槽位并发施法；施法实例共享法力与神识账户。变量和列表仍存活时占用神识，释放、结束或失败后归还。

## 属性控制：参数与生命周期

所有公开属性控制均为 `(目标: entity, 效果, 时间: num) -> bool`。时间是秒：正有限数表示时长，`0` 表示无限；负数和非有限值会被拒绝。三个参数适用于下列入口：

| 元法术         | 效果类型 | 属性         |
| -------------- | -------- | ------------ |
| `设置位置`     | `vec2`   | `position`   |
| `设置朝向`     | `vec2`   | `rotation`   |
| `调整速度`     | `num`    | `speed`      |
| `强化伤害`     | `num`    | `damage`     |
| `设置存活时间` | `num`    | `lifetime`   |
| `调整感知`     | `num`    | `perception` |
| `调整护体`     | `num`    | `armor`      |

目标 binding 决定属性是否可用、接受何种时间，以及由哪种生命周期管理：

- **write/commit**：立即写入基础状态，不保存可撤销快照。当前 `position` 和 `lifetime` binding 只接受时间 `0`；位置不会在施法结束后回弹，已移除弹道不会复活。
- **write/overlay**：写入由世界持有的覆写层，可限时或无限，不随施法结束撤销。到期、替换或能力失效时移除该层，再按基础值和仍有效层重算。当前 Actor 的 `rotation` 与 Projectile 的 `rotation`、`speed`、`damage` 使用此模式。

- **maintain**：效果归当前施法会话持有，建立和更新时先付费；之后每 `0.25` 秒按模拟时间结算法力与 tick，再覆盖下个周期。暂停不计时，会话结束、目标/能力失效或无法支付时清理记录。时间 `0` 的无限维持仍持续收费，并受会话生命周期约束。

Actor 的鼠标瞄准与妖兽追踪更新基础朝向，施法与表现读取合成后的有效朝向；最新有效朝向覆写优先于输入。覆写到期后露出仍有效的下层，全部到期后使用当前输入方向，不恢复施加控制时的旧方向。

当前 Actor 的 `speed`、`damage`、`perception`、`armor` binding 使用 `maintain`。实体是否支持某项属性取决于 binding；例如 Projectile 没有生命能力，不能因句柄统一就被 `伤害` 当作有生命目标。未知属性或缺失 binding 明确拒绝，不补造默认能力。

## 资源公式

- **神识**衡量同时存活的程序状态：`num`、`bool`、`entity` 各 1；`vec2` 为 2；`list<T,N>` 为表头 1 加 `N × T` 的容量成本。列表容量参与静态峰值预算。
- **法力**衡量世界 I/O。固定元法术按注册价扣费；动态请求还会按实际请求、距离、关系或目标状态增加价格。实扣基础价格乘施法者有效 `manaCostMul`。
- **耗时**衡量执行工作。tick 累加元法术、参数表达式、下标和被调用法术；演武场真实推进速度受 `castSpeed` 影响。maintain 的周期 tick 也计入执行债务。

控制价格把关系倍率、binding 抗性和实际效果变化计入法力与 tick：

```text
起手法力 = G + A × (2 + S + D) × (1 + r)
起手 tick = ceil(G + A × (1 + 0.1 × S + D / 4) × (1 + r))
周期法力 = A × (1.25 + S') × (1 + r)       # 每 0.25 秒
周期 tick = ceil(A × (1 + 0.1 × (S' + 0.25)) × (1 + r))
```

`A` 按自身/自有、友方、非己方分别为 `1/2/8`；非己方另有固定门槛 `G=4`，其他关系为 `0`。`r` 是目标 binding 的非负有限抗性，当前内建 binding 为 `0`。`S`、`S'` 衡量实际效果强度；`D` 是有限 `write/overlay` 的剩余时间项（秒），其他模式为零。法力按公式计算，tick 向上取整。无限维持没有有限总价上界，参考与分析结果会标为无界/动态，不编码成 `Infinity`。

静态分析只在能够给出可信上界时显示有限总预算。目标、关系、效果、抗性或未来周期仍未知时会显示动态项。推演面板的基础预算不等同于特定战斗目标的实扣值。

## 当前边界

- 统一句柄仍由 Actor 与 Projectile 两种世界集合承载，不是通用 ECS。
- 首批统一控制属性仅为 `position`、`rotation`、`speed`、`damage`、`lifetime`、`perception`、`armor`；生命上限、法力、神识上限和施法倍率不属于公开控制属性。
- 目标抗性接口存在，当前内建 binding 抗性为零；更丰富的抗性与对抗规则尚未提供。
- 兼容旧法术时会尝试规范化 AST；无法证明安全等价的旧链应诊断拒绝，不能假定所有旧法术都可迁移。

完整元法术签名见[元法术参考](./meta-spells.md)，法术起步见[法术编写指南](./spell-authoring.md)。统一控制与预算合同见 [ADR 0017](../adr/0017-统一实体控制属性模型.md)。
