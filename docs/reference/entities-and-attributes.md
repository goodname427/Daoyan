# 实体与属性（当前工作树实现）

本文说明当前工作树中的实体、属性和统一控制入口。项目版本中的整体能力仍以对应工作项验证为准；本页不代表该版本已完成集成或验收。

## 实体与句柄

玩家和妖兽都是 `Actor`，共用属性结构与施法管线。`Projectile` 是弹道。DSL 的 `entity` 是统一、不透明的数字句柄，可指向 Actor 或 Projectile；句柄在所属 `World` 中不复用，不能跨 World 传递或持久化。操作按目标声明的能力判断，不通过实体种类决定同一属性控制的语义。

`创建弹道(起点, 方向, 速度, 基础伤害, 存活时间)` 是新法术的统一创建入口。它一次完成参数校验、创建和激活，成功返回句柄，失败返回 `空`。参数应为有限坐标、有限非零方向以及正的有限速度、基础伤害和存活秒数；方向会归一化。施法者的 `power` 乘到基础伤害一次。每位所有者最多保有 16 枚弹道。旧 `发射` 语法仅供兼容迁移，不是新法术入口。

五参创建的创建费、初始冲量和单次命中伤害储能分别付款；创建费用本身不形成可退余额。`注入运动能量`、`注入伤害能量`、`注入扫描能量` 按 `1 法力 → 0.8 E` 向自有法球分池注入。`设置法球推进` 给出每 `0.25` 秒的速度变化，`设置法球追踪` 同时消耗扫描池与运动池；可用 `设置法球滑行` 取消主动行为。余额不足时不再推进或扫描，已有速度仍随阻力滑行，法球不会自行支取所有者后续法力。命中只释放当次可用的伤害池余额，穿透逐次扣款；护体可吸收伤害，但不能返还能量。动能不转换为伤害。

实体控制成功返回 `true`。失效句柄、缺少目标能力、权限不符、非法效果或不支持的时间会拒绝并返回 `false`，不留下部分效果。调用仍按尝试规则计价；法力不足、非法动态价格或 VM 执行上限错误会终止施法。`传送(目标, 落点)` 是独立高价效果，越界或与存活角色重叠时直接拒绝并只收统一的正尝试价，成功保留朝向与实际速度。

## 逐属性探查

`读取位置`、`读取朝向`、`读取速度`、`读取速度上限`、`读取生命`、`读取生命上限`、`读取法力`、`读取法力上限`、`读取法力回复`、`读取神识上限`、`读取神识占用`、`读取施法速度`、`读取法力消耗`、`读取护体`、`读取伤害`、`读取感知` 和 `读取存活时间` 接收实体句柄，返回 `query<vec2>` 或 `query<num>`。缺少目标能力的字段会拒绝。先用 `查询可用(结果)` 检查成功分支，再用 `查询向量` 或 `查询数值` 取得值；失败是统一的 `unavailable`，合法的零值不会被当成失败。成功结果带目标、字段和模拟时刻，`查询时刻` 可读取时刻；缓存结果不会自动更新。

```daoyan
var hpRead: query<num> = 读取生命(target)
if 查询可用(hpRead) {
  var hp: num = 查询数值(hpRead)
}
```

非自身读取须具备目标字段能力、逐字段授权、可见性和距离条件。授权中的公开神识及抗性上界用于报价；没有覆盖隐藏状态的有限公开界时拒绝。自身私有读取、拒绝尝试均至少收 1 法力和 1 tick，且不受法力消耗倍率折扣。`扫描敌人` 与 `扫描坐标` 先按公开半径付款，再返回 `query<entities>` 或 `query<positions>`；最多保留 64 个获准目标，零个目标是成功空列表。旧 `探查`、`生命`、`感知敌人`、`快照` 的零值或裸列表语义不能无损迁移，新法术不应使用；迁移入口会保留原文并报告法术名和源码行。

## Actor 属性

基础属性及默认值来自 `src/core/attributes.ts`：

| 中文名   | 字段          | 默认值 | 用途                         |
| -------- | ------------- | -----: | ---------------------------- |
| 生命上限 | `hpMax`       |    100 | 生命上限；当前生命单独保存   |
| 法力上限 | `manaMax`     |    200 | 法力上限；当前法力单独保存   |
| 法力回复 | `manaRegen`   |     20 | 每秒法力回复                 |
| 神识上限 | `shenshiMax`  |     48 | VM 变量和列表空间容量        |
| 移动速度 | `speed`       |    140 | 主动驱动的速度上限           |
| 施法速度 | `castSpeed`   |      1 | 每秒推进的 VM tick 倍率      |
| 术法威力 | `power`       |      1 | 伤害与创建弹道基础伤害倍率   |
| 法力消耗 | `manaCostMul` |      1 | 实扣法力倍率                 |
| 感知半径 | `perception`  |      1 | 扫描半径倍率                 |
| 护体减伤 | `armor`       |      0 | 受伤时固定减免，最低伤害为 1 |

同一 Actor 可由多个槽位并发施法；施法实例共享法力与神识账户。变量和列表仍存活时占用神识，释放、结束或失败后归还。

普通移动先从角色独有的世界运动功率预付每 `0.25` 秒的驱动；初始与容量均为 `4 Wm`，模拟时间每秒补给 `4 Wm`。该功率不能转给法球或兑换法力。角色以每秒 `20` 的线性阻力向目标速度趋近，松开输入后保留短暂惯性；降低 `speed` 不会裁剪已有实际速度。弹道的显示方向、主动速度上限和实际速度相互独立，已付冲量后的惯性飞行不逐帧调用法术。`施加冲量` 可作用于自身或自有弹道，其运动做功和操控损耗在效果前计价。

## 属性控制：参数与生命周期

所有公开属性控制均为 `(目标: entity, 效果, 时间: num) -> bool`。时间是秒：正有限数表示时长，`0` 表示无限；负数和非有限值会被拒绝。三个参数适用于下列入口：

| 元法术         | 效果类型 | 属性          |
| -------------- | -------- | ------------- |
| `设置朝向`     | `vec2`   | `rotation`    |
| `调整速度`     | `num`    | `speed`       |
| `强化伤害`     | `num`    | `damage`      |
| `设置存活时间` | `num`    | `lifetime`    |
| `调整感知`     | `num`    | `perception`  |
| `调整护体`     | `num`    | `armor`       |
| `调整生命上限` | `num`    | `hpMax`       |
| `调整法力上限` | `num`    | `manaMax`     |
| `调整法力回复` | `num`    | `manaRegen`   |
| `调整神识上限` | `num`    | `shenshiMax`  |
| `调整施法速度` | `num`    | `castSpeed`   |
| `调整法力消耗` | `num`    | `manaCostMul` |

目标 binding 决定属性是否可用、接受何种时间，以及由哪种生命周期管理：

- **write/commit**：立即写入基础状态，不保存可撤销快照。当前公开控制仅有 `lifetime` 使用此模式。位置 binding 只供独立传送校验，普通属性写入会拒绝。
- **write/overlay**：写入由世界持有的覆写层，可限时或无限，不随施法结束撤销。到期、替换或能力失效时移除该层，再按基础值和仍有效层重算。当前 Actor 的 `rotation` 与 Projectile 的 `rotation`、`speed`、`damage` 使用此模式。

- **maintain**：效果归当前施法会话持有，建立和更新时先付费；之后每 `0.25` 秒按模拟时间结算法力与 tick，再覆盖下个周期。暂停不计时，会话结束、目标/能力失效或无法支付时清理记录。时间 `0` 的无限维持仍持续收费，并受会话生命周期约束。

Actor 的鼠标瞄准与妖兽追踪更新基础朝向，施法与表现读取合成后的有效朝向；最新有效朝向覆写优先于输入。覆写到期后露出仍有效的下层，全部到期后使用当前输入方向，不恢复施加控制时的旧方向。

当前 Actor 的 `speed`、`damage`、`perception`、`armor` 与六项新增属性 binding 使用 `maintain`。`hpMax`、`manaMax`、`manaRegen`、`shenshiMax` 的效果是数值增量，`castSpeed`、`manaCostMul` 的效果是倍率；合成值必须分别满足上限大于零、回复率非负、神识上限为正安全整数、倍率在 `0.25..4` 内。上限缩小时裁剪当前生命或法力，之后恢复上限不会补回余额；神识降额不会销毁已占用状态，只阻止超额后的新增预留。当前生命仅由伤害或治疗改变，当前法力仅由账本交易或世界回复改变。实体是否支持某项属性取决于 binding；Projectile 不提供这六项能力。

## 资源公式

- **神识**衡量同时存活的程序状态：`num`、`bool`、`entity` 各 1；`vec2` 为 2；`list<T,N>` 为表头 1 加 `N × T` 的容量成本。列表容量参与静态峰值预算；每条存续控制记录也占 1。
- **法力**衡量世界 I/O。固定元法术按注册价扣费；动态请求还会按实际请求、距离、关系或目标状态增加价格。仅显式声明可折扣的普通调用按 `manaCostMul` 调整其可折扣部分；控制、探查、注能、退款等资源路径全价支付。
- **耗时**衡量执行工作。tick 累加元法术、参数表达式、下标和被调用法术；演武场真实推进速度受 `castSpeed` 影响。maintain 的周期 tick 也计入执行债务。

控制价格把关系倍率、binding 抗性和实际效果变化计入法力与 tick：

```text
起手法力 = G + A × (2 + S + D) × (1 + r)
起手 tick = ceil(G + A × (1 + 0.1 × S + D / 4) × (1 + r))
周期法力 = A × (1.25 + S') × (1 + r)       # 每 0.25 秒
周期 tick = ceil(A × (1 + 0.1 × (S' + 0.25)) × (1 + r))
```

`A` 按自身/自有、友方、非己方分别为 `1/2/8`；非己方另有固定门槛 `G=4`，其他关系为 `0`。`r` 是目标 binding 的非负有限抗性，当前内建 binding 为 `0`。`S`、`S'` 衡量实际效果强度；`D` 是有限 `write/overlay` 的剩余时间项（秒），其他模式为零。法力按公式计算，tick 向上取整。无限维持没有有限总价上界，参考与分析结果会标为无界/动态，不编码成 `Infinity`。

六项属性的强度按上限变化量的十分之一、单周期额外回复量、或倍率的二进制对数绝对值计量。回复控制每层每周期的不可折扣价至少覆盖该层最大额外回复量再加 1 法力；并发层分别付款。施法速度只改变后续 tick 的真实推进时间，不减少已有 tick 债务。

静态分析只在能够给出可信上界时显示有限总预算。目标、关系、效果、抗性或未来周期仍未知时会显示动态项。推演面板的基础预算不等同于特定战斗目标的实扣值。

## 当前边界

被动事件在提交时为每位订阅者保存获准字段，派发前再次检查距离、可见性和字段授权。他方事件须有 `events` 授权，伤害量另需 `hp`，坐标另需 `position`；筛选也只使用获准句柄。未知来源返回 `null`，自身受击保留必要摘要。提交后新增授权不会补发旧字段，派发不读取新坐标；死亡或移除的终止摘要使用终止实体的能力与最后位置复核授权。

法球控制者死亡时，推进和追踪立即撤销，已付冲量产生的惯性继续按阻力衰减；后续周期不再消费运动或扫描池。当前尚无独立死亡后行为授权入口，预付储能和所有权都不能代替该授权。

资源账本的 4096 来源、4096 预留限制按同时活跃数量计算。结算完成即释放预留槽位，没有余额或预留的来源从活跃表回收；来源明细最多保留最近 128 条历史，累计守恒账不随历史淘汰。实体终结退款额独立保留至世界重置，旧预留 ID 不复用，因此重复结算或销毁不会再次消费或退款，串行使用不永久耗尽容量。

- 统一句柄仍由 Actor 与 Projectile 两种世界集合承载，不是通用 ECS。
- 统一控制包含前述基础属性及六项 Actor 资源属性；当前生命和当前法力不提供直接控制 binding。
- 目标抗性接口存在，当前内建 binding 抗性为零；更丰富的抗性与对抗规则尚未提供。
- 兼容旧法术时会尝试规范化 AST；无法证明安全等价的旧链应诊断拒绝，不能假定所有旧法术都可迁移。
