# 实体与属性（当前实现）

本文描述当前代码的数据模型。统一句柄、动态价格与旧元法术能力迁移已由 [ADR 0009](../adr/0009-统一实体句柄与能力判定.md)、[ADR 0010](../adr/0010-动态元法术价格与静态上界.md)、[ADR 0011](../adr/0011-无界效果与动态资源预算.md) 和 [ADR 0015](../adr/0015-统一实体能力迁移与移除法术冷却.md) 采纳。

## 当前世界对象

`World` 目前维护两个相互独立的集合：

```text
World
├─ actors: Actor[]
└─ projectiles: Projectile[]
```

### Actor

玩家和妖兽都是 `Actor`，共用属性、施法、受伤、临时修正和死亡逻辑。DSL 的 `entity` 是不透明数字句柄，可引用 Actor 或 Projectile；两个集合共用单调递增 ID，移除和 `World.reset()` 后也不复用。句柄只在所属 World 内有效，不能跨 World 传递或持久化。

Actor 除属性外还包含：位置、阵营、准星、当前生命、当前法力、半径、存活状态、法术绑定、AI 行为、硬直、施法减速和表现状态。

演武场允许一个 Actor 通过不同槽位同时运行多个施法实例。每个实例独立推进 tick 和生命周期，但所有实例共同使用 Actor 的当前法力与神识：元法术执行时实时扣除法力，变量存活时实时占用神识；返回、失败、打断或重开都会归还仍占用的神识。同一槽位在原实例结束前不能重入。

### Projectile

Projectile 具备 Identity、Transform、Movement 和 Projectile 能力，只有所有者、阵营、位置、方向、速度、伤害、半径、寿命、穿透次数、命中集合和激活状态。它没有 Actor 的 Vitality、Caster 或 Modifiers，不能增减生命、法力或临时属性。

`创建弹道(寿命)` 返回未激活实体的句柄，寿命接受任意正的有限秒数；创建失败返回 `空`。每位所有者最多同时保有 16 枚，旧 `发射` 和未激活对象共用该上限。未激活对象不移动、不碰撞、不渲染，但仍消耗寿命并占用名额；过期、命中销毁或场景清理释放名额。

所有者可调用 `设置弹道方向`（有限非零向量，自动归一）、`设置弹道速度`（任意正有限值）和 `设置弹道威力`（任意正有限基础值，再乘施法者有效 `power`）。配置速度和威力后，`激活弹道` 将其置于施法者前方。激活只能成功一次，飞行中仍可配置方向、速度和威力。

控制成功返回 `true`；无效句柄、其他所有者、能力缺失或非法参数返回 `false`，目标不变。尝试成本仍扣除；资源不足则由 VM 终止。`设置位置` 可通过同一个 Transform 能力入口移动 Actor 或 Projectile；`伤害` 检查 Vitality，`迟滞`、`虚弱`、`蔽识` 与 `破防` 检查 Modifiers。`实体存在` 判断对象是否仍在世界集合中（Actor 死亡不等于已移除）；`探查` 可读取两种实体的位置，`生命` 对缺少 Vitality 或失效的句柄返回 `0`。

默认“御剑·手动”演示完整创建与配置链路。旧 `发射` 保留固定参数和 `void` 返回值，直接创建激活弹道；达到上限时不生成弹道或发射特效。

## Actor 属性表

当前每个 Actor 都必须拥有下面全部属性，没有“属性缺失”的表达。

| 中文名   | 代码字段      | 默认值 | 当前作用                                              |
| -------- | ------------- | ------ | ----------------------------------------------------- |
| 生命上限 | `hpMax`       | 100    | 决定生命上限；当前生命另存于 `Actor.hp`               |
| 法力上限 | `manaMax`     | 200    | 决定法力上限；当前法力另存于 `Actor.mana`             |
| 法力回复 | `manaRegen`   | 20     | 每秒恢复法力，不能超过有效法力上限                    |
| 神识上限 | `shenshiMax`  | 48     | VM 同时可持有的变量与列表空间                         |
| 移动速度 | `speed`       | 140    | 影响战斗层的连续移动；`移动()` 元法术当前不读取该属性 |
| 施法速度 | `castSpeed`   | 1      | 放大每秒可执行的 tick 数，数值越大施法越快            |
| 术法威力 | `power`       | 1      | 乘到伤害元法术数值，以及 `设置弹道威力` 的基础请求值  |
| 法力消耗 | `manaCostMul` | 1      | 乘到所有元法术的基础法力价格，越小越省                |
| 感知半径 | `perception`  | 1      | 只放大 `感知敌人` 与 `快照` 的输入半径                |
| 护体减伤 | `armor`       | 0      | 每次受伤固定减免；最终伤害最低为 1                    |

战斗中的临时增益与减益保存在 `Modifier[]`：先合并加法修正，再乘乘法修正；持续时间结束后移除并重算有效属性。

法术冷却与冷却倍率已经移除。玩家输入只响应按下边沿，同一槽位在当前施放结束前不能重入；结束后再次按下即可立即起手。妖兽的攻击间隔属于 AI 决策节奏，不是法术属性。

## 当前资源公式

### 法力

固定元法术直接使用 `mana`；新动态元法术把 `mana` 作为固定基础价，并由 `cost` 同时计算本次法力与 tick：

```text
本次调用实扣法力 = 运行时基础价 × 施法者有效 manaCostMul
```

核心公式中的关系倍率 `R` 为：自身或自有实体 `1`，同阵营实体 `2`，敌对实体 `8`。代表性调用如下；完整调用清单见[元法术参考](./meta-spells.md)。

| 调用                | 运行时基础法力          | 运行时 tick                    |
| ------------------- | ----------------------- | ------------------------------ |
| `探查` / `生命`     | `8 + 距离 / 200 × R`    | `2 + ceil(距离 / 400 × R)`     |
| `创建弹道`          | `8 + 寿命 × 2`          | `2 + ceil(寿命 / 2)`           |
| `设置弹道速度`      | `2 + 速度 / 100`        | `1 + ceil(速度 / 300)`         |
| `设置弹道威力`      | `2 + 基础威力 / 4`      | `1 + ceil(基础威力 / 50)`      |
| `伤害`              | `5 + 请求伤害 / 10`     | `1 + ceil(请求伤害 / 200)`     |
| `瞬移` / `设置位置` | `5 + 位移距离 / 20 × R` | `2 + ceil(位移距离 / 100 × R)` |

其他扫描、发射、近战、移动和属性控制也按请求半径、强度、倍率、持续时间或实体关系增加两种资源。效果参数先按玩家请求值定价，再由 `power`、`perception` 等属性放大实际效果。正的有限请求不设人为最大值；非有限或不满足领域方向的值只收固定尝试成本且不产生效果。

VM 在扣费与执行效果前拒绝负数、非有限、非整数 tick、运行时仍含未知项或抛错的动态价格。分析器能解析的参数形成已知预算；距离、关系、运行时参数或分支不确定值显示为“+ 动态”。只有不含动态项时才是有限上界。推演台仍未结合演武场的 `manaCostMul`；目标神识强度和指定场景精确预算尚未实现。

### 耗时

固定元法术注册固定 tick；动态元法术还会按请求效果、距离或关系增加 tick。参数表达式与列表下标也会产生额外 tick。演武场每帧推进：

```text
每秒可执行 tick ≈ 100 × 有效 castSpeed
```

因此 `castSpeed=2` 大约把相同 tick 数的真实施法时间减半。`manaCostMul` 不影响时间。

### 神识

神识是法术执行期间的变量空间：

```text
num / bool / entity = 1
vec2 = 2
list<T,N> = 1 + N × T 的成本
```

`shenshiMax` 是容量，当前没有独立的“神识强度”用于远程探查、抵抗控制或动态计价。

## 当前元法术对属性的使用

| 属性          | 会读取它的当前逻辑                              |
| ------------- | ----------------------------------------------- |
| `speed`       | 玩家和妖兽的连续移动；`疾行`可临时修改          |
| `castSpeed`   | 战斗层的 VM tick 推进；`明心`可临时修改         |
| `power`       | 伤害元法术与弹道威力设置；`增威`和`虚弱`可修改  |
| `manaCostMul` | VM 扣除所有元法术法力；`节流`可修改             |
| `manaRegen`   | 世界每帧回复；`聚气`可修改                      |
| `perception`  | `感知敌人`、`快照`的有效扫描半径                |
| `armor`       | `World.damage` 的固定减伤；`护体`和`破防`可修改 |

## 后续边界

1. 统一句柄与能力查询已实现，存储仍为两个数组，不是通用 ECS。
2. Actor 内部属性仍全部必填；生命、伤害和目标属性修正已迁移，扫描、旧发射等专用世界操作仍可继续收敛。
3. 没有神识强度，远程探查与控制也没有对抗计算。
4. 当前世界 I/O 主路径已接入动态法力与 tick；目标抗性、神识强度和指定场景预算仍未实现。
5. 当前仅有弹道创建原型；护盾等其他原型需要独立规格。
