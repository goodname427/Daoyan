## 问题、范围和验收

当前 `src/core/metas/entity.ts` 用 `ownedProjectile` 实现创建、配置、激活链，`src/core/metas/control.ts` 另有立即发射；`MetaCost` 只有一次调用的法力/tick，`Modifier.duration <= 0` 隐含永久。它们尚不能表达跨实体的同属性效果、一次写入与无限维持的区别，也不能计量维持工作。

本决策固定 descriptor/binding、commit/overlay/maintain、控制会话、周期预算、定价与 AST 迁移的不可逆边界。验收是覆盖详细策划全部合同，并使后续核心、DSL、Battle 与 UI 能依据同一语义实现，不引入实体类型分支。非目标是实现运行时、平衡最终数值、完整 ECS、新实体原型、敏感资源属性或工作流控制面。

## 决策一：属性由语义描述，目标由 binding 声明能力

`ControlPropertyDescriptor` 拥有稳定 `propertyKey`、效果类型、领域校验及合并运算语义。`ControlPropertyBinding` 把该逻辑属性映射到目标存储，声明 `mode: write | maintain`、写入时的 `writePolicy: commit | overlay`、支持的时间、关系许可、非负抗性读取、实际效果强度及应用/撤销接口。binding 不得重新解释同一属性的效果含义。

公开控制统一为 `(目标, 效果, 时间): bool`，具名元法术只选属性键并调用同一个 `applyEntityControl`。流程为解析句柄、查 descriptor/binding、校验效果/时间/关系、计算价格、结算并应用；失败返回 `false` 与可解释原因，不能产生部分属性修改或残留记录。VM 的非法定价、资源和执行上限错误继续终止施法。已有的效果前基础尝试费用可保留，领域拒绝不能伪装为成功或租约。

首批属性合同如下；具体存储适配见详细策划，不能把适配表抄成通用执行器的类型判断。

| 属性键            | 效果                                        | 模式约束                                                         |
| ----------------- | ------------------------------------------- | ---------------------------------------------------------------- |
| `position`        | 有限 `vec2` 目标坐标，按 Transform 边界裁剪 | `write/commit`，只接受时间 `0`，不制造定身或到期回弹             |
| `rotation`        | 有限非零方向向量，归一化                    | `write/overlay`，最晚有效覆写优先                                |
| `speed`、`damage` | 正有限运动速度倍率、对外伤害倍率            | binding 声明 `write/overlay` 或 `maintain`；倍率含义相同         |
| `lifetime`        | 正有限剩余秒数                              | `write/commit`，只接受时间 `0`，继续正常倒计时，不复活已移除目标 |
| `perception`      | 正有限感知倍率                              | 首批 `maintain`                                                  |
| `armor`           | 有限有向护体增量                            | 首批 `maintain`                                                  |

`hpMax`、`manaMax`、`manaRegen`、`shenshiMax`、`castSpeed`、`manaCostMul` 不在本版公开控制范围。无描述符或无 binding 必须明确拒绝，不补默认能力。关系读取不等于实体类型读取；元法术、价格函数、控制调度及 UI 不得用 `kind`、`instanceof`、`ownedProjectile` 或存储数组选择控制语义。现有两类存储可以保留，在实体构造/适配边界安装 binding；未来实体只声明相同 binding 即可复用路径。

## 决策二：时间、记录、合并与恢复

`时间` 仍为 AST 的 `num`：正有限数为秒，`0` 为无限，负数、NaN、Infinity 均拒绝。无限不得编码成浮点 Infinity 或沿用旧 Modifier 的负时长。每条可存续记录显式包含目标句柄、`propertyKey`、效果、`mode`、`writePolicy | null`、`expiresAt | null`、控制者标识、`controllerSessionId | null`、单调稳定序号与结算状态。

| 模式            | 有限时间                                   | 时间 `0`                                       | 生命周期所有者             |
| --------------- | ------------------------------------------ | ---------------------------------------------- | -------------------------- |
| `write/commit`  | 拒绝                                       | 起手付费后一次写入，不保存可撤销旧快照         | 世界基础状态，不占施法实例 |
| `write/overlay` | 起手付费，记录绝对到期时刻；时长进入起手价 | 起手付费，无到期覆写                           | 世界属性记录，不占施法实例 |
| `maintain`      | 起手及周期付费，最迟在到期时移除           | 起手及周期付费，无到期但受会话、权限及资源约束 | 核心控制会话               |

覆写层不保存整个实体快照。数值属性按稳定序号遍历，先合并 `add`，再合并 `mul`；方向等替换属性由序号最大的有效层胜出。移除或到期时从当前基础值与仍有效层重新计算，绝不把到期前的基础值写回，避免覆盖其他来源的新变化。

`write/overlay` 的同源键为控制者、目标和属性；后一次成功写入替换本层，赋新序号，即使来自该控制者的另一施法会话也不堆叠永久层。`maintain` 的同源键为控制会话、目标和属性；更新替换旧记录，不再增加租约。不同来源按上述规则合并。替换前完成校验与扣费，领域校验拒绝不破坏仍合法且已付费的旧记录；若资源或执行错误导致整个会话终止，则仍须释放该会话的旧租约。目标、binding、属性生命周期或权限失效则独立清理旧记录。

持续周期不能因重复调用、同源替换或帧率变化获得免费窗口；每次更新仍付起手，增加的效果必须在生效前完成相应周期结算。write 在施法结束后仍有效，直到自身到期、替换或目标能力失效；maintain 在会话结束时全部移除。commit 不是可撤销租约，后续模拟和合法写入可以继续改变基础状态。

## 决策三：核心会话及 0.25 秒原子结算

核心持有 `ControlSession`，绑定稳定施法实例 ID、控制者、共享资源账户、模拟时钟、租约集合和结束状态。Battle 只适配这些接口及完成、取消、受击打断、死亡等事件，不实现另一套控制价格或计时器。无头 VM 使用同一会话接口；`duration/channel` 的会话属于外层施法实例，不能随一次 VM 片段返回而误结束，瞬发则在本次施法正常完成时结束。

结算量子固定为模拟时间 `0.25` 秒，暂停不流逝，禁止使用墙钟计费。周期在效果覆盖前付费：建立租约时结算起手及首周期，首周期覆盖 `[t0, t0 + 0.25)`；随后在 `t0 + n × 0.25` 结算下周期。有限时长 `d` 最多 `ceil(d / 0.25)` 个周期，尾部不足一周期仍按一周期收费，到期边界先移除、不再续费。例如 `d=0.1/0.25/0.5` 分别最多结算 `1/1/2` 次；提前结束不退已成功周期费用。这是效果前结算原则的周期化，不预扣未来全部周期。

同源 maintain 更新视为一次新的付费请求：成功时原子替换旧记录，以更新时间作为新 `t0`，重算到期时刻并支付新起手和完整首周期；旧周期的剩余时间不退款、不抵扣。即使效果值相同也遵守此规则，因而重置周期不会获得免费维持。上述最多周期数是每次成功请求的上界；循环或多次更新的预算必须累加各次请求，不能只按最终保留的那条租约计算。例如在 `t=0.1` 更新一条 `t=0` 建立的租约，必须在 `0.1` 支付新首周期，下一结算点为 `0.35`，旧 `0.25` 结算点随旧记录失效。

稳定记录序号由同一世界统一分配，跨控制者与会话可比较，不依赖实体类型或存储数组遍历顺序。结算事件按应结算的模拟时刻、稳定记录序号排序；同一时刻先处理到期及失效，再处理续费，不能以租约的最终到期时间倒置扣费顺序。单个周期原子执行：

1. 先清理已到期、会话结束、目标失效、binding 丢失或关系不再许可的记录。
2. 以本周期的关系、抗性和实际效果计算双资源价格；不能把上一次运行时价格当作永久锁价。
3. 确认价格合法、共享法力可支付、执行上限与会话仍有效，原子扣法力、登记 tick 执行债务及周期已付标记，再发布本周期效果。首周期与起手必须一并预检，失败不留下新租约或部分效果。
4. 法力不足或本次租约失效时，在未支付周期生效前移除该租约，发出可观察结束原因；取消、`结束施法`、正常完成、打断和执行上限终止则幂等释放会话所有租约。已付 tick 债务不得由释放抹掉。

多次推进同一时刻不重复扣费；大步长须按上述边界分段推进，不能先模拟一段未付费效果再事后补扣。并发会话消费同一个账户并保持稳定顺序，不能各自复制余额。结束和失效清理不等待下一次扣费点，也不等待 tick 债务清空。

tick 是工作量，不是余额。每次周期计入所属施法的累计实耗及尚未执行的债务，后续 VM 推进先处理债务，再执行新指令；`castSpeed` 沿现有映射转成真实施法时间。不能以“tick 不足”拒绝，也不能把周期工作只记进 UI 而仍让法术免费执行下一步。`manaCostMul` 仅缩放实际法力且只应用一次；周期时钟不随 `castSpeed` 改变。

## 决策四：双资源定价和向后兼容预算

对法力与 tick 分别配置下式的系数，同一纯定价函数服务静态分析、起手与周期实扣；binding 只提供能力和测量输入，不另写元法术价格。

```text
起手 = G + A × (B + S + D) × (1 + r)
每周期 = A × (M + S' + Q) × (1 + r)
```

关系倍率 `A` 为自身/自有/友方/非己方 `1/1/2/8`，非己方的固定门槛 `G > 0`，其他关系 `G=0`。属性基础 `B > 0`，维持基础 `M > 0`，实际效果强度 `S/S'`、有限 overlay 时间项 `D`、周期时间项 `Q` 均非负；非 overlay 的 `D=0`。抗性 `r` 从目标该属性 binding 读取，缺省 `0`，必须非负有限；非法配置、非法抗性或计算溢出属于定价错误，不能静默按零处理。无效果变化也必须支付正基础，持续效果不能成为零周期费。

实际效果强度取同一属性应用前后可观察变化的非负度量；同源替换先剔除自身旧层再测新层，维持续费衡量继续维持该层的效果，不能因为效果已经存在而把每期强度降为零。其他来源仍参与当前基值。伤害/速度的基值不同可导致价格不同；控制者与所有者不同不能偷换伤害倍率来源。tick 在整项公式后向上取整为非负整数，分析和执行使用同一规则；不能通过舍入把正价格降为零。

锚点为 `G=4`（仅非己方）、有限 overlay 的 `B+S+D=5`、无限 write 的 `B+S=3`：`r=0/1` 时自身/自有分别为 `5/10`、`3/6`，友方为 `10/20`、`6/12`，非己方为 `44/84`、`28/52`。两资源分别断言，提高抗性不得降低任一价格。具体平衡系数可调整，但正基础、固定门槛、单调性和模式语义不能通过配置删除。

`MetaCost.mana/ticks: CostAmount` 保留原义，始终只描述本次起手；增加可选 `periodic` 描述，缺省表示没有周期。合同形状为：

```ts
type PeriodicBudget = {
  intervalSeconds: 0.25;
  mana: CostAmount;
  ticks: CostAmount;
  count: { kind: 'finite'; max: number } | { kind: 'unbounded' } | { kind: 'dynamic' };
};
// MetaCost 增加 periodic?: PeriodicBudget
```

已知有限 maintain 使用 `finite` 和上述最多周期数；已知无限 maintain 使用 `unbounded`；目标 binding 或时长未知、可能维持时使用 `dynamic`，不能省略为一次费用。周期价格本身仍可 `dynamic=true`：知道时长不等于知道未来关系、抗性、基值与倍率。有限周期数不自动证明有限价格上界。

分析器向消费者同时输出起手与周期明细；既有 `manaBudget/tickBudget` 和 `manaWorst/tickWorst` 可继续保留已知部分，但只在周期数及所有价格有可信上界时累加“起手 + 单周期上界 × 最多周期数”并宣称有限总上界。否则总预算标为动态；无限维持额外显式标记无界，不写 `Infinity` 到 JSON，也不显示成一个有限总价。分支、循环和函数调用必须传播周期项与动态/无界状态。VM 逐周期要求具体价格已解析，旧扩展没有 `periodic` 时保持原单次合同；新控制消费端必须同步升级，不允许旧 VM 静默忽略周期字段。

神识仍表示状态成本。会话及存续记录必须计入有界状态容量，maintain 占用所属会话，write 记录由世界属性系统持有并在替换/移除时释放，不能因法力一次付费而生成无主无限记录。具体单条容量值由核心任务定义并与分析/实测对齐；无限时间不等于无限数量，也不能豁免静态状态上界。

## 决策五：统一创建、AST 迁移和持久化

唯一新创建入口为 `创建弹道(起点: vec2, 方向: vec2, 速度: num, 基础伤害: num, 存活时间: num): entity`。起点有限、方向有限非零并归一化，其余均正有限；成功即安全偏移、激活并返回句柄，失败返回空。保留每位所有者 16 枚上限及命中/过期清理。基础伤害只在创建时按一次既有施法者威力规则形成命中基值；后续 `damage` 层只作用一次，不能控制和命中重复乘算。

兼容只在 AST 到 AST 规范化入口发生，DSL、蓝图、导入和默认法术书共用同一结果。旧名可被解析但不再作为玩家目录或长期专用运行分支：

- 旧 `发射(起点, 方向, 威力)` 转为同位置的新创建表达式语句（丢弃返回句柄），速度 `380`、寿命 `2.4`。保留参数求值次序、既有安全偏移、伤害和法力/tick 等价锚点。
- 旧一参创建及方向/速度/威力/激活链仅在同一顺序块、句柄未逃逸/重赋值、参数求值可保序、状态与资源能证明等价时折叠。创建和所有配置/激活调用的总价格及 VM 调用工作都须纳入等价验证，不把“四步”字面数量当作少算调用的依据。
- 旧两参 `设置位置` 补 `时间=0`；旧自身/目标属性控制按 `speed/damage/perception/armor` 映射，显式补目标与时间，成功/失败统一 `bool`；旧弹道绝对速度/威力不能直接冒充新倍率，只有可求出等价基值时转换，否则诊断。
- 单独一参创建、逃逸链、观察中间配置、重排有副作用参数、无法同时满足空间/伤害/价格锚点等情况均给出定位诊断，保留原文和最后可运行 AST。不能插入隐藏迁移折扣、按旧来源执行的后门或第二套 IR 来伪造等价。后续实现若证明某条旧链无法等价，走既定诊断边界，不扩大产品范围。

默认法术先迁移；导入和本地规范化必须全量验证成功后才替换可运行法术书，不保存半迁移状态。旧 `Modifier.duration <= 0` 仅在读取旧数据时保留旧语义，不凭空变成新的无限 maintain。没有 `ControlRecord` 的旧存档不补造记录；新记录字段损坏、控制者/会话无法验证或结算状态不可信时丢弃记录并报告诊断，不猜测历史扣费，也不恢复悬空租约。会话运行态不因读取普通法术书存档自动重建。

## 取舍与回退边界

选用逻辑 descriptor 加目标 binding，可在保留现有存储的同时统一玩法；拒绝按 Actor/Projectile 选择一次性或持续收费，也暂不引入完整 ECS。保留数值时间并用 `0` 表示无限，避免只为时长新增 AST 类型；代价是 UI 必须显示单位、无限与模式。commit 防止位置回弹和寿命复活，overlay 才支持恢复下层，maintain 才占用施法与周期资源；不以一套永久 Modifier 偷换三种生命周期。

回退先停止新入口的编辑/发布并结束活动会话，保留新版 AST、原始旧文及迁移前备份可读。不得把已规范化的三参数控制反向降级为类型专用调用，不得向旧程序写入其不能理解的记录，也不把已提交的位置/寿命写入当作可恢复快照。若必须启动旧代码，只能使用经过兼容检查的迁移前副本；保留新版增量供恢复，不能覆盖为旧数据。损坏/未来格式继续拒绝覆盖当前可运行状态。改变以上语义、丢弃用户增量或引入新的不可逆降级须另行决策，不能作为普通缺陷修复偷偷完成。

## 后续实现验收映射

以下是合同要求，尚非测试通过证据：

| 工作项                                                                | 必须证明的边界                                                                                   |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `core-property-bindings`                                              | 同一 damage/speed 请求跨现有与合成 binding 走同一路径；缺能力拒绝；不依赖类型字段                |
| `core-control-records`                                                | commit 不回弹、overlay 恢复有效下层、同源替换、多源合并、结束/失效幂等清理及状态容量             |
| `core-period-budget`                                                  | 首周期及 0.25 秒边界、尾周期、无界/动态传播、双资源锚点、续费强度、原子扣费、tick 债务与实测上界 |
