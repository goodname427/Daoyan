## 问题、范围与验收

旧合同允许所有正有限倍率、统一缩放法力，却未约束自回蓝、资源产出与退款；持有实体句柄又能直接读取私有状态。若仅补六个属性入口，会产生降耗后注能退款、自增回复获利、提高上限补满资源、探查失败泄密以及静态预算低报。

本项固定六属性的输入及合成域、读取矩阵、统一定价与不可折扣分类、三资源静动态预算、账本单位、失败/退款事务和旧 AST 兼容。验收是给出可计算的锚点、无歧义的失败结果和下游可执行的反例要求。非目标是实现运行时、界面、事件重入或蓄力状态机，调整版本排期，或生成开发阶段总报告。事件/执行上下文 ADR 应消费本合同的账户与退款规则，再固定派发及终止顺序。

## 决策一：六属性的效果、安全域和生命周期

统一入口仍为 `(目标, 效果: num, 时间: num) -> bool`，六项全部为 `maintain`。正有限时间是秒；`0` 为无到期但仍受会话、权限及付费约束；负数及非有限值拒绝。不使用永久 Modifier 替代会话。缺 descriptor、binding 或账户均拒绝，不能给 Projectile 补默认回复或 Caster。

| 属性        | 输入效果与合成                                  | 有效安全域                          | 生效、撤销和到期                                                                 |
| ----------- | ----------------------------------------------- | ----------------------------------- | -------------------------------------------------------------------------------- |
| hpMax       | 有限有向增量，add；需要 Vitality                | 有限且 >0                           | 下降令 hp=min(hp,新上限)，上升不治疗；不能复活，裁剪损失不退款                   |
| manaMax     | 有限有向增量，add；需要 Mana                    | 有限且 >0                           | 下降裁剪余额并记法力损失，上升不注入；付款预留也受新容量约束                     |
| manaRegen   | 有限有向速率增量，add；需要 Regen 和 Mana       | 有限且 >=0，单位法力/模拟秒         | 只在已付覆盖区间按世界时钟回复至 manaMax；暂停不回复，到期不补历史差额           |
| shenshiMax  | 有限有向容量增量，add；需要 Caster 共享神识账户 | 有限且 >0；可分配整单位容量取 floor | 降低不删除已有 VM/记录；占用超过容量时禁止任何新增保留，允许原位执行、释放和终止 |
| castSpeed   | 正有限倍率，multiply；需要 Caster               | 合成后的有效倍率 0.25..4，含端点    | 只影响后续 tick 推进对应的模拟秒数；不减少累计 tick 或债务，不改 0.25 秒收费时钟 |
| manaCostMul | 正有限倍率，multiply；需要 Caster               | 合成后的有效倍率 0.25..4，含端点    | 只影响之后的可折扣调用；不重算已付金额，不影响退款、产出或债务                   |

输入是增量/倍率而非目标绝对值；两项倍率的输入本身只须正有限，安全界检查应用于最终有效值（例如基础 2 乘 0.25 得 0.5）。这些界限属于合法效果域，不能先裁剪非法请求再收成功费；NaN、Infinity、算术溢出及不安全计量均拒绝。

新请求在候选副本剔除同源旧层后测量新层，其他来源按稳定记录序号合成；先加后乘，六项各只公开表中一种运算。请求合成越域时整笔拒绝，保留仍合法的旧层。移除、到期或基础属性合法变化后也必须重新验域：若剩余层越域，按最新序号优先撤销该属性的层，直到回到安全域，标记“合成域失效”，不静默截断层值、不收新费、不退已付费。原型/导入的基础值本身必须合法，否则拒绝装入世界。这样撤销一个抵消层不会留下非法属性。

首周期与起手一起预检并付款才发布。续费每 0.25 秒先付费再覆盖，有限 `d` 最多 `ceil(d/0.25)` 个周期；0.1/0.25/0.5 秒分别是 1/1/2 个周期。到期边界先移除，无末尾额外扣款；暂停不计时。更新视为新请求，支付新起手和完整首周期，旧剩余周期不退也不抵扣；成功替换可复用同容量记录槽，不能释放后被并发抢走。提升自身 shenshiMax 必须先用提升前可用容量保留记录，禁止借尚未生效的容量自举。

## 决策二：统一正价与不可折扣分类

六属性复用 ADR 0017 的纯定价路径；binding 提供合法性、实际强度和抗性，不写第二套价格。采纳下列初始系数，法力在结算时向上量化，tick 在整项后向上取整：

```text
A = 自身/自有/友方/非己方的 1/1/2/8
G = 非己方 4，其余 0；r = 该属性非负有限抗性
起手法力 = G + A × (2 + S) × (1+r)
周期法力 = A × (1.25 + S') × (1+r)
起手 tick = ceil(G + A × (1 + 0.1S) × (1+r))
周期 tick = ceil(A × (1.25 + 0.1S') × (1+r))
```

六项均非 overlay，起手时间项 D=0；周期基数 1.25 对齐当前 controlPrice 的基础 1 加量子 0.25，不另加整段时长。hpMax/manaMax 的强度是移除同源层后新旧有效值差的绝对值/10；shenshiMax 是容量差绝对值；manaRegen 是速率差绝对值×0.25；castSpeed/manaCostMul 是 `abs(log2(新有效值/无本层有效值))`。续费 S' 按当前无本层与有本层的差重算，不能因效果已存在取零。无法获得合法反事实基值时按合成域失效处理。无变化仍支付正基础。例：S=S'=1、r=0 的自身起手为 3 法力/2 tick，周期为 2.25/2；非己方起手为 28/13，周期为 18/11。提高 r 不得降低任何一价。

| 计价类别                                                                                               | 法力倍率规则                                                                            |
| ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| 全部属性控制（含旧七项）、传送、创建、注能、资源转移、回复/治疗等资源产出、探查/主动监控、退款相关操作 | 起手、尝试和周期全部不可折扣；未知类别默认不可折扣                                      |
| 注册表明确标记的普通付费效果，例如不产生可退资产的直接世界伤害                                         | 拆成固定世界 I/O F 与可折扣部分 V，`F + manaCostMul × V`，F>=1 法力、V>=0；倍率只用一次 |
| 神识内纯计算、已有快照的读取、自身句柄和授权输入意图                                                   | 不新增世界读取；可保持零法力，正常支付指令 tick 与状态容量                              |

可折扣调用至少保留原价的 25%，且固定 I/O 始终为正；例如 F=1、V=8、倍率 0.5 时实付 5，倍率 0.25 时实付 3。禁止在调用结算处再乘一次倍率，也禁止为每笔普通效果加回全部优惠抹消降耗作用。费用类别由核心元法术元数据声明并供分析和执行共用；外部扩展未声明不能获得产出折扣。

manaRegen 另加防套利下界：每个正增量层每周期法力费为 `max(通式周期费, 0.25×正增量+1)`，不可折扣；负/零增量层仍付通式正价。按正增量分别覆盖并相加，不用负层抵消正层费用，也不因为当前已满蓝降低下界。每周期最多额外回复 5 的层至少付 6；两个各多回 5 的层合计至少付 12，不能只为合成后的一个层付费。此规则适用于给自己、友方及转账环中的受益者，不能靠改付款身份免除。

回复按模拟时间分段，仅在各层已付区间积累；先扣本周期控制费，再允许这一周期产生额外回复，不能借未来回复支付首周期。基础回复与控制增量分账，裁剪损失单列；层移除不消除历史费用。castSpeed=2 可把基准 100 tick/秒下后续 10 tick 从 0.1 秒缩至 0.05 秒，仍记 10 tick；更快调用产生的每次 I/O 照常付费。容量提升、降耗、提速、注能、退款组合不能制造净法力；允许付费取得普通效果的真实效率收益。

## 决策三：读取矩阵与无歧义拒绝

句柄只标识实体，不授予读取权。每个字段声明能力、信息级别及关系授权；以下是默认矩阵，“可”仍须通过全部检查，友方不等于自有。自有私有信息还须具有明确的所有者读取授权，不能从单一 owner 字段推导全部账户权限。

| 字段                                           | 自身/获授权自有            | 他方默认上限                                   | 级别                   |
| ---------------------------------------------- | -------------------------- | ---------------------------------------------- | ---------------------- |
| 位置、朝向                                     | 有 Transform 可读          | 可见、范围内且逐项获准可读                     | 公开 L=0               |
| velocity、speedMax                             | 有 Movement 可读           | 可见、逐项获准可读；不给运动来源详账           | 一般 L=1               |
| 当前生命、hpMax                                | 有 Vitality 可读           | 逐项获准后精确值                               | 一般 L=1               |
| manaMax、manaRegen                             | 有 Mana/Regen 可读         | 逐项获准后精确值                               | 一般 L=1               |
| 当前法力、法力率                               | 有 Mana 可读               | 默认拒绝；明确敏感字段授权后才可读，敌方不例外 | 敏感 L=2               |
| shenshiMax                                     | 有 Caster 可读             | 逐项获准可读                                   | 一般 L=1               |
| 神识占用、VM 栈、逐项抗性                      | 仅具有对应私有读取授权可读 | 默认拒绝，不随其他字段授权一起开放             | 敏感 L=2；未授权为隐藏 |
| castSpeed、manaCostMul、护体、伤害、感知、寿命 | 有对应能力可读             | 各字段分别获准才可读                           | 一般 L=1               |
| 阵营、公开命中摘要                             | 获准公开信息               | 获准公开信息；不暴露私有源账户                 | 公开 L=0               |
| 会话、订阅、来源详账、能量池、退款受益账户     | 仅参与账户/会话的授权视图  | 默认隐藏                                       | 敏感 L=2；未授权为隐藏 |

非自身读取依次检查存续和能力、字段权限、可见性、距离和信息级别；有效感知必须正有限，范围 `R=240×探查者有效感知`，`d<=R` 才允许。自身免距离/遮蔽限制但不免能力、授权和费用；自有物不免距离与可见性。不存在、缺能力、隐藏、遮蔽、越距和越权对调用者均为同一个“不可探查”。检查用核心权威状态，不先把值写入结果或玩家日志。

允许的单字段读取采用正价：

```text
法力 = ceil(G + A × (1 + d/120 + 2L + max(0,Rt-Sa)/8 + r))
tick = ceil(G + A × (1 + d/240 + L + max(0,Rt-Sa)/16 + r/2))
```

A/G 同控制关系规则；Rt/Sa 为目标/探查者有效神识容量，r 为该项探查抗性，均须合法。自身私有内视固定为 1 法力/1 tick（不代入自身隐藏状态报价）。拒绝尝试固定为 1 法力/1 tick，与目标身份、距离、抗性无关；成功价已包含尝试部分，不重复相加。无力支付尝试则资源失败，不能由低余额试探权限。

**价格本身也是输出。** 对获准字段成功读取仍不能由价差反推未获准的神识/抗性/位置：公式只可使用读者已获准的输入；否则用面向该读者公开、稳定且覆盖真实值的计价上界代入（d、Rt、r 向上，Sa 向下），只披露这个公开报价。没有这样的有限公开上界就按固定尝试价拒绝，不查询私有精确价后以“余额不足还差 X”泄漏它。上界不能随隐藏真值暗中改变档位。控制等操作的费用/拒绝也遵守此规则：未获准的实际强度、抗性等使用公开保守上界定价，不能让调整属性成为私有抗性探针。批量扫描同样先支付公开预算再过滤，仅返回获准项目，不披露被隐藏数量、排序空洞或未获准坐标；扫描/查询条数须有声明容量。

新查询结果为可判别的 `ok(value, observedAt, targetId, field)` 或 `unavailable`，拒绝分支不携带值、真实价格或私有原因。这是 AST/类型系统共用的结果合同，DSL 与蓝图必须显式处理成功分支后才能取值；不得各自定义一套失败哨兵，也不得把 0、空坐标、空列表同时解释成拒绝。运行资源错误单独终止当前 VM；获准但无目标的扫描是 `ok([])`。对方失败细节只进核心受限审计，公开事件及面板同样按矩阵过滤。已获准结果是带模拟时刻的快照，可本地计算和缓存，不自动刷新；主动追踪续期前重新检查权限，不能使用失权旧快照继续主动追踪。

## 决策四：法力、tick 与神识预算

保留 `MetaCost.mana/ticks` 为起手，`periodic` 为不重复包含起手的周期价；首周期计入周期次数。`CostAmount.value + dynamic` 和 `finite/unbounded/dynamic` 继续兼容。总预算按所有可能调用、同源更新、分支最坏路径、循环容量和函数调用传播；只有价格、次数、倍率、关系及未来状态均有可信界时才给有限总上界。已知时长仅能证明周期次数；无法界定未来抗性/基值仍是动态。已知无限正价维持为无界，未知事件次数为动态，除非能证明持续无限则标无界；不用 Infinity 写 JSON，也不能用执行失败上限冒充完成法术所需有限成本。

- **法力**显示毛支出预算；回复、退款与损失分列，不相减伪造可施放性。没有场景倍率时“基础价”不可宣称实扣上界；可证明倍率始终在安全域时可用最大值 4 给可折扣部分保守界，否则标动态。运行时每笔取得具体合法价，仍含 dynamic、非法/溢出价格均不得发布效果。
- **tick**包括调用/控制流指令、效果及周期工作，不重复登记 worldCharged 起手。先预检累计上限再提交本次法力、tick 和效果；tick 是工作而非可消费余额。新增工作计入累计及债务，推进先偿还债务；取消不抹去累计实耗，也不能把债务退成法力。castSpeed 只改变以后推进速度，暂停不偿债、不续费。
- **神识**是同时存续状态的峰值，不是各次分配总和。保留 num/bool/entity=1、vec2=2、列表=1+容量×元素成本；结果类型的标签、值及元数据按同一类型表计容量。VM、维持记录、订阅、法球行为上下文、快照/历史缓冲均先从唯一共享账户保留额度再发布。write 记录由世界代持创建时付款账户的有界配额至移除，不能因原 VM 结束失去归属或提前释放；纯引擎审计环使用单列有界世界配额，不能让玩家把可读取状态藏在免费日志中。

各类外部状态单条成本及容量上限由实现任务登记在核心同一元数据表，分析器和运行时必须共用；本 ADR 不把尚未定义的记录大小猜成 0。静态按最大同时存续数与并发配额计算峰值；运行数量未知时显式输出动态峰值及硬容量。缺硬容量的订阅/记录/行为创建拒绝，不能用 dynamic 允许无限分配。单个法术的局部峰值不能冒充多个并发 VM 的账户峰值；共享账户逐笔原子保留、释放恰一次。缩小 shenshiMax 允许占用暂时超额，不把已有状态强删到静态预算；任意新增分配仍预检，失败不得产生半条记录。清理路径不得依赖额外神识才能释放自身。

## 决策五：账本单位、预留和精度

每笔事务带稳定世界序号、模拟时刻、effectId/entityId/payerId/sessionId、源/目的账户、单位、分类、实际毛支出、预留变化、余额、退款来源与终止原因。tick 工作和神识保留/释放是关联分录，不与法力或 E 相加。账本在核心共享，Battle/UI 只消费授权投影。记录历史使用有界环，淘汰明细前归并到单调累计摘要；尚有余额/预留/退款权的来源凭证不能淘汰，凭证容量不足须拒绝新注入或合并完全同权来源，不能丢掉债权归属。

| 单位        | 总账口径                                                                                                                 |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ |
| 法力 M      | 期初 + 世界回复 + 转入 + 实收退款 = 期末（含付款预留）+ 调用费/注入付款 + 转出 + 上限裁剪/其他已记损失                   |
| 能量 E      | 注入付款按 1 M=1 E 计量基准折合 = 未用池余额（含预留）+ 已做功 + 已释放伤害 + 已扫描 + 转换/操控/终止损耗 + 已退款折合额 |
| 世界功率 Wm | 期初 + 实际世界补给 = 期末（含预留）+ 驱动支出 + 已记损耗；封顶未发放部分不计收入                                        |
| tick / 神识 | tick 是累计工作及待偿债务；神识是已保留容量及历史峰值，均不能兑回 M/E/Wm                                                 |

E 的付款折合基准只为核对注入：10 M 对应注入基准 10 E，其中 8 E 入池、2 E 转换损耗；并非 1 M 可以无损兑换可用 E。实际费用、创建费、控制费不入 E 总式。motion/damage/scan 独立；跨池转账拒绝。已做功的后续物理耗散及已释放伤害中的护体吸收只细分原支出去向，不在总账再次加损耗。

M/E/Wm 账户以各自 `10^-6` 单位整数记账，余额、预留、累计分录均需安全整数；法力/能量扣款向上量化，入池和退款向下量化，差额记明确舍入损耗。转换使用整数比例 4/5（入池）和 1/1（退款上限），不重复对倒数取整。超过可精确计量范围、tick 非安全整数或合计溢出即定价失败，不封顶费用后执行巨大效果。计算轨迹仍可浮点，但进入账户必须走统一量化；不得用 epsilon 赊欠负余额或补出正余额。批次总量与逐笔合计须按同一量化分录相等。

量化边界是权威事务/周期边界，不是渲染帧或物理子步；持续驱动在同一预留内累计工作后结算，回复/功率补给跨子步保留有界小数余量，同一模拟时间线须得到相同整数总账。不得逐渲染帧向上扣一次微单位而令费用依赖帧率；未支付的余量不能提前消费或退款。

预留只是同一账户“可用→锁定”，不算支出或第二份余额；可用=总余额−全部预留。付款/驱动/神识预留都不许被并发花费、转出、退款。发布效果时才把相应预留转为实际支出；未发布的完整失败释放预留，未做功周期预留回原池。若 manaMax 下降，候选事务先撤销无法容纳的未提交付款预留（最新序号优先），再裁剪余额，受影响事务失败；已提交支出不回滚。不能出现预留大于账户余额。

## 决策六：失败、终止与退款

单笔操作顺序固定为：验证公开输入及尝试可支付性 → 权限/能力/安全域与公开报价 → 预检法力、tick、神识和池容量 → 保留 → 再校验目标/授权 → 原子提交分录和效果 → 发布允许的结果。报价阶段不得先改变世界。尝试价是失败分支的完整世界费用；成功价含尝试部分，二者不叠收。控制及读取领域拒绝固定收 1 M/1 tick，普通 VM 参数求值/调用指令的既有 tick 另计且不退；传送沿用相同尝试规则。内部续费/失效清理无玩家新调用，不收尝试价。

| 结果                                             | 新费用与效果                                                          | 旧状态/对外结果                                                            |
| ------------------------------------------------ | --------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 公开参数非法、缺能力、越权、越域、目标失效       | 有能力付尝试价则只结算尝试，不结算成功/首周期费；无新效果/记录        | 控制 false；探查统一 unavailable；仍合法的旧层保留，已失效层清理           |
| 合法请求但法力、神识或累计 tick 限额不足         | 本笔成功费与首周期均不扣，无新效果，释放预留；已执行参数/调用工作保留 | 终止该 VM/会话并释放其 maintain；其他会话不终止                            |
| 非法定价、非有限/溢出、扩展抛错                  | 不付成功费，不发布效果；未提交部分全部回滚                            | 终止该 VM 并记受限审计；不得输出私有价差                                   |
| 预留后再校验失败、提交前目标消失或授权撤销       | 释放全部预留，仅按领域拒绝结算可支付尝试；不能保留部分扣款            | 无新效果，清理失效旧层；重入/并发以同一权威顺序重算                        |
| 周期续费法力不足                                 | 不扣本周期、不发布未付覆盖、移除该租约                                | 不自动终止同会话其他已付租约；若为执行上限/定价错误则终止会话全部 maintain |
| 成功提交后取消、正常结束、打断、死亡、到期、销毁 | 已付创建/控制/扫描/工作不退款；停止未来效果、核销工作并释放未用预留   | 清理幂等；只有下述未用有来源储能可退，提交过的裁剪/伤害不回滚              |

成功分录与效果必须一起可见；实现不得先调用任意会抛错的 binding 产生副作用再尝试补偿扣费。对不可回滚外部副作用只允许在本地事务成功后发出；派发失败不重复效果或退款。首周期失败不会留新租约，成功更新后取消也不能取回旧周期款。

退款不是把原付款撤销，而是独立、有来源、至多一次的结算：

1. 停止未来驱动/扫描/命中，结清已做功，从预留中核销实际消费，剩余释放回原池；仅未用、未锁定余额进入退款。
2. 按注入序号 FIFO 消费及退各来源余额，不能把别人或不可退来源换成自己的退款权。每一来源建立时固定退款受益账户；所有权转移不改它。转移 M 必须源扣与目标入账原子完成且容量足够，转移自身不生成退款权。
3. 该来源可退额为 `min(未用E按1:1向下换成M, 原始付款减已退M, 受益账户可接收空间)`，不得取 0.8 的倒数。10 M→8 E，消费3 E后最多退5 M；已满法力则实退0，不能因此恢复能量继续消费。
4. 退款接收空间以清理后的有效 manaMax 和余额计算；不能因退款把当前法力抬过上限。余额中可退但未被接收的部分、账户不存在/失效部分均记终止损耗并注销凭证，不留重复领取窗口。死亡不是换受益人的理由：原账户若仍依法可接收就退给它，否则记损耗；何时关闭账户由事件 ADR 明确，但不得猜测继承者。
5. 原子标记来源已终结，减少池余额，增加受益余额及退款累计；重复取消、死亡、销毁、通知重放都返回既有结算结果，不重复付费或退款。自动清理/退款本身无额外 M 收费，避免余额为零时无法清理；也无倍率优惠或额外资源产出。

## 决策七：旧 AST、数据迁移与回退

新合同经同一 AST 类型、元数据和规范化入口落到 DSL、蓝图、默认法术书、导入及执行。新查询的可判别结果必须同步支持分析、编译、VM 和序列化；类型消费者未升级前不得静默加载。旧扩展的 manaCost 有限上界合同仍有效，但不默认获得折扣或绕过权限。

- 旧明心/节流/聚气及直接 Modifier：逐项证明倍率/增量换算、生命周期、合成域、法力/tick、神识和退款语义等价，才可迁移。旧一次付费持续增益通常不能等价成周期维护，应定位拒绝；不能用旧倍率制造不可折扣例外或把负时长改成无限 maintain。
- 旧探查/生命/自身法力率及快照/扫描：不能仅改名字或把拒绝转零。只有能力、权限、成功/失败分支、求值顺序和资源成本均可证明等价时才重写；否则报告法术名、调用和源码位置，保留原 DSL/AST。新增正价、自身法力率支付后读数以及过滤后的目标集合均算行为变化，不能冒称无损迁移。新读数在本笔扣款完成后的快照读取，时间与分录对应。
- 旧两参位置、speed、发射和五参/分步创建继续受 ADR 0018 的守恒及等价证明约束，旧 VM 专门扣旧价的分支不是新版绕过账本的许可证。旧 AST 可作为备份供旧版本使用，未经本合同验证不得在新版活动世界继续执行。
- 整本在隔离副本解析、规范化、类型/预算/能力校验全部成功才原子替换；局部不兼容、损坏或未来格式不覆盖原件和当前可运行书。旧演武配置越安全域不静默夹值；给定位诊断并保留副本。
- 普通存档不恢复会话、私有缓存、事件队列、付款预留、法球余额或退款权；不能靠旧 damage/法力显示值补造交易来源。新版增量和迁移前副本分开保存。回退先停止新版活动、幂等清理并保留新数据，仅在兼容检查通过的旧副本上启动旧代码，不反向写坏新版 AST。

## 取舍与后续验收

选择显式安全域而非允许任意正倍率，防止零费用、瞬时工作及数值失稳；仅限制敏感域，普通域内强度仍随资源定价。选择拒绝越域而非夹值，使成功含义明确；代价是层撤销可能引发依赖层失效，必须可观察。选择毛支出预算与保守公开报价，而非扣掉未来收益或按私有值精确报价，代价是部分探查较贵或不可用，但不会承诺不存在的资源或泄密。选择分单位、有来源退款而非统一“能量余额”，防止世界功率、工作和容量互兑。选择保原件拒绝不等价旧法术，而非永久隐形兼容后门。
