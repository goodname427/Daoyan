## 问题、范围与验收

按槽位持有 VM 无法表达同一事件触发多个独立法术；同步伤害回调没有派发链边界；法球所有权也不等于可以持续支用所有者的法力。直接把五参创建改为持球状态，则会破坏已验证的即激活语义。

本项固定多订阅排序、共享账户竞争、重入与容量上限、执行上下文及付款授权、死亡与账户关闭、两种蓄力、旧槽位和创建入口兼容。验收是每个冲突有明确覆盖条款、可复现的先后顺序、失败/退款结果、迁移和回退路径。非目标是实现运行时或编辑器、重排正式版本、生成阶段总报告、开放任意账户转授或死者施法。

## 决策一：核心事务产生事件，订阅按稳定序执行

核心持有事件信封：`eventId/worldSequence/simTime/rootEventId/parentEventId/depth/type/sourceId/targetId/initiatorAccountId` 及有界载荷。序号在世界内单调、不复用；source 是效果来源而非付款人。四类离散事件为受击、碰撞、法力耗尽、实体消失。它们只由权威世界事务生成，玩家 DSL 不能伪造序号或直接发出同名世界事件。

1. 效果、资源账本和必要失效清理先原子提交，成功后才入队，禁止在扣款或 binding 回调中同步递归运行响应 VM。失败事务不发成功效果事件；超限或响应失败也不伪装受击/耗尽。
2. 派发按 `(simTime, worldSequence, subscriptionSequence)`。订阅登记得到稳定序号；同一事件的候选订阅在事件提交时取快照，派发前再次检查存续和授权。注销立即生效，新订阅不追收旧事件。无用户优先级，不依赖 Map、数组、UI 槽位或法术名字排序。
3. 一个订阅对应一次独立响应实例和失败结果。同一事件允许多个订阅绑定同一或不同法术；每个实例拥有 VM、sessionId、状态及工作限额。创建及第一次推进依订阅序；跨帧继续时依稳定实例序推进，各自取得完整施法速度对应的 tick 信用，不等待前一个 VM 全部结束、不平分 tick。每个原子操作读取最新共享余额，前一笔付款/神识保留立即影响后一笔；不预先复制余额，也不因后一个失败回滚前一个成功。
4. 响应产生的后继事件在当前事件的全部候选订阅尝试完后才开始派发，保持世界序号；跨模拟时刻的因果后继仍继承 rootEventId 与深度。响应内的主动监控/定时后继不能通过等待一帧把同一因果链洗成新根。
5. 载荷按每个订阅者投影：内部账户、完整余额、私有订阅、隐藏来源不直接进入 DSL/UI。派发只给发生时已获准且派发时仍获准的字段，不追加现时坐标或敌方法力；未知句柄用不透明缺省表示，不能依“是否有事件”探测隐藏对象。自身必要受击/终止摘要可见；其他实体依 ADR 0019。回调想取额外信息仍须付费查询。

订阅声明触发类型、许可的源/目标筛选、法术、所属账户/会话、容量及下面的限额。筛选仅使用获准信封字段，不能免费执行任意探查谓词。实体级绑定订阅可独立于响应会话存在，响应结束不注销这种绑定；法术动态订阅则随其所属会话终止释放。两者均占共享神识，不能由每次响应免费重建无限订阅。

## 决策二：重入与耗尽边沿有硬边界

默认同源去重键为 `(rootEventId, 稳定绑定标识, type, sourceId, targetId)`，当前因果链最多响应一次；稳定绑定标识不因注销重建而更新。链中新建订阅不能接收该链后继，防止以新订阅序号绕过去重。独立外部事件有新根，可合法触发同一法术，不被全局“法术已在运行”挡住。

采纳以下初始上限，核心元数据、分析器和运行时共用；每项配置只能声明更小正整数，缺省取表值，不接受无限值。上限是调度/容量安全边界，不是免费工作额度。

| 项                       | 硬上限及超限结果                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------- |
| 因果深度                 | 根深度 0，最大 8；深度 9 的响应丢弃并记受限摘要，世界已提交效果不回滚                                   |
| 每因果根的响应尝试       | 256；超限关闭该根的新响应；已付独立效果依自身生命周期存续                                               |
| 每世界调度周期的响应尝试 | 256，周期为从世界起点对齐的 `[n×0.25,(n+1)×0.25)` 模拟秒；超出丢弃响应，不无限积压或移到下一帧重试      |
| 世界待派发信封           | 1024；满时不接纳新派发项，按原因累计有界摘要；权威伤害、清理及退款仍完成                                |
| 活跃订阅                 | 每账户 32、每世界 256；登记前保留神识，超额拒绝且无残留                                                 |
| 活跃响应实例             | 每账户同一法术 8、全部事件响应 32；超额拒绝此次响应，不取消已有实例                                     |
| 单响应 VM                | 默认最大 600 tick、200000 指令、调用深度 32，沿现 VM 默认；行为授权可更小，片段重启不能重置会话累计限额 |

有效候选进入尝试前先消耗根/周期次数，领域拒绝与资源失败也计次数；去重抑制项不新建 VM。神识不足只终止/拒绝本实例；tick/指令超限终止本会话并清理其 maintain/动态订阅，其他会话继续。事件深度、VM 调用深度与 AST 禁止递归各自有效，不能互相替代。审计摘要使用固定容量/累计计数，不为每个丢弃项再发事件；关键终止清理永远不依赖派发配额。

因果去重集合、候选快照、事件队列、响应上下文及输入缓冲均有界；玩家可访问部分按 ADR 0019 计入共享神识，纯引擎队列用有界世界配额。每根只在其队列、VM 及定时后继均结束后释放去重状态；根状态容量计入配额，不能保留无主根。预算未知事件次数标动态，无限期订阅/监控的总工作标无界，不把“每周期 256”误报成整场有限总价。

`法力耗尽` 固定观察付款账户的**可用法力**（总余额减预留）能否支付 `1 M` 的最小尝试价。只有有效账户从 `>=1 M` 跨到 `<1 M` 时发一次，恢复到 `>=1 M` 才重新武装；初始不足不补造事件。预留/释放、回复、付款及裁剪按事务最终可用余额更新，不观察事务中间状态。余额 5 支付 10 失败不构成耗尽事件；支付后从 1 到 0 才构成边沿。关闭账户不发耗尽；死亡发终止摘要。响应失败且余额未变不会递归发耗尽；同根内反复退款/消费仍受去重与根上限约束。事件不承诺响应一定付得起，也不赠送救急法力。

## 决策三：执行上下文与法球授权显式且不可扩权

普通角色、妖兽、事件响应和法球行为都消费同一核心执行合同；不得为法球伪造 Actor/Caster 或把 owner 当成可支用账户。上下文至少含 `contextId/sessionId/selfId/ownerId/controllerId/payerAccountId/grantId`、根事件链、能力白名单、字段读取范围、固定 tick/指令上限、预留神识配额、有效期和死亡后策略。`self` 是执行实体，owner 是所有权，controller 是操控主体，payer 是付款账户，退款受益人随每笔注入固定；这些身份不自动相等。

- 只有账户本人能签发 grant；已有授权的执行上下文只能在其范围内消费，不能另签子授权。绑定具体实体、会话/独立行为和允许操作；包含可花的池、总 M 额度、可选单笔更小限额、有效期及撤销状态。授权不可转授，不能凭句柄更换付款人、读取其私有余额或把 owner 的未来回复当成自己的预算。
- 创建时有限提款额度从付款账户**预留**，不是立即支出，也不形成另一份余额。每次调用同时检查剩余额度、能力、权限、有效期和账户状态，再按 ADR 0019 原子提交。只消耗已预留额度；消耗后不自动补满，增加额度必须新授权并付款预检。主 VM 和其他法球不能花这份预留。例：账户 20 M 授权 5 M 后可用为 15；球已花 3 后，原账户总余额 17、其中锁定 2，而非另外出现一个 5 M 账户。
- motion/damage/scan 只支付对应能量效果。E 不能代付任意 M 操作，Wm 不能授予法球。注能仍从已获准 M 扣款并计损耗；行为 VM 工作累计 tick，订阅、闭包、历史和最大活跃变量空间先保留有界神识，不能挪到 owner 的免费隐形内存。
- 每次行为、续费和事务提交前再验授权；转移所有权默认撤销原控制/提款 grant，新 owner 不继承付款权或退款权。已提交的一次冲量/命中不回滚，仍有效的世界 write 不因原 VM 返回被取消；需要持续授权的驱动/扫描立即停止未来工作。
- 默认行为随控制者结束；要脱离发射会话存续，必须在发射提交前建立独立、有限寿命和总工作上限的行为上下文并转交资源保留。不得先释放原配额再“免费重建”子行为，也不得让 duration 片段返回错误清空外层会话。

## 决策四：伤害、死亡、实体消失与退款顺序

非致命受击顺序固定为：提交伤害与账本 → 对伤害提交前已经活跃的可打断实例全部打断并释放其 maintain/动态订阅/VM 状态 → 登记受击事件 → 派发仍合法的响应。不可打断实例继续。由该受击新生的响应不再次被同一次伤害打断；后续伤害仍正常打断。旧 onDamage 不再兼任用户派发与打断入口，兼容钩子只能消费一次提交摘要，不得重复扣血/打断。

受击仅在生命实际损失大于 0 时产生；零伤害碰撞仍可有获准的碰撞摘要，不能伪报受击。一次接触由碰撞事务先登记碰撞序号、再登记其伤害序号，两者均在必要清理后才可派发；持续接触不每帧重发接触开始。命中去重、穿透顺序与能量扣除沿 ADR 0018。

致命伤害或明确移除依下列顺序完成一个不可被用户回调插入的终止屏障：

1. 提交伤害/移除事实，立即使目标不可操作；控制者死亡时其账户进入 `closing`，禁止提款、回复、转入和退款接收。对外保留获准的终止摘要，不以遗体仍在渲染数组表示存活。
2. 终止该控制者所有会话（不可打断也不豁免死亡），撤销其实体级绑定及动态订阅、监控、未来输入、未提交释放及提款 grant。第 3 步获准存续的独立实体上下文只保留自身仍合法的订阅/行为，不保留死者自身订阅。目标已失效的其他控制者租约也立即撤销。首个已提交终止原因不再改写。
3. 清理其未发射持球；已发射的被动弹道按已付冲量、damage 余额及寿命继续。主动行为只有在建立时显式 `surviveControllerDeath` 且独立上下文、剩余工作/神识/本地 E 足够时才继续；它只能用预付三池和预留状态，不能新提死者 M、申请死者新增神识、扫描越权信息或转成通用死者施法。不符合条件时撤销行为，保留已付惯性；无生命的 Projectile 不自动获得死亡或回复能力。
4. 对本次被终止的实体/效果核销已做功，释放未提交付款和未用工作预留，移除 maintain 后按有效上限重算接收空间，再依 ADR 0019 FIFO、有来源、至多一次地退未用储能。第 3 步继续存续的弹道/行为保留其池余额及合法工作预留，不能一边退款一边继续消费；待自身终止再结算。退款受益账户仍活且有效才接收；死者账户在第 1 步已不能接收，故该部分记终止损耗，不转给攻击者、新 owner 或其他账户。存活的其他付款人仍可按原来源受益。
5. 账户转为 `closed`。残余 M/解除锁定的 M 记关闭损失，神识保留由世界留存至合法存续行为/write 释放，不恢复账户可用能力或产生退款。账户 ID 不重用。随后发布受击（若有）与实体消失的只读投影；同一实体只产生一次消失事实，遗体到时移除不再生成第二次可响应消失。

死者自己的订阅已撤销，不启动死亡响应 VM；其他仍存活且获准的观察者可由摘要启动正常付费响应，但不能重新对失效目标施效。不会因事件队列满而遗漏撤权/退款。场景整体重开或退出则先关闭派发，再清理全部会话、行为和余额，不运行旧世界的终止响应；普通暂停不走此路径。

普通会话结束不等于账户死亡：存活付款人可以收到依法可退余额。commit 永不回滚；overlay 仍由世界持有至到期、替换或自身权限/binding 失效，控制者死亡本身不撤销已经授权的一次 write；maintain 必须随会话结束。只撤销“未来操作 grant”不等于撤销已提交 write 的效力。

## 决策五：两种蓄力共用会话，效果发布时点不同

输入只产生带到达序号及目标会话的意图。核心会话为 `idle → preparing → held → releasing → settled`；任何活跃状态可至 `interrupted/cancelled/exhausted`。`settled` 与三个失败终态均幂等，保存首次终止原因和结算 ID。VM 片段返回不是外层会话结束；所有维持、订阅、工作、实体和授权都必须有明确的会话或独立行为所有者。

| 阶段                            | 蓄时瞬发                                                                                                                  | 持球注能发射                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| preparing                       | 预留有限状态、付起手费；声明准备工作量和最大持有模拟时长                                                                  | 付创建费并创建未发射实体；三池起始零，不提供免费威力或速度；预留名额/状态/授权                                          |
| held                            | 按模拟 tick 完成准备工作，记录实际费用与债务；工作完成只标 ready，不提前发布攻击效果                                      | 按 0.25 秒效果前结算注能及维护；首周期先付；逐池记录来源，不能用持有秒数直接变出伤害                                    |
| releasing                       | 松开时 ready 且工作债务已清、账户/目标/授权有效，原子付最终费用并发布一次效果；提前松开取消，不补做剩余工作或发布部分效果 | 松开时校验声明的最低池余额、权限及落点，原子支付发射控制费和 motion 冲量并激活一次；不足取消/耗尽，不免费发射或静默降级 |
| settled                         | 释放本会话状态/maintain；已发布的独立效果按自身寿命存续                                                                   | 把实体及已授权行为转交世界，释放持球会话；后续不再按“仍在按键”注能                                                      |
| interrupted/cancelled/exhausted | 不发布待释放效果，已做工作/起手不退；未用预留解锁                                                                         | 销毁未发射实体，停止注能，释放名额，依来源退未用 E；已付创建/维护/转换损耗不退                                          |

持有上限到期默认取消，不代玩家发射。准备/注能都不能在暂停中进展；castSpeed 只影响工作完成速度，不改变注能/维护周期。持球寿命从创建算起，持有时也倒计时，释放不重置寿命。未发射对象不积分飞行、不碰撞伤害；跟随手部只是依附变换/显示，不能把已激活飞行物免费拉回施法者，也不能带着储能远端任意改落点。独立移动持球需走 ADR 0018 的付费控制。

所有到期、续费、输入及世界事务在模拟时刻执行；同一时刻先处理既有到期/失效，再执行到期的续费，再按权威序处理其余意图/效果。续费耗尽或死亡若先提交，随后松开无效；松开若先成功激活，后来的死亡按已发射实体处理。重复松开、取消、耗尽、死亡只结算一次。同一个时刻不以 UI 回调快慢在两个分支都发布效果。

暂停冻结模拟时钟、VM、续费及事件派发；输入适配以有界 FIFO 缓存边沿（每输入拥有者最多 64 条，重复 held 状态合并）。恢复先处理当前模拟时刻已到期/失效和应付周期，再按到达序消费缓存，墙钟暂停时长不成为 heldTime。缓冲溢出记录一次错误并置输入取消标志，恢复清理后先取消相关输入会话、丢弃其待释放边沿；不得猜测松开发射。角色/会话终止使缓存意图失效，过期松开不能释放同槽后来新建的会话。

## 决策六：旧槽位和五参入口保留明确兼容语义

核心以 sessionId 区分实例，槽位仅为外部输入适配器：按下去抖、粘性按下/松开边沿、持有时长均属于该输入会话，每个响应有自己的输入视图，不能消费别人的边沿。无输入来源的事件响应/妖兽默认按键 false/0，不读取玩家 heldSlots；AI 可通过明确的虚拟意图使用同一会话入口。

旧槽位绑定迁移为显式 `singleActivePerInputSlot` 策略：该槽启动的外部输入会话结束前重复触发仍拒绝；不同槽不互锁，事件启动的同名法术也不占/借该槽锁。这保留旧同槽测试和操作体验，但不把槽位排斥扩张为核心全局法术排斥。旧 duration 的片段重启保留同一 session、键边沿和累计工作，不重置事件限额。旧 `按键蓄力` 以 Battle 当前实现为准：松开后保留刚松开时的模拟持有时长，读取松开边沿只清标志；不能依据旧注释的“松开归零”改变运行事实。

`创建弹道(起点, 方向, 速度, 基础伤害, 存活时间)` 成功仍返回**已激活**句柄，调用期间没有可观察未激活半成品，不需要再松开或调用激活。创建、必要初始注能、足额单次 damage 与冲量一起预检/提交；失败无实体、特效、名额或部分成功扣款。费用依据 ADR 0018/0019，不承诺旧价。参数求值次序、安全偏移、有限寿命及创建时威力仅作用一次继续保留。

持球采用单独、显式的未发射创建/释放语义（DSL 最终名称由下游统一 AST 接线），不得按调用者是否按键、参数个数或当前槽位偷偷改变五参含义。旧一参创建及 legacy 激活链不是新持球入口；迁移仍需证明中间观察、返回值、寿命、资源、失败和次序等价，不因“都是未激活”自动改写。

## 迁移、回退与取舍

迁移在同一 AST/绑定配置规范化入口完成，并增加语义版本以选择校验，不作为运行时折扣开关。旧书、默认法术、蓝图、导入及本地加载共用规则：

- 槽位保持绑定和 singleActivePerInputSlot；事件绑定是新增显式配置，不从槽位猜造订阅。旧键读取保序，每个旧会话独享边沿；原 duration/channel 只有全部效果发布时点、工作/收费、提前松开及终止语义可证明等价时才变为新蓄力，否则定位拒绝。不能将会在准备中伤害世界的旧 channel 悄悄改成延迟攻击。
- 五参、旧发射和分步链继续接受 ADR 0018/0019 的效果、供能及总资源等价证明；证明不了则列出法术/调用/源码位置及差异，保留 DSL、原始存档和最后可运行旧 AST。尤其旧 12.7 M 发射不能免费补足新注能需求；旧按键蓄力按秒增加威力也不等于已购买池余额。
- 旧扩展 onDamage 只可作为提交后的受限通知兼容接口；不能继续在原同步栈中启动未授权 VM。扩展若依赖同步反写世界或旧顺序，需显式迁移并验证，否则拒绝加载，不双重注册新旧回调。
- 整本及关联绑定在隔离副本全量类型/预算/权限校验成功后原子替换。不兼容、损坏及未来格式保原件，不保存半迁移状态。普通存档只存法术书与显式配置，不恢复事件队列、因果去重、活动订阅、键边沿、会话、grant、池余额、预留或退款权。
- 回退先关闭新派发/输入，幂等清理活动世界并保留可读结算诊断，再保留新版增量和迁移前副本；仅把通过旧格式兼容检查的旧副本交给旧代码。不得将池余额倒推成旧威力、让旧 VM 取得死者账户、重放终止事件退款或反向覆盖新版 AST。重新启用从新世界开始。本项纯文档回退不改当前运行态。

选择稳定排队而非同步递归回调，使多订阅竞争可复现，代价是响应发生在提交/清理之后。选择有界根与周期配额而非无限延后，使资源失败不会制造永远积压的事件风暴，代价是超限响应会明确丢弃。选择有限预留授权而非 owner 无限提款，避免法球花未来回复，代价是创建时可用法力减少。选择死亡立即停止账户接收而非遗体期间可退款，关闭重复死亡/延迟退款窗口；仍活的其他受益人不受牵连。选择保留五参并新增持球语义，而非改写旧入口；输入槽防重保留在适配层，不阻止合法事件并发。
