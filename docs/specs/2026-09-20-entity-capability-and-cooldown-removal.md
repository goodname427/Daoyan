# 旧元法术能力迁移与冷却移除纵向切片

- 状态：已完成，待制作人体验
- 负责人：执行 Agent
- 创建日期：2026-09-20

## 问题

统一实体句柄目前只覆盖新弹道链路和位置能力；旧的生命、伤害与属性控制仍依赖 Actor 专用查询。法术冷却和冷却倍率也仍与资源、施法占用并行生效，使玩家无法只根据法力与耗时判断再次施放时机。

## 目标

- 让旧的生命、伤害和目标属性元法术遵循统一句柄、能力判定和确定性失败语义。
- 完整移除玩家法术冷却字段、属性、运行时阻挡和界面展示。
- 兼容读取包含旧冷却字段的 DSL 与存档，并在规范化后移除旧字段。

## 非目标

- 不把 Actor 与 Projectile 改造成通用 ECS 存储。
- 不让 Projectile 凭空获得生命或属性修正能力。
- 不改变动态价格公式、法力/tick 结算、同槽施法互斥或妖兽 AI 决策间隔。
- 不迁移神识强度或伤害类型。

## 验收标准

- [x] `生命` 可读取具备 Vitality 的统一实体；对 Projectile 或失效句柄返回 `0`。
- [x] `伤害` 和目标属性控制只修改具备对应能力的实体，成功返回 `true`，能力不符时返回 `false` 且目标不变。
- [x] 法术结束后无需等待冷却即可由一次新的按下再次施放；施法中的同槽重入仍被拒绝。
- [x] 核心模型、默认法术书、演武属性和 UI 不再暴露冷却。
- [x] 包含 `@cooldown` 和 `cooldownMul` 的旧存档可读取，规范化结果不再包含这些字段。
- [x] 聚焦测试与完整交付门禁通过；战斗输入路径覆盖松开后立即再次施放，演武主流程 E2E 通过。

## 验证计划

- 核心测试：能力匹配/缺失、成功/失败返回值、无部分修改、旧 DSL 规范化。
- 战斗测试：施法期间同槽互斥，结束后立即重施；妖兽攻击间隔保持有效。
- 存档测试：旧冷却注解和属性被兼容读取并清理。
- 实际体验：演武场连续按同一绑定键，确认完成后可再次起手且无冷却数值或冷却属性。
