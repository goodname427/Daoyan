# 功能规格

`docs/specs/` 保存跨模块或需要多轮反馈的功能规格。它描述本次要解决的问题和验收结果，不代替 ADR，也不记录每天的实施流水账。

## 生命周期

1. 从 [`template.md`](./template.md) 创建 `YYYY-MM-DD-简短主题.md`。
2. 状态依次为 `草案`、`已确认`、`实现中`、`已验收`、`已归档`。
3. 架构取舍链接到 ADR；完成后把当前状态同步到 [`../status.md`](../status.md)。
4. 需求变化直接更新规格中的验收标准，并在“变更记录”解释原因。

小型修复如果问题和验收方式显而易见，可以只记录在开发日志和测试中。
