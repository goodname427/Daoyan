# 手机版项目中枢预览

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-09-20

## 问题

制作人离开电脑后无法查看项目进度。现有项目中枢仅由本机 notice guard 提供，虽然具备窄屏布局，但没有可从手机访问的托管入口。

## 目标

- 复用现有项目中枢，提供手机优先的私有托管预览。
- 导出正式版本、流程节点、Agent、文档、待办和秘书对话的安全快照。
- 明确区分本机实时模式与云端快照模式，不把离线数据伪装成实时状态。
- 云端预览中的留言保存在当前设备并标记为待同步，为后续远程信箱保留体验入口。
- 保持 notice guard 空闲零模型消耗，不新增轮询项目的后台进程。

## 非目标

- 本轮不开放公网匿名访问。
- 本轮不允许云端页面直接控制本机 Agent 或修改正式版本状态。
- 本轮不实现跨设备消息同步和游戏移动版。
- 本轮不复制一套独立的中枢业务界面。

## 验收标准

- [x] 同一份中枢前端可在本机实时 API 和静态快照两种模式运行。
- [x] 手机宽度下无页面横向溢出，可在流程、详情和控制台间触控切换。
- [x] 快照站点展示同步时间，并明确说明数据不是实时连接。
- [x] 快照可切换正式版本、阅读对应节点和全部关联文档。
- [x] 快照中的 Agent 不包含本机 PID、绝对运行目录或原始运行日志。
- [x] 快照留言仅保存在当前设备并标记待同步，不误报秘书已收到。
- [x] 私有 Sites 部署可从手机浏览器打开。
- [x] 自动测试、完整门禁和实际手机视口体验通过。
