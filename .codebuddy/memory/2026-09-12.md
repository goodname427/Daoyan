# 2026-09-12

## 项目启动：道衍（Noita -like 修仙编程 roguelike）

### 用户确认的关键决策
- **技术栈**：TypeScript（AI 友好 + 可无头测试）；不用 Unity/Godot 等重型引擎；
  渲染 Canvas2D → 后期 PixiJS；节点编辑 React Flow；最终 Electron 打包 exe（后期可换 Tauri 减小体积）
- **输入方式**：可视化节点图为主，但先用类代码 DSL 验证原型
- **图灵完备性**：默认禁止递归（DAG 保证消耗可静态精确分析）；
  高阶「轮回术」解锁递归 + fuel + 走火入魔

### 资源模型（核心设计）
- 神识 = 持有状态的成本（内存/空间）
- 法力 = 与外界交互的成本（I/O）
- 耗时 = 执行步数（时间）
- 规则：神识内运算（加减/比较/距离/长度）几乎不要法力；
  读写世界的元函数收高额法力 → 自然涌现「批量 I/O vs 逐个 I/O」的优化权衡

### 架构决定
- **AST 是唯一真相且可 JSON 序列化** → DSL 与未来节点图产出同一份结构；AST 即秘籍分享码
- 静态分析在 AST 上做（不在字节码上），才能算准神识峰值与分支最坏情况

### 已完成（阶段一：无头核心）
- `src/core/`：types / ast / meta / builtins / analyzer / compiler / vm / world / dsl
- 受限 VM：DECL/FREE 管神识、CALLMETA 收法力、IDX 与元函数收耗时、fuel 兜底
- VM 内置 `trace`（为后续推演/单步调试模式预留）
- 8 个单元测试通过；`npm run dev` 沙盒验证三维度取舍成立

### 踩过的坑
- `for` 循环用 PEEK 复制栈顶元素会残留副本 → 加 `SWAP` 指令修正栈布局
- `for`/`repeat` 的退出跳转必须回填地址，否则默认跳到 0 号指令
- DSL tokenizer 需要把 `->` 作为整体 token（函数返回类型）
- 分析器的 `return` 语句必须分析其表达式，否则消耗漏算
